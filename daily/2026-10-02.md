## 📄 学术论文研究动态

- **Learning Chaos Without Seeing Chaos：自回归 Transformer 从局部观测外推全局动力学**：研究团队用从零训练的小型自回归 Transformer，在 logistic 与 sine 映射、Lorenz 系统、广义 Hopf 系统等非线性动力系统的受限参数区间轨迹上训练，控制参数与状态轨迹均表示为连续 token 序列。在训练分布之外的参数上做闭环评估时，模型能恢复出自相似的倍周期分岔级联、混沌动力学与吸引子结构。logistic 映射上，Transformer 复现了直到周期 128 的逐级倍周期分岔，得到的有限阶标度比为 4.6687，与 Feigenbaum 常数的误差在 5×10⁻⁴ 以内。作者进一步追踪这些结构在训练过程中的涌现方式，并通过因果干预揭示控制参数信息如何经注意力被处理进状态预测、进而塑造闭环动力学。结论是：对系统局部行为的一个异常狭窄的观测窗口，可能已足以让自回归 Transformer 外推出全局组织。
  - 重要性：★★★★★ / 5
  - 来源：[HuggingFace Papers](https://huggingface.co/papers/2609.38814)

- **How Much Is an AI Token Worth：野生 AI 生成网页文本的缩放律**：研究者在 FineWeb 质量过滤后统计，2026 年 6 月网页数据中 27.5% 的 token 被 Pangram 标记为 AI 生成，到 8 月升至 31.1%。这类野生 AI 文本与合成数据或模型坍缩设定不同：它来自众多模型、面向人类读者写作、且以未标注形式进入预训练语料。为量化影响，团队预训练了 800 个语言模型，改变 AI token 与人类 token 的配比，并对人类文本与 AI 文本上的留出损失拟合缩放律。结果显示：数据饥渴型模型加入 AI token 起初会降低人类文本损失，但收益随加入量饱和并迅速转为有害；而用高预算人类文本训练的模型，AI token 几乎立刻抬高损失，同等数量的新鲜人类文本却持续降低损失。Hoffman et al. (2022) 等缩放律无法预测这一行为，作者提出带独立收益项与损害项的新缩放律，允许 AI token 的价值变号，并在无 AI 文本时退化为 Chinchilla。新律在小模型上拟合后，能预测最多 3.6 倍大模型受 AI 文本影响的人类文本留出损失，误差比最佳现有律低 41%。
  - 重要性：★★★★★ / 5
  - 来源：[HuggingFace Papers](https://huggingface.co/papers/2609.40295)

- **MILO：通过编排式多智能体演化自动发现 agent harness**：现代 agentic 系统由 AI 模型与负责控制执行和环境交互的 harness 共同构成，harness 设计强烈影响长程表现，但其组合搜索空间需要大量人力，且随模型更替必须重做。现有自动化方法探索范围狭窄，只优化 prompt 或 skill 等单一组件，或陷入固定的利用式搜索策略。MILO（Meta-evolutionary Island Orchestration）让 agent harness 与发现它的搜索策略共同演化，包含三部分：基于岛屿树的分层谱系记忆，把被拒绝的变异当作负证据；每个岛屿的 mutator agent 利用全局搜索历史与父代特定反馈重写完整 harness；一个 orchestrator 通过谱系嫁接与物种形成、mutator 重新分配和课程修订来调整搜索。在 Terminal-Bench 2.1、PaperBench 和 DeepSWE 上，MILO 发现的 harness 在 frontier 模型 Opus 4.8 与开放权重模型 gpt-oss-120b 上均超过八个 SOTA harness 和六种搜索方法。以 Opus 4.8 计，MILO 相对初始 harness 分别提升 +12.0%、+28.3%、+10.3%，而此前最佳搜索增益仅为 +4.5%、+18.3%、0%。在 Terminal-Bench 2.1 上达到 86.1±2.0%，超过官方榜单首位（83.8±2.3%），且 token 用量少 26%。
  - 重要性：★★★★★ / 5
  - 来源：[HuggingFace Papers](https://huggingface.co/papers/2609.38349)

- **DAGent：面向深度研究智能体的 Evaluate-then-Grow 规划**：深度研究任务要求智能体在庞大知识空间中导航、跨多来源综合证据，并随发现动态调整计划。基于有向无环图（DAG）的多智能体系统适合这一场景，因为支持并行执行并把每个子任务隔离在聚焦的依赖上下文中。但现有 DAG 智能体在执行前就实例化任务级计划，只在观察到失败或证据缺失后才修补图，这种 Plan-then-Patch 策略在证据最弱时承诺最强，后续修订还会浪费算力在原本不该规划的分支上。DAGent 提出 Evaluate-then-Grow 增量规划：Orchestrator 一次扩展一批任务图，每次扩展都以已完成节点的置信度与不确定性信号为条件；分层上下文层默认传播紧凑的 QueryDocs，同时保留完整执行轨迹供按需召回。记录的 DAG 拓扑支持结果导向配方无法定义的结构化 RL 信号，DAGRPO 作为 GRPO 变体，在 Executor rollout 上注入拓扑条件信用，并对 Orchestrator 计划施加结构合规正则。在 BrowseComp-Plus、GAIA 和 xbench-DeepSearch 上，DAGent 在 Qwen3-235B-A22B 规模下分别超过最强开源基线 5.3、5.8、2.0 分。
  - 重要性：★★★★★ / 5
  - 来源：[HuggingFace Papers](https://huggingface.co/papers/2609.39154)

- **BIABench：评测 AI 智能体在真实生物图像分析任务上的表现**：AI 智能体有望自动化生物图像分析，但此前没有基准能端到端检验它们能否完成真实分析。这类任务对智能体很难，因为 2D 图像、3D 体数据和延时序列往往大到无法作为上下文读入，智能体必须通过代码、专用软件和渲染视图来选择并执行分析。已发表研究让这一能力变得可测，因为每项研究都把原始图像与同行评审结果配对。BIABench 包含 16 个从已发表生物学研究重建的任务，保留其科学问题、成像数据与真值，覆盖从 H&E 组织学到单分子定位显微镜等十一类分析子任务与模态。每个提交获得两项评分：结果分用领域标准指标比较输出文件与真值，过程分由视觉语言模型依据专家撰写的评分细则评判方法选择与质量控制。研究评测了通用与生物学专用智能体、多种语言模型，并对每个任务重复运行。常规二维任务完成良好，但在增加第三维或时间轴的任务上，没有任何智能体得分高于 0.19；生物学专门化、更强模型和详细专家指令都未能弥合这一差距。智能体还不可靠，同一智能体重复运行的得分波动很大。
  - 重要性：★★★★★ / 5
  - 来源：[HuggingFace Papers](https://huggingface.co/papers/2609.34274)

- **Prompted Identity Degrades Cooperation in Multi-Agent LLM Systems**：多智能体 LLM 系统越来越多地混合来自不同提供商的模型，但把每个智能体背后的模型身份暴露给同伴，会显著损害合作。研究显示，当智能体知道彼此的模型家族时，群体会分裂成簇，智能体偏好与携带相同标签的同伴交互，尽管任务中没有任何奖励或要求促成这种分裂。作者认为标签本身导致了这种分裂，并将其定义为派系主义（factionalism）。研究在两个合作博弈和一个推理基准上展示并度量了这一现象，参与智能体数量为 9 到 25 个，来自最多五个开放权重模型家族。进一步实验显示，当公布的家族被随机打乱或替换为任意标签时，派系仍然跟随这一信息；而当标签被移除时，该行为消失。在严格合作任务中，带标签的群体达成决定平均多花 30% 的轮次和 55% 的 token，成功率从 96% 降到 81%。该效应在任务、群体规模和模型家族上均可复现，向智能体隐瞒身份标签是简单有效的缓解手段。
  - 重要性：★★★★★ / 5
  - 来源：[HuggingFace Papers](https://huggingface.co/papers/2609.35928)

- **PixelUMM：无编码器的统一图像与视频理解及生成**：统一多模态模型（UMM）常对理解与生成使用分离的视觉表示，这增加了视觉上下文长度，也让与既有视觉语言预训练流程的整合变得复杂。近期像素空间建模提供了无编码器的替代方案，但把这一范式从图像扩展到视频并不简单：视频理解与生成采用不同的时间表示，统一视觉接口的设计仍是开放问题。PixelUMM 是一个直接在像素空间做统一图像与视频理解及生成的无编码器模型，把图像表示为空间 patch、视频表示为时空 tubelet，通过单层线性投影把原始像素接入共享多模态主干。其 Mixture-of-Transformers 架构结合共享注意力与任务特定参数，并把干净像素预测扩展到视频生成，同时支持自回归文本预测与像素空间 flow matching。实验显示 PixelUMM 在图像与视频的理解和生成任务上取得有竞争力的表现。作者还对解码器设计、时空 patch 尺寸等关键设计选择做了实证研究，为未来像素空间统一多模态模型提供参考。
