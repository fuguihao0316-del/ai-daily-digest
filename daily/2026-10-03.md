## 📄 学术论文研究动态

- **Ego2Act：首个面向自我中心视频生成的目标导向操作基准**：HuggingFace Papers 发布 Ego2Act，包含来自 110 个真实世界任务的 2,640 段视频，覆盖日常场景、不同物体杂乱度与多步复杂度。任务设定为给定初始场景图像与高层目标，评估视频生成模型能否生成手部操作物体的真实自我中心视频。团队同时提出无参考评估流程 Ego2ActJudge，在任务完成度与物理合理性两项上与人类共识的对齐度优于相关基线。实验发现模型生成的模拟常跳过或只部分执行步骤，导致后续步骤缺失依赖状态，最终目标无法完成；模型在细粒度物理一致性上也持续失败。对世界模型与具身规划研究者而言，该基准把评估从单一短动作推进到多步物理推理，暴露了当前视频世界模型作为执行模拟器的关键短板。
  - 重要性：★★★★★ / 5
  - 来源：[HuggingFace Papers](https://huggingface.co/papers/2610.01092)

- **MemFold：用在线策略优化学习紧凑软记忆，实现长上下文个性化**：长期服务同一用户的助手必须区分哪些偏好仍有效、哪些已被修改、哪些约束当下适用，但保留信息与据此行动常被当作同一目标优化。MemFold 将查询条件下的文本记忆压缩为 K 个连续向量，构成读者的记忆接口，再用两类信号在读者自身 rollout 上训练：任务结果的分组相对奖励，以及置信度门控的在线策略蒸馏，后者由冻结的文本记忆教师对学生的采样 token 重新打分。教师从不被采样，监督始终停留在学生当前分布上，推理阶段完全移除。在三个 Qwen 骨干上，MemFold 在 PersonaMem-32K 与 PersonaMem-128K 上取得所测最高准确率，且历史越长优势越大，并可零目标域训练迁移到 PrefEval 与 LongMemEval。
  - 重要性：★★★★★ / 5
  - 来源：[HuggingFace Papers](https://huggingface.co/papers/2609.36435)

- **Video Generation Models：首篇视频生成后训练与对齐综述**：视频生成已从短时长低质量片段发展到高分辨率长时序复杂时空动态，但预训练模型仍难以可靠遵循人类意图、维持时序连贯或满足物理与安全约束。与图像和文本生成相比，视频对齐面临误差随时间累积、运动与外观耦合、多目标权衡、时序属性监督稀缺等独特挑战。该综述是首篇系统梳理视频生成后训练与对齐的综述，将后训练视为统一框架，按对齐信号施加方式区分隐式与显式对齐，并把现有方法归为四类：监督微调、自训练与蒸馏、偏好与奖励方法、推理时方法。文章还整理了常用数据集、基准与评估实践，并讨论开放挑战，为从事视频生成对齐的开发者提供了统一坐标系。
  - 重要性：★★★★★ / 5
  - 来源：[HuggingFace Papers](https://huggingface.co/papers/2610.00812)

- **Persona Dosing：校准激活引导，实现分级人格特质控制**：激活引导系数决定干预强度，但要请求特定程度的人格表达需要一把行为标尺。作者研究 persona dosing，即通过特质描述加请求的平均强度来控制语言模型。PersonaDose 先在人格响应上特化一个共享的描述条件 FLAS 控制器，再将其流时间针对测得的特质表达进行校准，训练响应并不与请求的目标强度配对。在 Llama-3.1-8B、Qwen3-8B 和 Gemma-3-4B 上，PersonaDose 在 Persona Vectors 的 75 连贯性下限处，将核心特质表达较对比激活加法分别提升 33.2、18.3 和 17.8 个点。校准选出的设置在有保留问题上仍保持表达优势，但连贯性下限并非对每个特质都成立。七个已训练特质上，校准请求的平均目标误差为 4.7 至 6.2 个点。
  - 重要性：★★★★★ / 5
  - 来源：[HuggingFace Papers](https://huggingface.co/papers/2609.36388)

- **Transformers 过早停止思考，一个微型 LoRA 即可修复**：预训练 Transformer 在上下文中跟随引用时只用了很少的深度。13 个基础模型只能可靠跟随 1.4 至 3.6 行，额外加预训练循环也提升有限。作者在某一早期层训练 rank-8 LoRA，冻结全部模型权重，Qwen3-8B 在 24 行链条上的精确准确率从 15.5% 提升到 99%，更长训练的 LoRA 可达 50 行；Ouro-1.4B 在四个循环后达 60 行，八个循环后至少 160 行。机制上 LoRA 启动了一次接力：程序行通过一段中间层传递链条身份，冻结的输出头逐步读取链条更远处，移除父行注意力会中断接力。在四个留出模型中的三个里，冻结模型测量能定位最后一个有效干预层。任务专用 LoRA 在 MuSiQue 上也有提升，说明默认答案低估了微小编辑可解锁的计算量。
  - 重要性：★★★★★ / 5
  - 来源：[HuggingFace Papers](https://huggingface.co/papers/2609.36585)

- **Honeycomb：面向视频世界模型的恒定大小场景记忆表示**：视频世界模型需要持久场景记忆以在长时程生成中保持一致，但现有空间记忆会累积 RGB 观测或潜特征，存储随生成推进而增长。作者提出 Honeycomb，基于低秩表示 HexMemory，用总计六个空间与时空平面在固定大小记忆中存储场景特征。前馈写入器把每个新生成块映射为新平面特征；空间覆盖或时间范围扩大时，对旧平面做形变并保持维度，再通过置信度加权池化与学习到的残差校正与新特征融合。读取器从 HexMemory 取潜变量以条件化后续生成。写入器只处理新块观测，避免逐场景优化与重复处理全历史。在 WorldScore 与 RealEstate10K 上，该方法在保持记忆存储恒定的同时取得强生成质量与稳健重访一致性。
  - 重要性：★★★★★ / 5
  - 来源：[HuggingFace Papers](https://huggingface.co/papers/2609.37690)

- **X-Tree：将可复用经验 token 化，提升智能体泛化效率**：多步智能体通常在扁平动作流上训练，SFT 与 RLVR 对每个 token 一视同仁，忽略了跨任务复现的子过程，也就是人类自上而下规划所依赖的可复用例程层级。已有智能体虽使用该结构，但仅作为上下文中的 LLM 编写技能，从未进入权重，收益无法超出检索范围。X-Tree 从数据本身恢复层级并据此训练，全程无需 LLM 调用：仿照文本分词器仅靠计数构建词表，按可复用性对动作片段打分，并把规范化动作合并为可复用经验树，每个节点刻画一个高频且带成功信号的技能如何由子技能组成。X-Tree 被整合进三种训练设置：离线 RL 中每个节点作为训练实例，在线 RLVR 中作为自适应技能奖励，在线策略自蒸馏中作为自教师的特权上下文。在 WebArena、ScienceWorld、WebShop 三个尺度上，同等数据与预算下分别最高提升 4.5%、5.8% 成功率与 4.1% 成功率。
  - 重要性：★★★★★ / 5
  - 来源：[HuggingFace Papers](https://huggingface.co/papers/2609.32993)

- **OpenTumorBoard：多学科肿瘤委员会讨论轨迹的真实世界基准**：多学科肿瘤委员会通过专家讨论整合多模态临床观察与纵向病史，但现有基准很少捕捉这类真实轨迹。OpenTumorBoard 包含 611 个患者病例与 19,157 个讨论轮次，覆盖十种专家角色，转录自 YouTube 上公开的 12,534 分钟肿瘤委员会录像。基准评估两种设定：SPECIALIST TURN 要求 LLM 回答真实讨论中提出的临床重要问题，BOARD SIMULATION 要求其生成完整往复讨论，并就治疗建议、手术方案、下一步行动与临床试验匹配达成共识。对 14 个通用前沿与医学 LLM 的评估显示明显局限：最佳模型在与专家回答的临床等价性上仅得 3.43 分（满分 5），与记录结论的一致性仅 2.78 分。监督微调与强化学习在留出测试集上有改善，三位医学博士专家审查确认病例信息覆盖度高、事实性强，提取的共识结论保真度强。
