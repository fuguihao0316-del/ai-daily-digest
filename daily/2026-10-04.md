## 📄 学术论文研究动态

- **Jev 决策模型替代 LLM 用于低延迟边缘服务编排**：研究将 Jev 面向决策的 API 集成进边缘服务编排，从自然语言请求中抽取 4 至 8 个有界意图字段，配合共享校验器、准入策略与调度器。在 8,280 条已验证请求、33 种测试条件下，Jev 相比最快的托管 LLM 将决策延迟中位数降低 22.7% 至 64.5%，且该延迟几乎不随输入规模、契约宽度或目录规模变化。四字段契约上，Jev 每次正确决策的 API 费用低 59.7% 至 80.9%，代价是少量精确匹配点下降。在实时准入路径上，Jev 在 LLM 低于 0.1 的负载下仍保持 0.91 至 0.95 的请求精确且准时。结论支持在延迟受限场景用决策模型替代 LLM。
  - 重要性：★★★★★ / 5
  - 来源：[HuggingFace Papers](https://huggingface.co/papers/2609.22753)

- **Ego2Act：以第一人称视频生成评估目标导向操作**：现有视频生成基准多聚焦单一短动作或分步指令，忽视多步物理推理。Ego2Act 构建了目标导向基准，包含来自 110 个真实世界任务的 2,640 段视频，覆盖日常场景、不同物体杂乱度与多步复杂度。给定初始场景图像与高层目标，基准评估模型能否生成手部操作物体的真实第一人称视频。团队同时提出无参考评估流程 Ego2ActJudge，在任务完成度与物理合理性上比相关基线更贴合人类共识。结果显示模型生成的模拟常跳过或部分执行步骤，导致后续步骤缺失依赖状态、目标无法完成，且在细粒度物理上持续失败。
  - 重要性：★★★★★ / 5
  - 来源：[HuggingFace Papers](https://huggingface.co/papers/2610.01092)

- **MemFold：用同策略优化学习长上下文个性化的紧凑软记忆**：长期服务同一用户的助手必须区分哪些偏好仍成立、哪些已修改。把信息存为文本会让输入随历史增长，压缩成固定数量隐向量虽能限制接口，但通常以重建文本或模仿参考答案为目标，评分序列并非读者产生。MemFold 按记忆所支持的行为来优化固定预算软记忆：将查询条件化的文本记忆压缩为 K 个连续向量构成读者记忆接口，再用两组信号在自身 rollout 上训练读者，即任务结果的分组相对奖励，以及冻结文本记忆教师对学生采样 token 重新打分的置信门控同策略蒸馏。教师从不被采样，推理时完全移除。在三种 Qwen 骨干上，MemFold 在 PersonaMem-32K 与 PersonaMem-128K 取得最高准确率，历史越长优势越大，并零样本迁移到 PrefEval 与 LongMemEval。
  - 重要性：★★★★★ / 5
  - 来源：[HuggingFace Papers](https://huggingface.co/papers/2609.36435)

- **视频生成模型后训练与对齐综述**：视频生成已从短时长低质量片段发展到高分辨率长时长序列，但预训练模型常难以可靠遵循人类意图、保持时间连贯性或满足物理与安全约束。相比图像和文本生成，视频对齐面临误差随时间累积、运动与外观耦合、多目标权衡、时间属性监督稀缺等独特挑战。该综述称是首篇系统梳理视频生成后训练与对齐的综述，将后训练作为统一框架，按对齐信号施加方式区分隐式与显式对齐，并把现有方法归为四类：监督微调、自训练与蒸馏、偏好与奖励方法、推理时方法。文章还梳理常用数据集、基准与评估实践，并讨论开放挑战。
  - 重要性：★★★★★ / 5
  - 来源：[HuggingFace Papers](https://huggingface.co/papers/2610.00812)

- **Persona Dosing：校准激活引导实现分级人格特质控制**：激活引导系数决定干预强度，但请求特定程度的人格表达需要行为量表。研究提出 persona dosing，即通过特质描述与请求的平均强度控制语言模型。PersonaDose 在人格响应上特化共享的描述条件化 FLAS 控制器，再依据实测特质表达校准其流时间，训练响应不与请求目标强度配对。在 Llama-3.1-8B、Qwen3-8B、Gemma-3-4B 上，PersonaDose 在 Persona Vectors 的 75 连贯性下限处，将核心特质表达分别比对比激活加法提高 33.2、18.3 和 17.8 分。校准选出的设置在留出问题上仍保持表达优势，但该连贯性下限并非对每个特质都成立。七个已训练特质上，校准请求在每模型 28 个目标中 14 至 22 个可达目标上平均误差 4.7 至 6.2 分。
  - 重要性：★★★★★ / 5
  - 来源：[HuggingFace Papers](https://huggingface.co/papers/2609.36388)

- **Transformer 过早停止思考，一个微小 LoRA 即可修复**：预训练 Transformer 在上下文中跟随引用的深度利用率很低，13 个基础模型只能可靠跟随 1.4 至 3.6 行，额外预训练循环也收效甚微。研究在某一早期层训练 rank-8 LoRA，冻结全部模型权重，Qwen3-8B 在 24 行链上的精确准确率从 15.5% 提升到 99%，训练更久的 LoRA 可达 50 行；Ouro-1.4B 四轮循环后达 60 行，八轮后至少 160 行。该 LoRA 启动一个中继机制：程序行通过中间层的一个短区间传递链身份，冻结的 head 逐步读取更靠上的链条，移除父行注意力会中断中继。冻结模型测量能在四分之三的留出模型中定位最后一个有效干预层。任务特定 LoRA 也提升 MuSiQue，说明默认答案低估了微小编辑可解锁的计算。
  - 重要性：★★★★★ / 5
  - 来源：[HuggingFace Papers](https://huggingface.co/papers/2609.36585)

- **Honeycomb：视频世界模型的恒定大小场景记忆表示**：视频世界模型需要持久场景记忆以维持长时程生成的一致性，而现有空间记忆会累积 RGB 观测或隐特征，存储随生成推进增长。Honeycomb 基于提出的低秩表示 HexMemory，用共六个空间与时空平面以固定大小存储场景特征。前馈写入器把每个新生成块映射为新平面特征；当空间覆盖或时间范围扩展时，对旧平面做形变并保留维度，再通过置信加权池化与学习到的残差校正与新特征融合。读取器从 HexMemory 取隐变量以条件化后续生成。写入器只处理新块的观测，避免逐场景优化与重复处理全历史。在 WorldScore 与 RealEstate10K 上，方法在保持 HexMemory 特征存储恒定的同时取得强生成质量与稳健重访一致性。
