- **Anthropic 重构 Cowork：VM 与推理全部搬到云端**：Anthropic 的 Felix Rieseberg 解释了 Cowork 的架构变更。旧版 Cowork 在云端做模型推理，但把工具调用放在一个 Anthropic 提供、下发到用户电脑上的 VM 里执行，加入 VM 是为了能力、安全和安保，只映射用户显式加入会话的数据；用户认可 Claude 能做的事，但不喜欢本地跑 VM 带来的磁盘、电池和性能开销，也不喜欢合上笔记本工作就停止。新版 Cowork 把模型推理和 VM 都放到云端，每个会话拥有自己的沙箱，不与其他会话共享状态；当 VM 需要用户设备上的东西（例如某个文件）时，由桌面应用负责那次文件访问的工具调用。官方认为这解决了手机端使用 Cowork、保持工作持续运行、以及不牺牲电池拿到同等能力等问题。对 Agent 产品设计者来说，这是一次明确的取舍示范：把执行环境从端侧移到云端沙箱，换取持久性与跨设备可用性。
  - 重要性：★★★★★ / 5
  - 来源：[Simon Willison](https://simonwillison.net/2026/Oct/5/felix-rieseberg/)

- **Google 提出 RRSI：阻止自我改进 Agent 背题**：自我改进的 AI agent 倾向于记住测试任务，导致其在全新任务上的收益缩水甚至消失。Google 研究者提出的 RRSI 方法抑制了这一效应，在未见过的基准上把分数最高提升 4.7 分，同时比未加正则化的版本少用约 30% 的 token。这一结果同时命中两个痛点：一是自进化循环中的评测污染，二是推理成本。对做 agent 自训练或 self-play 流水线的团队来说，RRSI 提示了一个更根本的问题——当模型自己生成训练任务并自己评分时，如何区分真实能力提升与对测试分布的过拟合。少用三成 token 也说明正则化并未以算力为代价换取泛化。

## 📄 学术论文研究动态

- **PointWAM：面向灵巧操作的 3D 世界动作建模**：现有世界动作模型多以 RGB 帧或隐空间表示世界、以末端位姿或关节角预测动作，难以刻画灵巧操作所依赖的 3D 空间结构与接触几何。PointWAM 将世界解耦为场景（环境）与手（动作主体），在统一的时空坐标系内联合预测二者的 3D 点轨迹，从而可在无任务特定物体或关键点标注的大规模人类演示视频上预训练。给定彩色点云与语言指令，模型预测场景与手在 3D 空间中随时间的共同演化，再将预测的手部运动重定向为机器人动作。在人类视频上预训练使 DexJoCo 平均成功率提升 56.9 个百分点，加入场景轨迹监督后比仅预测手部再提升 10.9 个百分点；两者结合后，在十项 DexJoCo 任务上超越此前 SOTA 11.7 个百分点，并在真实机器人上优于强 VLA 模型。该工作表明显式 3D 点轨迹表示是释放人类视频预训练价值的关键。
  - 重要性：★★★★★ / 5
  - 来源：[HuggingFace Papers](https://huggingface.co/papers/2610.02840)

- **CUAWright：面向数字代理的最小统一接口**：当前计算机使用代理普遍将模型与领域专用外壳耦合，浏览器或桌面环境中的工具在任务执行前即被固定，GUI 原生且静态的外壳阻碍模型直接以程序化方式操作系统状态并灵活构造工具。CUAWright 提出约 3K 行代码的最小终端外壳，以 bash 命令作为唯一动作接口，用文件系统作为可演化的空间来动态创建工具与管理上下文。在 OSWorld 2.0 上，相较已发表的 GPT-5.5 基线，部分奖励相对提升 33.2%，估计成本降低 37.5%；在 Online-Mind2Web 与长程 Odysseys 基准上，成功率分别比 GUI 原生外壳高 4.7% 和 44.0%。在需要精确视觉理解与 CLI 交互的 CAD 场景中，CADGenBench 与 BenchCAD 上相对其他 CLI 外壳取得 8.1%–41.6% 的提升，说明极简可编程接口对代理能力有系统性增益。
  - 重要性：★★★★★ / 5
  - 来源：[HuggingFace Papers](https://huggingface.co/papers/2610.04116)

- **JEPA-TTT：潜在世界模型的持续测试时训练**：世界模型通过预测未来状态支持规划，但当测试时动力学与训练分布不同时预测会失效。JEPA-TTT 在测试全程持续适配预训练动作条件 JEPA 世界模型中的潜在动力学预测器，自监督更新跨回合累积，而视觉编码器与奖励头保持冻结，以保留预训练表示与任务目标；规划既不需要目标图像也不需要在线环境奖励。方法采用密集回放，在每个时间偏移处构造预测窗口并存入持续增长的缓冲区，再从缓冲区采样小批量更新预测器。在四个连续控制环境的八种动力学偏移下，JEPA-TTT 在所有偏移上均改善规划；经过 500 个测试回合后，自回归潜在预测误差平均降低 83%，规划性能相比冻结的 JEPA 世界模型提升 153%。这证明持续自监督测试时训练可让预训练潜在世界模型适应动力学变化。
  - 重要性：★★★★★ / 5
  - 来源：[HuggingFace Papers](https://huggingface.co/papers/2610.00722)

- **WM-VLM：用内部世界模型做交错视觉-文本推理**：人类常通过心理模拟视觉变换来解空间问题，而传统 VLM 主要用语言推理。WM-VLM 为预训练 VLM 配备轻量世界模型分支以生成中间视觉状态，采用两阶段训练：先教模型生成下一视觉状态，再教其利用该状态进行推理。研究者以程序化方式构造带可验证中间视觉状态的空间推理任务，从而既能评估视觉状态生成质量，也能衡量模型对生成状态的依赖程度。在 2D 与 3D 心理旋转任务上，WM-VLM 稳定优于监督微调的骨干模型，增益最高达 39.25 个百分点；消融显示这些增益依赖生成的视觉状态，移除或破坏它们会显著降低性能。该结果提示内部世界模型是让 VLM 同时在语言与视觉空间中推理的可行路径。
  - 重要性：★★★★★ / 5
  - 来源：[HuggingFace Papers](https://huggingface.co/papers/2609.34826)

- **The Extender：一种日志结构化的 Transformer 变体**：标准 Transformer 中各层仅通过残差流 h 这一叠加通道与后续层通信。The Extender 额外引入拼接通道 x：每层同时输出加到 h 上的残差更新 δ 与追加到 x 上的更小的扩展 ε；FFN 与 query 仍读取 h，而注意力的 key/value 投影只以 x 为输入。由此完全扩展后的 x 包含所有层 kv 投影的完整输入，持久注意力内存占用从 2Ld_model 降至各层扩展维度之和。实验显示，当每层扩展维度为 32 时，Extender 在 199M–924M 参数上于短上下文 CORE 任务上与 Transformer 精度持平，并在 924M 参数的长上下文 RULER 负载上超过 Transformer；对 1664 宽、924M 的模型，其持久注意力内存占用比 MHA 小 104 倍，且节省随模型宽度增长。这为长上下文推理的内存瓶颈提供了架构级解法。
  - 重要性：★★★★★ / 5
  - 来源：[HuggingFace Papers](https://huggingface.co/papers/2609.32759)

- **4DCodeBench：用代码生成评测动态场景逆向图形**：该基准要求代理从视频中重建动态场景，并以可执行的图形程序形式输出，代理须把视觉观测转化为场景结构与动力学的紧凑表示，实现物理模拟等抽象以复现复杂行为。研究团队整理了真实世界视频，并构造覆盖形变、流体流动、断裂等多种物理现象的合成场景，对前沿模型进行了广泛评测，发现强大的静态重建能力尚不能转化为对复杂动力学的可靠重建。4DCodeBench 为追踪代理通过代码理解世界动力学的进展提供了测试平台，代码与基准已在 GitHub 公开。对从事视频理解、物理仿真与代码代理交叉方向的研究者而言，这是一个明确的能力缺口信号。
