## 📄 学术论文研究动态

- **WebFovea：当模型判断正确但点击落空，为实时网站上的视觉 Web Agent 构建可靠往返**：该工作在 WebRetriever Challenge 2026 的 Protocol III 上以 57.0/100 分获得第二名。作者指出，多模态大模型只是必要条件而非充分条件：模型决策要经过 harness 才能到达浏览器，每一步有四件事必须同时正确——回复被解析为预期动作、动作在页面上生效、结果被准确回报、模型看到所需信息。在真实网站上，许多失败发生在上述四个环节而非模型推理本身：坐标空间错配导致每次点击落在预期坐标的 3/4 处；原生下拉框、iframe 内和文本框中的动作静默失败；自生成的 chat-template token 污染了 4.9% 的任务回合。WebFovea 对每个环节做了加固，并在循环外围加了护栏以约束规则与预算。由于四次提交使用同一模型，官方隐藏集分数从 31.0 提升到 57.0，说明增益主要来自 harness 而非模型能力。
  - 重要性：★★★★★ / 5
  - 来源：[HuggingFace Papers](https://huggingface.co/papers/2610.03036)

- **RLHND：把视频基础模型当作物理接地的手部追踪器用于机器人学习**：现有手部追踪器多从裁剪帧回归姿态，对手部运动和手物交互的先验有限，估计结果不准确且物理上不一致；同时缺少接触与力等物理线索，限制了人类视频在机器人策略训练中的使用。RLHND 基于视频基础模型，从单目第一视角视频中联合估计手部姿态与真实感触觉信息。方法上，它通过 clean-latent conditioning 把预训练的 Cosmos 3 视频扩散骨干转成确定性的片段级特征提取器，把学到的手部运动与手物交互先验带入追踪；姿态估计方面预测解剖学上合理的关节角，并可选地以形状参数为条件，使同一视频乃至同一演员录制的不同视频中手形保持一致；触觉估计方面用独立专家流在冻结姿态流的前提下预测手表面的稠密接触与力。作者还采用基于 LBS 的特征扩散，实现逐顶点特征提取而无需昂贵的逐顶点注意力。RLHND 在多个姿态估计基准上达到 SOTA。
  - 重要性：★★★★★ / 5
  - 来源：[HuggingFace Papers](https://huggingface.co/papers/2610.09455)

- **We Query, Therefore We Compute：论机器之外的 Oracle 计算及其在 Agent 上的应用**：现有 Agent 系统常零散借用操作系统的调度、缓存、隔离等抽象，机制之间缺少共同基础，Workflow 与 Agent 两种形态也缺乏统一视角。作者构造了一台抽象机器同时提供两者：把 LLM 视为 Oracle，在双栈下推自动机上增加一条指令，将整个栈作为查询交给 Oracle，并把答案追加回同一栈。该机器因此执行两种计算——Oracle 的计算，以及作者称为 Priestess 的图灵完备计算。只追加的栈像 Agent 上下文一样自回归增长。存储上的对称性破缺 S 与转移上的对称性破缺 T，使 Priestess 程序成为 Oracle 所运行程序的操作系统，并让 Agent 与 Workflow 成为同一任务程序的两种放置方式。对内部自回归的 Oracle，两种计算在满足一定条件时于每次答案结束时同步，作者借此建模缓存并分析调度。作者还提出 V 构造把该机器适配到冯·诺依曼计算机，并提出扩展 RISC-V ISA 的 ArchNights 以证明可实现性。
  - 重要性：★★★★★ / 5
  - 来源：[HuggingFace Papers](https://huggingface.co/papers/2610.09243)

- **TimeBraid：统一时间序列与语言的理解与预测模型**：TimeBraid 通过交错的全局残差注意力层，对齐预训练语言模型与预训练时间序列基础模型。每个模型从语言侧继承知识、指令跟随与推理能力，从时间序列侧继承连续信号感知与零样本预测能力，并在共享表示空间中融合两种模态，实现理解与生成。论文系统研究了让这种统一建模奏效的设计选择：在何处对齐两个表示空间、如何把语言接地到时间结构、如何平衡理解与生成、如何保持联合优化稳定。最终配方结合了面向多样时间序列与文本任务的统一提示方案、稳定的联合训练，以及来自 220 万条精选序列-文本对和 490 万条指令微调样本的监督。在覆盖时间序列感知、理解、推理以及上下文辅助与单模态预测的基准上，TimeBraid 与规模大得多的通用模型和任务专用模型相比仍具竞争力。
  - 重要性：★★★★★ / 5
  - 来源：[HuggingFace Papers](https://huggingface.co/papers/2609.29792)

- **Structuring MoE Expert Selection for Agentic Reinforcement Learning：用 Agent 轨迹结构优化 MoE 专家路由**：长程 LLM Agent 常用稀疏 MoE 模型实现，但 Agent 行为与 MoE 结构的协同设计仍未被充分探索。作者发现，在现成 MoE 模型中专家选择呈现出与 Agent 轨迹自然对齐的专门化结构：当 Agent 执行语义相似操作（如 READ、UPDATE）的回合之间，专家路由的重叠度高于操作不同的回合之间。然而标准 RL 算法忽略这种专门化，训练中 MoE 路由不受控制，经验上限制了任务性能与推理效率。为此作者提出面向 Agent 任务的分层路由控制框架：显式鼓励回合级专家选择与 Agent 操作对齐，同时正则化 token 级专家选择以维持局部一致性。针对后训练中出现的稳定性问题，进一步引入熵门控控制机制。该框架在所有评测基准上取得超过 10 个百分点的成功率提升，表明 Agent 轨迹结构是 RL 后训练中优化 MoE 容量的有效信号。
