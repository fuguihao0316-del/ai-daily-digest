## 📄 学术论文研究动态

- **扩散与自回归统一为「转移律格」：解码步数由数据几何决定**：论文把 diffusion、autoregression 及两者之间的混合模型统一描述为 corruption lattice 上的路径，并把某个解码 schedule 的代价定义为并行步骤所丢弃的依赖关系。核心结论是零代价 schedule 的最少步数由数据几何决定，对 token 和连续场同样成立：若数据在图上满足 Markov 性且沿路径相关，最少步数等于图的 treedepth，该量对序列长度呈对数、对网格边长呈线性。步数少于 treedepth 时任何 schedule 都要付出正代价，且其排序可在解码前用从预训练权重估计的成对依赖核预测。作者在文本、图像、视频生成上验证了大部分排序预测，为未来 AR、diffusion 及混合模型提供了统一解码设计原则。
  - 重要性：★★★★★ / 5
  - 来源：[HuggingFace Papers](https://huggingface.co/papers/2610.11216)

- **Opera：为长程编码智能体引入「语言批评家」，并追踪反馈是否真正解决问题**：现有 critic 多关注评估轨迹与生成反馈，很少跟踪反馈之后的执行结果，导致误判或未触及根因的反馈反而有害。Opera 把每条纠正当作持续存在的 note，通过周期性触发与事件驱动触发决定何时复审，用带类型的 operator 诊断问题，在交付前用可见证据审计反馈，并追踪智能体后续动作以区分「表面服从」与「真正解决」。作为 test-time critic，它在 Terminal-Bench 2.1、SWE-Bench Pro 子集与 DeepSWE v1.1 上把非 critic 智能体的 resolve rate 分别提升最多 12.4、15.0、8.9 个百分点，覆盖四个策略模型，并在三个基准上取得竞争性 critic 基线中的最高平均 resolve rate。用其 rollout 微调 Qwen3.5-9B，在留出 SWE-Bench Pro 仓库上提升 10.2 个百分点且推理时无需 critic。
  - 重要性：★★★★★ / 5
  - 来源：[HuggingFace Papers](https://huggingface.co/papers/2609.33987)

- **Station：开放式科学发现中智能体重现已发表 ICLR 论文 62.7% 的结论**：以往 AI for science 的进展多发生在指标明确的任务上，能否自主开展开放式科学发现仍不清楚。作者在 Station 这一多智能体模拟科学生态的开放世界环境中，加入 Supervisor 机制与周期性 Meta Reflection，以在缺乏中间指标时维持持续探索。任务取自三篇近期 ICLR oral 论文，只给出研究问题，隐藏论文结果并禁用网络访问，再把原始发现拆成独立判据衡量重现比例。结果显示 Station 平均重现 62.7% 的判据，而 Codex Multiagent-v2 为 15.4%，AI Scientist-v2 为 14.4-20.6%；消融与行为分析表明两个机制叠加提升研究覆盖度与连续性。在两个没有 oracle 论文的开放式任务上，智能体的部分发现与知识截止后研究者报告的发现高度接近。
  - 重要性：★★★★★ / 5
  - 来源：[HuggingFace Papers](https://huggingface.co/papers/2610.08927)

- **Skill Constellations：首个 agent skill 复制网络，揭示 GitHub 上的技能供应链风险**：Agent skill 是 Claude Code、Codex 等编码智能体以用户权限执行的 SKILL.md 指令与脚本，开发者通过仓库间复制来分享，使其成为没有 registry、版本与溯源信息的软件供应链，被复制技能的来源、安全修复的覆盖范围都无从得知。作者基于 GitSkills 中每个 SKILL.md 的 git 历史，构建了首个带日期的 agent skill 复制网络，覆盖 GitHub 上 2,193,119 次技能采用，并配套交互式查看器。分析发现少数仓库是几乎所有复制的源头，且 GitHub stars 无法识别它们；技能复制后几乎从不随源头更新，源头的修复很少传播。作者拟合复制来源模型用于审计排序，检查排名最高的 100 个仓库可阻止 14.9% 的后续高风险技能采用，而 100 个最高星仓库仅为 0.5%。

  - 来源：[HuggingFace Papers](https://huggingface.co/papers/2610.11169)

- **MiMo-V2.6：沿三个维度扩展 RL 算力，开源训练动态与环境**：该报告提出 omni-modal 的 MiMo-V2.6 系列，通过扩展 RL 算力推进模型智能。RL 之前先在广泛多模态语料上做 mid-training 以提供探索空间，并在预训练 hybrid-SWA 架构上搭建支撑后续扩展的基础设施。RL 算力沿三个方向扩展：更大 batch 与更高吞吐，异步训练每步消耗 1,568 个样本与 2.7-3.7B tokens，上下文长度最高 1M；更复杂多样的环境，覆盖 code、general、visual、cyber 领域并混合多种 agent harness；更多 grader 算力，通过 groupwise agentic grading 为长程任务提供更准确奖励信号，并引导模型给出更短、更省 token 的解。为在大规模下保持稳定，作者冻结 MoE router 并建立多层防御对抗 reward hacking，同时开源训练动态、RL 环境与 RL 框架。
