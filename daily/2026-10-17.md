## 📄 学术论文研究动态

- **SAE 特征可加性存在边界：行为组合性需二阶交互项**：论文提出 SAE Additivity Residuals（SAR），量化在选定交互阶数之上仍无法被解释的行为变异。在独立特征子集采样下，群体 SAR 恰好等于该阶以上交互的归一化能量，并给出最优低阶近似的联盟排序误差上界。为区分「SAE 表征本身的组合性」与「下游计算诱导的组合性」，作者将学习到的 SAE 坐标与同一子空间的保和随机旋转对比，在全部 18 个模型与行为设置中，学习坐标的一阶残差都更低。但坐标并非完全可加：成对项在全部设置中都能提升留出联盟排序，并优于使用随机三阶项的参数量匹配模型。联合 steering 实验中，成对建模把 rank fidelity 从 0.5874 提升到 0.7790，排序误差从 0.1444 降到 0.0606。结论是 SAE 坐标支持相对可组合的行为描述，但忠实的联合解释与干预仍需超越单个特征效应。
  - 重要性：★★★★★ / 5
  - 来源：[HuggingFace Papers](https://huggingface.co/papers/2610.21261)

- **SAE 训练数据存在收益递减：功能行为不保证特征可复现**：论文系统测试 SAE 是否真需要数亿到数十亿 activation token。作者用四种 SAE 架构、三个语言模型，预算从 5M token 到 500M token 参考规模。结果发现功能数据需求高度依赖指标：重建质量往往在远小预算下就逼近全量参考，而特征可复现性则持续随数据增长。以 Gemma-2-2B BatchTopK 为例，严格匹配特征比例从 5M token 时的 2% 升到 50M 时的 29%。数据选择同样关键：随机采样更好保留原始激活分布、通常利于重建，而多样性采样常改善 AutoInterp。理论分析把子采样训练的统计一致性与一对一特征恢复所需的更强可辨识性、优化条件区分开。作者认为，只要把预算与目标匹配，SAE 训练可以大幅提升数据效率，特征级结论应附带显式可复现性检查。
  - 重要性：★★★★★ / 5
  - 来源：[HuggingFace Papers](https://huggingface.co/papers/2610.20680)

- **LEASH：面向计算机使用智能体的不确定性感知弱到强升级与监督**：计算机使用智能体处理长时程任务时，每步都调用前沿模型成本高昂，而小开源模型单独运行又常失败。弱到强升级提供折中方案：默认由弱智能体行动，仅在需要时移交强智能体，核心难点是判断何时升级，需要每步都可廉价检查的不确定性信号。但即便移交后，强智能体仍可能迷失，而通常以黑盒 API 形式提供的强模型不暴露任何内部状态可供监控。为此作者提出 LEASH，一个免训练框架：仅当弱智能体的隐层不确定性表明需要时才释放强智能体，之后对其「拴绳」。LEASH 分三层：初始任务不确定性用于早期路由，步级不确定性用于运行时升级，移交后用影子观察器持续监督黑盒强智能体。不确定性估计复用动作生成时已产生的激活，无需额外前向或专门监控训练。在 OSWorld 上跨四个当代模型骨干实验。
  - 重要性：★★★★★ / 5
  - 来源：[HuggingFace Papers](https://huggingface.co/papers/2610.22280)

- **可扩展的弱到强验证器加固：让当前模型自动修复智能体环境**：智能体环境是 LLM 开发的关键基础设施，用程序化验证器把复杂结果转成奖励。但验证器可被攻击，使作弊智能体在未完成预期任务时仍获满分，导致评估失真与训练失配。随着环境数量与难度扩张，可被利用验证器的修复也必须规模化。作者提出一个可扩展、全自动的弱到强验证器加固方法：先建立智能体无法直接修改的隔离验证器沙箱，再用黑客-修复者循环发现并修补残余漏洞。该循环应用于 Terminal Bench、KernelBench 和 SETA，显著降低这些环境中的攻击成功率。迭代设计随加固预算扩展，循环次数增加带来更强防御，并优于静态非迭代基线。该黑客-修复者循环的早期版本已被 Terminal Bench 官方仓库采用，用于审计其环境中的漏洞利用。
  - 重要性：★★★★★ / 5
  - 来源：[HuggingFace Papers](https://huggingface.co/papers/2610.15924)

- **LeanPRM：用 Lean 接地为自然语言证明验证提供过程监督**：AI 系统已能写出又长又难的数学证明，逐步检查其有效性正成为瓶颈。学习型验证器可廉价检查证明，但训练需要每步的正确性标签，而开放式证明难以获得此类标签：人工标注昂贵，从最终答案推导不适用于证明，用 Lean 形式化每个证明又需专家投入。作者提出 LeanPRM，用 Lean 证明助手为自然语言证明生成步级标签：模型同时写出自然语言证明与配对形式化证明且不接受 Lean 反馈，Lean 为每一步打标，第二个模型剔除仅由形式语法导致的失败，使负标签标记数学错误。LeanPRM 含 10,634 个证明、152K 标注步，无需人工标注。基于它训练的 Qwen3-4B 验证器在 200 个证明的留出集 LeanPRM-Bench 上把精确步标签准确率从 48.2 提升到 74.7，而同一基座用 PRM800K 训练仅得 60.3。
  - 重要性：★★★★★ / 5
  - 来源：[HuggingFace Papers](https://huggingface.co/papers/2610.17697)

- **semCER：等 CER 不等于等损害，OCR 指标应按严重度加权**：Character Error Rate（CER）是 OCR 与视觉语言模型的标准指标，但它把一个错别字和一个错名字等同计费。作者提出 semCER，保留 CER 的对齐方式与分母，由 LLM 判官为每个字素编辑赋予严重度，且不做分词。归一化 CER 保留整段转写的分数，其与读者判断的吻合度与 semCER 相当或更好，而 semCER 还能把该分数拆解为具名编辑。这些计费在英语、越南语和中文中逐编辑跟踪读者评分，并把读者评为最严重的编辑排在排序列表前列。在 CER 与 semCER 判断不一致的样本对上，英语和中文里读者更常支持 semCER，越南语中两者持平。跨 16 种语言，判官对西班牙语中错误变音符或声调几乎不计费，而在泰卢固语中几乎等同错一个字母的严重度。作者开源了 6100 万条判定编辑、聚合读者评分与蒸馏评分器。
  - 重要性：★★★★★ / 5
  - 来源：[HuggingFace Papers](https://huggingface.co/papers/2610.20461)

- **PathFM：多变量轨迹的快速生成式预测**：时间序列基础模型日益流行，但多数领先模型只预测边际分位数，未指定未来轨迹的依赖结构。这对累积需求、峰值负载、事件时序等依赖轨迹的量很关键，而点预测与边际分数无法揭示。作者提出 PathFM，一个基于轨迹的预测模型，用 flow matching 生成完整未来路径，并通过蒸馏到一到两步、跨采样共享历史注意力缓存，使单序列生成多条路径的耗时约等于一次分位数模型查询。蒸馏采样器还让直接优化校准损失变得可行。PathFM 在 fev-bench 与 TIME 上取得有竞争力的边际精度。作者同时提出 Forecast Path Score Bench（fps-bench），在 fev-bench 任务上加入能量与变差函数分数及下游指标，PathFM 在该基准上取得高于所有外部基线的聚合路径分数。混沌系统实验显示其能维持长期变异性，而强基线迅速崩溃。
  - 重要性：★★★★★ / 5
  - 来源：[HuggingFace Papers, arXiv](https://huggingface.co/papers/2610.22358)

- **学习读出：语言模型预训练中的 unembedding 动态**：模型何时获得某项能力？发展性研究通常通过追踪模型何时开始产出正确 token 来回答，但该预测要经过 unembedding 矩阵（读出层），而读出层本身在预训练中仍在学习。作者表明，模型隐状态可以在自身读出层表达任务信息之前就编码该信息，因此从输出读出的时间线混淆了「模型编码了什么」与「读出层表达了什么」。为直接追踪读出层，他们提出 parameter-trajectory crosscoding，为每个 checkpoint 上每个 token 的读出层行拟合一个稀疏字典，与激活上的 crosscoder 不同，它只需 checkpoint 权重。作者据此定位到 Pythia 预训练 0.4-1.1% 处一个狭窄早期窗口，读出层在此期间重组，WordNet 词类别变得可从其行解码。此时隐状态上的线性探针已能解码模型输出尚未显示的任务信息。从零预训练仅读出层学习率不同的小模型显示，提高学习率使读出层更早发展、差距更快闭合，对最终损失影响很小。
  - 重要性：★★★★★ / 5
  - 来源：[HuggingFace Papers](https://huggingface.co/papers/2610.21025)
