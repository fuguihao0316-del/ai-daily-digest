## 📄 学术论文研究动态

- **SAE 特征可复现性远比功能收敛更吃数据**：研究在 3 个语言模型、4 种 SAE 架构上把训练预算从 5M token 扫到 500M token，发现「功能收敛」和「特征复现」是两回事：重建指标往往在远小于全量数据时就逼近参考值，但严格匹配的特征比例持续随数据增长，Gemma-2-2B BatchTopK 从 5M token 时的 2% 升到 50M 时的 29%。数据选择策略也有分化：随机采样更好保留原始激活分布、通常利于重建，多样性采样则常提升 AutoInterp。作者用理论分析区分了子采样训练的统计一致性与一对一特征恢复所需的更强可辨识性与优化条件。对做 SAE 可解释性研究的团队，这意味着应按目标而非默认规模配置预算，且特征级结论必须附显式复现性检查。
  - 重要性：★★★★★ / 5
  - 来源：[HuggingFace Papers](https://huggingface.co/papers/2610.20680)

- **SAE 特征的行为组合性并不等于可加性**：作者提出 SAE Additivity Residuals（SAR），度量在给定交互阶数之上仍未被解释的行为变化，并证明在独立特征子集采样下，总体 SAR 恰等于该阶数以上交互的归一化能量，同时给出最优低阶近似的 coalition 排序误差上界。在全部 18 组模型与行为设定中，学习到的 SAE 坐标一阶残差都低于同一子空间的保和随机旋转；但坐标并非完全可加，成对项在每种设定下都改善留出集排序，并优于使用随机三阶项的等参数量模型。联合 steering 实验中，成对建模把 rank fidelity 从 0.5874 提到 0.7790，排序误差从 0.1444 降到 0.0606。结论是 SAE 坐标支持相对可组合的行为描述，但忠实的联合解释与干预仍需超出单特征效应的交互项。
  - 重要性：★★★★★ / 5
  - 来源：[HuggingFace Papers](https://huggingface.co/papers/2610.21261)

- **LeanPRM 用 Lean 自动标注自然语言证明的每一步**：长证明的逐步校验正成为瓶颈，人工标注昂贵、终答无法反推步骤、逐步形式化又需专家投入。LeanPRM 让模型同时写出自然语言证明与配对的形式化证明（不给 Lean 反馈），由 Lean 为每一步打标签，再用第二个模型剔除仅由形式语法导致的失败，使负标签对应真正的数学错误。数据集含 10,634 个证明、152K 个标注步骤，零人工标注。基于 Qwen3-4B 训练的验证器在 200 个留出证明（LeanPRM-Bench）上把逐步标签准确率从 48.2 提到 74.7，而同一基座用 PRM800K 训练只有 60.3；在 IMO 级题目的 best-of-N 选择中更优，并在 4 个外部验证基准中的 3 个上超过 PRM800K 版本，0.6B 到 8B 各规模均有提升。
  - 重要性：★★★★★ / 5
  - 来源：[HuggingFace Papers](https://huggingface.co/papers/2610.17697)

- **远程 KV 缓存可能比直接重算更慢：GLM-5.3 上的实测与成本模型**：作者在 8 台 B300 节点、开启 prefill 上下文并行（PCP8）的解耦部署中服务 FP8 MoE 模型 GLM-5.3（使用 MLA），接入 LMCache + Valkey 远程层后中位首 token 时延不变，但 16k token 的 p99 从 3.96 s 涨到 17.3 s。回放生产请求流发现远程命中耗时 0.88 s，而重算 prompt 只需 0.31 s；同步加载把命中密集的流量变成不稳定队列，p99 达 83.32 s 而 GPU 仅 7% 忙碌。两项成本模型解释了这一现象：命中只有在带宽超过 B* = sR（该模型与 GPU 上为 2.53 GB/s）时才划算，且每次命中存在约 0.33 s 的固定引擎开销，因此短于约 17k token 的 prompt 在任何带宽下都赢不了重算。据此他们按 PCP rank 分片 MLA KV 存储、按 rank 分区远程层（GET 带宽提升 6.3 倍至 10.76 GB/s）并引入异步加载。
  - 重要性：★★★★★ / 5
  - 来源：[HuggingFace Papers](https://huggingface.co/papers/2610.21500)

- **Virtual Head Attention 同时压缩 KV 缓存、算力与质量三角**：长上下文注意力面临 KV 缓存、训练与 prefill FLOPs、模型质量之间的「不可能三角」：GQA 质量好但缓存开销高，MLA 压缩缓存却损质量，MFA 大幅增加训练与 prefill 计算。VHA 用两个轻量线性操作破局：Q Premix 在每个 KV 组内对 query 做近恒等变换，从减半的物理 query head 中恢复虚拟 head 多样性；Linear Postmix 以低秩 I + AB^T 残差结构融合头间特征。由于无非线性操作，推理时 Premix 可折叠进 query 投影、Postmix 可折叠进输出投影，模型退化为标准 GQA-2，直接复用现有 GQA 推理优化。仅用 2 个 KV head 时大模型组大小可达 64，充分利用解码期 Tensor Core 并行。在 4K 上下文、50B token 预训练的四个规模上均超 GQA 基线（+0.05% 至 +0.81%），dense 规模下 KV 缓存比 GQA-8 减 4 倍、MoE 规模下比 GQA-4 减 2 倍，1.7B、S=4096 时训练与 prefill FLOPs 降 7.9%。
