## 📄 学术论文研究动态

- **Mine, Sample, Render 把生成多样性外化为语料采样**：针对生成模型即使被明确要求也难以产出多样结果的问题，论文提出 MINE-SAMPLE-RENDER（MSR）测试时方法：先从真实语料中挖掘可解释的分类模式并统计属性分布，再按该分布采样属性配置，最后把生成模型降级为条件渲染器。在天气报告生成、用户模拟、网页设计、text-to-image 与 agent 生成 3D 资产五类任务上，MSR 同时提升了输出与语料分布的对齐度和多样性。其思路是把「多样性」从模型内部采样策略中剥离，交给可审计的显式采样程序，对需要可控多样输出的产品侧部署有直接参考价值。
  - 重要性：★★★★★ / 5
  - 来源：[HuggingFace Papers](https://huggingface.co/papers/2610.21185)

- **SAE 特征的行为组合性被量化：一阶可加、二阶必要**：论文提出 SAE Additivity Residuals（SAR），度量在给定交互阶数之上仍未被解释的行为变化，并证明在独立特征子集采样下总体 SAR 恰等于该阶以上交互的归一化能量。在全部 18 组模型与行为设定中，学习到的 SAE 坐标一阶残差均低于同子空间的保和随机旋转；但坐标并非完全可加，成对项在每种设定下都改善留出联盟排序。联合 steering 实验中成对建模把 rank fidelity 从 0.5874 提到 0.7790，排序误差从 0.1444 降到 0.0606。结论是单特征干预不足以支撑忠实解释，需引入交互项。
  - 重要性：★★★★★ / 5
  - 来源：[HuggingFace Papers](https://huggingface.co/papers/2610.21261)

- **SAE 训练数据存在边际收益递减，功能收敛不等于特征可复现**：研究在 3 个语言模型、4 种 SAE 架构上把训练预算从 5M token 扫到 500M 参考值，发现重建类指标常在远小预算下就逼近全量参考，而特征一一复现性持续随数据改善。Gemma-2-2B BatchTopK 上严格匹配特征比例从 5M token 的 2% 升到 50M 的 29%。数据选择同样关键：随机采样更好保留原始激活分布、利于重建，多样性采样则常提升 AutoInterp。理论分析区分了子采样训练的统计一致性与一一特征恢复所需的更强可辨识与优化条件，意味着按目标匹配预算可大幅降低 SAE 研究成本。
  - 重要性：★★★★★ / 5
  - 来源：[HuggingFace Papers](https://huggingface.co/papers/2610.20680)

- **LEASH 用隐状态不确定性决定弱模型何时交棒强模型**：computer-use agent 在长程任务上每步都调用前沿模型代价高，小开源模型单独跑又常失败。LEASH 是无训练框架：比较弱模型当前隐状态与其历史成功、失败轨迹的隐状态，越像失败则不确定性越高，据此做初始任务路由与步级升级；交棒后再用 shadow observer 持续监督无法访问内部的黑盒强模型。不确定性估计复用动作生成时已产生的激活，无需额外前向或专门训练监控器。在 OSWorld 四个当代骨干模型上做了实验，为「便宜模型打底、贵模型兜底」的部署形态给出可操作判据。
  - 重要性：★★★★★ / 5
  - 来源：[HuggingFace Papers](https://huggingface.co/papers/2610.22280)

- **弱到强验证器加固：自动修补 agent 环境的 reward hacking**：agent 环境用程序化验证器把复杂结果转成奖励，而验证器可被攻击为作弊 agent 发放满分，污染评测与训练。论文提出可扩展的全自动弱到强验证器加固方法：先建立 agent 无法直接修改的隔离验证器沙箱，再用 hacker-fixer 循环寻找并修复剩余漏洞。应用于 Terminal Bench、KernelBench 与 SETA 后攻击成功率大幅下降，且防御随循环迭代次数增强，优于静态非迭代基线。该 hacker-fixer 循环的早期版本已被 Terminal Bench 官方仓库采用，用于审计其环境中的 exploit。
  - 重要性：★★★★★ / 5
  - 来源：[HuggingFace Papers](https://huggingface.co/papers/2610.15924)

- **LeanPRM 用 Lean 自动标注自然语言证明的逐步正确性**：长而难的数学证明使逐步校验成为瓶颈，而人工标注代价高、最终答案又无法为证明提供标签、逐条形式化需专家投入。LeanPRM 让模型同时写出自然语言证明与配对形式化证明（不给 Lean 反馈），由 Lean 为每一步打标签，再由第二个模型剔除仅由形式语法导致的失败，使负标签指向数学错误。数据集含 10,634 个证明、152K 标注步骤，零人工标注。基于 Qwen3-4B 训练的验证器在 200 个证明的 LeanPRM-Bench 上把逐步标签准确率从 48.2 提到 74.7，而同一基座用 PRM800K 训练仅 60.3；在 IMO 级问题的最佳 N 选与四个外部基准中的三个上同样占优，且 0.6B 到 8B 各规模均有提升。
  - 重要性：★★★★★ / 5
  - 来源：[HuggingFace Papers](https://huggingface.co/papers/2610.17697)

- **Gen4P 把预训练视频生成器改造成前馈 4D 感知器**：论文提出 Gen4P，从单目视频恢复 4D 几何与运动，无需迭代去噪：以单次编码器前向处理干净视频 latent，再通过轻量 cross-attention 解码器按需查询预测 4D 属性。on-demand query 支持灵活空间采样，连续时间查询进一步提供时间灵活性；把预训练 video-depth LoRA 作为冻结几何先验即插即用，不增加可训练参数。在 3D 点跟踪、视频深度与相机位姿估计上达到 SOTA 或竞争力水平，野外视频上能跟踪复杂运动并保持精细结构，支持视频生成预训练可迁移到统一 4D 感知的判断。
  - 重要性：★★★★★ / 5
  - 来源：[HuggingFace Papers](https://huggingface.co/papers/2610.22371)

- **远程 KV 层可能比重算更慢：GLM-5.3 上的成本模型与分片改造**：在 8 张 B300、prefill 上下文并行 PCP8 的解耦部署中研究 GLM-5.3（FP8 MoE + MLA）的远程 KV 层，开启 LMCache + Valkey 后首 token 中位数不变，但 16k token 的 p99 从 3.96 s 升到 17.3 s；隔离引擎回放显示远程命中耗时 0.88 s，而重算 prompt 只需 0.31 s，同步加载把命中密集流变成不稳定队列，p99 达 83.32 s 而 GPU 仅 7% 忙碌。两项成本模型给出判据：命中仅在带宽超过 B*=sR（该配置 2.53 GB/s）时划算，且固定每次命中开销 T0≈0.33 s 使约 17k token 以下的 prompt 命中永远打不过重算。据此做 MLA KV 按 PCP rank 分片、远程层按 rank 分区（GET 带宽提升 6.3 倍至 10.76 GB/s）并加入异步加载。
