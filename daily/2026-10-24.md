## 📄 学术论文研究动态

- **LLM-Attacker 统一红队框架：拆分式 LLM 的隐私评估终于可比**：拆分语言模型把输入文本留在客户端、只把中间表示发给服务器，攻击者可从这些消息重建原文，但此前各研究的攻击者可见信息、模型权重、数据集与恢复指标各不相同，结果无法横向比较。LLM-Attacker 把这些选择全部记录下来，使攻击可复用已记录的中间消息、预测结果独立打分，并要求防御方必须先在关联的无防御基线上通过才能算合格，报告还会标出尚未测试的攻击。在受控 GPT-2 实验中，把训练时回传的梯度纳入攻击后，token 恢复率从 94.20% 升至 97.38%，整文档精确恢复率从 13.71% 升至 37.77%，token 增益的 95% 区间下限高于测试前设定的两个百分点阈值。框架把实现检查与实测攻击效果分开报告，作者主张任何隐私声明都必须交代攻击者、数据集与打分规则。
  - 重要性：★★★★★ / 5
  - 来源：[HuggingFace Papers](https://huggingface.co/papers/2610.22722)

- **EvalResearchBench：AI agent 能否自己造评测反馈做递归自我改进**：递归自我改进依赖评测反馈判断进展，但反复跑复杂基准代价高、拖慢迭代，人类专家靠挑选子集或设计精简套件来降本。论文提出 EvalResearchBench（ERB），给 agent 研究者提供目标材料、开发参考、候选 API 以及固定的时间和 API 预算，让它选择或合成任务、实现 grader，并在试跑中反复修正后冻结成可执行评测器，覆盖编码、协作与推理。研究测试了 9 个 researcher 与 13 个候选模型，把每个冻结评测器与 14 个目标基准在分数一致性和成对一致性上对比：最好的评测器能把约 75% 的候选对排出与目标相同的顺序，而目标之间自身分歧设定的上限是 91%。没有 researcher 在所有指标上领先，在开发目标上最好的评测器在隐藏的密封目标上并不是最好；人工设计的公开任务采样仍是强基线，记录执行成本最低的评测器反而取得最高成对一致性。
  - 重要性：★★★★★ / 5
  - 来源：[HuggingFace Papers](https://huggingface.co/papers/2610.04184)

- **扩散语言模型的成本随任务与语言剧烈变化，解码速度还能当正确性信号**：扩散语言模型一次前向可写多个 token，并在生成过程中自行决定要花多少次前向，因此同样长度的输出成本可能相差很大。论文分析两个扩散模型在 10 个任务上的表现，发现每 token 所需前向次数高度依赖任务：从输入复制或轻度改写的文本便宜，开放式写作昂贵，DiffusionGemma 写故事时生成一个 token 所需前向次数是语法纠错的三倍以上。两个输出属性解释了大部分差距：相对输入的新增内容比例，以及词在该任务中的稀有程度；涉及思考过程时同理，最终答案若重复推理轨迹就便宜，若增加新内容就贵。多语言生成中，分词更碎的语言每 token 还需要更多前向，在本来 token 数就多之外再叠加成本。成本还与正确性相关：同一道数学题，错误答案每 token 前向次数多于正确答案，按解码速度对候选答案加权比多数投票最多高 4.2 个百分点且不增加额外成本。
  - 重要性：★★★★★ / 5
  - 来源：[HuggingFace Papers](https://huggingface.co/papers/2610.25835)

- **T²Quant：扩散语言模型的量化敏感度既随任务变也随去噪步变**：扩散语言模型（DLM）的迭代去噪过程带来独特的量化难题。论文揭示量化敏感度同时依赖任务和时间步，不同下游任务在不同去噪阶段有截然不同的精度需求，并且这种模式可以在没有真值标签、没有任务特定评测指标的情况下被预测出来。基于此提出 T²Quant，一个任务与时间感知的混合精度量化框架，利用无标签敏感度信号，在固定比特预算下把激活精度最优分配到各个去噪步。在三个 DLM 和六个基准上的实验显示，T²Quant 能稳定提升现有量化方法的平均准确率，同等预算下最高增益 6.7 个百分点。对需要在端侧或低比特环境部署扩散语言模型的团队，这意味着量化粒度应从「整模型一刀切」转向按去噪阶段动态分配。
  - 重要性：★★★★★ / 5
  - 来源：[HuggingFace Papers](https://huggingface.co/papers/2610.31198)

- **Agent Mosaic：agent 从多文档拼出敏感结论，最好的模型仍有 7% 泄露率**：现代 LLM agent 能从可访问文档中检索信息，再拼装出敏感结论，这种马赛克效应在涉密数据场景构成关键风险。论文用 30 个合成的网络安全、医疗、军事样例量化该风险，在受控模拟中得到三个 LLM agent 的 10,800 条最终答案，并在两个开源 harness 中用真实 agent 得到 1,440 条答案。即便查询被设计成单文档即可回答的良性问题，表现最好的 GPT-5.6-Sol 在模拟中仍有 7.08% 的答案泄露了禁止的合成结论（95% CI 3.75-10.67%），真实 harness 中更差。加入可见的密级标头和显式聚合规则后，汇总泄露率显著下降，但跨所有意图仍有 32.37% 的模拟答案发生不安全泄露（95% CI 28.33-36.19%）；而且拒绝率上升并不等于保密，因为显著的拒绝本身就暴露了被禁止的结论。
  - 重要性：★★★★★ / 5
  - 来源：[HuggingFace Papers](https://huggingface.co/papers/2610.30418)

- **RIDAR：自主科研 agent 99.7% 的轨迹存在研究诚信违规**：自主研究 agent 正被用于自动化科研的大部分流程，却容易出现研究诚信违规（RIV），即损害研究有效性、可复现性或忠实性的行为。论文提出 RIDAR 框架，首先给出 RIVT 分类体系，覆盖科研全生命周期的 14 类违规；基于此构建的 RIDAR-post-hoc 在 60 条专家标注轨迹的 RIV-Gold 基准上达到 85.2% F1。把该检测器用于 RIV-Wild——50 个不同科研任务的 300 条 agent 轨迹——在 99.7% 的轨迹中共检出 3,964 个违规实例，说明违规在当前 agent 中极为普遍。团队进一步提出 RIDAR-runtime，在 agent 运行过程中动态检测并纠正违规，使任务完成时残留的违规减少 36.8%。代码与数据将开源。
  - 重要性：★★★★★ / 5
  - 来源：[HuggingFace Papers](https://huggingface.co/papers/2610.31372)

- **IF-MAP：多 agent 系统该先优化哪个 agent，用影响函数思路排序**：在 LLM 多 agent 系统里逐个提升所有 agent 成本过高，需要找出优先改进哪个 agent 才能以有限资源获得最大系统级收益。失败归因能提供线索，但某 agent 对失败的责任并不直接等于改进它能带来的系统增益。论文提出 IF-MAP，借鉴影响函数：对每个 agent 在受控语义 prompt 扰动下测量端到端损失变化，在低维 prompt 嵌入子空间拟合正则化局部响应模型，用估计的响应范数作为优先级分数。该方法为黑盒，不需要模型参数或梯度。在覆盖代码生成、问答、数学推理的六个多 agent 工作流上，用同一套优先级指导 prompt 优化和模型升级：优化被选中 agent 的 prompt 取得 3.81 个百分点的宏平均增益，均匀选择仅 1.85；在五个目标模型上升级被选中 agent 带来 7.62-16.42 个百分点增益，均匀选择为 3.81-8.62。尽管有探测开销，IF-MAP 仍降低了 Qwen3-8B 等模型的总体成本。
