## 📄 学术论文研究动态

- **TARSphere 发布：面向长时程具身智能体的全栈机器人框架**：TARSphere 由 TARSphere-Infra、TARSphere-Harness 和 TARSphere-Bench 三部分组成。Infra 在物理模拟器中运行机器人策略，并包含具身 NPC 与受限对话；Harness 让冻结的多模态大模型通过多级可执行技能行动，结合观测、分层记忆与执行反馈修正决策；Bench 覆盖 30 个室内场景的 360 个回合，设置感知鲁棒性、扰动适应、任务更新、人类协作与意图理解五组配对条件，考察导航报告与取送两类任务。团队评测 8 个 MLLM，发现通用模型可胜过具身专用模型，而任务更新与人机交互仍是难点，频繁碰撞与跌倒也说明执行安全需与任务成功率一并评估。
  - 重要性：★★★★★ / 5
  - 来源：[HuggingFace Papers](https://huggingface.co/papers/2610.30043)

- **LLM-Attacker：拆分式与分布式 LLM 系统隐私评估的统一红队框架**：拆分语言模型把输入文本留在客户端，只把中间表示发往服务器，攻击者可据此重建原文，但不同研究在攻击者可见消息、模型权重、数据集与恢复指标上各不相同，导致隐私结论难以横向比较。LLM-Attacker 记录这些选择，使评估可检查、可比较、可扩展：兼容攻击复用已记录消息，预测结果单独保存以便独立打分，评分规则要求先有未设防的关联参照，防御才能判定通过，报告还会标出尚未测试的攻击。在受控 GPT-2 实验中，加入训练时回传的梯度使 token 恢复率从 94.20% 升至 97.38%，整文档精确恢复率从 13.71% 升至 37.77%，token 增益的 95% 区间高于事前设定的两个百分点阈值。
  - 重要性：★★★★★ / 5
  - 来源：[HuggingFace Papers](https://huggingface.co/papers/2610.22722)

- **EvalResearchBench：AI 智能体能否自建反馈实现递归自我改进**：递归自我改进依赖评估反馈判断进展，但反复运行复杂基准成本高、迭代慢，人类专家通常靠挑选子集或设计精简套件来降本。论文提出 EvalResearchBench，给定目标材料、开发参考、候选 API 与固定时间及 API 预算，让被称为 researcher 的智能体自行选择或合成任务、实现评分器并在试点中修改，最终冻结可执行评估器，覆盖编码、协作与推理。研究测试 9 个 researcher 与 13 个候选模型，将每个冻结评估器与 14 个目标基准在分数一致性和成对一致性上比较：最佳评估器与目标基准在约 75% 的候选对上排序一致，低于目标基准之间分歧所设定的 91% 上限；没有 researcher 在所有指标上领先，开发目标上的最佳评估器在隐藏目标上并非最佳。人工设计的公开任务样本仍是强基线，执行成本最低的评估器成对一致性最高。
  - 重要性：★★★★★ / 5
  - 来源：[HuggingFace Papers](https://huggingface.co/papers/2610.04184)

- **扩散语言模型的计算成本随任务与语言大幅波动**：扩散语言模型一次前向可写多个 token，并在生成中自行决定前向次数，因此同样长度的输出成本可能相差悬殊。论文分析两个扩散模型在 10 个任务上的表现，发现每 token 所需前向次数高度依赖任务：从输入复制或轻改的文本便宜，开放式写作昂贵，DiffusionGemma 写故事生成一个 token 所需前向次数是语法纠错的三倍以上。两个输出属性解释了大部分差距：相对输入的新增内容比例，以及词在该任务中的稀有程度。同一回复内部亦然，最终答案复述推理轨迹时便宜，补充新内容时昂贵。多语言生成中，分词粒度高的语言每 token 还需更多前向。成本还与正确性相关：同一道数学题，错误答案每 token 前向次数多于正确答案，按解码速度对候选答案加权可在零额外成本下比多数投票高出最多 4.2 个百分点。
  - 重要性：★★★★★ / 5
  - 来源：[HuggingFace Papers](https://huggingface.co/papers/2610.25835)

- **T²Quant：面向扩散语言模型的任务与时间步感知混合精度量化**：扩散语言模型的迭代去噪过程带来独特量化难题。论文揭示量化敏感度既与任务相关也与时间步相关，不同下游任务在各去噪步骤上有不同精度需求，且这些模式无需真值标签或任务专属评估指标即可预测。基于此提出 T²Quant，一种任务与时间步感知的混合精度量化框架，利用无标签敏感度信号在固定比特预算下为各去噪步骤最优分配激活精度。在三个扩散语言模型与六个基准上的实验显示，T²Quant 在同等预算下持续提升现有量化方法的平均准确率，增益最高达 6.7 个百分点。
  - 重要性：★★★★★ / 5
  - 来源：[HuggingFace Papers](https://huggingface.co/papers/2610.31198)

- **ID-TAP：面向测试时智能体个性化的信息导向对决框架**：有效的测试时个性化要求 LLM 智能体通过轻量交互适应用户随查询变化的偏好。论文研究以候选回复之间的二元比较作为在线信号的人格选择问题，提出 ID-TAP，一个受信息导向采样启发、面向大规模离散人格空间的可扩展神经对决 bandit 框架。它把查询条件化的神经效用模型与轻量 Bradley-Terry 探索器结合，并通过相似度加权热启动在相关查询间迁移比较证据：神经模型在查询间共享统计强度同时保留查询专属分数，BT 更新则高效地为假想挑战者打分。在参考模型与模型两类偏好模拟器下的七个用户条件生成基准上，ID-TAP 在固定十轮比较预算内取得所评估基线中最强的综合表现，支持将信息导向的挑战者选择作为测试时人格适配的有效设计。
  - 重要性：★★★★★ / 5
  - 来源：[HuggingFace Papers](https://huggingface.co/papers/2610.24385)

- **IF-MAP：多智能体系统中基于影响函数的智能体优先级排序**：提升 LLM 多智能体系统中的每个智能体成本过高，因此需要识别在有限资源下能带来最大系统级收益的智能体。失败归因可辅助决策，但某智能体对失败的责任并不直接反映改进它能获得的系统级增益。论文提出 IF-MAP，借鉴影响函数，对每个智能体在受控语义提示扰动下测量端到端损失变化，在低维提示嵌入子空间中拟合正则化局部响应模型，并以估计的响应范数作为优先级分数。该黑盒流程无需访问模型参数或梯度。在覆盖代码生成、问答与数学推理的六个多智能体工作流上，用同一套优先级指导提示优化与模型升级：优化所选智能体的提示取得 3.81 个百分点的宏平均增益，均匀选择为 1.85；在五个目标模型上升级所选智能体带来 7.62 至 16.42 个百分点增益，均匀选择为 3.81 至 8.62。尽管有探测开销，IF-MAP 仍降低了 Qwen3-8B 等模型的成本。
