## 📄 学术论文研究动态

- **TARSphere 发布面向长程具身智能体的全栈框架与基准**：机器人需在物理与社会约束下行动并适应环境变化，现有具身智能体系统多聚焦指定目标或将执行抽象为符号动作，难以在动态世界中评估。TARSphere 由三部分组成：TARSphere-Infra 在带具身 NPC 与受限对话的物理模拟器中运行机器人策略，用事件驱动有限状态机依据已完成动作与已交付信息更新任务状态并评估结果；TARSphere-Harness 让冻结的多模态大模型通过多级可执行技能行动，借助观测、分层记忆与执行反馈修正决策；在此基础上以 agent-in-the-loop 方式对齐任务语义、因果依赖与场景几何，构建含 30 个室内场景、360 个 episode 的 TARSphere-Bench，设置五组配对条件考察感知鲁棒性、中断适应、任务更新、人类协作与意图理解。对 8 个 MLLM 的评测显示通用模型可胜过具身模型，任务更新与人机交互仍是难点，频繁碰撞与跌倒说明执行安全需与任务成功率并列评估。
  - 重要性：★★★★★ / 5
  - 来源：[HuggingFace Papers](https://huggingface.co/papers/2610.30043)

- **LLM-Attacker 统一分割式与分布式 LLM 系统的隐私评测**：分割语言模型将输入文本留在客户端，只把中间表示发送到服务器，攻击者可据此重建文本，但当攻击者可见消息、已知模型权重、所用数据集与恢复度量各不相同时，隐私评测难以横向比较。LLM-Attacker 记录这些选择，使研究者能检查、比较和扩展评测：兼容攻击可复用已记录消息，预测结果单独保存以便独立打分；评分规则要求先有可关联的无防御参照，防御才算通过；报告还会标出尚未测试的攻击。在受控 GPT-2 实验中，加入训练时回传的梯度使 token 恢复率从 94.20% 升至 97.38%，整文档精确恢复率从 13.71% 升至 37.77%，token 增益的 95% 区间高于测试前设定的两个百分点阈值。框架将实现检查与实测攻击效果分开报告，作者主张每项隐私声明都应说明攻击者、数据集与评分规则，报告对照条件并列出未测试攻击。
  - 重要性：★★★★★ / 5
  - 来源：[HuggingFace Papers](https://huggingface.co/papers/2610.22722)

- **EvalResearchBench 检验 AI 智能体能否自建评测反馈实现递归自我改进**：递归自我改进依赖评测反馈判断进展并指导后续研究，但反复运行复杂基准成本高昂、拖慢迭代，人类专家通常靠挑选基准子集或设计精简套件来降低开销。论文提出 EvalResearchBench（ERB），给定目标材料、开发参考、候选 API 以及固定时间与 API 预算，名为 researcher 的智能体需选择或合成任务、实现评分器，并在试点测试中修订后冻结可执行评测器，覆盖编码、协作与推理。研究考察 9 个 researcher 与 13 个候选模型，将每个冻结评测器与 14 个目标基准在分数一致性和成对一致性上比较：最佳评测器对约 75% 的候选对排序与目标一致，低于目标之间分歧所设定的 91% 上限；没有 researcher 在所有指标上领先，在开发目标上最好的评测器在隐藏的密封目标上并非最佳；人工设计的公开任务样本仍是强基线，记录执行成本最低的评测器成对一致性最高。智能体能借助试点反馈修复任务与评分器，但其评测器仍可能截断回答、耗尽评测预算或让少数问题主导领域得分。
  - 重要性：★★★★★ / 5
  - 来源：[HuggingFace Papers](https://huggingface.co/papers/2610.04184)

- **扩散语言模型的计算成本随任务与语言大幅波动**：扩散语言模型可在一次前向中写出多个 token，并在生成过程中自行决定前向次数，因此同样长度的两个输出成本可能相差很大。论文分析两个扩散模型在 10 个任务上的表现，发现每 token 所需前向次数高度依赖任务：从输入复制或轻微编辑的文本便宜，开放式写作昂贵，在 DiffusionGemma 中写故事生成一个 token 所需前向次数是语法纠错的三倍以上。两个输出属性解释了大部分差距：相对输入的新增内容比例，以及词在该任务中的稀有程度；同一回答内部也成立，最终答案重复推理轨迹时便宜，加入新内容时昂贵。多语言生成中，分词粒度高的语言每 token 需要更多前向，在本已因 token 更多而付出的成本上进一步叠加。成本还与正确性相关：同一道数学题，错误答案每 token 前向次数多于正确答案，按解码速度对候选答案加权可在无额外成本下比多数投票最多高 4.2 分。结果表明扩散的计算优势取决于输出中有多少已被确定。
  - 重要性：★★★★★ / 5
  - 来源：[HuggingFace Papers](https://huggingface.co/papers/2610.25835)

- **T²Quant 提出任务与时间感知的扩散语言模型混合精度量化**：扩散语言模型因迭代去噪过程带来独特的量化挑战。论文揭示量化敏感度既与任务相关也与时间步相关，不同下游任务在去噪各阶段有不同精度需求，并进一步表明这些模式无需真实标签或任务特定评测指标即可预测。基于此提出 T²Quant，一个任务与时间感知的混合精度量化框架，利用无标签敏感度信号在固定比特预算下为各去噪步最优分配激活精度。在三个扩散语言模型和六个基准上的大量实验表明，T²Quant 在同等预算下持续提升现有量化方法的平均准确率，最高增益达 6.7 个百分点。
  - 重要性：★★★★★ / 5
  - 来源：[HuggingFace Papers](https://huggingface.co/papers/2610.31198)

- **IF-MAP 用影响函数思想为多智能体系统定位优先改进对象**：逐一改进 LLM 多智能体系统中的每个智能体成本过高，需识别在有限资源下能带来最大系统级收益的智能体；失败归因虽可提供线索，但某智能体对失败的责任并不直接等于改进它能获得的系统级增益。IF-MAP 为每个智能体测量受控语义提示扰动下的端到端损失变化，在低维提示嵌入子空间中拟合正则化局部响应模型，并以估计的响应范数作为优先级分数。该黑盒流程无需访问模型参数或梯度，产出的优先级可指导后续改进。在覆盖代码生成、问答与数学推理的六个多智能体工作流上，用同一套优先级做提示优化与模型升级：优化选中智能体的提示取得 3.81 个百分点的宏平均增益，均匀选择为 1.85；在五个目标模型上升级选中智能体带来 7.62 至 16.42 个百分点的宏平均增益，均匀选择为 3.81 至 8.62。尽管存在探测开销，IF-MAP 降低了 Qwen3-8B 与 Dee 的成本。
