- **DiscoDemo 用 RL 生成多样化示教数据，真机模仿学习成功率从 39% 升至 78%**：机器人行为克隆对训练数据覆盖度高度敏感，但采集多样化成功示教成本高昂。该研究把强化学习当作数据生成器而非部署控制器，训练带特权信息的隐变量条件 RL 生成器，配合并行逆向课程与成功门控的多样性目标，先发现多条成功闭环行为，再经安全过滤导出为静态数据集供下游视觉运动模仿学习。在四个操作任务上，DiscoDemo 带来更广的成功状态覆盖；仿真中下游成功率由最强基线 40% 提升至 62%，真机由 39% 提升至 78%。作者指出，成功解多样性对预训练 flow-matching VLA 的模仿学习有实质增益，且与纠错式数据采集互补。
  - 重要性：★★★★★ / 5
  - 来源：[HuggingFace Papers](https://huggingface.co/papers/2610.32093)

- **FLORA 机器人数据引擎开源：日标注 20 万小时，成本约为 GPT-6 Astra 的 1/125**：机器人基础模型的全生命周期都依赖数据标签：监测真实部署需要结果奖励标签，RL 后训练需要过程奖励标签，预训练数据筛选与配比需要带时间戳的描述。FLORA 是用于训练 GR00T 系列的工业级数据引擎，同时覆盖上述能力，在描述基准 WGO-Bench 与奖励基准 RoboReward、Robometer 上取得 SOTA，内部基准上可与 GPT-6 Astra 竞争且成本约为其 125 分之一。该引擎已在 512 台 GB300 上每天标注 20 万小时数据，此次开源意在让研究者扩展自定义机器人数据集，并探索物理自动科研、人到机器人迁移等方向。

- **FSPO 用函数空间时间自蒸馏稳定 RLVR，平均精度提升约 4 个百分点、峰值显存降至 56GB**：可验证奖励强化学习提升了语言模型推理能力，但标量结果对整条回答轨迹的监督过于粗糙。自蒸馏通过对比无辅助策略与带反馈的自教师提供更密的 token 级指导，然而教师随学生同步演化，目标不稳定且需额外正则。Function-Space Policy Optimization 提出单策略框架，把稀疏的历史 next-token 分布存为固定时间目标，在不维护持久教师模型的前提下实现时间分离，并引入特权分歧纠正、可靠性自适应 grounding 与质量/覆盖感知的时间记忆。在推理与工具使用基准上，该方法在 5 小时训练预算内取得最高平均准确率，较最强基线平均高约 4 个百分点，同时在 Olmo3-7B-Instruct 上把峰值显存从约 70GB 降至 56GB。

- **Kolab 发布 115 小时真实协作录像，指出现有 agent 基准测不出人机协同能力**：长程任务中，人类更看重与 AI agent 的持续交互（如修订计划），而非一次成功率，但主流 agent 基准偏重自动化，高分并不代表能有效协作。Kolab 收录来自 40 个职业的 50 位专业人士、115 小时以上的屏幕录制，记录他们与 agent 协作解决真实长程问题的过程，并附参与者对协作质量与产出质量的判断。分析显示协作模式差异显著，关键在于专业人士何时、以何种方式介入。协作型 agent 需具备两项自动化基准从未考察的能力：预测专家会采纳、修改还是拒绝其贡献，并在缺少持续专家反馈时从工作流中评估协作质量。基准将这两点操作化为可测任务，结果显示前沿模型表现仍不均衡。
  - 重要性：★★★★★ / 5

- **LLM2Cert 用 LLM 合成 Lyapunov 函数与 barrier certificate，Lean/SMT 验证通过率 77.1%**：非线性高维系统的稳定性与安全性证书合成长期依赖平方和规划、区间方法或 SMT 求解，往往需要松弛、偏保守，且随维度与非线性程度扩展性差；标准测试集也因此被低维多项式系统主导。作者同时补齐基准与方法：DynaCertBench 含 105 个实例，覆盖稳定性、吸引域、前向不变性与安全任务，并加入高维、控制受限与非线性耦合系统；LLM2Cert 让 LLM 生成候选证书，再把每条证明义务分派给 SMT 求解器或直接交给 Lean Proof-Repair agent。在 DynaCertBench 上验证通过 81/105（77.1%），较无反馈的一次性提案提升 17.1 个百分点，并在 81 个固定证书中额外解决 22 个 All-SMT 无法处理的情形。
  - 重要性：★★★★★ / 5
  - 来源：[HuggingFace Papers](https://huggingface.co/papers/2610.30524)

- **PaperFormalizer 把论文转成 Lean 已验证版本，作者全程把关语义决策**：即便经过仔细校对的论文，证明与假设陈述中仍可能留有细小缺口。PaperFormalizer 是 Lean 驱动的 agentic 流水线，从 LaTeX 源文件出发把论文转写为陈述依赖图，用自然语言逐条审计其忠实性、歧义与正确性，再针对 Mathlib、可选领域库与作者个人工具库完成形式化与证明。由于只有作者知道某条陈述的本意以及形式化缺口该如何修补，流水线在陈述存在多种读法时会停下询问作者，把每处修补以自然语言与 TeX 符号呈现为可接受、拒绝或改向的提案，凡可能改变论文主张的决策一律交由作者定夺。产出包括带注释的修订稿、变更报告，以及与陈述逐一关联的 Lean 代码。
  - 重要性：★★★★★ / 5
  - 来源：[HuggingFace Papers](https://huggingface.co/papers/2610.31810)

- **FocusVLA 以未来意图引导多视角动态路由，RoboTwin 2.0 成功率较 π0.5 提升 10.10 个百分点**：VLA 模型做机器人操作需要充分观察物体、末端执行器及其空间关系，多视角输入因此被广泛采用，但实验显示现有模型并未充分利用多视角互补性，策略倾向持续依赖腕部视角，无法随操作阶段动态调整全局与局部视角的依赖。FocusVLA 是阶段感知的多视角路由框架，从历史动作预测未来交互意图，并用该意图在动作生成过程中引导视角动态路由，从而按任务阶段自适应协调全局与局部观测。在 RoboTwin 2.0 上平均成功率较最强基线 π0.5 提升 10.10 个百分点，真机成功率从 71.7% 提升至 85.0%。其意图预测与动态路由模块可在不改动核心架构的前提下接入现有 VLA 框架。
  - 重要性：★★★★★ / 5
  - 来源：[HuggingFace Papers](https://huggingface.co/papers/2610.31423)

- **RoboJudge-9B 成为具身视频生成最贴合人类判断的评审模型，Pearson 相关 0.719**：视频生成模型有望成为具身世界模型的基础，前提是生成的 rollout 物理合理且忠实于任务指令。多模态大模型被越来越多地用作评审，但其与人类判断的一致性缺乏系统评估。RoboJudge-Bench 覆盖 8 个源语料、10 个视频生成器的 800 段人工标注视频，涉及夹爪、人手与灵巧手，从物理遵循与指令对齐两个维度测评，结果显示通用 MLLM 在物理遵循上一致性偏低，面向通用物理推理的专用视频评审模型也难以迁移到具身场景。作者据此构建含 12K 视频、25K 人工核验分数的 RoboJudge-Train，对一个 9B MLLM 先监督微调再强化学习，得到 RoboJudge-9B，在被评估的模型评审中总体一致性最高。
