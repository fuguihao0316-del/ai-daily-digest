## 📄 学术论文研究动态

- **CellTrack-Bench 发布：视觉语言模型细胞追踪能力系统性落后专用算法**：研究团队构建 CellTrack-Bench，从 15 个标准细胞追踪数据集、四种成像模态中抽取 1,537 个问题，对应 9,041 次细胞链接决策，并通过寻找不同算法追踪器共同失败案例构造高难度子集。评测覆盖 9 个前沿闭源模型与 13 个开源权重模型，同时比较了多种 VLM 环境脚手架，并给出失败模式分析。结论指向通用模型在需要时空感知的细胞动力学任务上仍难与专用追踪器抗衡。代码、模型输出与基准再生流水线已开源，对生物影像方向的从业者，这是一个可直接复用的评测底座。
  - 重要性：★★★★★ / 5
  - 来源：[HuggingFace Papers](https://huggingface.co/papers/2610.31566)

- **SO-101 Bench：低成本机械臂上的语言条件空间操作基准，仿真排名与真机完全一致**：作者基于真实 SO-101 装置在 Isaac Lab 中构建数字孪生，含四类任务（计为五个评分族）、138 个物体（分为已见、未见实例、未见类别三档）、916 个评测回合，以及 3,629 条仿真演示，所有策略在等算力预算下微调。关键结果是五个未用真实数据训练的策略在真机未见环境与未见物体上保持完全相同的排名（Spearman rho = 1.00），但仿真会高估成功率。九个 VLA 与世界动作模型中最好的仅约 61%，而一个写代码并调用学习策略做抓取的 LLM agent 达到 83.2%，消融显示优势来自脚手架与语言模型选择。
  - 重要性：★★★★★ / 5
  - 来源：[HuggingFace Papers](https://huggingface.co/papers/2610.36420)

- **Ψ-0.6：统一视觉-语言世界模型中的自适应思维流**：该工作提出统一视觉-语言世界模型 Ψ-0.6，将感知、语言、几何与仿真组合进共享推理过程「streams of thought」，图像、文本与显式几何运动表示通过统一 token 接口交错生成与解读。模型在多视角空间推理上零样本超过领先开源权重模型，经几何中间表示推理还能进一步提升；同时支持反事实仿真，例如判断移动某物体是否会阻挡通路。基于任务反馈的强化学习联合优化中间表示的选择、生成与使用，视觉问答准确率提升可迁移到未见基准。对做具身与世界模型的研究者，这条路线主张的是「不只预测物理世界，还要选择用何种表示去推理」。
  - 重要性：★★★★★ / 5
  - 来源：[HuggingFace Papers](https://huggingface.co/papers/2610.32177)

- **ParetoRSI-Gym：把递归自我改进放到多领域后训练里评测**：现有 RSI 评测通常在单一基准上让 agent 从静态数据池挑选或蒸馏更强模型，而真实后训练是多领域的，一个领域的收益要与其他领域的回退权衡。ParetoRSI-Gym 固定初始 LLM、五个领域（数学、代码、金融、医学、科学）、工具集与 SFT 流水线，只让 agent 搜索数据、筛选、训练、读回分领域结果并迭代。三个 agent 系统、三个基座模型、五轮、多随机种子下，最强系统 Claude Code 配 Opus-5 将代理最优 checkpoint 的泛化分数相对起点模型提升 9.2%（+2.3 绝对点），单领域相对增益最高达 63%（Ministral-3-3B 上的医学）。分析还指出脚手架与模型同等重要。
  - 重要性：★★★★★ / 5
  - 来源：[HuggingFace Papers](https://huggingface.co/papers/2610.34386)

- **CRM-Agent-Bench：在有状态企业环境中评测工具调用 agent**：作者主张可部署 agent 的基准应同时考察四件事：达成的结果、走过的轨迹、运营可行性与策略合规。CRM 场景恰好同时具备可变记录、运营规则与有后果的副作用，因此他们构建了 555 个有状态多轮任务，覆盖九个业务域、36 个能力标签，每个任务附带由动作、参数、顺序、响应、目标状态与受保护状态检查构成的可执行契约，成功定义为所有声明检查的严格合取。审计后的最终版本上评测 16 个系统，严格成功率区间为 64.32% 至 83.60%，但领先系统在成本与分领域可靠性上差异明显。对做企业 agent 落地的团队，这套契约式评分比准确率更接近生产要求。
  - 重要性：★★★★★ / 5
  - 来源：[HuggingFace Papers](https://huggingface.co/papers/2610.32004)

- **Rethinking Verification in Agent Harnesses：独立评审是准确率与成本的最优折中**：论文把验证当作测试时扩展的一个维度，考察何时介入、谁来检查、检查如何转化为修订，框架覆盖初始指令、轮内提醒、完成门禁与独立评审四层。在 Terminal-Bench 与 SWE-bench Verified 上，对七个前沿编码模型的 17 种设计做比较，并引入 VisualBench 做专家评估。初始指令与执行期提醒带来温和且依赖模型的增益，完成门禁增益更大但成本显著上升；由 critic 独立评审在 TB 上平均提升 5.9-9.5 个百分点、SWE 上 3.9-6.6 个百分点，成本分别为基线的 1.13-1.25 倍与 1.00-1.04 倍。VisualBench 上独立评审相对基线净偏好为 13.2-23.8 点。
  - 重要性：★★★★★ / 5
  - 来源：[HuggingFace Papers](https://huggingface.co/papers/2610.34577)

- **ReGE：把重复尝试的历史经验合成为可复用指导**：交互任务的多次尝试会暴露事实、有用操作与失败点，ReGE 将这些记录转成面向新一次尝试的指导。主实现 ReGE-Syn 用单次 coach 调用把有界执行记录与可用工件合成为自包含指导，把任务特定发现、建议动作与相关陷阱连接起来；学生模型从任务初始状态出发，把指导适配到当前观测。源生成、合成与学生执行共用同一基座模型，不做参数更新也不依赖更强教师。四个基准上，GPT 平均提升 9.9 个百分点、Claude 提升 8.8 个百分点；BrowseComp-Plus 匹配子集上，指导构建 token 相对适配版 AggAgent 分别减少 98.2% 与 95.5%，构建加执行总 token 下降 15.7% 与 35.4%。
  - 重要性：★★★★★ / 5
  - 来源：[HuggingFace Papers](https://huggingface.co/papers/2610.33861)

- **iPrefBench：移动端个人 agent 会执行任务，但不会替用户做推断与提问**：真实用户请求往往信息不全，agent 需要从用户活动历史推断部分缺失信息，另一些只能向用户询问，且不能做无依据假设或提出多余问题。iPrefBench 在可执行 iOS 环境中配交互式模拟用户，基于含 3,051 条历史活动事件的连贯人设，覆盖 26 个应用的 130 个欠指定任务，每个被省略的用户相关需求按构造要么可从历史推断、要么只能询问。评测 7 个前沿 agent 显示执行与个性化之间存在明显落差：动作完成分最高 91.6%，但完整任务成功率最高仅 47.7%，其中对「只能询问」类信息尤其失败，未能提出足够问题。
