## 📄 学术论文研究动态

- **AdaPRA 用自适应评分标准监督数据科学智能体**：数据科学智能体在端到端机器学习工作流上仍远落后于人类排行榜，常见过程错误包括探索不足、验证不可靠、代码 bug 以及固定预算下反复重跑同一份 EDA 和基线模型。AdaPRA 是一个持久化编码智能体框架，跨同一任务的多次尝试累积知识，并用评分标准引导的过程监督审计智能体的轨迹与工作区、执行检查并针对任务调整评分标准。实验显示，从较易任务播种的评分标准可泛化到更难任务，自适应调整进一步提升效果；每任务五次尝试下，80B Qwen 模型在 DSPredict-Easy 上排行榜百分位提升 24.5 点、DSPredict-Hard 上提升 14.8 点，同时减少过程错误。用某一基座模型运行轨迹中挖掘的评分标准去监督另一个模型（DeepSeek-V3.2）同样有效，且 AdaPRA 优于数据科学专用 PRM 方法 DataPRM。代码已开源。
  - 重要性：★★★★★ / 5
  - 来源：[HuggingFace Papers](https://huggingface.co/papers/2610.33245)

- **SARL 让检索增强模型学会感知自身搜索状态**：现有搜索智能体常缺乏搜索状态感知，即无法判断已获得哪些信息、还缺什么，导致幻觉推理与过早终止搜索。SARL 是一个强化学习框架，让模型在训练中学会识别自身搜索状态并据此调整搜索行为，测试时无需额外评估模块；其双重奖励设计既衡量每次评估的纠错效果，又惩罚对评估的过度依赖，从而同时鼓励有效与高效的搜索轨迹。相对最强基线，SARL 取得 24.3% 的相对提升，在多跳推理上平均增益 35.9%、深度研究基准上 27.9%，并超过依赖辅助监督或多智能体协作的方法，而它本身只是无推理期脚手架的单体 RL 框架。SARL 还在延长搜索视野下保持训练稳定，而现有方法在该情形下会持续退化。
  - 重要性：★★★★★ / 5
  - 来源：[HuggingFace Papers](https://huggingface.co/papers/2610.30435)

- **AlphaBet 用强化学习训练 LLM 事件预测智能体**：预测未决事件需要先找到相关证据、再判断证据对各结果的支持强度，但现有基于结果的 LLM 预测器训练往往从单一预测日期的预组装证据开始，把证据获取排除在学习回路之外。AlphaBet 是一个智能体强化学习框架，训练单一 LLM 策略在多个解析前日期上搜索、推理并报告概率；每个带日期的预测用恰当评分规则对照最终结果打分，使一个已解析事件能监督不同信息状态下的决策。作者将预测遗憾分解为证据获取缺口与概率报告缺口，并指出 GRPO 的标准差归一化在多类恰当评分下会扭曲报告目标。在 GLM-4.5-Air 上，AlphaBet 将 Forecast-Dojo 的 Brier 分数从 0.731 降至 0.626、FutureX 从 0.612 降至 0.528，消融表明增益来自多日期训练及信息获取与概率报告两方面的改善。
  - 重要性：★★★★★ / 5
  - 来源：[HuggingFace Papers](https://huggingface.co/papers/2610.22684)

- **h1 用最简智能体循环刷新形式定理证明 SOTA**：非形式数学的进展主要来自扩展前沿模型的思维链与智能体推理，而形式定理证明越来越依赖人类设计的工作流，如规划、分解与编排专用证明器。h1 提出一个 bitter lesson 式问题：一个只扩展测试时算力的简单智能体循环能否匹敌这些工作流。h1 给模型提供到 Lean 4 的高效接口，依靠验证器反馈与自我反思持续工作，不施加分解或搜索结构。它在 PutnamBench、FATE-X 和 FormalConjectures100-Solved 上达到 SOTA，解决 FormalConjectures 中八个开放问题，并在同等模型下匹敌或超过 Goedel-Architect、AlphaProof Nexus 等专用工作流，显示单次尝试（pass@1）常能扩展到解决开放问题。与 Claude Code、AxProverBase 的对照表明，高效的 Lean 接口在很大程度上决定成本与求解率。
  - 重要性：★★★★★ / 5
  - 来源：[HuggingFace Papers](https://huggingface.co/papers/2610.35962)

- **EmbeddingGemma 2 统一多模态嵌入并刷新帕累托前沿**：EmbeddingGemma 2 是一个开放多模态嵌入模型，在统一空间中原生表示文本、图像、音频、视频及其组合。方法上引入简化的逐层嵌入，以及按模态与目标推进的多阶段课程，保证单模态、跨模态与混合模态评测上的质量。在所有模态的综合嵌入基准上，EmbeddingGemma 2 建立了新的帕累托前沿，优于专用模型以及体积大 2 至 12 倍的模型。设计还面向资源受限环境提供灵活性，支持按需加载模态编码器、可调视觉 token 预算、可截断嵌入维度和量化权重。论文给出关键设计决策的消融，并开放 EmbeddingGemma 2 以推动后续研究。
  - 重要性：★★★★★ / 5
  - 来源：[HuggingFace Papers](https://huggingface.co/papers/2610.37364)

- **研究揭示结果型 RL 主要买到完成度与可靠性而非新能力**：结果型 RL 提升 pass@1 但在大 k 的 pass@k 上无增益，而每个 pass@1 都在 token 预算下计分。作者在固定 token 预算的物理与数学题上，比较 20 个已发布 RL 模型（1.5B 至 32B）与其起始思考模型的 pass@1，并把变化拆为完成度、可靠性与触及三部分。结论有四：基座常在预算耗尽前未作答时，增益或损失的大部分是完成度（4k 与 8k 下为 82%），给更多 token 基座可自行弥合；基座 token 充足时增益来自可靠性；按作者定义 RL 很少解决基座解决不了的问题，四个物理数学集上触及最多增加 2.1 个百分点，144 道仅 RL 模型解出的物理题中仅 3.5% 在重采样或人工阅读后成立；8B 模型小规模 RL 运行中新题增益仍属完成度。
  - 重要性：★★★★★ / 5
  - 来源：[HuggingFace Papers](https://huggingface.co/papers/2610.34894)

- **MPO 面向长程 LLM 智能体做多尺度策略优化**：长程 LLM 智能体以完整助手回合与环境交互，却逐 token 生成每个动作。作者观察到 critic 价值主要在回合之间变化，因而主张以回合为锚做优化，同时在 token 之间做更细的信用分配。据此提出多尺度策略优化（MPO），结合多尺度优势估计（MAE）与回合级重要性采样，使信用分配与策略更新在回合尺度上对齐。在搜索、工具使用与自动化任务上，用 4B 和 30B-A3B 模型做的广泛实验显示，MPO 相对强 RL 基线取得一致增益。
  - 重要性：★★★★☆ / 5
  - 来源：[HuggingFace Papers](https://huggingface.co/papers/2610.35013)

- **Heads of Security 用学到的注意力门控防御提示注入**：Heads of Security（HoS）是一种提示注入防御，通过一小组成员级学习到的注意力门控强制指令与数据分离。HoS 学习每个注意力头应如何在可信与不可信 token 之间重新分配注意力，使模型能对不可信内容进行推理而不遵循其中注入的指令。在 Llama-3.3-70B-Instruct 与 GPT-OSS-20B 上，与基于微调的 SOTA 防御 SecAlign++ 及架构内置分离的 ASIDE 对比，HoS 对自适应攻击更鲁棒、标准效用基准表现更好，并在标准智能体提示注入基准上持平最优。黑盒攻击 RL-Hammer 对 GPT-OSS-20B 达 97% 攻击成功率、对 SecAlign 达 85%，对 HoS 仅 10%；白盒攻击 Claudini 经自动研究强化后，在 HoS 上达到同等成功率需 3 倍 FLOPs。HoS 在少样本设置下保持基座效用，而 SecAlign 与 ASIDE 会退化。
