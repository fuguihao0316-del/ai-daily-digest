## 📄 学术论文研究动态

- **PreView 用预处理视图与线索提升 GUI grounding，无需重训主模型**：GUI grounding 需要在杂乱截图中定位小控件，裁剪放大虽能暴露局部细节，但仍可能留下目标歧义。PreView 作为辅助预处理器，在不额外训练 grounding 模型的前提下改进其输入：一个轻量辅助模型预测并精修中心点，把截图裁成局部视图并放大，同时生成红色圆圈标记加位置提示的视觉线索，以及描述候选控件身份或功能的文本线索。冻结的 grounding 模型据此输出最终点击位置。在五个基准上，PreView 提升了 Qwen3-VL-2B、OS-Atlas-4B 与 Qwen3-VL-4B 的平均 grounding 准确率，且三者均未再训练。论文还分析了视图与线索各自的贡献、中心精修的作用以及视觉输入预算的影响。
  - 重要性：★★★★★ / 5
  - 来源：[HuggingFace Papers](https://huggingface.co/papers/2610.33645)

- **PersonaCUABench：同一任务换人提问，计算机使用 agent 完成率下降 36%**：现有计算机使用 agent（CUA）通常在固定任务描述下评测，但真实用户会省略需求、追加约束，或在关键操作前要求确认，完成基准指令并不等于服务好了提问的人。PersonaCUABench 固定 74 个任务、覆盖 11 个领域，只改变提问者：44 个 persona 分四组，用自己的话重写指令并回答 CUA 的追问，CUA 只看到对话，看不到用户画像和原始指令。在九个基座模型、3330 次运行中，平均任务完成率相对原始请求下降 36%；失分单元里 59.9% 是 agent 按用户要求执行却做错，11.2% 是用户主动叫停却被判失败。即使任务完全完成，用户给出最高满意度的比例仅 62.7%，原始请求为 84.1%。结论是 CUA 评测需同时考察是否满足用户表达的需求与约束。
  - 重要性：★★★★★ / 5
  - 来源：[HuggingFace Papers](https://huggingface.co/papers/2610.22990)

- **LOB-Impact：生成式限价订单簿模型自发涌现市场冲击**：生成式限价订单簿模型要作为交易 agent 的世界模型，必须重现真实的市场冲击；若模拟器把这一机制定价错误，agent 会学到在模拟中最优、在真实市场错误的策略。已有指标只做与历史数据的分布比较，几乎不考察对 agent 自身订单的反事实响应。作者向五个自回归模型在五只 NASDAQ 股票上生成的报文流注入执行型 metaorder，用实证冲击文献的估计量测量响应，基准的物理性质事先已知。评测分三阶段：自由生成、metaorder 注入（给出冲击律的指数与幅度）、执行后窗口（测量松弛），并用仅模拟器的盲对照分离模型学到的响应与订单簿机械效应。结果显示冲击在仅做下一 token 预测训练的模型中自然涌现，指数落在 0.63 至 1.21 区间。
  - 重要性：★★★★★ / 5
  - 来源：[HuggingFace Papers](https://huggingface.co/papers/2610.27100)

- **Know, then Draw：自回归预训练学知识、扩散后训练做渲染**：视觉生成既需要高层语义知识，也需要细粒度像素细节。该工作把两种角色分给不同阶段：自回归预训练负责知识获取，扩散后训练负责高保真渲染，并系统研究了知识获取与渲染的目标函数、表示与规模定律。受控对比显示自回归是更强的预训练目标，提升了下游渲染的学习效率与最终质量；而纯自回归的生成质量并不必然与最终表现相关，语义质量更重要。这促使其采用仅用语言监督训练、不含图像解码器与重建损失的纯语义 tokenizer。作者建立了知识获取与渲染的计算最优缩放律，发现自回归预训练比从零训练的像素扩散模型有更低的渐近渲染损失。据此训练的 3B 参数文生图模型仅耗 6600 H100 GPU 小时，在 GenEval 得 86、DPG-Bench 得 87。
  - 重要性：★★★★★ / 5
  - 来源：[HuggingFace Papers](https://huggingface.co/papers/2610.37626)

- **Instruction Capacity：用可计算单位量化语言模型的指令承载上限**：语言模型遵循指令的质量随负载上升而下降，但此前没有带不确定度的量来表达模型在负载单位下的极限。作者提出的测量工具让负载由替换文本中单 token 虚词的规则构成：指令是原子的，规则因任务构造而相互独立，每次应用规则的结果都由可计算参考答案确定。每个待替换词的出现成为一次伯努利试验，位置与规则编号已知。统计模型先测量正确替换概率对文本长度、词位置、替换密度、规则数与规则编号的依赖形状，再用平滑律描述并恢复与编码选择无关的参考水平，最终给出在给定正确率下可保持的规则数即指令容量及其不确定度。对 GPT-4o mini 的测量（2958 次请求、642430 次试验）显示各负载因子下规律稳定，正确率 0.95 时容量约 37 至 38 条规则，满替换密度下约 18 至 19 条。
  - 重要性：★★★★★ / 5
  - 来源：[HuggingFace Papers](https://huggingface.co/papers/2610.36095)

- **第三方评测 DeepSeek V4.1 Flash-1017 的失控与有害操纵风险**：闭源模型发布常附系统卡，开放权重模型在前沿风险上受审视较少。作者依据 EU General-Purpose AI Code of Practice，对 DeepSeek V4.1 Flash-1017 做独立安全评测，该版本相对 V4 换了新架构、扩大训练规模并具备强 agent 能力。评测覆盖 34 个基准，含 5 个自建套件，横跨评测完整性、失控与有害操纵，按 AEF-1 标准与 V4.1 Flash、更早的 V4 系列以及 GPT-6 Astra、GPT-5.6 Sol、Gemini 3.8 Flash 对比。总体看 V4.1 Flash-1017 相对 V4 代有实质安全改进，在若干维度接近或匹配领先闭源基线，但仍表现出值得持续关注的行为。作者给出三点建议，包括把安全评测纳入增量发布，因为安全表现会在小版本更新中漂移甚至回退。
  - 重要性：★★★★★ / 5
  - 来源：[HuggingFace Papers](https://huggingface.co/papers/2610.35671)

- **RealCLI：统一评测 CLI agent 的任务执行与人机协作质量**：CLI agent 正承担更长程的任务，但现有基准要么假设用户指令在整个执行过程中不变，要么只看任务结果而不衡量运行时协作质量。RealCLI 是成对基准，同时评测真实 CLI 任务上的执行效果与协作质量，其五维协作框架细化为 22 个子维度和 51 个交互场景模板。它提供两种配对模式：REALCLI-EXEC 一次性给出完整规格，REALCLI-COLLAB 引入脚本化用户，逐步提供信息、纠正、约束修订与授权决策。评测暴露前沿 agent 的明显能力缺口：最佳配置平均分仅 49.2%，联合协作分 J_collab 峰值只有 37.6%。任务有效性与协作质量明显背离，模型在可引导性、信任校准和安全边界管理上持续吃力，说明只看任务完成率会高估 agent 的可用性。
  - 重要性：★★★★★ / 5
  - 来源：[HuggingFace Papers](https://huggingface.co/papers/2610.22507)

- **LongZero：不依赖任何外部数据提升长上下文推理**：强化学习能增强长上下文推理，但需要长、多样、有挑战且可验证的训练数据。人工标注昂贵，自然数据不足以支撑 RL，现有合成方法依赖外部语料或更强教师模型，而随着被训练模型变强，这些资源越来越难获得。LongZero 让模型从自身提出的任务中学习：先以紧凑结构化形式合成问题、答案及其支撑证据，再把证据单独扩展成长篇多文档上下文，从而避免直接在现有文档上出题。方法把自写的多跳推理任务与自写多轮检索任务结合，用 GRPO 训练。在两个模型、五个长上下文推理基准上，LongZero 可泛化到真实任务，并优于基于外部语料合成数据的 RL 基线，为无外部数据的长上下文推理改进提供了可行路径。
