## 🗞 AI 行业动态

- **OpenAI 发布新版 Model Spec，围绕五项核心价值重构行为准则**：OpenAI 更新了 Model Spec，将 AI 行为准则围绕五项核心价值重新组织，其中包括对人类意图的忠实（faithfulness to human intent）与可纠正性（correctability）。新规范要求 GPT 系列模型主动利用对话历史推断用户的真实意图，并披露自身所做的假设，而不是机械地按字面执行指令。The Decoder 的报道指出，这些规则针对的正是此前已被证明难以控制的模型行为，但模型是否真正遵守规范仍是另一回事。对开发者而言，这意味着系统提示词与产品逻辑需要重新对齐：依赖模型「照字面执行」的旧工作流可能出现行为漂移，而利用对话上下文推断意图的能力提升，也为多轮任务型 Agent 提供了更好的基础。OpenAI 同时发布了官方博文说明此次修订，两份材料可对照阅读以理解规范的具体变化。
  - 重要性：★★★★★ / 5
  - 来源：[OpenAI](https://openai.com/index/updated-model-spec)

- **OpenAI 公布前沿模型失准检测方法，采用分层监控提前干预**：OpenAI 发布文章介绍其如何检测前沿模型失准（misalignment）与未经授权的 Agent 行为。核心做法是分层监控（layered monitoring）：在不同层级上部署检测手段，使响应团队能够在事件升级之前介入处置。这一披露的背景是前沿模型的自主性与工具使用能力持续增强，Agent 一旦出现目标偏离或越权操作，后果可能难以回滚。对构建 Agent 产品的团队来说，这套思路的价值在于把「事后审计」前移为「运行中拦截」，即监控不应只作为日志系统存在，而应具备触发干预的能力。OpenAI 未在摘要中给出具体检测指标或误报率数据，但分层设计本身提示了一种工程取向：单一检测器难以覆盖全部风险面，需要组合多种信号并明确各层的响应权限。
  - 重要性：★★★★★ / 5
  - 来源：[OpenAI](https://openai.com/index/how-we-detect-frontier-model-misalignment)

- **OpenAI 与 Anthropic 同步推出订阅额度兑换 API credits 的福利**：继 Anthropic 本月早些时候为 Max 与 Team 订阅用户推出 API 额度福利后，OpenAI 上线了几乎相同的方案。按 Simon Willison 的记录，两家的规则一致：月付 100 美元、200 美元、500 美元档位的订阅用户，可获得等额、带有效期的 API credits，用于其名下的某个 API organization。Anthropic 的原方案覆盖 100、200、500 美元三档。这意味着高频使用 API 的开发者可以把订阅费直接转化为调用额度，而不必重复付费；对同时持有两家订阅的用户，等于两份额度都能落到实际开发中。Willison 表示自己正好同时订阅了两家，并称有了这些额度覆盖，他可能会发布一些面向公众的 demo。这一动作也反映出两家在开发者留存上的正面竞争正在从模型能力延伸到计费结构。

- **OpenAI、Google、Microsoft、Anthropic 共同采纳出版商 AI 抓取退出新标准**：据 The Verge 援引 Search Engine Roundtable 的报道，OpenAI、Google、Microsoft 与 Anthropic 表示将采纳一项新标准，允许出版商选择退出被 AI 抓取。关键设计是共享的 policy token 信号：出版商只需设置一次 AI 训练偏好，即可跨多家 AI 公司生效，而不必逐家单独配置。这解决了此前 robots.txt 式退出机制碎片化的问题——各家爬虫规则不一，出版商维护成本高且难以验证。对 AI 公司而言，统一信号降低了合规摩擦；对内容方而言，这是把训练数据授权从双边谈判推向标准化基础设施的一步。目前尚不清楚该 token 是否具备法律约束力，以及未遵守者的处理机制，但四家主要厂商同时表态，已使这一标准具备事实上的行业基线地位。

- **Anthropic 研究：专家会采纳 AI Agent 随机生成的观点并误认为是自己的判断**：Anthropic 开展了一项实验，给 50 名专家配备一个 AI Agent，其偏好设置由抛硬币随机决定。结果显示，在需要判断的场合，专家跟随 Agent 观点的比例最高达 86%，且大多数人相信这些结论出自自己的判断。这一发现对 Agent 产品的设计与评估有直接影响：当 Agent 以自信语气给出建议时，人类监督可能退化为形式上的确认，所谓 human-in-the-loop 的独立性被削弱。对把 Agent 用于分析、评审、决策支持场景的团队，这意味着需要引入盲评、对照或强制记录理由等机制，避免模型偏好被无声地吸收为组织结论。研究同时提示，Agent 的「随机」立场也能被高效放大，说明影响力来源更多是表达形式而非内容质量。

## 📄 学术论文研究动态

- **EPSBench 用 149 个公司季度检验 LLM 智能体盈利预测**：研究团队发布 EPSBench，覆盖 86 家美国公司的 149 个公司-季度，智能体需读取固定财报、电话会记录与新闻集合，给出带证据引用的利润表驱动项估计，再由统一的会计计算器换算为 GAAP 摊薄每股收益。在统一测试框架下评测六个模型，其中三个模型的点预测误差与同日分析师一致预期无可检测的配对差异，另三个误差更高；六个模型名义 80% 预测区间实际仅覆盖 37% 至 70% 的报告 EPS，且多数未命中落在上界之上，说明预测系统性偏低。驱动项记录显示，模型间误差差距主要来自营业收入估计。对做金融智能体的团队而言，这说明当前瓶颈不在信息获取而在会计驱动项建模与不确定性校准。
  - 重要性：★★★★★ / 5
  - 来源：[HuggingFace Papers](https://huggingface.co/papers/2610.38293)

- **WISD：用「弱化版自己」做在线自蒸馏，无需特权信息**：针对自蒸馏依赖特权信息构造更强教师的问题，论文提出 Weakening-Induced On-Policy Self-Distillation，反向构造原模型的弱化副本，用两者对比作为训练信号，弱化方式包括低比特量化和幅度剪枝。在数学与代码推理任务上跨多种架构和规模验证，量化与剪枝分别带来平均 4.0 和 5.5 个百分点的准确率提升。具体地，剪枝让 Qwen3.5-4B 在 HMMT 2025 上从 57.7% 升至 70.5%、LiveCodeBench v6 上从 39.1% 升至 56.7%；量化让 Qwen3.6-35B-A3B 在同一基准上从 68.5% 升至 74.6%、从 61.8% 升至 69.5%。这条路线把「弱模型」当作可复用的监督来源，为只有无标注 prompt 的场景提供了可行替代。
  - 重要性：★★★★★ / 5
  - 来源：[HuggingFace Papers](https://huggingface.co/papers/2610.38681)

- **把预训练自回归图像模型改造成任意顺序生成器**：自回归图像生成器用固定光栅扫描顺序训练，推理时无法做 inpainting、outpainting 或编辑；现有方案从零训练混合顺序，算力约为标准训练的 3 倍，且离散扩散牺牲了 KV 缓存、vLLM 等 AR 推理生态兼容性。论文主张这一成本不必要，提出用 future-aware positional embeddings 解决目标位置可识别性问题，再配合顺序课程，把预训练光栅模型迁移为任意顺序生成器。在 LlamaGen-L/XL 与 RAR-L/XL 四个基座上，ImageNet inpainting FID 为 6.21，显著优于 MaskGIT 的 10.44，outpainting 同样占优，与 MAR-L 相当，代价是类别条件 FID 上升 1.2 至 1.9，额外算力 13% 至 33%。对已有 AR 图像栈的团队，这是一条低成本获得编辑能力的路径。
  - 重要性：★★★★★ / 5
  - 来源：[HuggingFace Papers](https://huggingface.co/papers/2610.39293)

- **MICA 研究：能力相同，MCP 与 CLI 接口仍显著改变智能体行为**：论文提出 Matched Interface Comparison and Analysis，从共享语义动作契约渲染 MCP 与 CLI 两种接口，并把解码动作路由到同一运行时，从而在可执行能力对齐的前提下比较表示差异。在六个模型、三个交互环境中，匹配接口仍产生显著的任务表现与交互成本差异，影响延伸到语义动作选择、失败路径与恢复行为。配对自然轨迹显示，2004 个回合中 94.3% 出现结构化分歧，且早期差异会沿后续交互传播。作者据此提出 DART，在保留已验证语义承诺的同时修复接口特定的实现方式，在全部六个设置中最高提升 9.0 分。结论是接口实现本身就是可直接干预的边界，工具设计不应被视为中性包装。
  - 重要性：★★★★★ / 5
  - 来源：[HuggingFace Papers](https://huggingface.co/papers/2610.34298)

- **公共模型库里的量化 LLM 存在「到手即坏」的失效文件**：作者检查的注册库均未记录对文件的功能测试。他们测试 Ollama 官方库中 15 个模型线共 305 个可用代码的 GGUF 标签，外加 22 个热门 Hugging Face 社区文件：15 题代码筛查找出可疑项，再在全部 164 个 HumanEval+ 任务上复测，7 个官方标签（2.3%）最多只解出 6 题，全部是参数量不超过 40 亿模型的低比特量化。重建的 5 个可疑文件与原权重逐张量一致，说明文件未损坏，精确可复现并不等于可用；在权重、工具链与张量组合固定时，加入 importance matrix 让三个 Qwen2.5-Coder-3B 构建从 0 题升至 76 至 113 题，而同样的未校准配方对更小的 1.5B 版本仍可用。66 个通过筛查的标签无一失效。团队发布审计数据与 quantcheck 工具，建议发布前筛查低比特标签。
  - 重要性：★★★★★ / 5
  - 来源：[HuggingFace Papers](https://huggingface.co/papers/2609.05881)

- **统一训练：把预训练、SFT 与 RL 收进同一个似然算法**：论文指出基础模型的分阶段训练并非本质必要，通过把合适的 RL 目标推导为对模型生成目标分布的最大似然拟合，可将预训练、midtraining、SFT 与 RL 全部置于单一 likelihood-based 训练算法之下，传统分阶段训练成为特例。作者实现了一个在单一训练器内混合静态数据与 RL 生成的统一训练系统。在受控与真实实验中，统一训练改善了准确率与算力的权衡和任务覆盖，同时保留更广泛能力，并为持续学习提供更好的起点。其意义在于把训练生命周期问题转化为「选什么数据、按什么比例、在何时训练」的问题，为训练科学与基础设施的协同设计提供了统一框架。
