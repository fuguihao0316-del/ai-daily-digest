## 📄 学术论文研究动态

- **EPSBench 用 149 个公司季度检验 LLM 盈利预测**：EPSBench 从 86 家美国公司取 149 个 firm-quarter，让 agent 阅读固定集合的财报、电话会记录与新闻，估计公司特定的利润表驱动项并给出引用证据，再由统一的会计计算器换算为 GAAP 摊薄每股收益，从而把不同模型的预测假设放到同一基准上比较。在统一 harness 下评测六个模型，对照同日期的分析师一致预期：三个模型的点预测误差与一致预期无可检测的配对差异，另外三个误差更高。更值得警惕的是不确定性校准——六个模型的名义 80% 区间只在 37% 到 70% 的运行中覆盖实际 EPS，且多数失准发生在区间上界之外，说明预测系统性偏低。驱动项记录显示，模型间误差差距主要来自对营业利润的估计。
  - 重要性：★★★★★ / 5
  - 来源：[HuggingFace Papers](https://huggingface.co/papers/2610.38293)

- **WISD 用「弱化版自己」当教师，无需特权信息做自蒸馏**：常见自蒸馏依赖特权信息构造更强的 self-teacher，在只有无标注 prompt 时不可用。WISD 反其道而行，用低比特量化或幅度剪枝构造原模型的弱化副本，以强弱对比作为训练信号。在数学与代码推理任务上跨架构、跨规模验证：量化与剪枝分别把平均准确率提升 4.0 和 5.5 个百分点。具体地，剪枝把 Qwen3.5-4B 在 HMMT 2025 上从 57.7% 提到 70.5%，LiveCodeBench v6 从 39.1% 提到 56.7%；量化把 Qwen3.6-35B-A3B 从 68.5% 提到 74.6%、从 61.8% 提到 69.5%。作者称即使没有特权信息也达到 state-of-the-art，为推理模型提供了一条低成本的自我提升路径。
  - 重要性：★★★★★ / 5
  - 来源：[HuggingFace Papers](https://huggingface.co/papers/2610.38681)

- **把预训练自回归图像模型改造成任意顺序生成器**：栅格扫描顺序训练把图像分布固定为单一因子分解，模型因此无法在推理时做 inpaint、outpaint 或编辑；现有离散扩散方案需从零训练混合顺序，算力约为标准训练的 3 倍，还牺牲 KV caching、vLLM 等自回归推理生态。作者主张预训练模型已学到联合分布，缺的只是非顺序条件通路，于是提出 future-aware positional embeddings 解决目标位置可辨识问题，配合 ordering curriculum 从预训练解稳定过渡到任意顺序解。在 LlamaGen-L/XL 与 RAR-L/XL 四个模型上，ImageNet inpainting FID 为 6.21，优于 MaskGIT 的 10.44，outpainting 同样领先，与 MAR-L 相当，代价是类条件 FID 上升 1.2 到 1.9，额外算力 13% 到 33%。
  - 重要性：★★★★★ / 5
  - 来源：[HuggingFace Papers](https://huggingface.co/papers/2610.39293)

- **MCP 与 CLI 能力相同，agent 行为却大不同**：论文提出 MICA，从共享的语义动作契约同时渲染 MCP 与 CLI 两种接口，并把解码出的动作送入同一运行时，从而在可执行能力完全匹配的前提下比较表示差异。在六个模型、三个交互环境中，匹配接口仍带来显著的任务表现与交互成本差异，且影响深入语义动作选择、失败路径与恢复过程。配对自然轨迹显示，2004 个 episode 中有 94.3% 出现结构性分歧，早期差异会沿后续交互传播。匹配状态探针把敏感来源定位到能力呈现、实现方式与反馈。作者据此提出 DART，在保留已验证语义承诺的同时修复接口特定实现，在全部六个设置中最高提升 9.0 分。

- **公共仓库里的量化 LLM 存在「到货即坏」**：作者检查的注册库均未记录对文件的功能测试，于是实测 Ollama 官方库中 15 个模型线的全部 305 个可用 GGUF 标签，外加 22 个 Hugging Face 社区热门文件。15 项代码筛查筛出可疑项，再在全部 164 个 HumanEval+ 任务上复测：7 个官方标签（2.3%）最多只解出 6 题，全部是参数量不超过 40 亿的模型的低比特量化。从原始权重重建 5 个可疑文件后，与仓库文件逐张量一致，说明并非文件损坏，精确可复现不等于功能可用。固定权重、工具链与张量混合后加入 importance matrix，可把三个 Qwen2.5-Coder-3B 构建从 0 题提升到 76 至 113 题。作者发布审计数据与 quantcheck 工具，建议低比特标签发布前先筛查。

- **用一个算法统一预训练、中期训练、SFT 与 RL**：基础模型通常分阶段训练，数据与学习算法都随之切换。作者把各阶段的 RL 目标推导为对模型自生成目标分布的最大似然拟合，从而将全流程纳入单一 likelihood-based 训练算法 unified training，把生命周期的核心问题变成选什么数据、按什么比例、在何时训练，传统分阶段训练只是其特例。作者实现了在单一 trainer 内混合静态数据与 RL 生成的系统。在受控与真实实验中，统一训练改善了准确率与算力的权衡和任务覆盖，同时保留更广泛能力，并为持续学习提供更好的起点。这一视角把数学原理、训练基础设施与能力发展串到同一框架下。

- **ABF-Bench 把链上资金追踪变成可验证的 agent 任务**：区块链取证是开放且对抗性的：洗钱者拆分、兑换、跨桥转移资金，在 mixer 或托管服务处断链，手法逐案变化；但公共账本的不可篡改性让每笔记录可被独立核验。ABF-Bench 要求 agent 对每一条声称的资金流动引用其检索到的账本记录。case-to-task 流水线用保守规则在记录无法延续处停止追踪，并以这些规则确定的参考图作为答案。任务取自真实洗钱活动，涵盖多跳转账、DeFi 兑换、跨链往返、托管与 mixer 存款、地址投毒。配套的 ABF harness 以工作记忆为核心，达到 75% 边召回，同模型下 Codex 为 47%，Claude Code 仅 10%，后者因过度自信引用未检索记录而损失召回。

  - 来源：[HuggingFace Papers](https://huggingface.co/papers/2610.23656)

- **把 Platonic Representation Hypothesis 变成定理**：论文证明，分别在任意数量模态上训练的 Joint-Embedding Predictive Architectures，只要正样本对是同一场景的两次观测（good views），学到的表示就相差一个旋转；错配受限时亦然。作者进一步指出 next-token prediction 是使用 bad views（同一文档的片段）的 JEPA，这解释了语言模型为何只能靠规模与视觉对齐。实证从 14.5 万条 caption 扩展到 9.4 亿网络图像的文本，并给出可在种子噪声内预测未跑实验的对齐 scaling law：达到同等对齐，good views 所需样本比 next-token prediction 少 42 倍；1.09 亿参数的文本 JEPA 对齐 DINOv2 与 CLIP 图像编码器的效果，优于所有评测过的语言模型（最大 720 亿参数）乃至 CLIP 文本编码器。
  - 重要性：★★★★★ / 5
  - 来源：[HuggingFace Papers](https://huggingface.co/papers/2610.39302)
