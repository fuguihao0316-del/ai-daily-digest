- **微软开源 TokenEconomizer，把 coding agent 成本最高降 30.9%**：Microsoft Research 与 UC Berkeley 联合发布开源插件 TokenEconomizer，它从历史会话中学习，在 SWE-Bench 上把 coding agent 的 token 成本降低 18.4% 至 30.9%，且不需要对 agent 本身做任何改动。这个"零侵入"特性是它最实用的地方：团队无需重写 prompt 或更换框架，只需在现有管线上挂载插件即可见效。对大规模跑 agent 的团队来说，成本下降近三成意味着同样的预算可以支撑更多并行任务或更长上下文，也意味着此前因成本被判定不划算的批量重构、全仓扫描类任务重新变得可行。开源发布则让这套学习机制可以被审计和移植到其他 agent 框架。

- **OpenAI 披露前沿模型失准的检测方法**：OpenAI 发文介绍其分层监控体系，用于检测前沿模型的失准（misalignment）以及 agent 的未授权行为，目标是让响应人员在事件升级前介入。分层监控的核心思路是不依赖单一信号：不同层级的监测覆盖模型输出、行为轨迹与系统侧异常，形成交叉验证。对部署 agent 的团队来说，这套框架的可借鉴之处在于把"检测失准"从一次性的离线评测，转变为持续运行时的观测能力——因为 agent 在长任务中偏离目标往往是渐进的。OpenAI 并未在摘要中给出具体指标或误报率，实际效果仍需结合其后续的安全报告评估。

- **单张 RTX 3090 Ti 跑 552B MoE 模型，解码约 35 tok/s**：一位用户在 r/LocalLLaMA 分享了六年老硬件的本地推理配置：AMD Ryzen Threadripper 3990X、128GB DDR4、单张 RTX 3090 Ti（24GB 显存），运行 DeepSeek-V4.1-Flash-1017（552B MoE，40 层、每层 384 个专家、约 39B 激活参数）达到约 35 tok/s 解码，运行 Qwen3.8-Flash-Next（125B MoE + 51B N-gram，约 3.5B 激活）达到约 138–140 tok/s。关键手段是把专家权重和 KV 缓存放到 NVMe，配合 XQ/GSQ 量化与 FP4 KV。帖中称消费级 Ampere 卡（GA102、GA104）存在人为的 FP16/BF16 矩阵运算固件限速。这类配置说明 MoE 架构让大模型本地部署的门槛显著下移，瓶颈正从显存容量转向存储带宽与调度效率。

## 📄 学术论文研究动态

- **EPSBench 用 149 个公司季度检验 LLM 盈利预测能力**：研究团队提出 EPSBench，覆盖 86 家美国公司的 149 个公司季度，要求智能体在固定的一组财报、电话会议记录与新闻中估计利润表驱动项并附引用证据，再由统一的会计计算器折算为 GAAP 稀释每股收益。六个模型在同一测试框架下评测，三个模型的点预测误差与同日分析师一致预期无显著配对差异，另三个误差更高；六个模型的名义 80% 区间实际仅覆盖 37% 至 70% 的报告 EPS，且多数漏在区间上界之外，说明预测系统性偏低。误差差距主要来自对营业利润的估计。
  - 重要性：★★★★★ / 5
  - 来源：[HuggingFace Papers](https://huggingface.co/papers/2610.38293)

- **WISD 用「弱化版自身」当教师，无需特权信息做自蒸馏**：论文提出 Weakening-Induced On-Policy Self-Distillation，不依赖外部教师或特权信息，而是用低比特量化与幅度剪枝构造原模型的较弱副本，以强弱对比作为训练信号。在数学与代码推理任务上，量化与剪枝两种构造方式分别把平均准确率提升 4.0 与 5.5 个百分点。剪枝使 Qwen3.5-4B 在 HMMT 2025 上从 57.7% 升至 70.5%、LiveCodeBench v6 上从 39.1% 升至 56.7%；量化使 Qwen3.6-35B-A3B 在这两项上从 68.5% 升至 74.6%、从 61.8% 升至 69.5%。这为只有无标注提示词时提升推理模型提供了可行路径。
  - 重要性：★★★★★ / 5
  - 来源：[HuggingFace Papers](https://huggingface.co/papers/2610.38681)

- **把预训练栅格序自回归图像模型改造成任意顺序生成器**：论文指出栅格序训练把单一分解顺序硬编码进模型，导致无法在推理时做补全、外扩或编辑，而离散扩散类方案需从零训练、算力约为标准栅格训练的 3 倍，还牺牲 KV 缓存与 vLLM 兼容性。作者提出由未来感知位置嵌入与顺序课程组成的两步改造配方，在 LlamaGen-L/XL 与 RAR-L/XL 四个基座上验证：ImageNet 补全 FID 为 6.21，优于 MaskGIT 的 10.44，外扩任务同样领先，与 MAR-L 相当，代价是类条件 FID 上升 1.2 至 1.9，额外算力 13% 至 33%。这意味已有自回归权重可低成本获得编辑能力。
  - 重要性：★★★★★ / 5
  - 来源：[HuggingFace Papers](https://huggingface.co/papers/2610.39293)

- **MCP 与 CLI 能力对齐后行为仍显著分化，DART 最多提升 9 分**：论文提出 MICA 方法，从共享语义动作契约同时渲染 MCP 与 CLI 接口，并让解码动作走同一运行时，从而在可执行能力匹配的前提下比较表示差异。在六个模型、三个交互环境上，匹配接口仍带来任务表现与交互成本的显著差异，影响延伸到语义动作选择、失败路径与恢复；2,004 个配对自然轨迹中 94.3% 出现结构性分歧，早期差异会沿后续交互传播。作者据此提出 DART，在保留已验证语义承诺的同时修复接口相关实现，六个设置基准分全部提升，最多 9.0 分。
