## 📄 学术论文研究动态

- **Tools Need Not Speak in Text：用隐空间压缩工具观测，Agent token 消耗降 70%-89%**：清华团队提出 Coca-Cola，把 Agent 的工具返回结果从原始文本 token 压缩成隐空间 token，直接嵌入模型输入嵌入空间，避免多步交互中冗长噪声观测稀释注意力。配套的 Action-Preserving Training 让 Agent 在全量观测与压缩观测下的下一步动作分布对齐，从而学到保留决策关键信息的「动作充分」隐 token。在四个 QA 基准、两类模型家族的网络搜索 Agent 实验中，token 消耗下降 70.01%-89.24%，端到端运行时间缩短 24.45%-55.97%，任务表现还同步提升。这打破了「Agent 必须以显式文本消费工具输出」的默认假设，对长程工具调用链的成本控制有直接参考价值。
  - 重要性：★★★★★ / 5
  - 来源：[HuggingFace Papers](https://huggingface.co/papers/2611.06500)

- **SwarmEvolve：数百个低成本 Agent 在隐空间成群进化，3-8 分钟追平他人 60 分钟成绩**：LLM 引导的进化搜索每轮都要生成冗长文本思维链，速度慢且需重复生成以维持种群多样性。SwarmEvolve 让每轮数百个低成本 Agent 组成群体，在隐空间推理、不解码为文本，通过传递 KV cache 共享信息；每个群体从不同角度研究问题，新颖性过滤器直接度量隐状态向量距离保留最独特想法，汇总 Agent 接收全部 KV cache 实现隐空间交叉。在 21 个数学发现与科学计算问题上，它取得最高平均分，且中位仅需 3 至 8 分钟即可达到其他 SOTA 框架 60 分钟的最好成绩；在部分问题上，Qwen3 8B 驱动的 SwarmEvolve 改进了 AlphaEvolve 用前沿 LLM 首次找到的解。
  - 重要性：★★★★★ / 5
  - 来源：[HuggingFace Papers, arXiv](https://huggingface.co/papers/2611.08483)

- **OpenFrontiers：12,151 条开放研究问题 + 200 题回溯基准，闭卷重发现最多仅 7/40**：现有 LLM 研究级问题求解缺少系统化题目集合与可靠评测。OpenFrontiers 构建跨学科资源：语料库记录 12,151 个开放问题的陈述、背景与进展；基准含 200 题，其中 110 题于 2026 年被解决、90 题仍开放，每题配经自动探针与两次独立评审的 Lean 4 陈述，HQ-50 子集再按质量分筛选。评测协议在隔离沙箱中用两个独立检查器、在闭卷/冻结检索/实时联网三种条件下评分。七个 LLM Agent 在标准化预算下跑 HQ-50，闭卷重发现极少，40 题中最多解出 7 题；联网成功则多反映检索到已发表解。这为「研究级重发现」提供了可形式化评分的标尺。
  - 重要性：★★★★★ / 5
  - 来源：[HuggingFace Papers](https://huggingface.co/papers/2610.37739)

- **Scientist World：把每篇论文变成可执行环境，前沿 AI-Scientist 74% 超越原作者**：AI-Scientist 已出现，但缺少可供其成长的世界。Scientist World 用自主流水线把每篇论文的开放研究问题抽出、并将其提出的方法复现为基线，AI-Scientist 进入环境后与人类作者的实际成果对比。首批发布 1,000 个已验证环境，以此作为评测发现前沿 AI-Scientist 已有 74% 的概率超越人类研究者；同时积累 6,400 小时研究轨迹，记录每个想法、实验、失败与成功。作为训练场，它能把小模型在研究构思上提升 158%，追平前沿模型。这意味着科研 Agent 的评测正从静态问答转向可运行、可对比的论文级环境。
  - 重要性：★★★★★ / 5
  - 来源：[arXiv](https://arxiv.org/abs/2611.08478v1)

- **StepX-OPD：合并多教师蒸馏与步数蒸馏，四步扩散模型反超四十步 Flow-OPD**：可部署的文生图扩散模型需同时具备指令跟随、文字渲染、人类偏好等能力并少步采样，但现有流程分两阶段串行：先多教师 on-policy 蒸馏整合能力，再以固定教师做步数蒸馏，且每个全步模型压缩后分数都会下降。StepX-OPD 把两阶段合并，让学生在一次训练中同时获得能力与少步采样，冻结专家在学生自身 rollout 访问的状态上监督，而非其从未运行的长轨迹。作者还发现能力整合会让模型在未要求文字的 prompt 上把提示词写进图像，并给出降低该问题的变体。在 SD3.5-Medium 与 FLUX.1-dev 上，其四步方法归一化平均分最高并超过四十步 Flow-OPD，SD3.5-Medium 上比串行 DiffusionOPD 少约 37% GPU 小时。
  - 重要性：★★★★★ / 5
  - 来源：[HuggingFace Papers](https://huggingface.co/papers/2611.04386)

- **Identically Trained Language Models Break on Different Jailbreaks：越狱脆弱性主要由预训练随机种子决定**：越狱基准通常只测一个 checkpoint，并把哪些越狱能攻破它当作预训练数据与安全训练的属性。该工作对 25 种预训练数据配方各取 3 个预训练种子得到 1B 基座模型，再各做 2 个种子的相同安全后训练，共 150 个模型，对共享越狱 prompt 各收集 20 条回复并计算逐 prompt 拒答率相关性。同一预训练运行的两个后训练副本相关性达 0.984；换预训练种子降至 0.811，换数据配方仅再降至 0.779，该模式在全部 25 种配方及 150M、300M 参数上成立。一个 checkpoint 上找到的 91 个攻击模板中最优者，换预训练种子后仅在 27% 模型对中仍最优，换后训练种子则为 67%。预训练运行还留下指纹：3,211 个 prompt 的逐 prompt 拒答率可 100% 识别其预训练运行，随机 50 个 prompt 仍有 98% 准确率。
