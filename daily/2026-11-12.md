## 📄 学术论文研究动态

- **Deletion Tuning：只删 0.05% 权重即可媲美全参微调**：论文提出 Deletion Tuning，在 transformer 各层 gate projection 上学习一个二值掩码，通过将不到 0.05% 的权重置零来获得新能力，在 RLVR、监督微调与 on-policy 蒸馏三种后训练范式下均与全量微调（FFT）持平。两个直接收益：训练得到的掩码比对应 FFT checkpoint 小数百到数千倍；灾难性遗忘显著减轻，在强化学习设置下其先验任务准确率保持在基座水平附近，而 FFT、LoRA 与随机稀疏微调最多掉 5.4 分。作者用 stable rank、谱漂移与主权重重叠度分析 RL 下权重变化的几何结构，发现 Deletion Tuning 在三项指标上都最接近 FFT，为「掩码为何足够」提供了机制解释。对做后训练与持续学习的团队而言，这意味着更新载体可以极小，且可把「保留旧能力」从调参问题变成结构约束。
  - 重要性：★★★★★ / 5
  - 来源：[HuggingFace Papers](https://huggingface.co/papers/2611.10866)

- **Embodied First Exam：给编码智能体的具身第一考，最强仅 34%**：论文指出既有机器人基准围绕视觉运动策略学习构建，未回答编码智能体能否在物理约束下可靠控制多样机器人，因此提出 Embodied First Exam，一个允许智能体自选控制方式（直接控制、写代码控制、训练策略控制）的智能体原生评测框架。规模为 47 台机器人、35 个套件、1,156 个任务，其中 9 个新套件超出抓取放置范畴，覆盖空间谜题、灵巧操作、多机器人交互、动态全身控制与 sim-to-sim 工程；每个任务最多可在三种设置下运行，Standard 设置只给传感器观测且默认不可重置环境，Realtime 变体在智能体推理时保持环境运行，Privileged 设置开放完整模拟器状态与无限重置以逼近上界。在 456 个核心任务上，八个智能体中最强的 GPT-6 Astra（运行于 Codex）Standard 成功率仅 34%。
  - 重要性：★★★★★ / 5
  - 来源：[HuggingFace Papers](https://huggingface.co/papers/2611.12177)

- **RoboRisk 与 LEASH：基础模型控机器人的安全缺口与拦截方案**：论文发现用 GPT、Claude 等基础模型控制机器人存在严重安全风险，而全面安全评测仍缺失，于是提出 RoboRisk 基准，含 92 个模拟任务与 13 个真机任务，分为任务级拒答、计划修复、执行期危害、注入、序列记忆五类；此前基准最多覆盖其中两类，部分只评文本输出，而 RoboRisk 五类全覆盖且每个任务闭环执行。作者评测 GPT-6 Astra、GPT-6.1 Sol、GPT-6 Luna、Claude Opus 5.5、Gemini 4 Argon、Grok 4.7 六个前沿模型，普遍呈现高危害率，另评测 Dream API 与 PokeBot 的 RoboAPI 两个机器人专用接口。为此提出 Lease-Enforced Agentic Safety Harness（LEASH），借助决策模型（Jev 或 OpenAI 的 Decisions API）实现任务、动作与提交三道闸门，在视觉上下文中审查任务、每个动作及每个不可逆操作，可接入几乎任何智能体架构。
  - 重要性：★★★★★ / 5
  - 来源：[HuggingFace Papers](https://huggingface.co/papers/2611.14115)

- **Sable：单卡 92.5 秒为 32B 模型 4096 token 推理生成逐位证明**：论文提出 Sable，一个论证系统与单 GPU 证明者，用于证明某个已承诺的整数量化 transformer 从给定 prompt 逐位生成了给定 token 序列。Sable 固定一个不含浮点步骤的整数函数 F_O，使每次舍入、归一化、softmax 与采样决策都由输入唯一确定，并用约束系统证明其关系在 31 位 KoalaBear 素数下可证不发散；证明把 zerocheck 与 LogUp-GKR 查找按域批处理为单次 sumcheck，并用基于 Reed-Solomon 码、BLAKE3 Merkle 树与混合长度 BaseFold 打开的多线性承诺承诺全部见证张量与权重。单张 NVIDIA RTX PRO 6000 Blackwell 上，Qwen2.5-32B 全部 64 层、4,096 token 用时 92.5 秒，16,384 token 用时 398 秒，并覆盖 Qwen3-32B 与 MoE 的 Qwen3-30B-A3B。证明开销为服务耗时的 41 至 50 倍，按公开 GPU 价格约每 4,096 token 请求 6.4 美分；验证端单 CPU 核 19 至 56 秒完成校验。
  - 重要性：★★★★★ / 5
  - 来源：[HuggingFace Papers](https://huggingface.co/papers/2611.14083)

- **等算力协议推翻稠密奖励结论：Monte-Carlo 过程奖励反落后 GRPO 14.3 分**：论文指出 RLVR 中 GRPO 给解答的每个 token 相同信用，稠密过程奖励（如从中间步骤采样续写打分的 Monte-Carlo 奖励）被提出来给中间步骤分配信用，但以往比较按每次更新或单批次梯度检验，忽略了成本——在其设置中续写本身占全部生成 token 的 91%。作者提出匹配算力协议，以生成 token 数与训练 GPU 小时数为预算，在预注册研究中对六模型共 1,668 次运行做对照。结果算力对齐后排序反转：Qwen2.5-1.5B 上 Monte-Carlo 奖励每次更新领先标准 GRPO，但等 token 预算下最终低 14.3 个百分点、等训练时间下低 7.8 个百分点，四种稠密奖励变体无一在同等训练时间下胜过 GRPO；逐 token 梯度检验的排序与训练一致，但把每种奖励高估 1 至 2 分。相反，选择预测成功率最接近 1/2 的 prompt 训练在匹配算力下提升准确率，Qwen3-0.6B 上 +1.7 分、Qwen2.5-1.5B 上 +0.8 分。
  - 重要性：★★★★★ / 5
  - 来源：[HuggingFace Papers](https://huggingface.co/papers/2611.13560)

- **LO-World：共享 BEV 潜空间统一 4D 占据与 LiDAR 预测**：论文指出 LiDAR 点云与 3D 语义占据分别刻画精细度量几何与稠密体素语义，天然互补，但现有世界模型通常独立预测二者或启发式级联，错失跨模态互正则的机会。为此提出 LO-World，一个在共享 BEV 潜空间内同时预测两种模态的统一 4D 世界模型，单流公式让稠密语义与度量几何相互增强，同时消除多管线冗余。具体设计将高效混合 range-voxel 自编码器与 flow-matching 生成器耦合，后者缓存历史上下文以降低迭代采样延迟。实验显示 LO-World 优于此前 SOTA 基线，占据预测 IoU 提升 10.9%，LiDAR Chamfer Distance 降低 30.1%，同时在单张 RTX 4090 上保持超过 25 FPS 的实时吞吐。代码已开源。对自动驾驶世界模型而言，这提供了一条以统一潜空间替代多阶段管线的可行路线。
  - 重要性：★★★★★ / 5
  - 来源：[HuggingFace Papers](https://huggingface.co/papers/2611.11912)

- **Tree-Ising：把权重修复写成逐行 QUBO，MATH-500 上 54.6% 反超智能体编辑**：论文承接 MIT Take 等人的权重空间编程工作——GPT-6 Astra 智能体无梯度读取网络权重并写入修复，纠正 Qwen3.5-0.8B 的推理循环用了 158 个智能体回合、8,970 万 token 与 50 次前向请求。作者提出 Tree-Ising，把该修复转化为模型自身 BF16 权重上的稀疏离散优化：用前向统计定义目标，削弱循环方向、强化收束方向并保持该层在有效 token 上的输出；在状态树表示中（无损 BF16 存储为特例）允许的编辑是保持共享组指数与尾数的符号翻转与指数移位。该目标可精确分解为每个输出行一个独立 QUBO（Ising）问题，在 GPU 上用模拟退火或量子启发式模拟分岔求解。在智能体所改的两层上，Tree-Ising 在 MATH-500 取得 54.6%，高于智能体编辑的 51.7%，基座模型报告为 7.9%；模拟分岔求解器给出统计上无差别的 55.1%。两种求解器在全部五个数学基准上均优于智能体编辑，MATH-500 与 GSM8K 上经多重比较校正后显著，且修改权重少 13% 至 17%。
