- **语言模型可重写自身权重**：论文提出 self-rewriting，一个 27B 模型仅凭自身推理、无梯度、无训练即可诊断失败并编辑自身权重。在预先固定的 490 道未见题上，自我编辑使准确率提升 6.6 个百分点；它只在自测通过时才提交编辑，前八次会话中准确率持续上升。该方法还能修复受损副本：仅凭文本数学题定位并重写被损坏矩阵，使该副本在六个未见图像基准上从 7% 升至 70%，达到未受损模型 83% 的水平。与测试时扩展不同，收益固化在权重中且不增加单次回答成本；与训练不同，它无需预训练或后训练基础设施，只需一个开放模型和单卡数小时。该能力随规模涌现，在四个同系列尺寸上均出现。
  - 重要性：★★★★★ / 5
  - 来源：[HuggingFace Papers](https://huggingface.co/papers/2611.21885)

- **扩散 Transformer 的 RL 后训练本质是激活引导**：论文用刻意简单的参数化探测 RL 后训练的增益来源：在冻结基座模型的 block 输出上加一组固定 steering 向量。在 SD3.5-M 上，这些向量参数比 RL 调优的 LoRA 少 65 倍（0.29M 对 18.8M），且拟合目标不含奖励，仅匹配公开 RL checkpoint 的速度预测。尽管向量对所有 prompt、token 和采样种子完全相同，仍恢复了六个 RL 图像模型 90.0-96.3% 的奖励增益，两个 RL 视频模型上分别为 89.8% 和 111.9%。从零初始化并用在线 RL 训练，这些向量在文本渲染（OCR）和人类偏好（PickScore）上单独超过基于权重的 RL。结论是：大部分策略梯度 RL 后训练收益可由一个常数偏移解释，它把预训练生成器引向它本已能计算的内容，而无需学习输入相关变换。
  - 重要性：★★★★★ / 5
  - 来源：[HuggingFace Papers](https://huggingface.co/papers/2611.26627)

- **Squoosh Bench 用 318 个历史 A/B 测试评估 UX-1**：实验团队需决定哪些网站改动值得投入真实流量测试，论文评估模拟购物者的预测能否辅助该选择。研究者筛查 412 个历史网站 A/B 测试，在运行超过 21 天的 318 个上评测四个系统，每个系统需预测原版胜、变体胜或无结论，推理时屏蔽页面角色并隐藏真实结果。在人类浏览数据上微调的 Squoosh UX-1 每臂模拟 1000 名购物者，正确分类 318 个结果中的 267 个（84.0%，95% Wilson 区间 79.5-87.6%）；最强的通用配置 Qwen3 Next 80B 仅 61.6%。UX-1 在 126 个实验中看好变体，其中 118 个在真实测试中获胜（93.7%），4 个失败、4 个无结论。该结果为大模型模拟用户偏好提供了可量化的基准参照。

- **System 1 agents：不生成文本的本地工具调用智能体**：临床等敏感数据分析需要智能体自动化，但云端 LLM 会暴露患者数据，本地 LLM 又会幻觉，而工具调用中一个编造的值会沿后续每一步传播。论文提出构建 System 1 agents 的方法：局部智能体不生成文本而直接调用工具。确定性编译器把每个工具的 schema 和请求转成多选题，选项来自请求与 schema，再由单遍决策模型作答。在面向 157 个生物医学工具的 1952 个请求上，最佳 System 1 agent 正确选择工具或正确拒答的比例达 97.0%，显著超过全部 18 种本地 LLM agent 配置（最佳 95.2%）；它填对 6056 个声明参数值中的 97.0%，且没有任何一次调用包含编造内容，而 LLM 调用中该比例为 5.5-19.7%。框架已开源。
  - 重要性：★★★★★ / 5
  - 来源：[HuggingFace Papers](https://huggingface.co/papers/2611.21053)

- **TwinD：从 blending 假脸泛化到整脸合成检测**：现有面部 deepfake 检测器多在 blending 假脸上训练，即把生成人脸贴回真实帧；而新生成器合成整张脸，不留 blending 痕迹。在 2019 至 2026 年发布的 19 个数据集基准上，最佳既有检测器在十个 blending 数据集上平均 AUROC 达 96.2%，但在五个整脸合成（EFS）数据集上无一超过 78.1%，AIGC 检测器也未能弥补该差距。TwinD 仅在 FaceForensics++ 假脸和两类 twin 上训练：重建 twin 由自编码器重建真实帧并随机区域回填真实像素，针对解码器神经痕迹；blob twin 将真实帧的改动副本与原帧混合，针对 blending 伪影，无需生成器和人脸形状掩码。TwinD 平均 AUROC 达 96.3%，比先前 SOTA 高 8.9 个百分点，blending 数据集 98.1%、EFS 数据集 95.6%；仅用 twin 训练、不接触 deepfake 数据集时，三个随机种子平均仍达 94.3%。代码、模型与数据已公开。
  - 重要性：★★★★★ / 5
  - 来源：[HuggingFace Papers](https://huggingface.co/papers/2611.25935)

- **AURA：音频驱动的流式数字人**：现有音频驱动视频扩散模型能合成逼真说话头视频，但通常需对多秒视频块做数十步去噪，不适合语音助手和虚拟形象等要求低延迟与在线因果生成的流式场景。AURA 借助滚动 KV cache 逐块生成视频，只需当前块的音频即可开始，无需双向模型那样的多秒音频前瞻。它有两个尺寸：AURA 1.3B 在单卡上实时流式输出 576p（16 Hz 播放率下 20.7 fps），适合交互式数字人；AURA 5B 以 9.7 fps 流式输出 720p。两阶段蒸馏流程先让因果学生用更少扩散步数和块级滑动窗口因果注意力掩码匹配教师轨迹，再用 Distribution Matching Distillation（DMD）配合反向模拟缩小剩余质量差距。在标准说话头基准上，AURA 1.3B 比其双向教师快 23 倍，AURA 5B 在 720p 上匹配 TalkVerse 教师且快 17 倍。两模型权重与 3 万条合成视频数据集已发布。
  - 重要性：★★★★★ / 5
  - 来源：[HuggingFace Papers](https://huggingface.co/papers/2611.26540)

- **Direct3D-V3：抛弃 VAE 的原生体素域扩散 Transformer**：原生 3D 生成长期围绕潜空间扩散构建，进展集中于更强的 VAE 与更精细的潜表示，从 vecset、triplanes 到结构化稀疏体素，但共同前提是先把几何压缩进潜空间再建模。Direct3D-V3 走另一条路：完全舍弃 VAE，在原生体素域直接对原始 SDF 体素网格做训练与采样。为使直接体素形式在几何上可靠，论文引入对邻接体素的隐式流形正则以抑制非水密表面，并用 Marching Cubes 把预测 SDF 网格转为 mesh，使渲染法线损失能直接监督预测的 SDF。为改善条件图像与生成几何的对齐，模型还把预测条件图像的相机参数作为辅助任务，促使 DiT 学习从图像观测到 3D 形状的映射。该无潜空间设计移除重建瓶颈，产出局部细节显著更丰富的 mesh。
