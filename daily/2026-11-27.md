- **OpenAI 与 Cisco 开源 Shirudo：让 agent 在系统运行中部署防护**：OpenAI 与 Cisco 于 11 月 24 日发布 Shirudo，这是一个 BSD 许可的预发布 eBPF 运行时，面向 Linux。其机制是让 AI agent 编写带签名的「shield」，在运行中的系统上阻断漏洞利用路径，从而为团队测试和 rollout 真正的补丁争取时间窗口，避免传统打补丁必须停机或重启的代价。这条消息值得关注的点有两个：一是 agent 的输出从文本、代码延伸到了内核层面的可执行安全策略，且用签名机制约束 agent 的权限边界，这是 agent 落地高权限场景的一种工程范式；二是 eBPF 让策略可以动态加载而不中断业务，契合生产环境的可用性要求。对安全与平台工程团队，这意味着漏洞响应流程可能从「排期打补丁」变为「先由 agent 生成临时 shield、再验证修复」，但也带来策略误伤、签名密钥管理和审计追溯的新问题。预发布状态说明 API 与行为仍可能变化。
  - 重要性：★★★★☆ / 5
  - 来源：[MarkTechPost](https://www.marktechpost.com/2026/11/24/openai-cisco-shirudo-ebpf-linux-runtime/)

- **Boundary-Aware Policy Learning 让 agent 与机器人策略的交接边界可显式塑造**：针对多模态 agent 调度视觉运动策略时"交接即失败"的问题，论文把策略可靠起始状态集合定义为 handoff boundary，先用 Boundary-Explicit Training 在多样起始位姿的接触片段上微调，得到宽而可描述的边界并通过简单协议告知 agent，再用 Boundary-Expanding Self-Improvement 在筛选后的成功系统轨迹上重训，把边界向任务更早阶段延伸，使 agent 能更早交接、减少语言模型调用。在 RoboTwin 2.0 与 RoboDojo 上比最强基线高 26 个百分点以上，随机化 RoboTwin 2.0 场景达 98.4% 成功率，同时把 API 成本与执行时间分别降低 41.3% 和 37.5%。
