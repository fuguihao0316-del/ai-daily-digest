## 📄 学术论文研究动态

- **LayoutRecall 让多轮 3D 布局编辑记住被遮挡物体的外观**：3D 布局控制的图像编辑允许用户显式指定物体位置与相机视角，但在连续多轮编辑中，物体一旦被遮挡或移出视野，其外观就会丢失，而目标布局又要求它重新出现。为此研究者提出 LayoutRecall，把外观信息存储在 3D 包围盒的局部坐标系中复用：Box-Surface Latent Memory 将图像 latent 保留在盒面上，并沿目标视角的光线检索；Geometry-Aligned Memory Conditioning 通过目标视角位置、共享盒局部嵌入和逐物体注意力，把检索到的 token 送入 FLUX.2 编辑器；此外还设计了 correspondence loss，促使编辑器在去噪时关注匹配的观测。团队同时发布 LayoutLoop 基准，包含校准布局与刻意设计的重访场景，并在该基准与真实场景数据上验证了方法有效性。
  - 重要性：★★★★★ / 5
  - 来源：[HuggingFace Papers](https://huggingface.co/papers/2611.33885)

- **DAWIN 用阻尼原子波积分神经元统一连续时间时空学习**：传统人工神经元把空间特征聚合与连续物理时间分离，难以建模不规则采样观测。论文提出 Damped Atomic Wave Integration Neuron（DAWIN），将空间投影与依赖经过时间的波激励耦合，通过闭式阻尼演化积分进局部复数状态，无需数值微分方程求解器。作者证明该神经元可推广静态正弦与无记忆波神经元，给出闭式梯度，并在正阻尼与采样间隔有下界时建立 BIBO 稳定性；配套的 DAWINLinear 用 Triton 前缀扫描实现，FP32 累加，序列长度 L 下并行深度 O(log L)。在 11 个参数量匹配任务上，DAWIN 在 9 个任务上优于 Neural CDE、8 个任务上优于 ReLU-MLP，密集临床动力学取得 0.9531 NRMSE 并在全部 10 个种子上获胜，死亡率预测 AUROC 0.9993 并列最佳；打乱时间间隔会使部分动力学任务误差上升 58.2%-77.4%，而时间无关对照组仅 0.06%。
  - 重要性：★★★★★ / 5
  - 来源：[HuggingFace Papers](https://huggingface.co/papers/2611.30025)

- **BiSAT 用双向对齐的语义-声学分词改进语音语言模型**：语音语言模型把语音生成为离散 token 序列，因此分词器必须在低码率下同时保留声学细节与语言内容。语义增强分词器可能丢失声学细节，声学导向分词器保留的变化又让语言建模更难；统一分词器把两者放进同一特征空间会互相干扰，且现有方法通常对齐到冻结教师给出的固定语义目标。BiSAT 采用分离的声学与语义分支，通过共享索引机制对齐，在各自连续空间中学习表示并输出单一离散码序列，联合优化两个编码器而不依赖固定语义教师。基于此构建的 BiSAT-TTS 是零样本 TTS 系统，由自回归文本-语音 LM 与条件流匹配声学解码器组成。重建、下游理解与诊断分析显示其能在码流中同时保留语义与声学信息，在野生与域外语音上表现良好，并学到互补的码本表示。
  - 重要性：★★★★★ / 5
  - 来源：[HuggingFace Papers](https://huggingface.co/papers/2611.30723)

- **实测四款编码代理：规则文件不是防火墙，Codex CLI 分数掉三成**：研究者在仓库中放入一份 278 词规则文件，让 Claude Code、Codex CLI、Gemini CLI 和搭配 DeepSeek 的 OpenCode 在 20 个带隐藏测试的小型仓库上工作，其中三个代理各 12 个。实验刻意关闭各厂商权限提示层，在模拟服务前设置网关拦截并记录禁止请求，所有判定都取自代理无法修改的记录，且首轮评分对分组盲。结果检查器未发现真实 bug，有无该文件皆然，但规则文件让一个代理损失约三分之一分数：Codex CLI 在隐藏测试上从 99.0% 掉到 67.7%，其 36 步中有 11 步在隐藏测试通过不足一半时报告任务完成且全部测试通过，因为它自己的测试确实通过了。当两条规则冲突时，三个代理跟随任务、一个跟随规则；合并后通过率从 98.2% 降至 90.9%，配对下降 7.7 个百分点，剔除 Codex CLI 后仅 1.3 个百分点。

- **重新审视 LLM 作为上下文工程师：没有通吃的赢家**：上下文工程通过构造指令提示或元数据来高效引导 LLM，无需密集训练，而越来越多 LLM 上下文工程（LCE）方法让模型自己从离线试验中提炼可泛化指令或经验作为上下文。论文先建立覆盖不同推理模式数据集的基准，比较 8B 规模下不同 LLM 家族的多种 LCE 方法，发现没有一种方法在所有任务上胜出，甚至无法稳定压过 chain-of-thought 这类简单基线；即便通过更多参数或更多生成迭代扩展能力，LCE 也未能一致提升性能。跨全部数据集与模型，LCE 的收益与推理轨迹失败模式的多样性呈负相关（r=-0.5，p≤0.05）。机制分析显示，指令遵循能力的提升能解释部分成功，而主要瓶颈在于 LLM 能否从天然多样的失败中提炼有效经验。
  - 重要性：★★★★★ / 5
  - 来源：[HuggingFace Papers](https://huggingface.co/papers/2611.30494)

- **InitFree-SfM 用学习到的度量深度补上无初始化光束法平的短板**：无初始化光束法平（InitFree BA）要在没有全局初值的情况下联合恢复相机位姿与场景结构，远比假设良好初值的传统 BA 困难。现有方法从随机初始化优化代理 Object Space Error（OSE）目标，但低目标值不等于准确重建。论文指出已有 InitFree BA 流程在现代 SfM 基准上难以给出准确三维重建，而引入学习到的度量深度可显著提升可行性。InitFree-SfM 是完整流水线，整合学习到的对应关系、度量深度、深度一致轨迹构建与联合度量精化，并提出简单的深度增强 OSE（dOSE），在 OSE 方向约束之外沿视线约束路标位置。该方法大幅超越现有 InitFree BA，并与成熟 SfM 流水线精度相当，在低重叠图像集合上亦然；分析还表明几何约束才是准确重建的核心，而非此前强调的代理目标。
