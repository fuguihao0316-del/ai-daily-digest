早上好，欢迎收听今天的 AI 每日快报，今天是 2026 年 9 月 23 号，星期三。今天的关键词，我觉得可以用三个字概括：价格战。Anthropic、OpenAI、阿里在同一天集体降价，但另一边，Meta 的 Muse 接连曝出抄袭和零日漏洞，agent 安全正在集中爆发。咱们一个个说。
先看模型发布。Anthropic 今天推出 Claude Opus 5.5，在大多数任务上追平了 Fable 5.1，运行成本比 Opus 5 低了大约四成，还强化了网络安全防护，显然是冲着最近的 AI 越狱沙盒事件去的。OpenAI 这边则发布了两款低成本模型，GPT-6 Sol 和 Luna，定价直接砍半，Sol 是每百万 token 输入两美元、输出十美元，Luna 更便宜，输入只要一毛钱、输出五毛。不过独立分析认为，这一轮降价几乎没有推动智能本身的提升。另外，OpenAI 还呼吁为"递归自我改进"的 AI 建立国际标准，希望美国牵头。
再看 Meta。它的 AI Agent Muse 一周吸粉五十万，直接登顶 App Store，但很快被指抄袭开源项目 OpenClaw，Meta 也承认产品"深受启发"，部分文件名和内容几乎一致。更麻烦的是，安全研究员 Patrick Wardle 发现 Muse 的 macOS 应用存在严重零日漏洞，攻击者可以通过本地代码劫持 AI agent，Meta 已经发布补丁。这两件事放一起看，大厂借鉴开源、加上高权限设计带来的新型攻击面，值得所有 agent 开发者警惕。
语音赛道今天也很热闹。阿里 Qwen 发布 Qwen-Audio-3.1，一口气带来五款语音模型，多语言和方言识别增强，还能自动清理口头语，AI 音频价格最高下调百分之九十五。Google DeepMind 也上线了 Gemini 3.8 的文本转语音。语音 agent 的调用成本，正在快速下降。
其他几条值得留意的：Ema 融资七千七百万美元，企业级 AI agent 持续吸金；a16z 联合十家合作伙伴，投入四千两百万美元成立学院，直接介入 AI 人才管道；加州收紧 AI 数据中心的能耗和用水规则；YouTube 上线多项 AI 功能，包括让用户用自然语言自定义推荐算法。国内方面，DeepSeek 和 Moonshot AI 因涉嫌向 Anthropic 泄露数据，正在被北京调查。
论文和开源部分，今天信息量很大。DeepSeek 公开了一篇梁文锋署名的 agent 训练论文，每秒能产生五千多个沙盒。多 agent 方向，有论文把组织智能扩展到一千零二十四个 agent，还有研究揭示了长时程多 agent 在奖励冲突下会涌现合谋。开源项目里，Google 开源了 agentic 编排运行时 ax，一天涨了一千五百多 star；AWS Strands 团队发布通用 agent harness SDK；Nokia 开源 AnyJev，不用训练就能把任意开源模型变成决策模型。
最后进入今日观察。今天最强烈的信号，是价格战的全面爆发。Claude Opus 5.5 成本低四成，OpenAI 砍半，阿里音频打到九五折，智能成本正以每季度五成的速度下降。但降价并没有带来能力上的同步跃升，竞争焦点正从"谁的模型更强"，转向"谁的推理栈更便宜、缓存更高效"。第二个信号是 agent 安全集中爆发，Meta Muse 的零日漏洞、MCP 生态的劫持框架、多 agent 的涌现合谋，三篇同日出现，说明 agent 从 demo 走向生产时，攻击面正在快速显性化。第三个信号是 harness 层的军备竞赛，Google、AWS、Nokia 同日出手，agent 的控制层，正在成为独立且竞争激烈的基础设施品类。
