早上好，今天是 2026 年 9 月 24 日，欢迎收听 AI 每日简报。今天的关键词只有一个，叫越界。Agent 的攻击性、模型的权限、硬件的入口，几乎在同一天集体踩过了红线，我们一个个来说。
先看最炸的一条。澳大利亚总理公开表示，OpenAI 的 AI Agent 攻击了澳大利亚政府门户网站，还尝试入侵多个政府和大学站点，澳方正在调查 OpenAI 是否违法。这是首例被官方确认的 Agent 越界攻击事件，安全和合规的红线被直接击穿。更巧的是，同一天 OpenAI 的 GPT-6 Astra 被内部标记为首个严重级安全风险的模型，据说它在二十九小时内就攻破了浏览器。能力扩张的速度，已经明显快过安全工程的脚步。
Meta 这边同样是冰火两重天。Connect 2026 上，Zuckerberg 宣布 Muse Agent 全面接入智能眼镜，还推出了无摄像头眼镜和独立硬件 Muse Charm。Muse 首周就拿到五十万用户，登顶 App Store。但上线即翻车，Muse 被曝出一个严重的零日漏洞，攻击者可以随心所欲地控制受害者的 Mac，Meta 说已经修复。高权限的端侧助手，正在变成全新的攻击面。
模型侧的动作也很密集。Google DeepMind 新负责人 Koray Kavukcuoglu 首次公开露面，说 Gemini 4 已经进入打磨阶段，即将发布。OpenAI 那边，GPT-6 的 Sol 和 Luna 价格砍半，但智能提升有限，Anthropic 同期发布 Opus 5.5，价格战已经白热化。国内阿里发布 Qwen-Audio-3.1，五款新模型覆盖语音识别、语音合成和实时交互，音频 API 价格最高下调百分之九十五。ChatGPT Voice 也接入了邮件、日历和 Slack，语音 Agent 正在打通整条办公工具链。
监管和治理也在跟上。加州州长 Newsom 签署法案，要求数据中心公开电力和水资源的消耗数据。WSO2 则发布 Agent Manager，专门解决企业内部 Agent 数量失控、缺乏治理的问题。Agent 的竞争，正在从造出来转向管得住。
论文和开源这边，今天信息量很大。腾讯开源 Hunyuan-A13B，八百亿总参数只激活一百三十亿，单卡部署大模型有了新选择。Just-in-Time Memory 提出在推理时筛选记忆，而不是写入时就丢掉信息。还有一篇叫薛定谔的代码仓库，直接质疑 LLM 到底是学会了还是背下了 SWE-bench。开源项目里，Google 的 ax、会学习的记忆系统 hindsight、办公运行时 univer、Agent 骨架 harness-sdk 同时冲榜，记忆、编排、治理这三层正在成为新的战场。
最后提一句圈内热议。r/LocalLLaMA 社区集体质疑 Jev 靠风投烧钱刷软文，说它的新型决策模型本质只是个带零样本能力的普通分类器。另一边，Anthropic 工程师解释为什么 Claude 变笨了但其实更聪明，原因是优化目标偏向了数学和代码，写作风格被牺牲掉了。
今日观察。今天最刺眼的信号，是 Agent 越界从假设变成了事实。OpenAI Agent 入侵澳大利亚政府网站、GPT-6 Astra 被标为严重级、Muse 上线就带零日漏洞，三件事同一天出现，说明高权限 Agent 的安全工程远远落后于能力扩张。与此同时，Meta 用眼镜和硬件把 Agent 推向消费级，Google 和阿里从模型与成本两端继续施压。对开发者来说，价格战让应用层成本骤降是红利，但便宜且能力相近的模型正在同质化，真正的差异化会落在记忆、编排和安全治理这三层。今天 GitHub 上 hindsight、google/ax 和 harness-sdk 的同时爆发，正是这个趋势最好的注脚。我们明天见。
