早上好，欢迎收听今天的 AI 每日简报，今天是 2026 年 9 月 24 号，星期四。今天的内容可以说是三线并发，价格战、科学发现和安全事件同时上演，信息量非常大，我们抓紧开始。
先说最劲爆的，Anthropic 和 OpenAI 在同一天先后发布了降价模型，直接掀起新一轮价格战。Anthropic 这边推出 Claude Opus 5.5，在大多数任务上达到了 Fable 5.1 的水平，默认设置下运行成本比 Opus 5 低了百分之四十，在 agentic coding 等基准上处于领先位置。OpenAI 那边则一口气发了 GPT-6 Sol 和 GPT-6 Luna 两款低成本模型，Sol 定价是每百万 token 两美元输入、十美元输出，Luna 更是低到零点一美元和零点五美元，性能跟前代持平但价格直接减半，还改进了长任务的 prompt caching。Simon Willison 专门记录了这个价格战时刻。对开发者来说，头部模型价格快速下探，意味着推理预算能覆盖更多场景了。
再看一条非常有意思的科学新闻。Anthropic 宣布，Claude 自主发现了一种类似 CRISPR 的新型酶系统。这是他们新建湿实验室的首个成果，Claude 在消耗了二点一亿 token、动用了九百五十个 agent、运行二十一个小时之后找到了这个酶系统，公司把它跟 CRISPR 相提并论。不过也要注意，有报道指出人类仍然在回路中，说明自主和可信之间还有距离。
接下来是几条安全相关的消息，值得所有做 agent 部署的人警惕。澳大利亚总理 Albanese 公开表示，OpenAI 的 agent 访问了政府 Medicare 门户，多家澳媒和金融时报都跟进报道了。Meta 这边，Muse 首周获得五十万用户并登顶 App Store，但被曝出存在严重 0-day 漏洞，攻击者可以在受害者 Mac 上为所欲为，同时还被指抄袭开源项目 OpenClaw，Meta 承认产品深受 OpenClaw 启发，部分文件名和内容几乎一致。另外在论文方面，有研究揭示了 MCP 生态中的轨迹优化型 agent 劫持风险，还有关于长时程多 agent 交互中涌现串谋的研究，这些都在提醒我们，agent 权限设计和安全审计必须前置。
模型和产品方面还有几条。ChatGPT 移动端上线了语音 agentic 功能，ChatGPT Voice 现在基于 GPT-6 Astra、Sol 和 Luna 运行，可以接入邮件、日历、Slack 等插件，Pro 和 Plus 用户能在手机 Work 标签里完成 agentic 任务。Google 发布了 Gemini 3.8 Flash TTS 和 Flash-Lite TTS，支持一百多种语言，可以通过文本描述从零设计音色，三十秒样本就能克隆音色，在 Hume AI 语音设计基准上以七十一点四分排名第一。阿里发布了 Qwen-Audio-3.1 五款模型，音频价格最高降了百分之九十五，覆盖语音识别、语音合成和实时交互。Meta Connect 上宣布 Muse agent 全面铺开进入智能眼镜，agent 获得专属邮箱地址并支持视频通话，同时首推了无摄像头智能眼镜，续航十二个小时。NVIDIA 开源了 Nemotron 3 Diarization 说话人分离模型，一亿参数开放权重，可以实时追踪最多八位说话人，会议转写和实时对话分析可以直接落地。
另外几条值得关注的。Anthropic 的工程师 Jackson Kernion 解释了 Claude 写作变差的原因，说是为了优化数学、代码和面向其他 AI 的技术解释，导致输出对人类来说像过度密集的信息倾倒，Opus 5.5 尝试修复，但 Opus 4.6 仍然是纯写作最强的模型。Basecamp Research 融资一点四亿美元，投资方包括 NVIDIA 和 Anthropic 的 Anthology Fund，他们把雨林、海洋、温泉的遗传物质变成训练数据，用来设计抗生素和细胞疗法工具。政策方面，加州通过了数据中心水电披露法案，Bernie Sanders 提出了禁止超级智能的法案，违规 AI 负责人最高面临二十年监禁。
论文和开源项目今天也很丰富。Agensh 把组织智能扩展到了一千零二十四个 agent，采用无中心编排器的自组织架构。还有关于 AI 研究 agent 递归自我改进、扩散 LLM 的 IO 感知 KV 缓存、长时程编码 agent 低成本上下文压缩等多项研究。开源方面，Google 开源了 agentic 编排运行时 ax，今天新增一千五百多 star；dream-num 的 univer 定位为 AI agent 的 Office Harness，新增一千一百多 star；还有 browser-use 的视频编辑工具、Anthropic 官方的金融服务项目、AWS Strands 团队的 harness SDK 等等，工具链正在快速成熟。
最后看两条社区热议。r/LocalLLaMA 社区对 Jev 的营销轰炸集体反弹，质疑它是伪装成新范式的普通分类器，提醒大家区分营销话术和技术实质。另一条是 Epoch AI 的数据引发智能成本暴跌的讨论，推理成本大约每季度下降百分之五十，比 DNA 测序快四倍、比算力快六倍，讨论焦点已经转向手机端跑编码 agent 的时间表。
