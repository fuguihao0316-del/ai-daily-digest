早上好，今天是 2026 年 10 月 3 日，欢迎收听今天的 AI 每日简报。今天的关键词，是能力扩张和边界收紧同时发生：一边是 OpenAI 把接近旗舰的能力打到五分之一价格，一边是红队评估、蒸馏攻防和安全团队人事震荡接连出现。我们快速过一遍。
先看模型和产品。OpenAI 在九月二十九号发布了 GPT-6.1 Sol，这是 GPT-6 Sol 的升级版，在 agentic coding、computer use 和专业工作任务上已经接近 Astra 的水平，但 token 价格只有 Astra 的五分之一。输入每百万 token 两美元，输出十美元，缓存输入更是低到零点一美元。这意味着什么呢？以前只有旗舰模型才能干的复杂编码和计算机操作任务，现在可以塞进常规生产流程里跑了，agent 类产品的单位经济模型会明显改善，尤其是那种需要长链路、多轮工具调用的场景。
微软这边开源了 FrogNano-4B-2609，一个专门面向所谓“GPU 穷人”的 agentic 模型，基于 Qwen3.5-4B，主打仓库级软件工程，用合成任务做强化学习。它的局限也很实在：对测试质量敏感，训练数据偏 Python 和英文，生成的补丁即使通过测试也可能不安全。NVIDIA 则发布了 DGX Spark 的六十四 GB 新配置，一 PetaFLOP 算力，六家厂商共同推出，单机就能跑本地 agent 和微调，两台集群还能拼出一百二十八 GB 聚合内存。桌面级功耗，工作站级容量，这个定位很精准。
企业检索方面，Cohere 发了 Embed 5 系列，分 Pro 和 Fast 两档，都支持文本、图像和图文混合输入。你可以索引侧用 Pro、查询侧用 Fast，做非对称部署。Meta 则开源了自制 Muse AI 设备的代码，彩色电子墨水屏、HDMI 棒这些参考项目都有，明显是想把 agent 从手机应用推向自有硬件。
安全这块信息量很大。Anthropic 前沿红队公布评估结果，在一百个二进制漏洞利用任务里，GLM-5.3 有百分之四的试验实现了完整控制流劫持，Claude Mythos Preview 是百分之六。更早的模型一个都没成功。这说明具备完整漏洞利用能力的模型正在扩散，安全团队必须把这件事纳入威胁模型。OpenAI 这边，一边发了 GPT-6 家族实用指南，讲怎么选模型、调 reasoning effort、协调工具；一边披露阻断了一场协同模型蒸馏行动，还在加强对抗性蒸馏的防御。同时华尔街日报报道，OpenAI 与三名被指泄密给外部安全组织的研究人员解除了关系，另有一人离职，安全团队受到冲击。
其他几条也值得留意。Google 在 Gemini Live 里上线了 Guided Vision，摄像头对准什么就能实时语音描述，多模态实时助手正式变成系统级功能。Apple 因为 AI agent 风险上升，宣布收紧 macOS 全盘访问权限。微软 AI 还发布了实时转写模型 MAI-Transcribe-2-Streaming，面向语音 agent。
学术方面，今天有几篇很有意思。Ego2Act 是首个面向自我中心视频生成的目标导向操作基准，两千多段真实视频，结果发现模型经常跳过步骤，细粒度物理一致性持续失败。MemFold 用在线策略优化学习紧凑软记忆，做长上下文个性化，历史越长优势越大。还有一篇微型 LoRA 修复 Transformer 过早停止思考的研究，Qwen3-8B 在二十四行链条上的准确率从百分之十五点五直接拉到百分之九十九。另外，首篇视频生成后训练与对齐综述也发布了，给这个领域提供了统一坐标系。
今日观察。今天最清晰的信号，是能力扩张和边界收紧在同一条 agent 化路径上同步放大。OpenAI 一边发低价强模型，一边应对蒸馏和安全团队动荡；Anthropic 红队直接给出漏洞利用评估；微软和 NVIDIA 把 agent 推向低算力和桌面端；Apple 则因为 agent 风险收紧系统权限。真正值得警惕的不是单个模型的强弱，而是模型窃取、网络攻击和本地权限滥用这三类风险正在同时放大。部署面铺开的速度，已经快过治理工具的成熟度。好，今天就是这些，我们明天见。
