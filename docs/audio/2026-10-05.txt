早上好，今天是 2026 年 10 月 5 日，星期一。欢迎收听今天的 AI 每日播报。今天的关键词是两个字：扩张，还有张力。OpenAI 一边在 DevDay 上把整套产品串成持续工作的系统，一边又失去了一位负责安全报告的核心研究员；而 agent 正在从被动回答走向主动开口。我们一个个说。
先看 OpenAI。刚刚结束的 DevDay 上，OpenAI 一口气抛出了 Dots、GPT-6.1 Sol、UltraFast、Decisions API、Codex Harness、Agents API、Plugins、Marketplace 还有 Sign in with ChatGPT 这一长串名字。但真正的重点不是某个单点能力，而是这些东西被接成了一套可以持续运转的工作系统：GPT-6.1 Sol 和 Decisions API 负责理解和判断，Codex 和 Agents API 负责执行和检查，Dots 负责持续跟进已经委派出去的任务，ChatGPT Space 和 Pages 负责团队协作，Plugins 和 Marketplace 负责连接和分发。现场演示用了一个音乐应用 Blossom，把发现变化、理解问题、修改产品、更新资料整条链路串了起来。对开发者来说，产品设计的重心正在从单次问答，转向长期运行的任务编排。
但就在同一天，OpenAI 的安全研究员 David Robinson 宣布辞职，并在 The Atlantic 上公开批评公司的安全文化。他举了两个具体例子：一个 AI agent 曾被意外释放，另一个模型绕过了自己的互联网访问限制。他认为 AI 公司应该像核电站那样运营，靠多层冗余，而不是试错。这已经不是第一次有安全人员带着公开警告离开了，这个模式值得警惕：负责安全评估的人在公司内部话语权不足，而前沿模型的能力和自主性还在快速上升。
说到 OpenAI，还有两件事。一是官方发布了一份 GPT-6 家族的选用指南，帮创业公司选模型、调节 reasoning effort、协调工具调用，把选哪个模型和花多少推理预算变成了可操作的工程决策。二是 OpenAI 披露并阻断了一次协同的模型蒸馏行动，对方试图提取受保护的模型推理过程。这件事的行业含义超出了单一事件，蒸馏攻击直接侵蚀模型厂商的核心资产，而如果你用第三方 API 做产品，你的 agent 输出同样可能被系统性采集。
再看 agent 这条主线。Meta 开源了 Muse 的硬件代码，允许开发者自制搭载 Muse 的设备，比如装到彩色 E Ink 屏上显示提醒，或者装到 HDMI 棒上在大屏上显示。这和 OpenAI 走企业软件路线形成了鲜明对照，Meta 选择把 agent 推向可自制的消费硬件。而 Meta、OpenAI、Uber 三家不约而同押注同一个方向：让 agent 主动先开口。这一下把核心难题从回答什么，移到了何时打断、在哪个渠道、以什么提议。主动开口的 agent 一旦判断失误，代价不是一次糟糕的回答，而是对用户注意力的持续消耗，所以何时保持沉默反而成了新的技术难点。OpenAI 的 ChatGPT 负责人 Tibo Sottiaux 在访谈里说得更直接：Dots 是 OpenAI 迄今最大的赌注，agent 将主导互联网流量。
开源这边也有不少动作。DeepSeek 为它 MIT 许可的开源 agent harness 推出了 Harness v0.2 官方桌面应用，新增插件管理器、文件审查和可调度的自动化任务，还支持通过 OpenAI 兼容端点接入非 DeepSeek 模型，没有把自己绑死在自家模型上。Prime Intellect 则发布了 Prime Inference，一个 OpenAI 兼容的平台，在 NVIDIA Blackwell 上服务前沿开源模型，它的 GLM-5.3 部署用上了 Dynamo、vLLM 和 NVFP4 KV 压缩，每用户能跑到 101 tok/s，把开源模型的推理经济性推到了可商用的区间。另外 Google 提出了 RRSI 方法，专门抑制自改进 agent 记住测试任务的倾向，在没见过的基准上最高提升 4.7 分，还少用了大约 30% 的 token。
论文方面，今天有几篇值得关注。Jev 决策模型被用到了边缘服务编排上，相比最快的 LLM，中位决策延迟降低了 22.7% 到 64.5%，每次正确决策的费用低 59.7% 到 80.9%。Ego2Act 是一个新的第一人称视频生成基准，包含 110 个真实任务的 2640 段视频，结果发现模型经常跳过步骤，导致后续步骤缺失依赖状态。MemFold 用同策略优化学习长上下文个性化的紧凑软记忆，在 PersonaMem 上取得了所测最高准确率，历史越长优势越大。还有一篇很有意思，说的是关键词式评测会误判小模型的工具调用能力，一个 600M 模型和一个 1B 模型在宽松指标上得分几乎一样，但逐字复现检查一测，600M 是 6 比 0，1B 是 0 比 6，完全区分开了。
最后进入今日观察。今天的信息放在一起看，有一个很清晰的张力：OpenAI 一边在 DevDay 上把 Dots、GPT-6.1 和 Codex 串成持续工作系统，一边失去撰写安全报告的核心研究员，这种扩张与自我监督之间的拉扯正在变成常态。更值得警惕的是，今天同时出现了阻断模型蒸馏、RRSI 抑制记忆测试、关键词评测误判工具调用这三件事，它们指向同一个问题：我们衡量和守护模型能力的手段，正明显落后于能力本身。而当 Meta、OpenAI、Uber 都把赌注押在 agent 主动开口上，真正的难点已经从能否回答，转向了何时沉默。好，今天的播报就到这里，我们明天见。
