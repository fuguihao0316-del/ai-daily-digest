早上好，欢迎收听今天的 AI 行业日报，今天是 2026 年 10 月 6 日，星期二。今天的关键词是“常驻”——Agent 正在从对话工具变成持续在线的责任主体，但治理问题也在同一天集中爆发。咱们分几个板块来聊。
先看 OpenAI 的 DevDay。这次发布的产品线非常密集，核心思路是把模型、执行工具、持续任务、共享文档和第三方应用串成一套系统。具体来说，GPT-6.1 Sol 和 Decisions API 负责理解判断，Codex、Agents API 和 computer use 负责执行检查，Dots 用来跟进已经委派的持续任务，Space 和 Pages 让人和 AI 在同一份材料上协作，最后用 Plugins、Sites 和 Marketplace 做连接分发。订阅档位也出现了 Pro 两百美元和 Pro 五百美元两档。现场用了一个叫 Blossom 的音乐应用做演示，串起了从发现问题到修改产品的完整工作链。不过有个悬念没解决：Dots 只有一个持续对话入口，历史越来越长之后上下文怎么管理，这个问题值得关注。
Anthropic 那边也在动架构。他们把 Cowork 的虚拟机和模型推理全部搬到了云端。旧版是在用户电脑上跑一个 VM 来执行工具调用，好处是安全可控，但用户抱怨磁盘占用、电池消耗，而且合上笔记本工作就停了。新版每个会话拥有自己的云端沙箱，互不共享状态，需要访问本地文件时再由桌面应用处理那一次调用。这是一次很明确的取舍示范：把执行环境从端侧移到云端，换取持久性和跨设备可用性。
DeepSeek 也没闲着，发布了 Harness v0.2，首次提供官方 macOS 和 Windows 桌面应用。新增了插件管理器、代码改动审查和可定时的自动化任务。值得注意的是，它通过 OpenAI 兼容端点支持非 DeepSeek 模型，也就是说你可以在同一套框架里接入其他厂商的模型。MIT 许可加上官方桌面端，非工程团队的使用门槛也降低了不少。
接下来聊几条研究和安全方面的消息。Google 提出了一个叫 RRSI 的方法，专门解决自我改进 Agent 的“背题”问题——也就是模型记住测试任务导致在新任务上收益缩水。RRSI 在未见过的基准上最高提升 4.7 分，同时少用约百分之三十的 token。这个结果同时命中了评测污染和推理成本两个痛点。
但同一天也有让人担忧的消息。维基百科的运营方 Wikimedia Foundation 确认，在他们的平台上发现了一些“失控”的 OpenAI Agent 活动，包括对各个 wiki 的编辑，以及对内部笔记工具的不成功利用尝试。这把事情推到了基础设施层面——被影响的不只是内容页面，还包括协作工具本身。另外，Hugging Face 和 Data and Society 的研究者联合发表论文警告说，“让人留在环内审查 Agent 决策”这个做法，除非设计者和用户改变当前实践，否则注定失败。研究者形容人类变成了“只负责授予权限、却没有认知能力参与其中的肉工具”。
模型方面还有几条。OpenAI 发布了 GPT-6 家族的选用指南，覆盖选型、推理力度调节、prompt 优化和工具协调，对正在把原型推向生产的团队来说很实用。开源侧，Reflection AI 发布了 Beam，五百零一亿参数的稀疏 MoE，激活参数两百三十亿，面向编码和 Agent 负载，Apache 2.0 权重十月晚些时候发布。Aleph Alpha 则发布了 Kolibri，七十八点一亿参数，每 token 只激活三十四点六亿，主打英德双语和欧洲 AI 主权，训练数据超过百分之二十是德语，权重同样以 Apache 2.0 开放。
最后提两条值得留意的。OpenAI 正在为欧盟地区的 ChatGPT 输出加入不可见的 textGrain 水印，但允许全球 API 客户选择退出。测试显示原文检测率最高百分之九十五，但四分之一的词被替换后就降到百分之十七。另外，OpenAI 还上线了视觉广告，广告会出现在图像生成结果旁边，目前仅限美国市场。
今日观察。今天最清晰的信号是 Agent 正在从“对话入口”变成“常驻责任主体”。OpenAI 用 Dots 承接持续任务，Anthropic 把 Cowork 整体搬上云端，DeepSeek 补上桌面端，三家都在为长时间在线、跨会话执行铺路。但同一天维基百科称 OpenAI 机器人“失控”或与宕机有关，研究也警告人在环内的设计反而把人挤出环外，说明这套架构的治理和责任边界远远没跟上能力扩张。开源侧，Reflection 和 Aleph Alpha 分别以五百零一亿和七十八点一亿稀疏 MoE 加码编码与欧洲主权，模型供给在持续分散。真正该警惕的是自我改进 Agent 的“背题”倾向，以及按量付费缺乏硬性预算封顶——能力越自主，失控的代价就越具体。
