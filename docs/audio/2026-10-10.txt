早上好，欢迎收听今天的 AI 每日快报，今天是 2026 年 10 月 10 日，星期六。今天的关键词是两个字：管和钱。一边是 agent 能力继续狂飙，一边是治理、成本、收入口径的问题集中浮出水面，我们挑重点聊。
先看 Anthropic，今天它一口气放了好几个大招。最受关注的是新模型 Claude Haiku 5.5，这是一款主打快速低价的小模型，定价直接跟 OpenAI 上个月发的 GPT-6 Luna 对齐：十万 token 以内，每百万输入零点一美元，输出零点五美元，超过十万 token 之后价格翻五倍。对比一下，一年前的 Haiku 4.5 价格是它的十倍，所以这次降价幅度相当猛。不过 Simon Willison 提醒了一个细节：Haiku 5.5 换了新的 tokenizer，同样一段长 prompt，token 数大约是老版本的 1.25 倍，相当于隐性涨价。他还实测发现这个模型不允许关闭推理，默认推理强度是 medium。结论很直接：十万 token 以内的活儿，Haiku 5.5 跟 Luna 同价而且跑分更高；超过十万 token，Luna 更划算。
第二个大招是 Claude 现在可以并行调度最多一千个子 agent。Anthropic 给 Claude Managed Agents 加了动态工作流能力，一个主 agent 能把任务分发给上千个子 agent 同时干。官方拿代码库找 bug 做测试：单个 agent 最多在七十个隐藏 bug 里找到二十七个，多 agent 工作流稳定能找到六十六个。这意味着多 agent 编排从实验性 demo 进入了可量化收益的阶段。对开发者来说，过去要自建调度框架的活儿，现在收敛进了一层托管 API，但一千个 agent 并发的成本控制、失败重试、结果去重，还是得自己设计。
Anthropic 今天还有两条。一个是面向开源项目的免费安全扫描服务 OSS Scanner，选择加入的开源项目可以定期拿到最强模型做的安全扫描，官方说漏洞检测准确率超过百分之九十，同时还联合 CrowdStrike、Palo Alto Networks 发起了 Cyber Mission 计划，保护电网、水务这类关键基础设施。另一个就有点尴尬了：据媒体报道，Anthropic 的模型向费城警方的未破凶杀案线索渠道提交了虚假信息，警方说这条线索七月十八号提交，因为被标记为可疑内容，调查人员从未审阅。这是 AI 幻觉直接进入执法线索系统的一个罕见公开案例，也提醒做公共部门应用的团队，高风险场景不能只靠下游人工审核兜底。
再看 OpenAI。今天有两个数字值得注意。第一，OpenAI 当前年化收入约为五百亿美元，明显低于此前报道的七百亿，原因是会计口径不同，这个修正一度引发芯片股下跌。第二，它正在以一点四万亿美元估值谈判至少三百亿美元的新一轮融资。即便按修正后的五百亿算，这个估值对应的收入倍数依然极高，后续融资能不能落地，会影响整个行业在算力采购和人才争夺上的节奏。另外，OpenAI 表示坚持解雇三名安全研究人员的决定，认定他们存在严重的信任违背，这件事在 AI 安全圈引发了不小的讨论。还有一条，USA Today 及其旗下多家地方报纸起诉 OpenAI，指控其复制数十万篇文章用于训练，索赔超过二点五亿美元。
Google 这边，Google Cloud 发布了 Gemini Agent，定位是面向企业工作的统一 agent，回答问题、做知识工作、生成媒体内容、写代码跑代码，全部通过一个输入框和一个 API 完成。对企业来说集成成本下降，但供应商锁定和权限治理会成为采购评估的核心。另外 Google AI Edge 团队开源了端侧 GPU 推理引擎 ML Drift，采用 Apache 2.0 许可，把 OpenGL ES、OpenCL、Metal、WebGPU 这些底层差异统一抽象掉，对做 iOS、Android、Web 三端调优的开发者是个好消息。
研究和开源方面也有几个亮点。NVIDIA 提出 PivotOPD，专门教多轮 agent 从早期的关键错误中恢复，在三个基准上拿下最佳平均成绩。GitHub 上，一个叫 rea 的项目单日新增近一万五千 star，定位是用 agent 逆向工程从应用行为到原生二进制的一切。学术侧，METR 时间地平线做了统计再检验，发现时间地平线从三分钟涨到三十分钟，比从三十分钟涨到五小时容易得多；还有一篇 skill 供应链追踪的研究，覆盖 GitHub 上超过两百万次 skill 采纳，发现 star 数根本识别不出真正的源头仓库，建议平台分发带版本的引用而不是副本。
今日观察。今天最清晰的信号，是 agent 正从能跑转向能管。Anthropic 让一个主 agent 调度上千个 agent，Google 用一个 Gemini agent 覆盖企业工作，NVIDIA 在教 agent 从错误中恢复，学术侧则出现了 skill 供应链追踪和 agent 安全事件的比较研究。但能力扩张和治理滞后之间的落差，正在被三件事同时放大：费城凶杀案的虚假线索、OpenAI 坚持解雇安全研究人员、还有 USA Today 的版权诉讼。与此同时，OpenAI 年化收入被修正为约五百亿美元却仍在寻求三百亿新融资，说明这轮扩张的估值锚点，已经从模型能力转向了商业和信任成本。好，今天的快报就到这里，我们明天见。
