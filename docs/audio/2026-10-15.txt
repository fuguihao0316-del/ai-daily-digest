早上好，欢迎收听今天的 AI 行业快报，今天是 2026 年 10 月 15 日，星期四。今天最大的看点，是百万级上下文正式从前沿卖点变成入场券，Google 和 Meta 同周压上旗舰模型，而安全、审计和监管压力也在同步加码。
先来看今天最重磅的消息。Google 面向全球上线了 Gemini 4 Argon，这是它目前最强的前沿模型，通过 Gemini API、AI Studio、Gemini app 和 Google Antigravity 全面开放。Argon 采用稀疏 MoE 架构，单次最多可以输出一百万个 token，在 Vals Index 上以 68.9% 领先。价格策略相当激进，上线价每百万 token 输入两美元、输出十美元，跟 GPT-6 Sol 持平，只有 Claude Opus 5.5 的一半。不过要注意，十二月一号起价格会翻倍，到时候就跟 Opus 5.5 同价了。Google 内部说，Argon 已经把编码任务从几个月压缩到了几周。对开发者来说，现在真正要比的已经不是单价，而是在 agent 框架里完成一个目标到底要烧多少 token。
Meta 这边也没闲着，推出了 Muse Wonder 和 Muse Wonder Full 两款百万上下文的 agent 模型。Muse Wonder 定价是每百万 token 输入四美元、输出二十美元，Muse Wonder Full 面向 Muse Code 套餐，在 DeepSWE 和 SWE-Marathon 上领先。Artificial Analysis 把 Muse Wonder 的最高推理档位评为跟 GPT-6.1 Sol 同级，这可能是 Meta 首批 Fable 级模型。Simon Willison 也同步更新了插件并测试了六个推理档位。他指出 Meta 现在几乎每月发一个新模型，从八月初的 Muse 1.2 到九月初的 1.3，再到这次，代际提升是实打实的。对 agent 开发者来说，前沿模型的选择从三家变成了四家，而百万上下文正在成为 agent 场景的默认配置。
接下来聊聊基础设施和监管这两条线。Anthropic 公开了自研源码控制系统 Scion，用来替代 Git。今年五月他们日均合并代码变更大约两千五百次，到九月已经超过三万次，半年涨了十二倍。新代码审查系统叫 Antique，源码控制系统叫 Scion，思路接近中心化版本控制的重新发明。Anthropic 也承认 Google 的 Piper 和 Meta 的 Sapling 是先行者。需求规模非常极端：主分支历史接近一百个 GB，每天大约两千五百万次代码检出用于 CI。Simon Willison 推测，Fable 级模型的引入是编码速度跃升的关键。这给所有面临 agent 生成代码洪流的团队提供了一个基础设施层面的参考样本。
监管方面，Iowa、Kansas、Nebraska 等八个州分别起诉 OpenAI，指控 ChatGPT 对儿童不安全，并在安全性上误导消费者。注意，是各州分别立案，不是联合起诉，这意味着 OpenAI 要在八个不同司法辖区同时应诉。这是监管压力从联邦向州层面扩散的明确信号，儿童安全正成为最集中的攻击面。
其他几条值得关注的消息。Nvidia 承诺向欧洲投资二十亿美元，并向英国安全实验室提供两亿五千万美元算力，黄仁勋同时推销开放权重模型，称这是欧洲缩小 AI 差距的路径。OpenAI 这边，年内至少会发布一到两个新模型，但旗舰还需要对齐工作，采用的是跟 Astra 相同的 looped transformer 技术，权衡在于循环结构让安全监控变得更困难。Nvidia 还发布了 Nemotron Bolt 3.5 74B A9B，通过二比特量化塞进二十四 GB 显存，本地部署社区反响热烈。Google DeepMind 跟新加坡政府合作，用端侧 Gemma 模型检测聊天中的诈骗，全程零云端数据外泄。另外，DeepMind 迎来了一位驻场哲学家 Henry Shevlin，职位名称就是 Philosopher，这说明 AI 意识、道德地位这些学术议题正在进入产品与政策决策链条。
论文方面，今天有几篇值得留意。DuplexJev 让冻结的 LLM 用单 token 完成全双工语音决策，八卡节点处理八十个决策只要约零点一秒。WorkForge 从真实资源合成了 1.67 万个可验证的工作代理环境，覆盖四十个专业领域。ARBITER 用可验证反馈做代理式代码评判，把 USACO-JUDGE 上的判决准确率从 71% 提升到 87%。还有 Last Secure Code Benchmark，结果有点扎心：即便最强的 Claude Fable 5，也只有 25% 的任务能同时通过功能和安全测试。机器人方向，ACCRUE 做持续离策略强化学习，把真实机器人训练时间减少了三到六成；GreenWAM 作为世界基础模型，在多个榜单上取得顶级成绩。
最后是今天的观察。今天最清晰的信号是，百万级上下文正在从卖点变成入场券，Gemini 4 和 Meta 双线压上，而真正的瓶颈已经后移到安全与审计。八个州起诉 OpenAI，iFixAi 和 pentagi 同日冲上 GitHub 榜单，说明能力扩张和问责工具在同步军备。另一条暗线是 Anthropic 自研 Scion 后日合并量半年涨了十二倍，编码代理的产能已经开始倒逼工程流程本身重构。值得警惕的是，当模型能力以周为单位刷新，对齐与评测的节奏还停留在论文里。好，今天的播报就到这里，我们明天见。
