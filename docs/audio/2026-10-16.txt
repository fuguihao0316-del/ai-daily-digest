早上好，今天是 2026 年 10 月 16 日，星期五。欢迎收听今天的 AI 每日简报。今天的关键词是三个字：开放权重。Meta 甩出了一个八百一十六 B 的大家伙，Google 把单次输出推到了一百万 token，NVIDIA 则把一百二十 B 的多模态 agent 塞进了一台机器。与此同时，Anthropic 在 IPO 前夜交出了一份相当亮眼的成绩单。咱们一条一条来。
先说今天最重磅的。Meta 在十月十五号发布了 Muse Spark Open，八百一十六 B 总参数、四十二 B 激活参数的 MoE 架构，上下文窗口直接拉到一百万 token，原生支持文本、图像、视频、音频四种模态，主打编码和长程 agent 任务。工程配套也很猛，Meta 同步放出了可自动调优的 Helion GPU kernels，在 NVIDIA 和 AMD 的卡上都拿到了加速。但最抓眼球的是本地部署，Meta 说这个模型可以在两台搭载 M5 Ultra 的 Mac Studio 上，通过最新的 MLX 框架跑起来，这还是和 Apple 联合宣布的合作。权重已经在 Amazon SageMaker、Google Cloud、Hugging Face 和微软 Foundry 上开放下载，Baseten、Fireworks、Groq、OpenRouter 等一长串厂商同步提供 API。可以说，这是美国阵营对 Qwen、GLM、Kimi 这些中国开放权重模型的一次正面回应。
Google 这边也没闲着，Gemini 4 Argon 已经在 Gemini API、AI Studio 和应用里全面开放。这是个稀疏 MoE 模型，最夸张的规格是单次请求最多能写出一百万个输出 token，在 Vals Index 上以六十八点九零 percent 登顶。定价很有意思，发布价是每百万输入 token 两美元、每百万输出十美元，和 GPT-6 Sol 持平，只有 Claude Opus 5.5 的一半。但注意了，Google 已经明确说十二月一号起价格翻倍。不过从 Artificial Analysis 的整轮基准总成本看，Argon 跑完全套评测花了两千四百零七美元，即便涨价之后，仍然比 GPT-6 Astra 略便宜一些。
NVIDIA 同一天也出手了，发布 Nemotron 3.5 Super VL，一百二十 B 参数的开放多模态 MoE，激活参数只有十二 B，上下文一百万 token，权重采用 NVFP4 量化，一台 DGX Spark 就能跑。定位很明确，就是给需要七乘二十四小时不间断运行的企业级 agent 用的。但 The Decoder 点出了一个关键约束：想把这套模型发挥到极致，基本就意味着你得买 NVIDIA 的硬件。这和 Meta 主推 Apple Silicon 本地推理，恰好形成了两条互斥的硬件路线。正在评估自建推理栈的团队，这个岔路口值得好好想想。
接下来是 Anthropic 的三连击。第一，他们公开了自研源码管理系统 Scion。今年五月，Anthropic 平均每天合并约两千五百个代码变更，到九月，这个数字已经超过每天三万个。主分支历史接近一百 GB，每天为 CI 执行的 checkout 大约两千五百万次。按朴素方式抓取，每天会产生超过六百 PB 的 git 流量。新系统包括源码控制 Scion 和代码审查 Antique，形态上更像是对集中式源码控制的重新发明。这是头部实验室第一次用工程数据量化「模型写代码」对开发基础设施本身造成的压力。
第二，据 FT 报道，Anthropic 在投资人活动上披露，第三季度营收一百六十八亿美元，环比接近百分之五十，每花一美元算力产生一点七美元收入，调整后运营利润率百分之十一。还有一条很值得注意：他们向投资人表示，蒸馏贡献了百分之五到七的营收，而第三季度已经实质性削减了这块业务。粗略估算，如果蒸馏占第二季度营收的百分之五，意味着其他实验室那个季度为蒸馏 Anthropic 模型花了超过五亿美元。
第三，Anthropic 和评估机构 METR 达成了一项不同寻常的协议，METR 研究人员将获得员工级访问权限，可以自行发布对 Anthropic 风险、事故和做法的评估报告，而 Anthropic 放弃了阻止这些报告发布的权利。这在前沿实验室里是相当实质的一次让权，也给其他实验室立了一个可以对标的先例。
其他几条快速过一下。Google 正在把 Gemini 4 Argon 推向机器人场景，在自家 ERQA 基准上拿到八十七 percent，但演示仍然需要大量人工引导。Google DeepMind 和新加坡政府合作，用端侧 Gemma 模型在私人聊天里实时拦截诈骗，数据完全不出设备。OpenAI 这边发了两个案例，一个是 Amp 用 GPT-6 Astra 等模型把 agent 带出编码场景，另一个是 Third Moment Research 同时跑一万个 agent、持续工作三十六小时以上，这个负载量级对推理成本和状态管理都提出了全新要求。
学术方面今天也有不少好东西。FreeSolo 提出零样本长度外推的线性时间稀疏注意力，不需要昂贵的长上下文微调。LayerTrim 用免训练的结构化剪枝，在 Qwen3-14B 上实现了一点二四倍更快的 prefill，同时保住了长链推理能力。NoteBank 更夸张，用稀疏情节记忆，把线性注意力在一百万 token 检索上的准确率从一点七 percent 直接拉到七十点三 percent。还有一篇关于智能体内部状态的研究，线性读出可以在行动前预测越权行为，AUROC 达到零点九四，计算开销只有智能体的十的负八次方。
最后进入今天的观察。今天最清晰的信号，是开放权重和超长上下文的正面碰撞。Meta 用八百一十六 B 的 Muse Spark Open 回应中国阵营，Google 把单次输出推到一百万 token 并伸向机器人，NVIDIA 则把一百二十 B 多模态 agent 压进单台机器。与此同时，Anthropic 季度营收一百六十八亿美元、环比近百分之五十，还主动削减蒸馏收入、向 METR 开放员工级访问、放弃审稿否决权。头部实验室已经开始为 IPO 清理叙事风险。把这两条线放在一起看，能力扩张与自我约束正在同时加速，而真正稀缺的，不再只是模型规模，而是可被第三方验证的信任。
好，今天的简报就到这里。我们明天见。
