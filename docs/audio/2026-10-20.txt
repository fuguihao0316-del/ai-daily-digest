早上好，今天是2026年10月20日，星期二。欢迎收听今天的 AI 日报。今天的关键词只有一个，那就是 Agent，而且不是它能做什么，而是谁来管它、它跑在谁的地盘上。我们先从几条关于 Agent 治理的消息说起，再聊聊硬件和工具链上的几场硬仗，最后过一遍今天值得关注的论文。
先看治理这条线。微软公开表态，说前沿模型本身不可信，企业应该像对待内部威胁一样监控员工使用的 AI Agent。这话听着刺耳，但逻辑很清楚：Agent 手里有凭证，能调用内部系统，行为又难以完全预测，风险模型跟一个越权账号几乎一样。所以安全团队得给 Agent 建身份、划权限、做审计、留熔断，不能只靠模型厂商拍胸脯。几乎是同一时间，德国两家法院接连认定，Google 的 AI Overviews 内容算公司自己发布的内容，不能拿“模型自动生成”当免责理由。这对做搜索摘要和 RAG 的团队是个明确信号，幻觉治理已经从质量问题升级成法律问题。Anthropic 那边则走得更远，正在跟多家律所磋商，想给代用户议价、改合同的 Agent 定一套谈判规范。另外还有个现实摩擦：越来越多的网站开始主动封锁自主 Agent 的访问，内容方不愿意被自动化流量白嫖。你看，Agent 越能自己行动，瓶颈就越不在能力，而在边界。
再看硬件和工具链。NVIDIA 把收购来的 GPU 编排平台 Run:ai 整个开源了，Apache 2.0 协议，调度器、显存分片、配额管理全都在里面。过去要商业授权才能用的细粒度切分，现在任何团队都能集成，自建多租户 GPU 集群的门槛一下就降下来了。但另一边，亚马逊推出了 TorchNeuron，直接冲着 NVIDIA 对 PyTorch 的掌控去的，想让更多应用跑在 Trainium 这类替代芯片上。NVIDIA 自己也没闲着，发布了面向企业和 PC 的开放 Agent 模型，主打数据不出域、本地部署。还有个值得警惕的消息：neocloud 这轮洗牌可能只剩七到十家，NVIDIA 因为超大规模云以外的客户贡献了它数据中心收入的四成五，风险暴露最大。模型这边，Mistral 出了个时序基础模型 Timestral，最大的版本才两亿多参数，零样本就能打，还能在 CPU 上跑，做需求预测的团队可以拿它当新基线试试。OpenAI 则把注意力放到了 COBOL 这类冷门语言上，盯的是金融和政府系统的存量迁移市场。
最后快速过一下论文。小米的 Xiaomi-Lens-0 让四 B 的多模态模型用自身视觉 latent 直接解码分割掩码，指代理解平均涨了五点六分。GlobeBench 是首个文本世界模型基准，最强模型成功率也不到一半，动作影响一扩散，平均成功率直接掉到百分之五。还有 Intact，靠按网页语义隔离元素，把注入攻击的通过率从七成多压到了不到一成三。
今日观察。今天所有线索交汇在同一个判断上：Agent 的竞争，已经从模型能力转向了编排层和责任层。NVIDIA 开源 Run:ai、亚马逊推 TorchNeuron，争的是 Agent 跑在谁的工具链上；微软、德国法院、Anthropic 和那些关门的网站，争的是 Agent 出了事谁来担。能力已经不是瓶颈，可审计、可追责的边界设计才是。我们明天见。
