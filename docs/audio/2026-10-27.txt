早上好，欢迎收听今天的 AI 日报，今天是 2026 年 10 月 27 日，星期二。今天的关键词是“差距收窄”：开源模型第一次真正摸到了闭源前沿的门槛，而治理和评估体系明显还没跟上。我们一条条来说。
先看模型侧。Moonshot 上线了 Kimi K3.1 Pro，暂时没开放权重，但承诺十一月四号之前放出完整权重。定价是输入每百万 token 两美元、输出十美元，跟 GPT-6.1 Sol 持平，是 Claude Opus 5.5 的一半；另外还有一个速度提升两到三倍、价格翻倍的高速版本。官方基准显示它跟 Opus 5.5、GPT-6 Astra 大致打平，部分项目还领先；第三方评测机构 Artificial Analysis 给了五十五分，超过 Claude Fable 5.1、GPT-6 Astra 和 Gemini 4 Argon 的五十三分，只落后 Opus 5.5 的五十八分。这是首个即将开源的权重模型在前沿评测里拿到这么高的分数，意义不小。
OpenAI 这边推出了中端模型 GPT-6.1 Terra，主打快速高效、细致的视觉推理和精确的电脑操作，API 价格比前代直接减半，被不少人看作智能性价比的新标杆。不过 OpenAI 自己人也说了，对订阅用户来说这不算重磅更新，真正受益的是那些要大规模跑自动化电脑操作任务的团队。
Anthropic 今天动作特别密集，我们集中讲。第一，他们发研究结论说单智能体架构已经优于多子智能体，速度大约快一倍，还在 GitHub 上放了迁移工具包，这对已经投入多智能体编排框架的团队是个直接的架构压力。第二，他们正式递交了 IPO 申请，营收高速增长但亏损也在扩大，还带了一套保留创始人控制权和 AI 安全使命的特殊治理结构，这是头部实验室里第一个走向公开市场的。第三，联合创始人 Jack Clark 把自我改进型 AI 的时间预测提前到了 2027 年，起因是一个新基准显示相关能力提升超出预期。第四，他们开源了免费漏洞扫描器 OSS Scanner，用最强模型扫关键开源项目，报告直接发给维护者，不经过人工审核。第五，他们还开源了 sandbox-runtime，也就是 Claude Code 背后的操作系统级沙箱，不需要容器就能限制智能体的文件和网络访问。
跟 Anthropic 的单智能体路线形成对照的是微软研究院，他们开源了 Agensh，一个没有中心编排器的多智能体框架，靠共享的 Git 仓库和聊天频道协作，能在六小时预算内从 1 个智能体扩展到 1024 个。
科学侧，OpenAI 公布了数学、计算机科学和物理三个领域的发现，涉及 Kakeya 猜想、指数时间假设和量子色动力学，这次特别强调引入外部专家把关，跟之前一次性甩出几百篇手稿的做法明显不同。
研究方面还有几个纠偏信号值得注意：一个是新基准 Kolab，用 115 小时真实协作录像指出，现有 agent 基准根本测不出人机协同能力；另一个是 G-Retriever 被查出 token collapse，图 token 在不同输入之间几乎不可区分，学到一个常量提示就能匹敌原方法。机器人方向，DiscoDemo 用强化学习生成多样化示教数据，真机模仿学习成功率从 39% 提到 78%；FLORA 机器人数据引擎开源，每天能标注 20 万小时数据，成本只有 GPT-6 Astra 的一百二十五分之一。
今日观察。今天最清晰的信号，就是开源和闭源前沿的差距正在收窄：Kimi K3.1 Pro 逼近前沿闭源模型，微软开源无中心多智能体框架，Anthropic 连发沙箱和漏洞扫描器，能力扩散的速度明显快于治理和评估体系的跟进。另一边，Anthropic 一边递交 IPO、一边亏损扩大，Jack Clark 又把自我改进 AI 提前到 2027 年，商业化压力和能力跃迁被绑在了同一根时间轴上。研究侧同样在自我纠偏，单智能体优于多子智能体、现有基准测不出人机协同、图模型被查出 token collapse，都说明堆叠架构和漂亮分数未必对应真实能力。真正该警惕的，是评估滞后于部署，而不是模型本身跑得太快。好，今天就聊到这儿，我们明天见。
