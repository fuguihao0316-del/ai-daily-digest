早上好，欢迎收听今天的 AI 日报，今天是 2026 年 10 月 28 日，星期三。今天最值得关注的，是 OpenAI 用半价 API 把中端模型推向 Agent 场景，同时 Google 的世界模型和 Anthropic 的 IPO 也在推进；另外，今天一批论文集中指向同一个问题：验证和评审正在成为 agent 落地的真正瓶颈。下面我们逐条来聊。
先看 OpenAI。他们发布了中端模型 GPT-6.1 Terra，主打视觉推理和精确的 computer use，API 定价是每百万 token 输入一美元、输出五美元，比前代 GPT-6.1 Sol 便宜了一半。官方说它在 Agents' Last Exam 中等推理强度下的得分和旗舰 GPT-6 Astra 持平，但单任务成本只要零点二九美元，而 Astra 要四点八二美元。OpenAI 的 Ted Sanders 在 Hacker News 上给它的定位很直白：技术沟通强于 Astra 和 Sol，视觉和 computer use 相近但快得多，其余多数能力略弱。对做 Agent 和批量自动化的团队来说，这意味着高频重复的浏览器操作、表单填写、视频剪辑这类任务可以迁到低成本档位，高难度推理留给旗舰模型。Sanders 还分享了一条选型经验法则：模型规模、推理强度和多 agent 系统是三个独立维度，不能压缩成单一的 IQ 分数，与其按总分挑最强模型，不如按任务类型拆分。
OpenAI 今天还有两条企业侧的消息。一是扩大和 Oracle 的合作，把 Oracle 的业务应用和 AI agent 接入 ChatGPT，让 agent 在对话里直接查询和操作 ERP、CRM 这些系统。对做企业集成的开发者来说，接入路径要重新评估了：是继续自建 RAG 和工具层，还是直接用平台方的官方连接器，同时权限边界和数据驻留也是新问题。二是公布了语音 agent 平台 Retell 的案例，Retell 用 OpenAI 模型支撑每月一亿通电话，GPT-6 Astra 在其语音 agent 基准上排名第一，Codex 还帮他们把人均年化收入推到一百六十万美元。不过要提醒一句，这个基准是客户自建、供应商发布的，选型时还是得在自己的通话数据上复现，尤其是噪声环境和多轮打断的场景。
再看 Google。他们发布了 Genie 4 世界模型，四项主要更新：更真实的世界、可以用自然语言提示实时修改场景、可以生成音频，底层换成了 Gemini 3.8 Flash。它能维持最长两分钟的一致场景，是 Genie 3 的两倍，物理表现更好、角色更接近真人。对做游戏原型和具身智能仿真的团队来说，两分钟的一致性窗口和实时操控是两个能直接改变工作流的指标。
其他公司方面，Apple 把 AI 助手引入了 Keynote、Pages 和 Numbers，基于自家模型和 OpenAI 模型构建，能理解文档上下文，这是 Apple 首次把第三方模型能力嵌入 iWork 套件。Anthropic 则在冲刺 IPO，一边想动用公开市场的资金，一边坚称不会在安全使命上妥协，一旦上市，安全承诺就会从内部章程变成要对股东解释的披露事项，这是观察前沿实验室治理结构如何被资本市场重塑的关键窗口。另外，在 Meta 工作了八年的 AI 总监 Rohit Patel 离职创业，创办 Ndoc，目标是挑战 Microsoft Office 和 Google Workspace。
模型侧还有两条值得留意。Mirendil 发布了首个模型 Fern 0.1，从零预训练，上下文窗口达到一千万 token，在长上下文检索任务上得分满分，但在 agentic coding 上落后于前沿模型，说明超长上下文和真实 agent 能力还是两件事。开源社区这边，Liquid AI 开源了 LFM3 系列六款二十亿参数级的多模态模型，inclusionAI 升级了 Ling-3.1-flash，总参数五百六十亿、激活二百五十亿，上下文一百万 token。
接下来是今天的论文。今天这批工作有个共同点：大家都在给 agent 建更好的评测和验证底座。CellTrack-Bench 发现，视觉语言模型在细胞追踪这种需要时空感知的任务上系统性落后专用算法。SO-101 Bench 在低成本机械臂上做了语言条件操作基准，有意思的是仿真排名和真机完全一致，但仿真会高估成功率，最好的 VLA 模型只有约百分之六十一，而一个写代码调用学习策略的 LLM agent 达到了百分之八十三点二。CRM-Agent-Bench 则主张，可部署 agent 的基准要同时考察结果、轨迹、运营可行性和策略合规，他们用契约式评分评测了十六个系统，严格成功率在百分之六十四到八十四之间。
验证方面，有一篇论文把验证当作测试时扩展的一个维度，结论是独立评审是准确率和成本的最优折中，在 Terminal-Bench 上平均提升五点九到九点五个百分点，成本只有基线的1.13到1.25倍。还有一篇 iPrefBench 很有意思，说移动端个人 agent 会执行任务，但不会替用户做推断和提问，动作完成分最高九成一，完整任务成功率却只有四成七，对只能询问用户的信息尤其失败。另外 EnvLunch 提出把可执行环境本身当作免标注的预训练信号，无标签热启动让模型平均超过基线九分以上。还有 RoboJev-27B，一个开源的机器人成功检测裁判，单卡 H100 每回合只要零点二六秒。
最后是今日观察。今天的信息拼在一起，能看到两条主线。第一条是头部厂商的竞争重心已经从模型能力转向分发渠道和资本耐力：OpenAI 用半价 API 把中端模型推向 Agent 场景，Oracle 企业应用接入 ChatGPT，Anthropic 冲刺 IPO，都是这个逻辑。第二条是一批论文集中指向同一件事：验证、评审和可执行环境正成为 agent 落地的真正瓶颈，而不是模型本身。值得警惕的是能力与评测的错位在扩大，细胞追踪上通用模型系统性落后专用算法，移动端 agent 会执行却不会替用户推断，说明通用模型还没吃透垂直场景。开源侧单日几千星的项目多集中在去 AI 味和设计语言上，社区热度正从模型转向使用体验，这或许比榜单分数更能说明真实需求。好，今天的播报就到这里，我们明天见。
