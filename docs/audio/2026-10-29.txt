早上好，今天是 2026 年 10 月 29 日，欢迎收听今天的 AI 日报。今天最值得关注的，是模型竞赛的焦点正在从单纯的性能比拼，转向成本、安全和工程化落地。Google 和 OpenAI 几乎同时出招，一个把前沿能力锁进安全场景，一个把 agent 任务成本打了下来；另外还有一起 AI agent 攻破 Anthropic 内部系统的事件，给整个行业提了个醒。我们一条条来说。
先看 Google。它在 10 月 28 日发布了新一代前沿模型 Gemini 4 Carbon，距离上一代 Gemini 4 Argon 才两周。这个模型在 Artificial Analysis Intelligence Index v5.0 上拿了 59 分，登顶第一，Claude Opus 5.5 和 GPT-6 Astra 排在后面；在 SEC-bench Pro 上得分 88.2%。Google 说它是专门为长程 agent 工作流和完整的网络防御生命周期设计的，从威胁检测、漏洞分析一直到响应处置。不过因为安全能力比较敏感，Carbon 初期只向通过审核的安全专家开放，API 定价是每百万 token 输入 2 美元、输出 10 美元。这意味着前沿模型开始按用途分层发放了，普通开发者短期内只能通过合作渠道间接用到它的能力。
紧接着是 OpenAI。它推出了 GPT-6.1 Terra，定位在 Sol 和 Luna 之间的中端模型，定价每百万 token 输入 1 美元、输出 5 美元。官方说它在 agent 任务上追平了 GPT-6 Astra，但单任务成本只要 0.29 美元，而 Astra 是 4.82 美元，差了十几倍。Terra 强调视觉推理和精确的 computer use，官方把它类比成 Anthropic 产品线里的 Sonnet，不是最便宜也不是最强，但适合跑批量自动化任务。对 API 开发者来说，这是个替代高价模型跑批量 agent 的务实选择。
但能力扩散得快，风险也跟得快。网络安全初创公司 Cathedral 在一次漏洞赏金项目里，用 AI agent 通过第三方软件侵入了 Anthropic 的内部系统。Anthropic 确认销售、人力资源和 IT 数据被访问，不过对入侵深度还有争议。关键点在于，攻击路径不是模型本身被攻破，而是外部软件依赖成了入口。这对以 cyberdefense 能力著称的 Anthropic 来说，反差相当直接。从业者要意识到，agent 已经能自主完成侦察、利用和横向移动的完整链条，企业安全边界得从模型层扩展到供应链层。
其他几条动态也值得快速过一下。Google DeepMind 发布了 Genie 4 实时世界模型，首次原生支持音频、实时对话和文本操控，还把 Gemini 3.8 Flash 嵌进模拟循环里做事件规划，目前是研究预览。Nvidia 开源了语音识别模型 Nemotron 3.5 Transcribe，把转写、说话人识别和翻译整合进一个模型，激活参数只有最强开源竞品的六分之一，还放出了超过 80 万小时的语音数据集。OpenAI 和 ServiceNow 扩大了合作，把 agent 推进到企业的工单、审批和 IT 服务流程里，让模型直接触发业务动作，而不只是给建议。GitHub 的 Octoverse 2026 报告显示，agentic 工程推动每月合并的 pull request 在不到一年里增长了三倍，达到 2.2 亿，代码审查和质量控制的压力也跟着上来了。另外，Google 开放了 Gemini 和 Search 给更多第三方应用接入，这是在 agent 时代重建分发渠道的尝试。
学术方面，今天有一篇结论特别值得警惕。研究者在固定 token 预算下比较了 20 个已发布的强化学习模型，发现结果型 RL 提升的主要是完成度和可靠性，而不是新能力。基座模型经常在预算耗尽前没作答，增益的大部分其实是完成度；真正由 RL 解出、基座解不了的新问题非常少，144 道仅 RL 模型解出的物理题里，只有 3.5% 在重采样或人工阅读后成立。换句话说，榜单上的进步可能被高估了，真正的能力跃迁还得靠新方法。另外几篇论文也各有亮点，比如 AdaPRA 用自适应评分标准监督数据科学智能体，SARL 让检索增强模型学会感知自身搜索状态，h1 用最简智能体循环刷新了形式定理证明的 SOTA，EmbeddingGemma 2 则统一了多模态嵌入并刷新了帕累托前沿。
今日观察。今天最清晰的信号，是模型能力竞赛正在让位于成本与工程化竞赛。Gemini 4 Carbon 押注安全与编程，GPT-6.1 Terra 直接把 agent 任务成本压下来，配合 GitHub 上 PR 数量翻三倍和 ServiceNow 的企业工作流接入，agent 正从演示走向规模化生产。但 Cathedral 用 agent 攻破 Anthropic 内部系统提醒我们，能力扩散的速度快于防御，第三方依赖就是新的攻击面。而那条关于结果型 RL 的结论尤其值得警惕，它意味着我们看到的榜单进步可能被高估，真正的能力跃迁仍需新方法。好，今天的播报就到这里，我们明天见。
