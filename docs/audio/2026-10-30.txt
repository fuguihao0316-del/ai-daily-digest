早上好，今天是 2026 年 10 月 30 日，欢迎收听 AI 行业日报。今天的关键词是"发布"和"分发"——Mistral 和 Google 在两周内接连放出旗舰模型，OpenAI 则一边翻倍订阅额度、一边把 agent 塞进企业工作流。咱们一条条说。
先看模型侧。Mistral 上线了 Mistral Large 4，代号 Le Chonk，这是它迄今最大的模型，大约一万亿参数的原生多模态 MoE，每个 token 激活约五百二十亿参数，支持一百万上下文，原生支持一百六十多种语言，包括全部欧盟官方语言。更关键的是，它在欧洲自有数据中心、用三千八百块 NVIDIA Grace Blackwell GPU 从零训练，GGUF 和 NVFP4 量化版本已经放出来了。这是首次有欧洲实验室把万亿级 MoE 权重按开放形式放出，本地部署的显存规划估计会成为接下来社区讨论的焦点。
Google 这边，距 Gemini 4 Argon 才两周，DeepMind 又推出 Gemini 4 Carbon，主打编码、agentic 任务和网络安全，在 Artificial Analysis 智能指数上以五十九分登顶，定价是每百万 token 输入两美元、输出十美元。因为安全能力敏感，初期只向经过审核的安全专家开放。两周连发两个前沿版本，节奏明显是在压制 Anthropic 和 OpenAI；而按能力分级、限制访问，可能也会成为前沿模型发布的常态。
OpenAI 今天动作最多。先是发布了一套前沿模型失准检测方法，用分层监控在事件升级前发现模型的失准和未授权 agent 行为，把安全监控从离线评测推进到部署期运行时。然后是生态：Google 在 Android Studio 里推出 Bring Your Own Agent，支持包括 Claude Agent 和 Codex 在内的四十多个编码 agent，配套终端工具据说让 agent 完成 UI 任务快百分之七十七，token 消耗最多降到三分之一。OpenAI 则和 ServiceNow 扩大合作，模型和 agent 进企业工单与业务流程，ServiceNow 的工作流也接进 ChatGPT 和 Codex，这是实打实的双向集成。
对开发者更直接的是钱的事：OpenAI 把各付费档位的用量上限整体翻倍，原计划对 Pro 200 的配额下调在用户反对后撤回；同时上线了和 Anthropic 几乎相同的权益，一百、两百、五百美元档的订阅用户可以获得等额、会过期的 API 额度。两家同时把订阅和 API 消费打通，等于把订阅费变成了可迁移的筹码。
其他几条快速带过。NVIDIA 开源了语音模型 Nemotron 3.5 Transcribe，三十 B 总参数的 MoE，激活四点三 B，支持四十种语言转写，还带说话人标签和词级时间戳。Google DeepMind 发布实时世界模型 Genie 4 的研究预览，新增原生音频、实时对话和文本操控。Anthropic 已递交 S-1，计划登陆纳斯达克，这是前沿模型公司首次以公开招股书披露业务结构。
学术方面，今天最值得留意的是评测端暴露的落差。PersonaCUABench 固定七十四个任务、只改变提问者，结果九个基座模型、三千多次运行里，平均任务完成率相对原始请求下降百分之三十六；即使任务完成，用户给出最高满意度的比例也只有百分之六十二点七。另外 RealCLI 显示，最佳配置的平均分只有四十九点二，协作分峰值三十七点六，说明只看任务完成率会高估 agent 的可用性。还有几篇挺有意思：PreView 不重训主模型就能提升 GUI grounding；LongZero 完全不依赖外部数据做长上下文推理的强化学习；CausGround 把交互经验蒸馏成可复用的因果知识，在 VirtualHome 上把成功率从百分之二十四点九提到五十三点三。
今日观察。今天最清晰的信号是，模型能力的竞争正在让位于分发与承载能力的竞争。OpenAI 一边翻倍用量、发放等额 API 额度，一边把 agent 接进 ServiceNow；Mistral 和 Google 两周连发旗舰，迭代节奏已经快过用户的消化速度。但评测端的数字提醒我们，能力增长并没有同步转化为真实可用性。更值得警惕的是，Anthropic 递交 S-1 和 OpenAI 的额度补贴同时出现——上市压力下，用量和收入指标会进一步挤压安全投入，而 OpenAI 主动发布失准检测方法，恰恰说明这种张力正在前台化。好，今天就聊到这儿，我们明天见。
