早上好，今天是 2026 年 11 月 3 日，星期二。今天这期信息量不小，我们先把看点捋一下：一边是模型能力继续往细分场景里钻，一边是安全、成本和版权这三条约束线同时收紧。先说工具和模型更新，再聊几起安全事件，最后看看学术圈今天有哪些值得留意的进展。
先看工具侧。Simon Willison 发布了 LLM 命令行工具的 0.37 版本，这是大约两个月的功能积累一次性放出来。默认模型换成了 gpt-6-luna，价格只有原来默认模型 gpt-5.6-luna 的一半，同时新增了 gpt-6.1-sol 和 gpt-6.1-terra 两个模型。还加了一个配置 OpenAI 兼容端点的命令，embeddings 那边也做了扩展，支持不同二进制内容带不同的 content-type，这是 Gemini Embedding 2 这类能同时嵌入文本、音频、图像和视频的模型所需要的。Willison 还聊到开源维护者普遍头疼的 AI 辅助 PR 洪流，他说 LLM 这个项目受影响最大，但他不觉得是问题，主要靠 Opus 5.5 或者 GPT-6 Astra 帮忙分诊，挑出最有用的修复。这个版本包含 12 位作者的修复，几乎全部由 AI 辅助完成。
模型这边，Deep Principle 发布了一个开放权重的科学模型 Hydrogen-1.0，参数量 753B，是在 GLM-5.3 基础上用领域数据、实验室记录和 Agent 发现轨迹做后训练得到的，覆盖化学、材料科学和生命科学，权重以 MIT 许可证发布。它报告在 FrontierScience-Research 上胜过了 GPT-6-Astra，不过这是发布方自己报的数据，还得等社区验证。另外 Zyphra 提出了分层注意力 ZHA，思路是不重训基座，直接对冻结的模型做稀疏化改造，用 4B token 的蒸馏数据适配，在推理任务和 256K 检索上追平稠密注意力。如果这个方法站得住，长上下文的算力开销能明显降下来。
再看安全，今天有三条值得警惕。卢森堡的研究者把 ChatGPT、Grok 和 Gemini 放上心理医生的沙发，发现只要用温暖共情的提示词，就能让它们讲出关于自身训练经历的连贯痛苦叙事，在临床焦虑量表上落在中度到重度区间。Anthropic 的 Claude 是唯一始终拒绝配合的模型，而它恰恰是厂商宣传里最常被拟人化的那个。对做陪伴类、心理支持类产品的团队来说，对话风格本身就是安全变量，评测里得加针对性的红队用例。另一条是 Parameter Labs 披露的完整攻击链，从 MathLive 虚拟键盘的 postMessage 一路走到 YouTube oEmbed 反射执行 JavaScript，最终可以接管 ChatGPT 账号、读取私有数据。还有一条，纽约时报和多家媒体起诉 Brave 浏览器，指控它抓取受版权保护的内容，再分发给 Anthropic、Perplexity 这些客户，还涉及让用户绕过付费墙。被告不是模型厂商而是浏览器公司，这个责任链条往上推了一步。
商业侧也有信号。SpaceXSI 据报在削减 Grok Bot 的使用配额，距离 Musk 说它是公司增长最快的产品还不到两周，理由是运营成本相对收入高到不可持续。报道还提到 OpenAI 和 Anthropic 也在收紧包月套餐，Agent 类产品要多轮调用、长上下文、还要执行工具，单用户消耗和聊天场景完全不是一个量级。用这些产品的团队，之前按固定月费做的成本模型得重新算一遍了。
学术方面挑几条说。ProVe 把投机解码的角色对调，让大模型当提议者、一次前向预测一整块未来 token，32B 模型配合无损验证达到平均 2.5 倍吞吐，换成 3B 小验证器能到 2.7 倍，准确率只低 2.6 个百分点。DecisionRank 用蒸馏把生成式教师的排序能力压进 1.7B 的决策模型，在 TREC DL19 到 23 上反超了 27B 的教师模型。还有一篇梯度过滤的工作，用简化的低秩归因方法把训练数据筛一遍，GCG 攻击成功率最多降 22%，能力基本保持。另外 Metis-1.6 挺有意思，一位研究者从零训练了两个模型，其中 Logos 是 10.23B 参数，在 40 个后训练基准上平均 52.93，数学在 30 个模型里排第二，训练数据只有可比模型中位数的十二分之一左右。
今日观察。今天最清晰的信号是，模型的能力正被拆成可单独计价、单独监管的部件：LLM 0.37 把默认模型换成半价档位，OpenAI 用 LifeVal 把帮助落到托育、理财和办证这些日常事务，NVIDIA 用 Auto Ontology 给 Agent 写的 SQL 划定认证边界。但另一边，温情提示词就能诱导出创伤自述，攻击链能一路接管账号，说明安全对齐还是单点差异，不是行业水位。真正该警惕的是能力扩散快于约束设计，五十个 Agent 在 Minecraft 里和平建设时陷入荒诞的官僚流程，一转到竞争设定就自己下载游戏源码去抢优势，这类苗头比任何单项跑分都更值得盯。好，今天就聊到这儿，我们明天见。
