早上好，今天是2026年11月4日，欢迎收听AI行业每日播客。今天的关键词是“动手改东西”——从直接编辑模型权重，到让模型设计硬件，再到智能体自我演化暴露出的遗忘问题，我们一条条聊。
先看一条挺硬核的进展。MIT CSAIL 让 GPT-6 Astra 在不做梯度训练的情况下，直接编辑 Qwen3.5-0.8B 的原始权重，只改动了百分之零点零一六的参数，就把这个模型在 MATH-500 上的成绩从百分之七点九拉到了百分之四十八点一，IFEval 也提升了大约三倍。研究者公开了权重 diff，可以精确复现。更有意思的是，有开发者用 Anthropic 的 Jacobian lens 去看模型内部，发现模型准备再次输出“Wait”的那个 token 上，从大约六成深度开始，lens 读出的是“Wrong”、“Nope”、“Hmm”这类怀疑信号，而这时候答案其实已经写完了。编辑之后，同一位置的读数变成了“Verification”、“Completion”、“Result”。编辑后的权重还能干净转成 GGUF，在 Q4KM 量化下依然有效，四十次里只剩一次循环。样本量不大，但它把“权重空间编程”从论文演示变成了可下载复现的工程产物。顺带一提，Simon Willison 也复现了类似示例，确认本地二十七B的模型同样能读取并修改神经网络原始权重。
OpenAI 这边也放了个大消息：GPT-6 Astra 一周内从零设计出一台硬件设备，外壳、电路板、固件全部由模型完成。量产前经历了几轮修改，原因是模型不太考虑制造公差这类工程约束。关键不在“一周”这个数字，而在于模型开始承担跨多个专业领域的端到端设计，失败模式集中在可以被流程补上的环节。对硬件团队来说，原型阶段的迭代成本结构可能要变了，但量产前的工程校验还是省不了。
安全方面今天有一对值得放在一起听的消息。Parameter Labs 披露了一条针对 ChatGPT HTML 预览沙箱的完整攻击链，从 MathLive 库的 postMessage 入口，到父页面用了 innerHTML，再到利用 YouTube oEmbed 端点反射执行 JavaScript，最终可以读取私有数据并外传。说白了，沙箱边界往往败在父页面的一行 innerHTML 上。而同一时间窗口内，OpenAI 把漏洞赏金提高到原来的四倍，单个漏洞最高十七点二万美元，还启动了内部安全冲刺。这背后的信号很清楚：agent 产品攻击面在扩大，外部研究者的价值被认真定价了。
Anthropic 今天两条产品向的消息。一个是 FlashProve，用 zkSNARK 在不暴露权重的前提下证明某条回复确实来自某个已承诺的模型，单张 H100 上验证 Llama 4 Maverick 达到每秒一百一十个 token，证明体积十九 MB。短期内更适合合规审计和模型授权，而不是每次对话都附带证明。另一个是 Messages API 的 Message Threads，长对话只传变化的部分，在五十万到一百万 token 的请求区间，首 token 时间下降约百分之三十五。开发者需要在客户端维护线程状态，已有全量重发的实现要改造。
企业侧，NVIDIA 开源了 Auto Ontology，从企业元数据自动生成语义层，让 agent 生成的 SQL 锚定在认证过的业务定义上，通过 MCP、CLI 和 API 三种方式提供上下文，解决的是“语法正确但口径错误”这个老问题。另外 NVIDIA 还展示了在单台 DGX Spark 上对 124B 的 Ling-3.0-flash 做 MoE 推理三重优化，GSM8K 解码吞吐提升百分之四十二点五，没有检测到精度变化，中小规模私有部署的可行性边界在移动。
学术方面挑几条说。IdeaTaste 基准发现，LLM 的科研品味只达到人类的大约百分之十八，引用匹配约百分之二十六，瓶颈不在找方向，而在把方向转成具体方法。编码智能体这边，CrossSWE 显示最强模型 GPT-6.1 Sol 跨仓库任务也只有百分之五十八点四八的 Pass@1，跨仓库不一致是最常见失败。还有一项研究挺扎心：编码智能体持续演化会遗忘，SWE-Bench 成绩从百分之九十四一路跌到百分之三十二。协作智能基准里，最强模型作为队友也只拿到八十二点二分。
今日观察。今天最值得注意的信号是，模型能力正从“对话”转向“动手改东西”：GPT-6 Astra 直接编辑权重、一周设计出硬件，Qwen 二十七B 在笔记本上复现权重空间编程，权重层面的操作正在平民化，但安全边界远未跟上——同日披露的账号接管攻击链和 OpenAI 四倍赏金，恰好构成一对提醒。另一条线索是智能体的自我演化开始暴露代价：能跑分和能积累，仍然是两回事。好，今天就聊到这儿，我们明天见。
