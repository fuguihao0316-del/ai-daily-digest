早上好，欢迎收听今天的 AI 日报，今天是 2026 年 11 月 7 日，星期六。今天的内容相当密集，一句话概括看点：OpenAI 一天之内连发多个产品，估值冲到一点二五万亿美元，而另一边，一堆新基准提醒我们，模型在真实任务上的成绩单远没有宣传得那么漂亮。咱们按主题慢慢聊。
先看 OpenAI 这一波。图像方面，他们发布了 Images 2.6，还有配套的两个 API 模型，叫 GPT-Image-2.6 Flare 和 Sunburst。Flare 主打速度，单张图最快六秒出。两个模型都新增了 GIF 输出、SVG 导出和标记编辑，还有一个控制生成复杂度的参数。这意味着图像 API 从单纯出图，往可交付素材靠近了，SVG 能直接进设计稿和前端流程。安全方面，OpenAI 推出了 GPT-6 Cyber，专门做授权范围内的漏洞挖掘和修复，重点是把授权边界写进了训练目标，这对企业敢不敢让安全 Agent 上线，比漏洞发现率更关键。科研方面，他们发布了一个叫 BioBasicsBench 的基准，一百项任务，专门测 Agent 处理湿实验原始数据的能力。
资本这边，据 Bloomberg 报道，OpenAI 新一轮又募了一百一十亿美元，估值达到一点二五万亿美元，不到一年涨了大约百分之四十七。同一时间，Anthropic 正接近 IPO，一个走私募，一个走公开市场，头部实验室的资本门槛又被抬高了一档。
其他几家也没闲着。Google 发布 Gemini Omni 1.2 Flash，原生十五秒视频，支持多轮对话式编辑，720p 价格降到每秒零点零七美元，一分钟成本大约四块二，批量试片在商业上可行了。Mira Murati 创办的 Thinking Machines 发布 Inkling 2 Small，混合专家架构，总参数五千九百四十亿，自称西方最强开源权重模型，但代价是 token 消耗明显上升，选型时得把推理账单一起算。Perplexity 推出常驻 Agent 叫 Teammates，跑在独立虚拟机上，持续推进长期项目，但要每月两百美元的 Max 套餐。另外据纽约时报报道，中国情报机构招募了一名 Megaspeed 高管，对 Nvidia 的黄仁勋进行刺探，芯片合规审查正在向人员和渠道环节延伸。
再看评测和论文，今天这块特别值得留意。Wired 的实验显示，免费的 DeepSeek 和 GLM 在模拟入侵任务中，表现已经不落后于 OpenAI 未公开的最强网络安全模型，攻防能力正在快速商品化。清华团队提出用隐空间压缩工具返回结果，Agent 的 token 消耗降了七到九成，运行时间缩短两成到五成多，任务表现还同步提升。还有几个新基准给出的成绩相当克制：OpenFrontiers 里闭卷重发现四十题最多解出七题；VisSearch-Bench 上十六个多模态模型最高只完整解出百分之二十六点四七；鼻咽癌诊疗路径基准成功率最高百分之二十三。另外有个发现挺有意思，同样训练的模型，越狱脆弱性很大程度上由预训练随机种子决定，换个种子，最优攻击模板就换了一批。
今日观察。今天最值得注意的不是单点能力提升，而是资本和评测两条线同时加速。一边是估值冲到一点二五万亿，一边是新基准给出的成绩单相当克制，能力叙事和可验证能力之间的落差正在扩大，谁先把评测做实，谁才握有定价权。另一条信号是 Agent 开始啃硬骨头，漏洞挖掘、湿实验、化学信息学，加上成本大幅下降，这类专用 Agent 会铺得更快，安全和监管压力也会随之而来。好，今天就聊到这儿，我们明天见。
