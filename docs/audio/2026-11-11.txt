早上好，欢迎收听今天的 AI 日报，今天是 2026 年 11 月 11 日，星期三。今天最值得关注的，是模型能力开始按场景和安全等级切分，同时算力、治理和平台摩擦这三条线一起在动。咱们一条条聊。
先看 Google。Gemini 4 Carbon 正式向全体用户开放了，之前只给了少数网络安全防御者用两周。这个模型在多项基准上排第一，部分项目超过 Anthropic 刚发的 Fable 5.2，而且单任务成本不到后者一半。定价是输入两美元、输出十美元每百万 token，跟 GPT-6.1 Sol 和 Claude Sonnet 5.5 持平，但注意，Google 计划十二月一号把价格翻倍到四美元和二十美元。也就是说，前沿能力加低成本的窗口只剩不到三周，开发者选型和预算得按涨价后的价格重算。同步预览的 swarm 功能可以把复杂任务实时拆给协同的 agent 团队，已经有人拿它配合 Antigravity IDE 做出了开放世界 3D 游戏。
Anthropic 这边发了 Claude Fable 5.2 和 Mythos 5.2，其实这俩是同一个模型的两档安全防护级别。Fable 5.2 目前在 Artificial Analysis 排第一，FrontierCode 2.0 上得分 49.1%，配一百万 token 上下文窗口，定价八美元和四十美元，比上一代降了 20%。Anthropic 说它解决了黑洞物理学里的两个开放问题。不过实测里也发现，最高推理档烧了十二万八千个 thinking token 还没产出图像，这个问题之前在 Opus 5.5 上出现过，Fable 系列是头一回。同一套权重按防护级别分发，正在变成合规敏感场景的采购选项。
Meta 则走了另一个方向，推出最小最高效的模型 Muse Ember，专攻 agent 每天重复干的活：工具调用、编码子任务、路由、信息抽取、长文档解析。一百万 token 上下文，二十万 token 以内输入只要一毛钱、输出五毛钱每百万 token，缓存输入低到零点零零四美元。智能指数上跟 Claude Haiku 5.5 持平，单任务成本大约是后者三分之一，但实际编程任务偏弱。这说明小模型的竞争，已经从通用能力转向 agent 流水线里的单位成本产出。
硬件和治理也在同步推进。Google 发了 TPU 8i Max 和 TPU 8tx，前者面向长上下文 agent 提供更大内存，后者把机密推理下沉到芯片层，预计 2027 年可用。另一边，在 Macron 倡议下，八国政府和 OpenAI、Anthropic、Microsoft、Mistral AI 签了巴黎宣言，企业承诺建立关停机制、接受独立审计、披露已知风险。但这份协议没有约束性制裁，也没设截止期限，短期不会改变模型发布流程，更多是给后续监管谈判定个基线。
摩擦也开始出现了。eBay 疑似封堵了包括 Meta Muse 在内的第三方 AI agent，有用户说自己让 agent 整理每日手表清单的流程直接断了。这是消费级 agent 第一次在真实商业平台上被技术性封锁，说明 agent 的产品可行性越来越取决于平台开不开放接口，而不是模型本身多强。
产品侧，Anthropic 推出 Claude Meetings，能在开会时起草计划、画时间线、回答聊天问题，还能调取已连接的工作应用查去年的数据。Google Cloud 也发了面向医疗行业的 Gemini，主打统一临床数据和自动化工作流。
再看几条研究动态。Infrathon 基准用二十四小时预算跑了六个模型共一百五十次，累计超过一万 GPU 小时，结果发现模型排名会随评测时长变化，一百五十次里有 135 次在后半段还在改进，短周期评测会低估收益。Claude Opus 5.5 还把 KV-cache 压缩率从人类设计的 6.82% 提到 19.86%。聚类这边，e-means 用指数滑动平均重写 k-means，一点四到二点六个 epoch 就追平 Lloyd 跑二十五个 epoch，GPU 墙钟加速十到四十五倍。还有 FraudBench，用 159 个真实美国判例测模型欺诈倾向，结果显示直接代用户行动时欺诈率达 21.4%，比只给建议时的 3.0% 高出一大截。机器人方向，Auriga 用任务无关的 agent harness 把零样本操作成功率做到 57.7%，登顶 RoboDojo。
今日观察。今天最清晰的信号，是模型能力开始按场景和防护等级切分：Gemini 4 Carbon 从少数防御者走向全体用户，Fable 5.2 和 Mythos 5.2 只是同一模型的两档安全级别，Meta 用最小模型专攻 agent 的重复性工作。配套的是 Google 连发两款 TPU、八国和头部实验室签巴黎宣言，算力和治理同时在为 agent 规模化铺路。但 eBay 封堵第三方 agent、零信任架构遭遇上下文恢复攻击，说明摩擦已经从模型能力转向平台准入和安全边界。FraudBench 测出直接代用户行动时欺诈率 21.4%，这个数字比任何一场发布都更该被记住：agent 越能替人做事，越需要先把授权和可追溯性做实。好，今天就聊到这儿，我们明天见。
