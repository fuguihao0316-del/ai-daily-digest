早上好，欢迎收听今天的 AI 行业日报，今天是 2026 年 11 月 12 日，星期四。今天信息量很大，一句话概括看点：模型厂商开始按“安全等级”和“部署形态”把能力切成不同产品，而 agent 真正走进现实世界之后，摩擦和短板也集中暴露出来。咱们分几条线来说。
先看 Anthropic。昨天他们启动 IPO 路演，联合创始人 Tom Brown 第一次公开了多芯片战略的细节：Claude 的训练和推理，现在同时跑在 AWS Trainium、Google TPU、NVIDIA GPU 和 AMD GPU 四个芯片家族上。最让人意外的是接入 AMD 的过程，他们让内部模型 Mythos 自己去尝试，三天就完成了移植，几乎没人工干预，Claude 几乎百分之百的 kernel 都是模型自己移植或编写的。而过去引入一个新芯片平台，要几十名工程师干好几个月。这件事的含义很直接：模型厂商正在把“用自家模型优化异构硬件”变成压低成本、削弱 CUDA 依赖的常规手段。
同一天，Anthropic 还发布了 Claude Fable 5.2 和 Claude Mythos 5.2，其实是同一个模型，只是安全防护级别不同。Fable 5.2 在 FrontierCode 2.0 上得分 49.1%，定价是每百万 token 输入 8 美元、输出 40 美元，配 100 万 token 上下文。这个价格是同日 Meta 新模型的 80 倍。双版本策略的意思是，客户可以按风险场景选防护强度，不用在能力和合规之间二选一，安全分级本身开始变成采购维度。
说到 Meta，他们推出了最小、最高效的模型 Muse Ember，主打 agent 全天重复干的活：工具调用、编码子任务、路由、抽取、长文档解析，支持最多 100 万输入 token。短 prompt 定价每百万输入 0.10 美元、输出 0.50 美元，超过 200k 之后涨到 0.30 和 1.50。在 Intelligence Index 上和 Claude Haiku 5.5 持平，但每任务成本大约是它的三分之一。对小模型选型的人来说，缓存输入 0.004 美元加上百万上下文，是这轮低价竞争的新基准。
Google 这边动作也不少。DeepMind 发布了 Gemini Decisions API 和 Gemini Decision 1，正式加入决策模型赛道，支持是非题、多选和评分量表，覆盖文本、图像、音频、视频和 PDF，单次最多能评估 1000 个封闭式问题，返回只要 150 到 250 毫秒，成本约为 Gemini 3.5 Flash-Lite 的五分之一。另外，Gemini 4 Carbon 今天向全体用户开放，发布价是每百万输入 2 美元、输出 10 美元，但 12 月 1 日要翻倍到 4 和 20 美元，也就是说，涨价前的窗口期不到三周。还有一个挺震撼的：AlphaProof Code 四周完成了 Signal 加密核心的形式化验证，通常这类工作以年计，AI agent 写了超过六百万行证明代码，只有大约百分之一需要人工复核。DeepMind 还发布了 AlphaGenome 2，能按细胞类型预测变异效应，通过 API 向非商业研究开放。
硬件和机器人这条线，NVIDIA 发布了开源自动驾驶模型 Alpamayo 2 Edge，输入是 6 路摄像头加近期运动信息，用强化学习循环训练，优化版本在 AGX Thor 这类边缘硬件上比 PyTorch 快十倍以上。这意味着开源栈开始在车端算力约束下真正可用了。
然后是 agent 撞上现实世界的几条摩擦。eBay 疑似封堵了包括 Meta Muse 在内的第三方 AI agent 浏览平台，有用户说连续几周让 Muse 整理每日手表在售摘要，现在流程被打断了。这和 ChatGPT 同期推出已验证 Business Agent 形成对照：一边封堵，一边开放官方通道。做 agent 产品的团队要留意，抓取式浏览的商业可持续性正在下降。
学术方面今天有几个值得记住的结论。一篇叫 Deletion Tuning 的论文发现，只把不到 0.05% 的权重置零，就能在三种后训练范式下媲美全量微调，灾难性遗忘还明显减轻。具身智能评测 Embodied First Exam 显示，八个智能体里最强的 GPT-6 Astra 在标准设置下成功率只有 34%。金融智能体基准 FINCOSMOS 更狠，150 场会话没有一场被接受。还有一篇等算力协议的研究，直接推翻了稠密奖励的结论：算力对齐之后，Monte-Carlo 过程奖励反而比 GRPO 低 14.3 个百分点。
今日观察。今天最清晰的信号是，模型能力开始按安全等级和部署形态切分：Anthropic 同一模型出两档防护，Mythos 三天完成向 AMD 移植，Meta 用小模型打高频 agent 负载，竞争重心正从跑分转向算力自主和推理成本。另一条线是 agent 进入真实世界后的摩擦：eBay 封堵抓取，具身智能体最强只有 34%，金融智能体 150 场全军覆没，说明能力扩张快于信任和安全基建。值得警惕的是，评测和治理明显滞后于发布节奏，Gemini 4 Carbon 开放两周后就翻倍定价，也提示这轮能力释放带着很强的商业试探性。好，今天就聊到这儿，我们明天见。
