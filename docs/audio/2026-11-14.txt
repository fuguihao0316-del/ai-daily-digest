早上好，欢迎收听今天的 AI 日报，今天是 2026 年 11 月 14 日，星期六。今天最值得关注的，是 agent 正在从演示走向真正的交易和生产场景，同时算力和供应链的政治化也在加速。咱们一条条来聊。
先看 Anthropic。它在 IPO 路演视频里第一次系统披露了算力策略，联合创始人 Tom Brown 说，Claude 的训练和推理已经同时跑在 AWS Trainium、Google TPU、NVIDIA GPU 和 AMD GPU 这四个芯片家族上。要知道，多芯片押注早期被普遍认为不划算，因为每类芯片都得配独立的软件栈，成本很高。但 Anthropic 说他们已经积累多年经验。最具体的例子是今年第一次接入 AMD GPU，过去引入新平台要几十名工程师干好几个月，这次靠内部系统 Mythos，只用了三天就让 Claude 在 AMD 上跑起来，几乎没人工干预，Claude 自己移植或编写了近百分之百的 kernel。对做推理部署和自建集群的团队来说，多芯片异构调度正在从研究课题变成可复用的工程能力。
另一条算力相关的消息挺炸的。前 OpenAI 研究员 Will DePue 声称，在 DeepSeek、Moonshot AI、MiniMax 和蚂蚁集团的六个中国模型里，检测到了 NVIDIA 最新 Blackwell GPU 的指纹。他的方法是从已发布的模型权重里直接读芯片特征签名，不靠供应链记录，这比之前的间接推断更进一步。他估计这五次训练运行的硬件成本超过五亿美元。如果这个结论被独立验证，出口管制的执行难题就从物流层面推到了模型权重层面，公开发布的模型文件本身可能成为合规审查的证据。用这些模型做二次训练或商用的团队，要留意后续监管口径的变化。
模型方面，Google 发布了 Gemini 4 Hydrogen，定位是 Gemini 4 家族里成本最低的成员，支持一百万 token 上下文和四档思考等级，定价是每百万输入 token 一块五美元、输出七块五。不过要注意，同家族的 Carbon 和 Argon 现在还是两块和十块，但十二月一号会翻倍到四块和二十块，到那时 Hydrogen 才真正体现出大约七五折的折扣。现在它其实只比高端同门便宜两成半，却仍比 Claude Haiku 5.5 和 GPT-6 Luna 贵大约十五倍。这个模型已经在搜索、Gemini 应用和各订阅层级上线，适合需要长上下文和多步工具调用的 agent 工作负载做成本测算。
说到 agent，OpenAI 推出了 ChatGPT Wallet，让 ChatGPT Work、Codex 和 dots 里的 agent 在用户批准下完成购买，沿用现有的信用卡保护机制。首先面向美国十八岁以上、用符合条件的美国运通、大通、万事达和 Visa 卡的 Pro 订阅用户滚动开放。这意味着 agent 的能力边界从生成内容推进到了执行交易，审批环节成了风控核心。对开发者来说，agent 产品开始要处理支付授权、额度和争议处理这些金融级工程问题；对商家来说，流量入口可能部分转移到对话界面里。
Google 这边还上线了 Gemini Decisions API，由新模型 Gemini Decision 1 驱动，做快速、经过校准的多模态决策。它和 Jev、OpenAI 的决策模型属于同一品类，支持是或否、多选和评分量表三类问题，定价和 GPT-6 Luna 决策模型一致，每百万输入十美分、输出免费。差异在模态覆盖，Gemini Decision 1 覆盖文本、图像、音频、视频和 PDF。实测里它对是或否问题返回的是概率值，比如判断视频里有没有机器人，给出零点九二的置信度。对需要批量做内容审核、路由或质量打分的系统，这能极低成本地替代通用大模型调用。
还有一条人事震动。据 TechCrunch 报道，黄仁勋离开 NVIDIA 后，创始人和风投普遍预期 AI 创业公司会面对更小的支票和更低的估值。黄仁勋任内 NVIDIA 向 AI 初创投了数百亿美元，这种以芯片厂商为核心的资金循环很大程度上支撑了一级市场定价。华尔街日报说，他的离任更可能源于公司高风险的商业实践，NVIDIA 曾为云厂商的芯片采购提供数十亿美元财务担保，包括一项计划中的两千五百亿美元 OpenAI 交易。依赖 NVIDIA 投资或算力担保的初创公司，融资节奏和条款短期内可能明显收紧。
Anthropic 还发布了 Claude for Manufacturing 插件，把模型直接接进 Autodesk Fusion、Oracle NetSuite 和 Infor 这些工业和 ERP 系统。插件包含十七项专用技能，可以起草报价、比较供应商，交付延迟时下备份订单，所有动作都要人工批准。这是 Claude 从通用助手向垂直行业工作流嵌入的又一步，也意味着模型厂商直接对接主流 CAD 和 ERP，会压缩中间层工具的空间。
基础设施上，Google 开源了 TPU Sync，一个 C++ 库，用来在 TPU 的 HBM、主机内存、存储和网络之间搬运 KV cache 和模型权重。在二百三十五亿到四千八百亿参数的 MoE 模型上，KV 传输延迟降低超过九成。自建 TPU 推理栈的团队不用再从零实现这块，也降低了长上下文服务的显存压力。
研究侧今天也有不少看点。Google DeepMind 发布 AlphaGenome 2，能按细胞类型预测调控活性和变异效应，通过 API 面向非商业研究开放。论文里，MixUA 给多用户多智能体记忆做了分级，按受益范围和披露风险分成四种作用域，隐私探针里最多只有万分之二的私人事实泄漏到禁止区域。EgoX 用所谓具身做梦的统一架构，把跨形态机器人示范的平均任务进度从零点六三提到零点八。还有 DeepStress，专门用可控的劣质证据压测深度搜索 agent，发现不少开放权重 agent 面对明显可信度红旗仍然自信作答，说明现有基准分数可能高估了真实检索场景下的可靠性。
今日观察。今天最清晰的信号，是 agent 正从演示走向交易和生产。OpenAI 的钱包让 agent 直接代付，Anthropic 把 Claude 接进工厂软件，Google 用低成本的 Hydrogen 和 Decisions API 抢占 agent 的决策与执行层，竞争重心正从模型分数转向谁掌握支付、工具链和工作流入口。另一条线是算力与供应链的政治化，Anthropic 亮出多芯片策略，中国模型被指带 Blackwell 指纹，国会又查 NVIDIA 对华销售，模型能力和硬件来源正被绑成同一件事。研究侧，SO-Arena 显示最强模型在决策可靠性上只排第七，DeepStress 专攻劣质证据，都提示能力提升并没有同步带来稳健，这是落地阶段最该警惕的落差。好，今天就聊到这儿，我们明天见。
