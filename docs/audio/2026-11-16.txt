早上好，欢迎收听今天的 AI 日报，今天是 2026 年 11 月 16 日，星期一。今天信息量很大，一句话概括看点：国产算力把万亿参数模型跑通了，Google 一口气放出好几个新东西，而 agent 正在从"给建议"走向"能花钱"。我们挨个聊。
先看今天最重的一条。美团开源了 LongCat-2.5，一点六万亿参数的 agent 模型，关键是训练全程没用 Nvidia 的 GPU，部署示例跑在一百九十四颗华为 Ascend 芯片上。在 Terminal Bench 上拿了八十八点四分，仅次于 Claude Opus 5。这意味着什么呢？超大规模 MoE 模型在国产算力上端到端训练和推理，已经被推到万亿参数这个级别了。对做 agent 的团队来说，终端操作类 agent 的能力基线又被抬高了一截，基于旧基线做的评测结论，得重新校准了。
说到 agent 模型，Google 这边发布了 Gemini 4 Hydrogen，定位是快速 agentic 模型，一百万 token 上下文，四档思考层级，输入每百万 token 一块五美元，输出七块五。速度比 Gemini 3.8 Flash 快二点五倍。这个组合实际影响的是 agent 工作流的成本结构，多步工具调用场景里，延迟和单价同时下降，那种"便宜快模型跑外层循环、强模型做关键决策"的分层设计就变得更划算。不过它在 Terminal-Bench 上是百分之五十七，跟美团那个八十八点四比，明显是两个档位。
数学基准这边也有变化。MathArena 上 OpenAI 不再是第一了，Google 的 Gemini 4 Carbon 和 Anthropic 的 Fable 5.2 把 GPT-6.1 Sol 挤下了榜首。但代价不小，Gemini 4 Carbon 的成本是 GPT-6.1 Sol 的十五倍。还有个细节挺有意思，Gemini 几乎从不在任务上放弃，甚至会无视时间限制。这在长时限 agent 任务里可能是优点，但在需要快速失败的批处理场景里就是负担，评测口径得把时间预算算进去。
基础设施方面，Google 开源了 TPU Sync，一个 C++ 库，专门在 TPU 的 HBM、主机内存、存储和网络之间搬 KV cache 和模型权重。官方说在两百三十五 B 到四百八十 B 规模的 MoE 模型上，KV 传输延迟降低超过百分之九十。长上下文推理和 PD 分离架构一直卡在这个搬运瓶颈上，这个数字直接影响首 token 延迟和多轮会话吞吐，做大规模服务的团队值得看一看。
机器人这块，Runway 以 Apache 2.0 开源了 Praxis-1，同时开放权重和源码。它把视频训练里学到的知识迁移到机器人控制上，在 Nvidia 的 RoboLab-120 基准里拿了 World Action Model 类别第一。局限也写得很清楚，目前还不能自主规划复杂动作序列。但路线意义很大，用大规模视频预训练替代传统遥操作数据采集，而且是可以直接下载复现的。
再看 agent 走向执行的关键一步。OpenAI 给 Dots 平台推出了 ChatGPT Wallet，首批面向美国用户开放，让 ChatGPT Work、Codex 和 Dots 里的 agent 在用户批准的前提下完成购买。支付授权、用户确认、风控责任怎么在 agent 链路里分配，这是所有做自动化采购、订票、下单的团队都绕不开的问题。
Nvidia 这边人事动荡还在发酵。安全主管八月就悄然离职了，TechCrunch 报道说，CEO Jensen Huang 也因多项关系辞职，其中包括与一名被怀疑向中国输送芯片的公司高管的关系。美国国会这边，民主党和共和党都在推动收紧 AI 芯片出口的法案，还要求 Huang 到国会作证。亚洲多国政府反应也不一样，有的在确认芯片供应承诺，有的在评估本地项目影响。对依赖跨境算力采购的团队，合规风险得往前放，别等清单落地再调整。
研究方面今天有几篇值得留意。一篇讲多用户多智能体记忆的 MixUA，把经验按作用域分成用户-智能体对、用户、智能体、全局四层，通过率最高提升十六个百分点，隐私探针泄漏最多只有万分之二。还有一篇 EgoX，用"具身 dreaming"做跨具身操作学习，平均任务进度从零点六三提到零点八零。另外 The Value of Thinking 提出 zero-or-T thinking，让模型自己判断值不值得推理，延迟降低七成多。还有一篇 JustRUA，专门拆解 GPT-6 机器人 agent 的设计，发现场景几何帮助最大，基准分数从二十九点七提到五十点三。
好，到了今天的观察时间。今天最值得关注的，是算力与供应链的自主化叙事在同时加速：美团用非 Nvidia 硬件训出一点六万亿参数模型，Google 开源跨卡 KV Cache 传输库，而美国国会正拟收紧芯片出口。模型竞赛的重心，正在从参数规模转向成本结构，Gemini 4 Carbon 登顶却付出十五倍成本，说明能力领先和可负担性开始分道扬镳。另一条线索是 agent 正被赋予行动和支付权限，钱包、记忆、经验交接、决策可靠性，这些研究共同指向同一个风险：系统越自主，错误的传播路径就越难追溯。好，今天就聊到这儿，我们明天见。
