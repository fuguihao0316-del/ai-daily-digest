早上好，今天是 2026 年 11 月 22 日，欢迎收听今天的 AI 日报。今天的关键词是“换路线”——从训练方式到调用方式，行业正在悄悄改地基。咱们花几分钟，把今天最值得关注的几条串一遍。
先看模型训练这边。Bytedance 联合多所美国高校发布了 AI agent 模型 Axion 1.0，基准测试上直接对标 OpenAI 和 Anthropic 的顶级商用模型，但整个训练流程只用了三个阶段。研究团队把性能提升归功于精心筛选的数据，而不是堆训练步数，这等于正面挑战“更多阶段、更多算力”的主流范式。更关键的是，权重、训练数据和代码全部免费开放，中小团队可以直接复现。开源阵营在 agent 能力上追平闭源前沿，这回算是拿出了公开证据。
说到闭源，OpenAI 这边动作也不少。他们大幅加强了 GPT-6.2 Astra 和 Sol 的内部推理防提取保护，自适应红队测试里，提取成功率从百分之五十四降到了百分之零点二，同时每周会因协同蒸馏封禁数千到数万个账号。对做模型评测和 API 二次分发的团队来说，靠探测模型内部推理做差异化的空间正在收窄。OpenAI 还发了一批新的提示词模板，专门治回答太短、动不动反问、写代码测试过多这几个毛病；但有个细节值得注意——编辑对话历史可能丢掉模型的推理内容，所以多轮 agent 的开发者，重心要从“怎么问”转向“怎么维护对话状态”了。
语音这边有个实打实的好消息。OpenAI 上线了 GPT-Live-1.1，全双工语音模型，改进了多语言口音和转写质量，空闲计费从每分钟五美分降到两美分。别小看这一半多的降幅，真实通话里大量时间都花在等用户开口和保持连接上，这会直接改写客服、陪伴类产品的单位经济模型。
基础设施层面，Perplexity 推出了 Orchestrator API，一个端点接入 OpenAI、Anthropic、Google、xAI 还有开放权重模型，支持跨供应商故障转移和统一计费。竞争焦点正从“选一个模型”转向“管理一组模型”的中间层。NVIDIA 则开源了 Nemotron-Labs-Sigma 连续扩散语言模型，十四个 checkpoint，解码速度最高比自回归快四点二倍，给低延迟场景提供了另一条路。
硬件和资本方面，Anthropic 上周四登陆纳斯达克，一家把安全放在产品节奏之前的公司，能不能扛住公开市场的季度压力，接下来看财报就知道。Meta 的 Muse Charm 据报定价三百美元，年底假日季出货，成败取决于 agent 能力本身，而不是硬件参数。
最后快速过一下学术侧。有论文提出零梯度改写自身权重，一个 270 亿参数模型靠自我编辑提升了六点六个百分点的准确率；还有研究把精确算术电路直接编译进预训练权重，六位数运算准确率逼近百分之百。另外一篇发现，扩散 Transformer 的强化学习后训练，大部分收益其实可以用一组固定偏移解释，参数量少了六十五倍。当然也有泼冷水的——模拟操作基准的成功检测器被查出六十一个缺陷，评测这块地基还得补。
今日观察：今天最值得注意的，是模型能力提升正从“加大训练”转向“改结构、改接口”。Axion 1.0 质疑训练阶段的必要性，两篇论文直接绕开梯度去改写权重；Perplexity 统一路由、OpenAI 压低空闲成本，竞争明显移向编排层和调用成本。但 Token 欺诈逼得 ChatPRD 关停免费试用，基准检测器又被曝大量误判，提醒我们：能力叙事跑得越快，计量和评测这两块地基就越显得薄弱。好，今天就聊到这儿，我们明天见。
