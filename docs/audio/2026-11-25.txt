早上好，今天是 2026 年 11 月 25 日，欢迎收听 AI 行业每日播报。今天的关键词是两个字：加速。模型架构在加速迭代，agent 的基础设施在加速铺开，但与此同时，安全可控和可靠性这两个老问题，也在加速暴露。我们一条条来说。
先看模型这边。中国实验室 Z.ai 发布了 GLM-5.4，这是他们第一个采用循环 Transformer 架构的模型。简单说，就是让同一组权重反复迭代、精炼隐藏状态，不增加参数量也能把网络做深。这已经是本周第二次出现循环 Transformer 的消息了，此前 Thinking Machines Lab 的 Inkling 2 Mini 也用了类似思路。GLM-5.4 目前还没有开放权重，需要订阅 Coding Plan 才能用。
另一边，OpenAI 把 GPT-6.2 Sol 设成了 ChatGPT 的默认模型，全球推送。内部测试里，图像理解准确率从百分之四十七点四提升到百分之七十一点七，困难指令的正确执行率到了百分之七十八点一。这个提升对带图提问、截图排障这些高频场景是实打实的。开发者要注意，默认模型换了，原来的 prompt 和工具调用链路最好重新验证一遍。
还有一个挺震撼的研究：OpenAI 说 GPT-6 系列能通过推理和写代码来设计蛋白质，实验室在五个靶点上找到了结合证据。注意，这不是专门微调出来的能力，是通用推理迁移到了结构生物学上。
再看 agent 基础设施。Anthropic 这边动作很密。MCP 的 SDK 月下载量突破了七亿次，协议还新增了后台任务、向用户追问、文件上传这些能力。同时他们推出了 Claude Ship，把代码评审、PR 修复和批准打包成产品，Claude 从给建议的助手，变成了能直接改代码、放行代码的流水线角色。Google 也没闲着，在 Gemini API 里预览了 Tool Retrieval，工具库再大，也只按需加载参数 schema，把 token 成本压回实际调用范围。开源社区这边，港大的 CLI-Anything 冲上趋势榜，思路是把命令行当作 agent 操作软件的通用接口，绕开一个个单独写集成的成本。
不过，能力跑得快，问题也跟得紧。据 Axios 报道，OpenAI 和 Anthropic 有数十名员工认为，自家还没发布的前沿模型已经超出了安全措施的可控范围，内部甚至在讨论要不要暂停发布、甚至停止训练。另外，一个新基准显示，即使最顶级的 agent，在完成日常任务时仍然难以做到可靠和安全。还有一条挺有意思，Anthropic 一位研究员用 AI 产出了 1700 万行的黎曼猜想证明，数学家预计要读好几个月。
学术方面今天也很热闹。LoomFormer 提出织机注意力，让 Transformer 能在每个 token 上动态重接电路，用三分之一的算力就能匹配常规模型。S-Mind 把多视图几何内化进多模态大模型，空间基准最高提升二十二点多。NightWatch 用一个只有 0.8B 的轻量模型做实时感知，把计算机使用 agent 的浪费时间降低了百分之五十三。另外还有面向本地部署的医疗模型 KMed-31B，以及揭示医疗空间推理短板的 Clinical3D-Bench，最佳闭源模型的准确率也只有百分之五十三点六，离医生的百分之七十九还差得远。
好，进入今天的观察。今天最值得警惕的信号，来自那两家前沿实验室的内部：员工自己觉得，模型的能力已经跑到了安全护栏前面。而同一天，我们既看到 AI 写出人类几个月都读不完的数学证明，也看到它设计蛋白质，还看到 agent 基础设施以七亿次下载的量级铺开。能力跃升和可解释性、可控性之间的缺口，正在同步拉大。扩张速度和可靠性之间的这道落差，就是接下来最该盯住的地方。好，今天就聊到这儿，我们明天见。
