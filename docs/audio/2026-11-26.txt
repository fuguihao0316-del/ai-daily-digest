早上好，欢迎收听今天的 AI 日报，今天是 2026 年 11 月 26 日，星期四。今天最值得留意的，是 AI 的竞争焦点正在从模型本身，悄悄转移到运行层，也就是谁能把 agent 安全地放进生产回路里。另外，架构效率这条新路线也开始浮出水面。我们一条条来说。
先看模型这边。中国的 Z.ai 发布了 GLM-5.4，这是它第一个采用 looped transformer 架构的模型。简单说，传统 Transformer 每一层在前向传播里只跑一次，而 looped transformer 让一组共享权重的层反复迭代运行，参数量不增加，网络却更深、隐藏状态也被反复精炼。有意思的是，这已经是本周第二次出现这个动向了，十一月二十号 Thinking Machines Lab 的 Inkling 2 Mini 也用了类似思路。GLM-5.4 目前还没开放权重，Z.ai 说会在完成安全加固后负责任地开源，暂时也不能通过常规 API 访问，需要订阅 Coding Plan。
再看大厂这边的动作。Google DeepMind 的研究主管 Koray Kavukcuoglu 确认，AI agent 已经接管了部分为新一代 Gemini 模型跑实验的算力，不过他强调，距离递归自我改进还很遥远。他们还特意不去训练 agent 的内部思维链，好让人工审查始终有抓手。Anthropic 这边推出了 Claude Ship，把代码审查、PR 维护和审批三个组件打包，覆盖 GitHub pull request 的整个流程，coding agent 的作用范围从写代码延伸到了代码合入。OpenAI 则和 Cisco 一起开源了 Shirudo，一个基于 Linux eBPF 的运行时，让 agent 生成带签名的防护策略，在系统运行中直接阻断漏洞利用路径，争取打补丁的时间窗口。安全方面还有一条，OpenAI 正在测试 Private Inference，承诺企业用最强模型查询时，OpenAI 自己看不到数据，这正在成为模型供应商竞争的新一条轴。
产业和地缘这块，据 The Decoder 报道，芯片出口限制、反蒸馏措施加上海外获取 Nvidia 硬件渠道收窄，正给 DeepSeek、Moonshot AI 和阿里巴巴带来越来越大的压力。DeepSeek 研究人员内部估计，自家模型已落后美国模型最多九个月，而且差距还在扩大。这也解释了为什么受限的一方开始从架构效率上找突破口，比如刚才说的 looped transformer。另外几条快讯：Amazon 据报正和 Meta 谈，可能解除对 Muse AI 购物 agent 的封锁，焦点是 agent 推荐哪些商品、以及这对广告收入的影响；FCC 批准 SpaceX 部署最多一百万颗搭载 AI 芯片的卫星；还有 Yale 的 Sonnenfeld 公开质疑 Nvidia 的公司治理和出口合规风险。
学术方面今天信息量很大，我挑几个重点。OWE-Bench 用二十六个长周期工程任务做评测，发现所有模型在隐藏用例上平均低十八分，也就是所谓的部署落差，而且模型普遍高估自己大约二十一分。ICLWorld 的结果更直观，前沿模型在电脑使用任务上能做到百分之八十二，到了机器人任务上只剩百分之二十七。另外，InstructReplay 发现，学新事实会让通用能力平均掉三十五分，但让模型回放自己当初的回答，就能把跌幅从二十八分压到两分多。还有 Model Carving 和 DyLoMo-DiT，都在说同一件事：与其堆参数，不如在训练中直接削出更小的网络，或者复用参数，效果反而更好。
今日观察。今天最清晰的信号，是 AI 的能力扩张正从模型层转移到运行层。DeepMind 让 agent 自主跑实验，Anthropic 用 Claude Ship 接管 PR 流程，OpenAI 和 Cisco 为 agent 做运行时防御，三件事指向同一个转向：竞争焦点变成了谁能把 agent 安全地放进生产回路。与此同时，芯片管制和反蒸馏据报已拖慢中国实验室，而 GLM-5.4 转向 looped transformer，说明受限的一方正从架构效率而非算力规模上找出路，这条分叉会决定明年的模型格局。学术界则在补另一块短板：能力在真实环境中的折损，远大于榜单上显示的数字，这比任何单点突破都更值得警惕。好，今天就聊到这儿，我们明天见。
