Approximating Softmax in Pretrained LLMs：B200 上软注意力近似与内核加速
研究团队在十个冻结的 decoder-only 模型（0.5B-72B）上系统刻画了预训练 Transformer 对 softmax 精度的真实需求。背景是 NVIDIA Blackwell B200 上 tensor core 吞吐比特殊函数指数吞吐高出两个数量级以上，fused attention 中的指数求值成为瓶颈。关键发现包括：softmax 分配概率的位置数量与行内分辨率可以大幅压缩，但对同一批位置做均匀加权会严重损害性能；固定分辨率预算的投放位置与预算大小同样重要，靠近行最大值的分辨率始终更优；在标量失真匹配的扰动下，不同模型会给出符号相反的响应。基于这些发现，作者提出 Rowmax-PoT，一种以每行最大值为锚点的粗粒度对数权重表示，以及其在 FlashAttention-4 中的硬件特化实现 Rowmax-H15。在 B200 上，打补丁后的 FP8 attention 前向在 causal 8K 下快 12.4%，在 non-causal 8K 下快 25.8%；causal 16K 下每次前向的板级能耗下降 8.4%。在 BF16 内核路径 2K 下单独测量，Rowmax-H15 在来自三个家族的五个模型上使困惑度上升 0.091-0.492%。

Selecting Diverse SFT Traces Improves Post-RL Generalization：路线多样性决定 RL 上限
论文系统研究了 SFT 数据中「推理路线多样性」（reasoning step 序列的变化程度），并提出一种轻量、基于规则的指纹来筛选这种多样性。实验控制严格：同一数据池、同一预算、匹配的训练配方与检查点。结论是选择多样化而非相似的推理路线，能提升 RL 之后的问题覆盖度，且覆盖到比两个训练阶段所见都更难的问题。在合成实验中，路线多样的 SFT 让 OLMo3-7B 在 SFT 未见的环境上 pass@8 提升 16.9 分；在单模型条件下（所有候选都由同一个模型生成），多样化选择在 10 个数学基准上平均 pass@8 最多提升 6.2 分。RL 前的诊断给出了机制解释：多样 SFT 虽然平均准确率略低，但能在更多 prompt 上同时产生成功与失败尝试，从而为 group-relative RL 提供更多带学习信号的 prompt。在三个开源语料上，这个仅用 CPU、不调用模型的选择器在每一组 post-RL 平均性能对比中都优于更昂贵的替代方案。

Do We Really Need KL Divergence for On-Policy Distillation：只保留更新方向即可
论文对 on-policy distillation（OPD）的标准损失 KL divergence 提出质疑。作者发现，只要保持更新方向指向 teacher，OPD 就能有效工作，KL 散度并非必要。更精确地说，起决定作用的不是每个 token 的方向，而是 teacher 与 student 分歧强烈的一小部分 token 的方向。实验显示，简单地对 teacher 概率高于 student 的 token 赋 +1 奖励、低于的赋 -1 奖励，即仅鼓励朝 teacher 方向更新，就能复现与 reverse KL 版 OPD 几乎相同的训练模式。进一步实验表明，只要分歧大的那部分 token 的更新方向朝 teacher，即使其他 token 被推离 teacher，训练依然有效。作为应用，作者提出 Consensus Multi-Teacher On-Policy Distillation（C-MOPD）改进多教师 OPD：原 MOPD 将每个样本路由到单一 teacher，可能引发跨域能力冲突，C-MOPD 则让每个样本同时接受多教师共识。这为蒸馏损失设计提供了更省算力的替代路径。
★★★★★
HuggingFace Papers
WhiteMatter：通过 KV Source Mixing 实现全连接跨层信息复用
标准 Transformer 在生成文本时，每一层只能使用同深度层的表示，无法复用已经算出的信息。WhiteMatter 打破这一限制，让每一层都能取用任意深度的历史 token 表示：一个学习到的 mixer 为当前上下文挑选最有用的深度，并将其表示组合成共享的 key-value（KV）cache 通道。共享这些通道还能压缩缓存体积。在相同训练 token 数下，使用完整缓存的 WhiteMatter 与层数多 50% 的标准 Transformer 性能相当；在 KV cache 减半时，WhiteMatter 在两个模型规模（最大 1.3B 参数）上均超过同等标准 Transformer。代价是跨层连接引入依赖，拖慢训练与 prompt 处理。作者用 cyclic iteration 解决：轮流更新交错分组的 token，组内并行处理。在按精确自回归执行训练的参考模型上，cyclic iteration 的收敛速度比标准 Jacobi iteration 快 12.5 倍。

OLIVE：在学生状态上向教师续写，在线蒸馏新范式
论文提出 OLIVE（OnLine InterVEntion），针对现有蒸馏方法的三类缺陷逐一设计：离线 SFT 在固定教师轨迹上存在序列性协变量偏移；token 级 on-policy distillation（OPD）在前缀失败时监督碎片化；分布匹配蒸馏则要求访问教师的 token 概率。OLIVE 的每轮迭代中，演化中的学生策略生成新前缀，教师自回归续写该前缀，学生用教师生成 token 上的交叉熵更新。在同等 GPU 小时成本下，OLIVE 的推理性能高于使用 top-16 KL 近似的 OPD；异步实现进一步将总训练时间减少 23.8%。在困难推理任务与反映现代后训练场景的 agentic 任务上，相同训练预算下 OLIVE 稳定优于现有蒸馏方法。由于前缀由演化中的学生重新生成，OLIVE 能在离线蒸馏进入平台期后继续提升，同时更好地保留学生的通用能力与可塑性。仅使用 GPT-5.4-mini 的文本，在 ScienceWorld 上持续用 OLIVE 训练比同教师的离线 SFT 高出 13%。

Specification Before Generation：预注册五模型配对实验证明规格框架有效
LLM 生成代码的安全检查通过率四年几乎未动，而在受监管后端中真正致命的缺陷类别是金额运算、时间处理、重试安全性与访问控制。此前最大规模的指令文件对照研究未发现收益。本文测试一个更窄的想法：当 prompt 携带一份 specification（固定前言，声明结果必须满足什么）时生成代码会改善。作者预注册了假设、反驳条件、分析代码与一次性生成规则，用来自五个厂商血统的五个前沿模型跑 50 个金融、医疗、保险实践中的真实后端任务，每个任务跑两次：裸跑，以及前置一份 267 词的填充规格框架。九个确定性的 AST 检查器打分，Bandit 安全扫描器独立打分。结果显示框架在全部五个模型上减少缺陷（每任务平均减少 0.16 至 0.70 个发现，每个 Holm 校正符号检验显著，每个 bootstrap 置信区间不含零）。在两组有差异的情形中，框架组 100 次里赢 95 次，且在任何领域都未让任何模型变差。

DISCO：用 Grounding-Reasoning 解耦消除长上下文性能崩塌
LLM 宣称百万 token 上下文窗口，但推理质量常随输入增长而崩塌，这一现象被称为 context rot。论文指出其结构性根源：单体架构中，上下文 grounding 的巨大搜索负担耗尽了复杂推理所需的表示容量。受 Apache Spark 等分布式计算框架启发，DISCO 将长上下文切分到一组 Worker LLM 上，这些 Worker 只负责并行的、局部化的 grounding；一个中央 Driver LLM 通过 RL（GRPO）训练优化规划，动态把查询映射为原子抽取任务，并将收集到的证据归约成最终答案。通过把推理与原始上下文噪声隔离，DISCO 有效消除了 context rot：在 1M token 的 RULER-QA 上保持 78.4% 准确率，而标准基线已经崩塌；在 LongBench v2 上比全上下文模型高出最多 9.8 分，性能匹配 Gemini-3-Pro-Preview，同时推理成本降低超过 80%。

CineSubBench：用多语言电影字幕评测长上下文叙事与文化理解
LLM 已在法律、医学、软件工程、网络安全等专业领域被广泛评测，电影却相对空白，而电影恰恰需要长程叙事整合、多语言解读与文化情境化的观众判断。CineSubBench 把一部电影表示为数千条按时间排序的短话语，模型必须在没有显式场景或事件结构的情况下重建人物、关系、事件、因果推进与主题。基准包含 1,012 部电影、六种语言的完整字幕覆盖，共 6,072 条字幕轨与 813 万条带时间戳的字幕条目。它提供匹配的多任务、多语言、多文化（MultiX）评测设置：七项任务横跨叙事重建与抽象、类型预测、年龄适宜性、覆盖十国分级体系的国别电影分级，以及基于字幕的语言安全。在九个 LLM 上，情节梗概的恢复比事件完整的故事梗概更可靠；跨语言一致性因模型与语言而显著不同；各国分级体系暴露出不同的校准模式；强烈脏话比轻度猥亵更容易被定位。
