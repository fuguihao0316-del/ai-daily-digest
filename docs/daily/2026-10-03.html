OpenAI 发布 GPT-6.1 Sol
OpenAI 于 2026 年 9 月 29 日发布 GPT-6.1 Sol，作为 GPT-6 Sol 的升级版本，在 agentic coding、computer use 和专业工作任务上达到接近 Astra 的水平，但 token 价格仅为 Astra 的五分之一。定价为每百万 token 输入 2 美元、输出 10 美元，缓存输入降至 0.10 美元。该模型现已通过 OpenAI API、ChatGPT Work 和 Codex 提供。对开发者而言，这意味着此前只有旗舰级 Astra 才能完成的复杂编码与计算机操作任务，现在可以用五分之一的成本在常规生产流程中调用，agent 类产品的单位经济模型将明显改善，尤其是需要长链路多轮工具调用的场景。

Ego2Act：首个面向自我中心视频生成的目标导向操作基准
HuggingFace Papers 发布 Ego2Act，包含来自 110 个真实世界任务的 2,640 段视频，覆盖日常场景、不同物体杂乱度与多步复杂度。任务设定为给定初始场景图像与高层目标，评估视频生成模型能否生成手部操作物体的真实自我中心视频。团队同时提出无参考评估流程 Ego2ActJudge，在任务完成度与物理合理性两项上与人类共识的对齐度优于相关基线。实验发现模型生成的模拟常跳过或只部分执行步骤，导致后续步骤缺失依赖状态，最终目标无法完成；模型在细粒度物理一致性上也持续失败。对世界模型与具身规划研究者而言，该基准把评估从单一短动作推进到多步物理推理，暴露了当前视频世界模型作为执行模拟器的关键短板。

MemFold：用在线策略优化学习紧凑软记忆，实现长上下文个性化
长期服务同一用户的助手必须区分哪些偏好仍有效、哪些已被修改、哪些约束当下适用，但保留信息与据此行动常被当作同一目标优化。MemFold 将查询条件下的文本记忆压缩为 K 个连续向量，构成读者的记忆接口，再用两类信号在读者自身 rollout 上训练：任务结果的分组相对奖励，以及置信度门控的在线策略蒸馏，后者由冻结的文本记忆教师对学生的采样 token 重新打分。教师从不被采样，监督始终停留在学生当前分布上，推理阶段完全移除。在三个 Qwen 骨干上，MemFold 在 PersonaMem-32K 与 PersonaMem-128K 上取得所测最高准确率，且历史越长优势越大，并可零目标域训练迁移到 PrefEval 与 LongMemEval。

Persona Dosing：校准激活引导，实现分级人格特质控制
激活引导系数决定干预强度，但要请求特定程度的人格表达需要一把行为标尺。作者研究 persona dosing，即通过特质描述加请求的平均强度来控制语言模型。PersonaDose 先在人格响应上特化一个共享的描述条件 FLAS 控制器，再将其流时间针对测得的特质表达进行校准，训练响应并不与请求的目标强度配对。在 Llama-3.1-8B、Qwen3-8B 和 Gemma-3-4B 上，PersonaDose 在 Persona Vectors 的 75 连贯性下限处，将核心特质表达较对比激活加法分别提升 33.2、18.3 和 17.8 个点。校准选出的设置在有保留问题上仍保持表达优势，但连贯性下限并非对每个特质都成立。七个已训练特质上，校准请求的平均目标误差为 4.7 至 6.2 个点。

Honeycomb：面向视频世界模型的恒定大小场景记忆表示
视频世界模型需要持久场景记忆以在长时程生成中保持一致，但现有空间记忆会累积 RGB 观测或潜特征，存储随生成推进而增长。作者提出 Honeycomb，基于低秩表示 HexMemory，用总计六个空间与时空平面在固定大小记忆中存储场景特征。前馈写入器把每个新生成块映射为新平面特征；空间覆盖或时间范围扩大时，对旧平面做形变并保持维度，再通过置信度加权池化与学习到的残差校正与新特征融合。读取器从 HexMemory 取潜变量以条件化后续生成。写入器只处理新块观测，避免逐场景优化与重复处理全历史。在 WorldScore 与 RealEstate10K 上，该方法在保持记忆存储恒定的同时取得强生成质量与稳健重访一致性。

X-Tree：将可复用经验 token 化，提升智能体泛化效率
多步智能体通常在扁平动作流上训练，SFT 与 RLVR 对每个 token 一视同仁，忽略了跨任务复现的子过程，也就是人类自上而下规划所依赖的可复用例程层级。已有智能体虽使用该结构，但仅作为上下文中的 LLM 编写技能，从未进入权重，收益无法超出检索范围。X-Tree 从数据本身恢复层级并据此训练，全程无需 LLM 调用：仿照文本分词器仅靠计数构建词表，按可复用性对动作片段打分，并把规范化动作合并为可复用经验树，每个节点刻画一个高频且带成功信号的技能如何由子技能组成。X-Tree 被整合进三种训练设置：离线 RL 中每个节点作为训练实例，在线 RLVR 中作为自适应技能奖励，在线策略自蒸馏中作为自教师的特权上下文。在 WebArena、ScienceWorld、WebShop 三个尺度上，同等数据与预算下分别最高提升 4.5%、5.8% 成功率与 4.1% 成功率。

SemanTok：可预测语义 token 实现高效自回归视频生成
