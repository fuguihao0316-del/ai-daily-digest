Jev 决策模型替代 LLM 用于低延迟边缘服务编排
研究将 Jev 面向决策的 API 集成进边缘服务编排，从自然语言请求中抽取 4 至 8 个有界意图字段，配合共享校验器、准入策略与调度器。在 8,280 条已验证请求、33 种测试条件下，Jev 相比最快的托管 LLM 将决策延迟中位数降低 22.7% 至 64.5%，且该延迟几乎不随输入规模、契约宽度或目录规模变化。四字段契约上，Jev 每次正确决策的 API 费用低 59.7% 至 80.9%，代价是少量精确匹配点下降。在实时准入路径上，Jev 在 LLM 低于 0.1 的负载下仍保持 0.91 至 0.95 的请求精确且准时。结论支持在延迟受限场景用决策模型替代 LLM。

Ego2Act：以第一人称视频生成评估目标导向操作

MemFold：用同策略优化学习长上下文个性化的紧凑软记忆
长期服务同一用户的助手必须区分哪些偏好仍成立、哪些已修改。把信息存为文本会让输入随历史增长，压缩成固定数量隐向量虽能限制接口，但通常以重建文本或模仿参考答案为目标，评分序列并非读者产生。MemFold 按记忆所支持的行为来优化固定预算软记忆：将查询条件化的文本记忆压缩为 K 个连续向量构成读者记忆接口，再用两组信号在自身 rollout 上训练读者，即任务结果的分组相对奖励，以及冻结文本记忆教师对学生采样 token 重新打分的置信门控同策略蒸馏。教师从不被采样，推理时完全移除。在三种 Qwen 骨干上，MemFold 在 PersonaMem-32K 与 PersonaMem-128K 取得最高准确率，历史越长优势越大，并零样本迁移到 PrefEval 与 LongMemEval。

Persona Dosing：校准激活引导实现分级人格特质控制
激活引导系数决定干预强度，但请求特定程度的人格表达需要行为量表。研究提出 persona dosing，即通过特质描述与请求的平均强度控制语言模型。PersonaDose 在人格响应上特化共享的描述条件化 FLAS 控制器，再依据实测特质表达校准其流时间，训练响应不与请求目标强度配对。在 Llama-3.1-8B、Qwen3-8B、Gemma-3-4B 上，PersonaDose 在 Persona Vectors 的 75 连贯性下限处，将核心特质表达分别比对比激活加法提高 33.2、18.3 和 17.8 分。校准选出的设置在留出问题上仍保持表达优势，但该连贯性下限并非对每个特质都成立。七个已训练特质上，校准请求在每模型 28 个目标中 14 至 22 个可达目标上平均误差 4.7 至 6.2 分。

Honeycomb：视频世界模型的恒定大小场景记忆表示
视频世界模型需要持久场景记忆以维持长时程生成的一致性，而现有空间记忆会累积 RGB 观测或隐特征，存储随生成推进增长。Honeycomb 基于提出的低秩表示 HexMemory，用共六个空间与时空平面以固定大小存储场景特征。前馈写入器把每个新生成块映射为新平面特征；当空间覆盖或时间范围扩展时，对旧平面做形变并保留维度，再通过置信加权池化与学习到的残差校正与新特征融合。读取器从 HexMemory 取隐变量以条件化后续生成。写入器只处理新块的观测，避免逐场景优化与重复处理全历史。在 WorldScore 与 RealEstate10K 上，方法在保持 HexMemory 特征存储恒定的同时取得强生成质量与稳健重访一致性。

X-Tree：为高效智能体泛化标记可复用经验
