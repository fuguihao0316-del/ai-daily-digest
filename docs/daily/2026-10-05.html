Google 提出 RRSI 方法，抑制自改进 agent 记忆测试任务
自我改进的 AI agent 存在一个结构性缺陷：它们倾向于记住测试任务本身，导致在新任务上的收益缩水甚至消失。Google 研究者提出的 RRSI 方法针对这一效应做了约束，在未见过的基准上最高提升 4.7 分，同时比未加正则的版本少用约 30% 的 token。这两项数字值得注意：提升来自泛化而非记忆，token 消耗的下降则说明约束并没有以算力换性能。对做 agent 自训练与自我改进流水线的团队来说，这直接关系到评测可信度问题——如果 agent 在训练分布外的任务上表现虚高，后续所有基于该评测的决策都会失真。

Jev 决策模型替代 LLM 实现低延迟边缘服务编排
边缘服务编排中，自然语言请求在开始执行前往往需要一次语言模型决策，这会消耗请求的延迟预算。研究将 Jev 面向决策的 API 集成进边缘编排流程，抽取 4 到 8 个有界意图字段，并共享校验器、准入策略与调度器，在整个请求时间线中计入决策等待。在 8,280 条已验证请求以及一条含建模执行和真实 OCR 服务的线上准入路径上，对比 Jev、两个自托管决策模型和三个托管 LLM。33 个测试条件下，Jev 相比最快的 LLM 将中位决策延迟降低 22.7% 至 64.5%，且该延迟几乎不随输入规模、契约宽度或目录大小变化。四字段契约下，Jev 每次正确决策的 API 费用低 59.7% 至 80.9%，代价是几个百分点的精确匹配下降；宽契约则是替代的极限。线上准入路径中，在 LLM 低于 0.1 的负载下 Jev 仍能保持 0.91 至 0.95 的请求精确且准时。由于缓存重复描述会让解释器获得几乎相同延迟，Jev 的收益来自新鲜决策。

MemFold 用同策略优化学习长上下文个性化的紧凑软记忆
长期服务同一用户的助手必须依据用户透露的信息作答，包括哪些偏好仍成立、哪些被修改、当前适用哪些约束。保留信息与据此行动并不等同，而现有做法常把两者混为一谈。以文本保存信息会让读取端输入随历史增长，压缩成固定数量隐向量虽能约束接口，但通常按重建文本或模仿参考答案来训练，评分序列并非读取端自己产生的。MemFold 按固定预算软记忆所支撑的行为来优化它：把查询条件化的文本记忆压缩成 K 个连续向量作为读取端记忆接口，再用读取端自身 rollout 上的两类信号训练，即任务结果的分组相对奖励，以及置信门控的同策略蒸馏，后者由冻结的文本记忆教师对学生采样 token 重新打分。教师从不被采样，监督始终停留在学生当前分布上且不增加自回归解码，推理时完全移除。在三个 Qwen 骨干上，MemFold 在 PersonaMem-32K 与 PersonaMem-128K 上取得所测最高准确率，历史越长优势越大，并零目标域训练迁移到 PrefEval 与 LongMemEval。

Honeycomb 用恒定大小场景记忆表示构建视频世界模型
视频世界模型需要持久场景记忆以在长时程生成中保持一致，而现有空间记忆会累积 RGB 观测或隐特征，存储需求随生成推进而增长。作者提出 Honeycomb，基于所提出的低秩表示 HexMemory，把场景特征存入固定大小记忆，共六个空间与时空平面。前馈写入器把每个新生成片段映射为新的平面特征；当空间覆盖或时间范围扩展时，对旧平面做 warp 并保持维度不变，再通过置信加权池化与学习到的残差校正与新特征融合。读取器从 HexMemory 取隐变量以条件化后续视频生成。写入器只处理新片段的观测，避免逐场景优化和对完整历史的重复处理。在 WorldScore 与 RealEstate10K 上，Honeycomb 展现出强视频生成质量与稳健的重访一致性，同时 HexMemory 特征存储在整个生成过程中保持恒定。

X-Tree 将可复用经验 token 化以提升智能体泛化
多步智能体通常在扁平动作流上训练，SFT 与 RLVR 对每个 token 均匀加权，忽略了跨任务反复出现的子过程，也就是人类自上而下规划所依赖的可复用例程层级。这种结构未被利用，扁平训练对每条稀缺轨迹的利用也不充分。近期智能体虽用到该结构，但仅作为上下文中的 LLM 撰写技能，从未进入权重，因此收益无法泛化到检索之外。作者改从数据本身恢复该层级并据此训练，全程不调用 LLM。仿照文本分词器仅靠计数构建词表，他们按可复用性为动作片段打分，把规范化动作合并成可复用经验树 X-Tree。每个节点刻画一个高频且带来成功的技能如何由子技能组成，从而引导高效泛化。X-Tree 被集成进三种训练设置：离线 RL 中每个节点作为训练实例；在线 RLVR 中加入自适应技能奖励；同策略自蒸馏中把 X-Tree 作为自教师的特权上下文。在 WebArena、ScienceWorld 与 WebShop 三个模型规模上，同等数据与预算下 X-Tree 相比标准配方最多提升 WebArena 4.5% SR、ScienceWorld 5.8% SR、WebShop 4.1% 成功率。

关键词式评测会误判小模型工具调用能力
