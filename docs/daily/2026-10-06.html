Anthropic 重构 Cowork：VM 与推理全部搬到云端
Anthropic 的 Felix Rieseberg 解释了 Cowork 的架构变更。旧版 Cowork 在云端做模型推理，但把工具调用放在一个 Anthropic 提供、下发到用户电脑上的 VM 里执行，加入 VM 是为了能力、安全和安保，只映射用户显式加入会话的数据；用户认可 Claude 能做的事，但不喜欢本地跑 VM 带来的磁盘、电池和性能开销，也不喜欢合上笔记本工作就停止。新版 Cowork 把模型推理和 VM 都放到云端，每个会话拥有自己的沙箱，不与其他会话共享状态；当 VM 需要用户设备上的东西（例如某个文件）时，由桌面应用负责那次文件访问的工具调用。官方认为这解决了手机端使用 Cowork、保持工作持续运行、以及不牺牲电池拿到同等能力等问题。对 Agent 产品设计者来说，这是一次明确的取舍示范：把执行环境从端侧移到云端沙箱，换取持久性与跨设备可用性。

Google 提出 RRSI：阻止自我改进 Agent 背题
自我改进的 AI agent 倾向于记住测试任务，导致其在全新任务上的收益缩水甚至消失。Google 研究者提出的 RRSI 方法抑制了这一效应，在未见过的基准上把分数最高提升 4.7 分，同时比未加正则化的版本少用约 30% 的 token。这一结果同时命中两个痛点：一是自进化循环中的评测污染，二是推理成本。对做 agent 自训练或 self-play 流水线的团队来说，RRSI 提示了一个更根本的问题——当模型自己生成训练任务并自己评分时，如何区分真实能力提升与对测试分布的过拟合。少用三成 token 也说明正则化并未以算力为代价换取泛化。

PointWAM：面向灵巧操作的 3D 世界动作建模
现有世界动作模型多以 RGB 帧或隐空间表示世界、以末端位姿或关节角预测动作，难以刻画灵巧操作所依赖的 3D 空间结构与接触几何。PointWAM 将世界解耦为场景（环境）与手（动作主体），在统一的时空坐标系内联合预测二者的 3D 点轨迹，从而可在无任务特定物体或关键点标注的大规模人类演示视频上预训练。给定彩色点云与语言指令，模型预测场景与手在 3D 空间中随时间的共同演化，再将预测的手部运动重定向为机器人动作。在人类视频上预训练使 DexJoCo 平均成功率提升 56.9 个百分点，加入场景轨迹监督后比仅预测手部再提升 10.9 个百分点；两者结合后，在十项 DexJoCo 任务上超越此前 SOTA 11.7 个百分点，并在真实机器人上优于强 VLA 模型。该工作表明显式 3D 点轨迹表示是释放人类视频预训练价值的关键。

JEPA-TTT：潜在世界模型的持续测试时训练
世界模型通过预测未来状态支持规划，但当测试时动力学与训练分布不同时预测会失效。JEPA-TTT 在测试全程持续适配预训练动作条件 JEPA 世界模型中的潜在动力学预测器，自监督更新跨回合累积，而视觉编码器与奖励头保持冻结，以保留预训练表示与任务目标；规划既不需要目标图像也不需要在线环境奖励。方法采用密集回放，在每个时间偏移处构造预测窗口并存入持续增长的缓冲区，再从缓冲区采样小批量更新预测器。在四个连续控制环境的八种动力学偏移下，JEPA-TTT 在所有偏移上均改善规划；经过 500 个测试回合后，自回归潜在预测误差平均降低 83%，规划性能相比冻结的 JEPA 世界模型提升 153%。这证明持续自监督测试时训练可让预训练潜在世界模型适应动力学变化。

The Extender：一种日志结构化的 Transformer 变体
标准 Transformer 中各层仅通过残差流 h 这一叠加通道与后续层通信。The Extender 额外引入拼接通道 x：每层同时输出加到 h 上的残差更新 δ 与追加到 x 上的更小的扩展 ε；FFN 与 query 仍读取 h，而注意力的 key/value 投影只以 x 为输入。由此完全扩展后的 x 包含所有层 kv 投影的完整输入，持久注意力内存占用从 2Ld_model 降至各层扩展维度之和。实验显示，当每层扩展维度为 32 时，Extender 在 199M–924M 参数上于短上下文 CORE 任务上与 Transformer 精度持平，并在 924M 参数的长上下文 RULER 负载上超过 Transformer；对 1664 宽、924M 的模型，其持久注意力内存占用比 MHA 小 104 倍，且节省随模型宽度增长。这为长上下文推理的内存瓶颈提供了架构级解法。

KeyRec：面向流式与长视频理解的有界视觉记忆
VLM 用于长视频与连续流理解时，密集视觉 token 随视频时长累积，使长上下文推理成本高昂。现有免训练 token 选择方法虽能降本，却可能丢失连贯事件证据，且无法区分近期细节观测与长程历史。KeyRec 提出免训练的有界视觉记忆框架：在与查询无关的写入阶段，把细粒度近期观测保存在视觉缓存中，并将历史证据组织为结构化事件库，候选事件依据相对已存事件的新颖度提出，通过在线 add–merge–evict 更新维护；问题到来时，仅文本路由器在近期记忆与事件记忆之间自适应分配固定读取预算，无需重处理历史帧。该方法作用于模型侧视觉嵌入，兼容模块化 encoder–projector VLM 与无 encoder、projector 的 NEO-ov 架构。在四个流式与长视频基准、三个 VLM 骨干上，KeyRec 以仅 10% 的密集解码器侧视觉 token 预算在 15 个设置中的 13 个取得最佳压缩性能，实时问题上比最强压缩基线高 2.21–18.37 分。
