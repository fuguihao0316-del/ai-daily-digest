OpenAI 发布 Decisions API，把复杂评估压缩成是/否/单选
OpenAI 在 DevDay 预告后正式上线 Jev 风格的 Decisions API，支持 yes/no、多选、评分三类问题，并首次在 gpt-6-luna decision 模型上支持图像输入。官方称其对文本与图像的分类速度约为 Responses API 的十倍，按输入计费、输出免费，价格为每百万输入 token 10 美分；同期付费 API 层级从五档削减为三档。对比 Jev 每百万输入 4.2 美分的定价，OpenAI 贵出一倍多，但多模态输入是差异点。Simon Willison 已基于此前的 llm-typesafe 插件，让 GPT-6 Astra 读文档后生成 llm-openai-decisions 插件，可通过 llm install 直接调用，并用一张图片做示例查询返回 probability 0.0 的判定结果。对开发者而言，这意味着分类、审核、路由这类原本要写 prompt 加解析逻辑的任务，可以换成结构化接口，成本与延迟都更可控。

Anthropic 发布 Claude Haiku 5.5，价格对齐 GPT-6 Luna
Anthropic 推出新一代小模型 Claude Haiku 5.5，定价为每百万输入 0.10 美元、输出 0.50 美元，与上月发布的 OpenAI GPT-6 Luna 完全一致，但仅限 10 万 token 以内；超过 10 万 token 后价格跳升 5 倍至 0.50/2.50 美元，而 Luna 在 27.2 万 token 处才涨到 0.20/0.75 美元。前代 Haiku 4.5 定价 1/5 美元，已是 Luna 的十倍，此次降价幅度显著。Haiku 5.5 还换用了更不慷慨的 tokenizer，同一段长 prompt 消耗的 token 约为 4.5 的 1.25 倍，构成隐性涨价。基准方面 MarkTechPost 报道其在 OSWorld 上得分 72.4%，支持 1M 上下文。模型不支持关闭推理，默认 medium 档，Simon Willison 用生成骑自行车鹈鹕 SVG 做了低中高各档测试。结论很直接：工作负载在 10 万 token 以内选 Haiku，超出则 Luna 更划算。

WebFovea：当模型判断正确但点击落空，为实时网站上的视觉 Web Agent 构建可靠往返
该工作在 WebRetriever Challenge 2026 的 Protocol III 上以 57.0/100 分获得第二名。作者指出，多模态大模型只是必要条件而非充分条件：模型决策要经过 harness 才能到达浏览器，每一步有四件事必须同时正确——回复被解析为预期动作、动作在页面上生效、结果被准确回报、模型看到所需信息。在真实网站上，许多失败发生在上述四个环节而非模型推理本身：坐标空间错配导致每次点击落在预期坐标的 3/4 处；原生下拉框、iframe 内和文本框中的动作静默失败；自生成的 chat-template token 污染了 4.9% 的任务回合。WebFovea 对每个环节做了加固，并在循环外围加了护栏以约束规则与预算。由于四次提交使用同一模型，官方隐藏集分数从 31.0 提升到 57.0，说明增益主要来自 harness 而非模型能力。

RLHND：把视频基础模型当作物理接地的手部追踪器用于机器人学习
现有手部追踪器多从裁剪帧回归姿态，对手部运动和手物交互的先验有限，估计结果不准确且物理上不一致；同时缺少接触与力等物理线索，限制了人类视频在机器人策略训练中的使用。RLHND 基于视频基础模型，从单目第一视角视频中联合估计手部姿态与真实感触觉信息。方法上，它通过 clean-latent conditioning 把预训练的 Cosmos 3 视频扩散骨干转成确定性的片段级特征提取器，把学到的手部运动与手物交互先验带入追踪；姿态估计方面预测解剖学上合理的关节角，并可选地以形状参数为条件，使同一视频乃至同一演员录制的不同视频中手形保持一致；触觉估计方面用独立专家流在冻结姿态流的前提下预测手表面的稠密接触与力。作者还采用基于 LBS 的特征扩散，实现逐顶点特征提取而无需昂贵的逐顶点注意力。RLHND 在多个姿态估计基准上达到 SOTA。

We Query, Therefore We Compute：论机器之外的 Oracle 计算及其在 Agent 上的应用
现有 Agent 系统常零散借用操作系统的调度、缓存、隔离等抽象，机制之间缺少共同基础，Workflow 与 Agent 两种形态也缺乏统一视角。作者构造了一台抽象机器同时提供两者：把 LLM 视为 Oracle，在双栈下推自动机上增加一条指令，将整个栈作为查询交给 Oracle，并把答案追加回同一栈。该机器因此执行两种计算——Oracle 的计算，以及作者称为 Priestess 的图灵完备计算。只追加的栈像 Agent 上下文一样自回归增长。存储上的对称性破缺 S 与转移上的对称性破缺 T，使 Priestess 程序成为 Oracle 所运行程序的操作系统，并让 Agent 与 Workflow 成为同一任务程序的两种放置方式。对内部自回归的 Oracle，两种计算在满足一定条件时于每次答案结束时同步，作者借此建模缓存并分析调度。作者还提出 V 构造把该机器适配到冯·诺依曼计算机，并提出扩展 RISC-V ISA 的 ArchNights 以证明可实现性。

TimeBraid：统一时间序列与语言的理解与预测模型
TimeBraid 通过交错的全局残差注意力层，对齐预训练语言模型与预训练时间序列基础模型。每个模型从语言侧继承知识、指令跟随与推理能力，从时间序列侧继承连续信号感知与零样本预测能力，并在共享表示空间中融合两种模态，实现理解与生成。论文系统研究了让这种统一建模奏效的设计选择：在何处对齐两个表示空间、如何把语言接地到时间结构、如何平衡理解与生成、如何保持联合优化稳定。最终配方结合了面向多样时间序列与文本任务的统一提示方案、稳定的联合训练，以及来自 220 万条精选序列-文本对和 490 万条指令微调样本的监督。在覆盖时间序列感知、理解、推理以及上下文辅助与单模态预测的基准上，TimeBraid 与规模大得多的通用模型和任务专用模型相比仍具竞争力。

Structuring MoE Expert Selection for Agentic Reinforcement Learning：用 Agent 轨迹结构优化 MoE 专家路由
长程 LLM Agent 常用稀疏 MoE 模型实现，但 Agent 行为与 MoE 结构的协同设计仍未被充分探索。作者发现，在现成 MoE 模型中专家选择呈现出与 Agent 轨迹自然对齐的专门化结构：当 Agent 执行语义相似操作（如 READ、UPDATE）的回合之间，专家路由的重叠度高于操作不同的回合之间。然而标准 RL 算法忽略这种专门化，训练中 MoE 路由不受控制，经验上限制了任务性能与推理效率。为此作者提出面向 Agent 任务的分层路由控制框架：显式鼓励回合级专家选择与 Agent 操作对齐，同时正则化 token 级专家选择以维持局部一致性。针对后训练中出现的稳定性问题，进一步引入熵门控控制机制。该框架在所有评测基准上取得超过 10 个百分点的成功率提升，表明 Agent 轨迹结构是 RL 后训练中优化 MoE 容量的有效信号。

CheckerBench：长程 Agent 能否合成静态分析检查器？

Learning Functional Subspaces for Neural Network Compression：端到端学习要丢弃的子空间
现代 Transformer 能力强的同时内存与算力需求巨大。低秩权重分解能在保持矩阵稠密、对标准硬件友好的前提下同时降低两者，但现有方法用局部闭式准则选择每个权重矩阵要移除的子空间，例如激活能量、逐层重建误差或损失的二次近似。这些准则忽略误差如何在网络中传播，因此在高压缩率下误差随深度累积、性能崩塌。作者提出 Learnable Subspace Projections（LSP），改为端到端学习要丢弃的子空间：每个线性层，或读取相同激活的绑定层组，被分配一个正交投影算子；所有投影算子针对全局目标联合优化——与稠密模型输出分布的 KL 散度，或模型原始训练损失——同时预训练权重保持冻结。投影算子由白化 SVD 截断初始化，秩按每个投影算子每节省一个参数所引入的输出 KL 分配。训练后投影算子可合并为标准低秩因子，每个绑定组共享一个因子；在注意力中还可让模型缓存一个窄隐向量替代完整的 key 和 value。在 OPT-125M/1.3B、Qwen3-4B、Llama-2-7B 与 ViT-B/16 上，LSP 优于基线，且压缩率越高优势越大。
