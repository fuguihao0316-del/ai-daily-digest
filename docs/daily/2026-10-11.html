Microsoft 发布 Microsoft-Decision-1：基于 Qwen3.5-9B 的决策评分模型
Microsoft 发布了 Microsoft-Decision-1，一个用于路由、分类、验证和 agent 控制的决策模型。与生成式模型不同，它针对每个固定答案选项返回一个经过校准的概率，而不是生成文本。该模型由阿里巴巴的 Qwen3.5-9B 后训练而来，目前已在 Microsoft Foundry 和 OpenRouter 上线。这类「决策模型」的定位值得注意：在 agent 系统里，大量调用其实不是开放式生成，而是在有限选项间做判断，比如该走哪条工具链、这个输出是否通过验证、下一步该交给谁。用生成模型做这些事既慢又不稳定，而返回校准概率的专用小模型可以显著降低延迟和成本，同时让下游可以用阈值做可控的自动化决策。对正在搭 agent 编排层的团队来说，这是一个可以直接替换掉部分 prompt 判断逻辑的组件。

扩散与自回归统一为「转移律格」：解码步数由数据几何决定
论文把 diffusion、autoregression 及两者之间的混合模型统一描述为 corruption lattice 上的路径，并把某个解码 schedule 的代价定义为并行步骤所丢弃的依赖关系。核心结论是零代价 schedule 的最少步数由数据几何决定，对 token 和连续场同样成立：若数据在图上满足 Markov 性且沿路径相关，最少步数等于图的 treedepth，该量对序列长度呈对数、对网格边长呈线性。步数少于 treedepth 时任何 schedule 都要付出正代价，且其排序可在解码前用从预训练权重估计的成对依赖核预测。作者在文本、图像、视频生成上验证了大部分排序预测，为未来 AR、diffusion 及混合模型提供了统一解码设计原则。
