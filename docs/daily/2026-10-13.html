T3lescope 实现任意分辨率高保真生成式表面重建
该工作针对多视角图像重建 3D 场景网格时，逐场景优化缺乏学习到的 3D 先验、现有生成方法又受限于固定分辨率和有限空间范围的问题，提出 T3lescope。它用单一固定分辨率生成器，在推理时以由粗到细的级联方式跨场景尺度工作：粗层级确立场景布局，更细层级在逐步细化的空间单元内对继承自粗层级的几何进行扰动与去噪以恢复表面细节。模型在多尺度单元上训练并跨所有层级共享权重，训练时不固定层级结构，层级数、单元尺度与位置均在推理时决定。在室内、室外和城市级场景上，T3lescope 优于前馈与生成式基线，匹配或超越逐场景优化，并能恢复精细结构以及高光和透明表面。

ARCS 用结构化消歧推动 Text-to-SQL 落地
该工作指出，随着 text-to-SQL 系统从演示走向真实部署，用户问题中的歧义成为主要错误来源，这类歧义往往细微、依赖领域或数据，会静默地让输出偏离用户真实意图。传统上通过对话式澄清解决歧义，但效率低、认知负担重、与实际工作流不匹配。作者提出结构化消歧这一新范式，用显式、受约束的交互替代自由对话。他们构建了 ARCS，首个面向真实数据库、包含自然发生且不受约束歧义的 text-to-SQL 基准，完整标注了所有有效歧义点、解释与 SQL 查询。实验显示存在歧义时 text-to-SQL 仍具挑战：gpt-6-sol 端到端执行准确率仅 51%，无开源模型超过 27%。

Thinking Inertia 揭示 LLM 无法真正停止思考
该研究关注 LLM 的「不思考」行为。作者指出以往用禁用思考模式或缺少长推理链等代理指标来衡量不思考并不可靠，因为禁用模式仍可能输出推理，长推理链也可能只是填充内容。他们改为把每个回答拆成答案前推理与最终答案，在三个层面评估：严格只答的 Empty-Thinking Rate、问题与答案前推理相似度的指令感知相关性、以及 LLM-as-judge 的显式推理率。作者在六种 LLM、Boolean、多选和开放式问题上测试六种提示干预，发现显式不思考控制无法可靠消除可见推理，模型表现出「Thinking Inertia」：严格控制下显式推理仍存在，且随答案空间开放而更普遍。Boolean 与多选题准确率稳定，开放题则出现取舍。

从视频恢复忠实 3D 手部运动受频繁遮挡和视觉观测不完整困扰，逐帧姿态估计不可靠且时序不一致。作者提出 JoHan，一个统一生成框架，不依赖中间逐帧姿态预测，直接从视频序列恢复手部运动。模型从零训练，通过学习时序动态与跨表示对应关系，联合生成对齐的 2D 与 3D 局部手部姿态序列。生成的 2D 轨迹利用图像中的直接时空线索引导后续生成式 3D 运动重建，而学到的运动先验提升时序一致性；学到的 2D-3D 对应进一步支持恢复手部相对相机的全局位置与朝向。在挑战性基准上，该方法在局部手部姿态与相机空间重建上显著提升精度与速度，运动动态更平滑。

DRMoET 把路由鲁棒性作为 MoE 训练目标
MoE transformer 通过每 token 只激活少量专家扩展容量，但这种稀疏性带来隐藏可靠性问题：路由不完美时，负载均衡的模型可能把 token 送给对相应输入训练不足的专家。作者提出 Distributionally Robust MoE Training，一个即插即用目标，把逐层专家视为内生鲁棒性分组，优化高损失路由结果而非仅均衡流量。DRMoET 通过基于 EMA 平滑、激活加权专家损失的熵正则 softmax 规则更新逐层专家分布，强化合理的非 top 路由路径，同时保持标准 MoE 计算。在 FLAME-MoE 配方下，746M 与 10.3B 总参规模均优于标准 FLAME-MoE 与无辅助损失均衡；10.3B 总参、67B 训练 token 时七任务平均从 0.6625 提升到 0.6767。

ELR 让循环语言模型摆脱单循环税
隐式循环语言模型重复应用共享层块，使单一 checkpoint 能通过改变循环次数在推理算力与精度间取舍。但单循环时这类模型通常远逊于同规模非循环模型，这一单循环税使得对延迟敏感时非循环模型更优。作者提出 Elastic Latent Recurrence，一种训练无此税的循环语言模型配方：单循环时 ELR 模型服务成本与同规模非循环模型相同，同数据训练下精度相近，之后每次额外循环以更多推理算力换取更高精度。三个关键设计是带学习步长的门控状态更新、每次优化器更新内混合循环次数、以及每次前向以循环索引与预算为条件。MoE 模型中在后几轮复用首轮专家路由可把混合深度更新时间减少 11.7%，精度无可测变化。

Self-Preservation 研究语言模型能否自主选择保留目标
持续学习旨在适配预训练模型同时保留既有能力，但用于保留的任务只覆盖模型所知的一部分，遗忘可能超出这些任务。近期工作表明语言模型可在无原始训练数据时生成有用的回放，这引出自我保存问题：模型能否帮助选择更广泛保护自身能力的保留目标。作者把任务描述与示例组织为 Task Banks，其条目可被选择与组合以指导冻结模型的回放生成。用不同规模 Qwen 模型做持续指令微调得到三点发现：新任务与学习率决定哪些能力退化，跟踪此前正确答案可揭示被平均准确率掩盖的损失；生成回放减少 bank 外任务的遗忘，组合部分 bank 进一步强化保护；模型还能帮助选择回放目标，由新任务引导的选择在 4B 上优于随机选择。
