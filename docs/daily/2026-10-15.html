DuplexJev 让冻结 LLM 单 token 完成全双工语音决策
全双工语音代理需频繁做小型封闭决策，现有系统靠慢速自回归解码。该工作提出 DuplexJev，将 ASR 编码器隐状态经小型连接器送入冻结 LLM，每个问题读作选项上的单 token 分布，无需解码。8 卡节点对八段语音的 80 个决策约 0.1 秒完成。使用末层连接器时，语音问答准确率 90%，接近阅读转录文本的 91%。跨注意力连接器还能感知说话人，性别与情绪准确率均达 90%（原为 55% 和 28%），语音问答仅从 83% 降至 82%。训练用读出答案 token 的交叉熵，而非转录蒸馏。编码器与 LLM 可互换，作者开源权重、训练配方、全双工批量推理管线及双语语音问答集。

WorkForge 从真实资源合成 16.7K 可验证工作代理环境
工作代理需在数字工件上执行专业知识密集型任务，要求长程交互与可信验证，但手工环境成本过高，合成方法又牺牲工作区复杂度或可验证性。该工作提出 WorkForge，从专家工作流出发识别所需资源、决策与交付物，检索真实文件组织成工作区，再抽取可检查事实锚点，据此推导任务指令、解决方案与程序化及语义验证器，使验证可追溯到可观察证据。作者构建覆盖 40 个专业领域、60 种文件类型的 16.7K 可验证环境。后训练 Qwen3.5-35B-A3B-Base 将 GDPVal 从 45.5 提升至 73.6，APEX Score 从 5.0 提升至 21.3，并使 Qwen3.5-27B 取得有竞争力的表现。

ARBITER：可验证反馈的代理式代码评判
竞赛编程官方评测只在有限提交预算下给出判决，不揭示失败原因或失败输入。该工作定义新任务：模型仅凭题面与源码评判并诊断候选程序，用生成的计数样例作为可检查证据。作者基于 USACO 2026 竞赛构建 USACO-JUDGE，收录人类专家与多个 LLM 编写的通过和未通过程序。随后在通用执行沙箱中用强化学习训练 35B MoE 代理式验证器 ARBITER。训练将错误程序上的计数样例成功率从 40.61% 提升至 62.67%，USACO-JUDGE 上平均二值判决准确率从 71.41% 提升至 87.41%，接近前沿验证性能。ARBITER 在代码选择与精修上也优于基线；IOI 2026 案例中，其引导的精修使 GPT-OSS-120B 在官方提交限制下预期得分超过金牌线。

Last Secure Code Benchmark：氛围编程代码有多不安全
AI 编码代理已产出大量上线代码，但其安全性仍不明确。作者提出 Last Secure Code Benchmark，基于 150 个真实漏洞构建 450 项任务，覆盖 Java、C、C++、JavaScript、Python、PHP、Go 七种语言，24 个 CWE（含 2025 CWE Top 25 中的 21 个、Top 10 KEV 弱点中的 8 个），并设三种氛围编程场景：补全函数、编写文件、从零构建仓库源码树。每项任务只提功能需求，规格从不提及安全，由隐藏的功能与安全测试评分。在六个前沿代理上，73.6% 至 91.3% 的任务功能通过，但即便最强的 Claude Fable 5，也仅 25.1% 的任务同时功能与安全通过，其余为 16.4% 至 24.7%。最佳模型在所有氛围编程设置下仅通过 12% 的漏洞场景。

Pristine Models：预训练阶段隔离不安全概念
在广泛未过滤数据上训练可带来高质量图像生成，但也会让模型学到不应生成的概念；限制训练数据虽安全却降低质量，因为含不安全概念的样本也提供本身无害的有用知识。现有方法多在后处理阶段做概念遗忘，随概念增多会导致灾难性遗忘。该工作提出 Pristine Models，一种文本到图像生成架构，其注意力机制鼓励将安全与不安全知识分离到独立参数化分支，分支参数在训练中学习，推理时可断开不安全分支。在 ImageNet 上，该方法在保持全数据预训练大部分效用的同时实现更安全生成，图像质量与文本对齐均优于仅用安全数据训练或后处理概念移除。作者进一步扩展到 CC12M，证明在更大更多样的开放世界预训练设置中依然有效。

ACCRUE：机器人基础模型的持续离策略强化学习
强化学习后训练可让机器人基础模型超越示范，但真实部署要求高效学习新任务并保留已有行为。现有基于 VLA 的持续 RL 方法缓解遗忘却依赖在策略更新、前向迁移有限，离策略方法提升单任务样本效率却不解决跨任务学习器持久性。该工作提出 ACCRUE，一种持续离策略 RL 框架，跨任务携带轻量 actor 与 critic 网络，使每个阶段复用先前 RL 获得的行为与价值知识。继承的 critic 仅在当前任务转移上适配并引导当前任务 actor 学习，先前行为通过对少量保留回合的缓存目标蒸馏 actor 来保持。固定视觉特征使继承学习器及其回放与基础策略更新兼容。在仿真接触密集型装配序列与真实机器人硬件上，ACCRUE 加速后续任务学习，遗忘接近零，并将真实机器人训练时间减少 31.0% 至 68.5%。

WATCH：从任务配对人类视频学习可迁移世界-动作模型
世界-动作模型从视频预训练继承广泛视觉与物理先验，但标准视频内下一帧预测使其依赖上下文与未来共享的外观，而非学习可跨场景与本体迁移的交互。作者提出 WATCH，一种跨视频预训练方法，从多样环境采集的任务配对人类示范中学习。以一个示范的视频与动作为条件，模型联合预测另一示范的动作及其当前观测下的未来帧。从一示范预测另一示范，促使模型学习跨场景与演示者可迁移的任务相关交互。预训练表明这些能力可仅从易扩展的人-人对中学习，无需匹配的人-机器人示范。机器人后训练前分析显示跨本体运动对齐改善，对未见机器人的动作与视频预测更好，表征更接近机器人配对所学。后训练后，WATCH 将 MimicDroid 上下文成功率从 40.9% 提升至 68.3%（Cosmos Policy），从 59.8% 提升至 77.7%（Cosmos3），未见关卡增益最大。

AUGUstus：统一生成与理解的自动驾驶 VLA 模型
VLA 模型在端到端自动驾驶上潜力大，但现有方法存在两难：回归或流式方法为低延迟直接生成动作，却未充分利用 VLM 理解，导致不安全且不可解释；自回归方法顺序生成思维链与动作 token，充分利用理解但延迟高。该工作提出 AUGUstus，将基于扩散的动作生成与自回归 CoT 理解统一在一个模型中，理解仅服务于生成。联合 CoT 监督在共享表征中保留 VLM 空间理解，带来更安全准确的轨迹。AUGUstus 模式将动作生成排在 CoT 之前，使 CoT 在训练中监督可靠动作，而推理只需动作输出，实现低延迟。AUGUstus-GRPO 统一算法联合优化动作与 CoT。实验显示其在 NAVSIMv1 上达 94.6 PDMS，NAVSIMv2 上达 90.7 EPDMS，为无评分模块的 SOTA 规划；nuScenes 上平均 L2 误差 0.27 米。

GreenWAM：面向机器人的世界基础模型
机器人需要世界模型预测动作如何改变场景，也需要策略选择动作，但模型通常只为其中一种角色构建与评估，且每个机器人以自有格式记录动作。该工作提出 GreenWAM 世界基础模型及其配方：共享解剖动作空间以共同关节坐标描述 20 个机器人族，从双臂到灵巧人形；在这些族上以视觉、动作条件与世界-动作模式联合训练；策略从生成器分离出动作专家。作为世界模型，GreenWAM 在 WorldArena 1.0 上取得顶级轨迹、深度与 3D 精度，领先所有对比的世界-动作模型与视频生成器。作为策略，它跻身 RoboTwin 2.0 排行榜前列，在 LIBERO-plus 上取得对比方法中最高的零样本成功率，在 CALVIN 与 LIBERO 上与专用 VLA 及世界-动作策略相当。作者进一步适配真实人形，成功率高于从 π_{0.5} 与 Cosmos 3 Edge 适配的策略，并蒸馏为单步策略用于实时控制。

ChunkAct：面向代理式机器人的动作分块
代理式机器人将 LLM 代理置于控制回路，在记忆引导下组合感知、运动与 VLA 工具，从而无需重训练即可泛化到新任务，但代价高昂：每个原语都需 LLM 基于完整交互历史推理一轮，回合成本随原语数增长。作者发现这种推理大多冗余：一旦选定子目标，其原语遵循记忆已规定的常规流程。ChunkAct 将动作分块引入代理式机器人：在线时单次调用启动一串链式原语，自主执行且仅在失败时归还控制；离线时将记忆编译为这些块，使测试时执行无需记忆，规划器只保留给需要推理的决策。因此 LLM 计算随决策数而非原语数扩展。在 LIBERO-Pro 上，ChunkAct 较代理式机器人 SOTA 提升 5.0 点任务成功率，同时 LLM 调用减少 2.9 倍，输入 token 减少 4.4 倍，输出 token 减少 2.3 倍。

DeRef 揭示工具调用参数验证中的推导缺口
工具调用评判器评估 LLM 代理提出的参数值。作者发现，当评判器输入中没有该值的参考文本时，其接受正确值的概率更低，称为推导缺口。这发生在值是函数 schema 中用户未提及的默认值、需推断得出、或来源文本被截断时。该缺口出现在所评估的全部七个评判器中，包括 System One 模型 CLM 与 Jev。它不只是截断假象：在无截断基准上，正确默认值的缺口最大。受控来源重定位测试显示评判器会跟随输入中的参考：它们偏好可见的错误值，而非来源被隐藏的正确值。作者提出 DeRef，由单独模型在不看候选的情况下读取完整历史并为评判器写参考。在三个基准上，DeRef 提升所有评判器的整体参数 AUROC；受控测试中将 AUROC 从随机或以下提升至 98.40 至 99.59。
