Anthropic 向投资人披露季度收入达 168 亿美元，IPO 前增速近 50%
据 Simon Willison 引述 FT 报道，Anthropic 在周三的投资者活动中披露，Q1 收入约 48 亿美元、Q2 为 115 亿美元、Q3 升至 168 亿美元，季度环比增速接近 50%。Q3 每花 1 美元算力成本对应 1.70 美元收入，剔除股权激励后的调整后营业利润率为 11%。公司同时收紧了对「蒸馏」的管控——即竞争对手用 Anthropic 模型输出训练自家模型的做法，并告知投资人蒸馏曾占收入的 5% 至 7%，Q3 已「实质性」削减。按此推算，若蒸馏在 Q2 占 5%，意味着未具名的其他实验室当季为蒸馏 Anthropic 模型花费超过 5 亿美元。另一个值得注意的变化是，Anthropic 在这类沟通中已不再使用「年化运行率收入」口径。对从业者而言，这组数字首次把「模型被当作训练数据供应商」的隐性收入结构摆上台面。

Google 开源 Harness2：测试时重写 agent harness，GLM-5 单步提升 11.5 分
Google Research 以 Apache-2.0 协议发布 Harness2，这是一个递归式 agent harness 框架，核心思路是在测试时（test time）重写 agent 的 harness 本身，而非更新模型权重。据 MarkTechPost 报道，仅一个 refinement 步骤就让 GLM-5 在 WorkBuddy-Bench 上提升 11.5 个百分点，全程没有做任何权重更新。这意味着围绕 agent 的脚手架、工具调用格式、提示结构与错误恢复逻辑，本身构成一条独立于模型能力之外的性能提升路径，且可以被自动化搜索和迭代。对构建 agent 系统的团队来说，Harness2 提供了一种低成本试错范式：在不重训模型的前提下，把工程侧的 harness 当作可优化对象。Apache-2.0 的许可也降低了商用集成门槛。

Mine, Sample, Render 把生成多样性外化为语料采样
针对生成模型即使被明确要求也难以产出多样结果的问题，论文提出 MINE-SAMPLE-RENDER（MSR）测试时方法：先从真实语料中挖掘可解释的分类模式并统计属性分布，再按该分布采样属性配置，最后把生成模型降级为条件渲染器。在天气报告生成、用户模拟、网页设计、text-to-image 与 agent 生成 3D 资产五类任务上，MSR 同时提升了输出与语料分布的对齐度和多样性。其思路是把「多样性」从模型内部采样策略中剥离，交给可审计的显式采样程序，对需要可控多样输出的产品侧部署有直接参考价值。

SAE 特征的行为组合性被量化：一阶可加、二阶必要
论文提出 SAE Additivity Residuals（SAR），度量在给定交互阶数之上仍未被解释的行为变化，并证明在独立特征子集采样下总体 SAR 恰等于该阶以上交互的归一化能量。在全部 18 组模型与行为设定中，学习到的 SAE 坐标一阶残差均低于同子空间的保和随机旋转；但坐标并非完全可加，成对项在每种设定下都改善留出联盟排序。联合 steering 实验中成对建模把 rank fidelity 从 0.5874 提到 0.7790，排序误差从 0.1444 降到 0.0606。结论是单特征干预不足以支撑忠实解释，需引入交互项。
