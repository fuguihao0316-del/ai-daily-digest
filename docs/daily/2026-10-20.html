NVIDIA 开源 Run:ai 全栈平台
NVIDIA 将收购而来的 GPU 编排平台 Run:ai 以 Apache 2.0 协议完整开源，包含 KAI Scheduler 调度器、CUDA 13.4 的 GPU 分片（fractioning）能力、配额管理以及基于 Kind 的本地开发环境。此举直接降低了企业在 Kubernetes 上自建多租户 GPU 集群的门槛，过去需要商业授权才能使用的细粒度显存切分与队列调度，现在可以被任何团队集成进自有平台。对自建推理集群的团队而言，这意味着不必再围绕 NVIDIA 的闭源工具链做适配，KAI Scheduler 也可与现有 Volcano、Slurm 方案对比选型；同时这也强化了 NVIDIA 在编排层的存在感，使 AMD、Intel 等替代硬件在软件栈上更难获得同等支持。

Xiaomi-Lens-0：4B MLLM 用自身视觉 latent 解码分割掩码
小米发布 Xiaomi-Lens-0，基于 Qwen3.5 构建的 4B 多模态模型，直接让语言模型从自身视觉表征预测分割掩码：轻量解码器把视觉编码器 patch 特征与语言模型的 mask-token 状态结合，掩码监督因此能回流到共享主干，无需额外分割编码器。模型可在思维链中交错生成区域 latent，做到"用视觉 latent 思考"，并用 grounded reasoning trace 监督其访问的区域。在 RefCOCO、RefCOCO+、RefCOCOg 全部八个划分上，指代理解平均比 Qwen3.5 高 5.6 分，分割 cIoU 为对比模型最高，且在全部感知基准上超过 Qwen3.5。这为细粒度区域理解提供了一条不依赖文本标注指明区域的监督路径。

Lean4AgenticRL：用 Lean4 形式化统一多层级过程奖励

Librarian Agents：训练 LLM 预先把语料整理成可复用工作区

DisaggKD：把教师与学生拆到不同节点做知识蒸馏
现有知识蒸馏把教师与学生放在同一批 GPU 上，单卡显存限制了可用的教师规模。DisaggKD 将二者分离到不同节点：教师副本向学生流式传输隐状态，按行窗口与词表分片计算的 KD 损失在精确算术下等价于全词表损失，且无需形成完整词表 logits，并用预取环调节生产者与训练者节奏；作者给出闭式显存与流量模型以定位各布局的显存上限。在 Qwen3.5-35B-A3B 到 9B 的配对中，分离布局在同损失下与同置运行持平且更快；融合损失也让同置运行能用更少节点更快训练。但在更大模型配对下，同置加融合损失仍会 OOM，只有分离布局能训练。
