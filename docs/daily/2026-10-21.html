TokenGate：用可学习 token 剪枝把长上下文 prefill 提速最高 11.3 倍
长上下文推理的成本大头在 prefill，而现有模型会把每个输入 token 都送进每一层。TokenGate 提出一个小型可插拔组件，让已训练模型端到端学习 token 剪枝；为解决 top-K 不可微的问题，作者引入受 Mixture-of-Experts 启发的 token-gated attention，用 token 重要性分数重新加权 attention logits，从而把剪枝决策纳入梯度回传。在多种任务上，TokenGate 在 transformers 的 prefill 阶段实现 1.4-11.3 倍的首 token 延迟（TTFT）加速和 1.5-3.4 倍的峰值内存下降，且精度不降；相比此前最佳 token 剪枝方法，prefill 快至 6.4 倍、峰值内存低至 2 倍。它可原生扩展标准 transformer（如 Qwen3）与混合注意力模型（如 Qwen3.5），适配成本与常规参数高效微调相当。对做长文档、代码库推理的团队而言，这意味着不必重训基座就能压低首 token 延迟与显存占用。
★★★★★

Harness-Delta Attribution：拆解 agent harness 进化收益，54% 来自过拟合
Harness evolution 通过自动优化固定权重模型周围的 prompt、技能、工具与编排代码来提升 agent 系统，无需更新模型权重，但搜索集上的涨分有多少是基准特定过拟合、多少来自额外推理算力、多少能泛化，此前缺乏量化。作者提出 Harness-Delta Attribution（HDA）评估协议，把进化收益拆成 artifact 驱动的过拟合、test-time scaling 可解释部分，以及剩余项（残余可泛化提升的上界）。在 11 个执行模型、3 个 harness 进化框架、覆盖数学、编码、创造性与 agentic 任务的 21 个取得统计显著搜索集涨分的设置中，过拟合与 test-time scaling 平均分别占 54% 和 14%，两者合计在 14 个设置中超过 50%。搜索集涨分常常无法迁移到留出任务。这提示 harness 自动优化的报告需要匹配的对照评估。

First Passage Attention：用路径极值替代路径求和，KV cache 压缩到 25% 仍完美检索
给 softmax attention 加遗忘门通常依赖沿 key-query 路径累加衰减贡献，这种累加是单调的，因而无法在保留较早结构相关 token 的同时选择性擦除中间上下文。作者提出 First Passage Attention（FPA），从路径求和转向路径极值：按学习到的标量场在中间跨度内低于某 key 水平的最深下探，成比例下调该 key 的 logit。FPA 把 Forgetting Transformer（FoX）作为特例涵盖，当标量场与水平遵循共享学习游走时，未被惩罚的存活 key 自然构成一个栈。理论上一维常维 FPA head 能实现后续下探留下的任意 key 子集，而带位置偏置的 softmax head 或 token 级遗忘门需要与 key 数成线性关系的 head 维度。合成实验中单层 FPA head 收敛到目标集合而 softmax 与 FoX 基线在每个随机种子都失败；扩到 110M 参数语言模型，FPA 困惑度与 FoX 持平，并在 8 倍训练长度上唯一实现完美 passkey 检索，KV cache 压缩到约 25%。

A Conditional No-Hair Theorem：证明 transformer 对 prompt 的记忆按幂律衰减
作者追问自回归 transformer 在生成 t 个 token 后还保留多少 prompt 信息。构造两个不同 prompt 后接相同续写文本，使隐状态差异只来自 prompt，发现其距离近似按幂律 t^{-α} 衰减，其中 α=1 对应固定 prompt 在均匀注意力中份额的收缩速率，α 越小记忆越长。训练过的模型遗忘快（α 约 0.55-0.7），未训练模型慢（α 约 0.2-0.5）。作者证明对长度 P、深度 L 的 prompt，这一偏移为 O(P(log t)^{L-1}/t)，界对有限深度 pre-LN softmax transformer 成立，前提是注意力 logits 有界且 pre-norm 激活远离零。机制是几何性的：prompt 的直接影响随上下文增长被稀释，续写 token 的中继只能增加对数因子。这就是所谓 conditional no-hair theorem：给定已生成文本，prompt 对下一 token 的影响随 t 增大而消失，任何存活下来的 prompt 属性（如语言）必须由文本本身携带。一个可精确求解的线性中继模型表明该界不可改进。
