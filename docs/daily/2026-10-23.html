Same Simulation, Different Evidence：检索工具输出如何让 LLM Agent 损失准确率
论文用 USGS 地球化学模拟器 PHREEQC 做受控实验，其报告最长可达 846.8k 字符，158 道执行可验证的选择题显示：当 Agent 通过章节索引而非上下文读取报告时，GPT-5.1 与 GPT-5.2 分别损失 11.3 和 7.9 个百分点准确率，Claude Opus 4.6 与 Sonnet 4.6 无可检测损失。重跑全部 11,007 次模拟调用发现，两个 GPT 模型算出关键值的频率几乎不变，变的是它们据以作答的证据：检索模式下它们常跳过报告，改用自身更高精度的输出文件作答并错误舍入到相邻选项，作者称之为证据替换。固定模拟过程后，检索仍让 GPT-5.2 损失 9.4 个百分点；GPT-5.4 因正确模拟更频繁而掩盖了约十点的证据使用损失。显式命名权威输出可在三个 GPT 模型上比普通检索提升 6.3 至 7.9 个百分点，内联放得下的输出同样有效，而要求正确舍入无效。
★★★★★

FrontierCS 2：面向计算机科学研究与开发的 Agent 基准

Language Models Learn to Improve Language Models：用研究世界模型做 RL 奖励
论文提出 LM2LM，用强化学习训练 LLM 生成有效的语言模型改进提案，指向递归自我改进。难点有二：真实反馈太贵，RL 需评估数万条提案，每条可能是一次完整训练，即便每次十 GPU 小时，仅收集奖励就要数十万 GPU 小时；而代理反馈在策略分布漂移后会失真，优化会偏向被高估的提案。LM2LM 的解法是用一个冻结 LLM 充当研究世界模型 RWM，依据上下文中的真实实验记录预测提案收益，作为 RL 奖励模型，并周期性执行当前策略高排名提案、把实测结果写回 RWM 上下文以维持反馈可靠。在八个自回归与扩散语言模型开发环境中，留出任务的真实执行评测显示，LM2LM 让 Qwen3.8-27B 胜过 GPT-6-sol，即便后者上下文中给了 300 条真实实验记录。

VerifierBench：评测 LLM Agent 生成可执行验证器的能力
Agent 在完成任务和过滤合成训练数据时都需要可靠地校验自己的输出。论文研究验证器生成：给定任务指令与环境，Agent 写一个可执行验证器，必须接受所有合法解并拒绝非法解。VerifierBench 含来自六个 Agent 基准的 222 个任务，覆盖工具调用、状态与代码验证，附 4,993 个隐藏测试用例，其中包含其他合法解与攻击样本；Verifier4Verifier 六项审计用于筛查源验证器与测试集。在统一 Agent 框架下评测 19 个模型，归一化平衡准确率仅 10.6 至 62.1，生成的验证器拒绝非法解明显比接受合法解更可靠。这种表面优势可能掩盖过度限制：分析记录中多数误拒来自不接受该任务任何已测解的验证器，案例显示它们对解的格式、工具使用与代码改动做了无依据假设，从而排除合法解；这些错误能躲过自测，因为 Agent 测试的解共享了验证器的错误假设。

DiffResearch：用扩散语言模型加速深度研究
深度研究系统反复规划、取证、综合与修订，端到端延迟是交互使用的关键瓶颈，而几乎全部生产系统都建立在自回归模型上，继承了从左到右解码。论文提出 DiffResearch，一个开放多智能体深度研究框架，在每个阶段核心位置都换成扩散语言模型，并在固定 Agent 脚手架、检索代码、提示与评测的前提下，将骨干在开放扩散模型与可比自回归模型之间互换。在 100 个 Deep Research Bench 任务上，扩散骨干端到端约快 6 倍，主要来自规划与写作环节的数量级缩短。作者还提出 dFast 分解模式，读取中间去噪状态，在生成完成前抽取子查询，单独分解环节中位加速 1.99 倍且报告质量无损，并在该基准 RACE 评分标准下取得三种配置中的最佳总分。公开系统级排行榜快照中，基于更强扩散模型的实例排名高于若干商业系统，代码以 Apache-2.0 发布。

Quant-Arena：评测 LLM Agent 的量化交易研究能力
量化研究是一个迭代闭环：提出市场假设、实现为可执行信号、在历史数据上检验、决定保留什么。现有基准只评公式、代码或单笔交易决策，无法回答 LLM 能否走完这个闭环并产出研究期之外仍有效的策略。Quant-Arena 是基于真实 A 股数据的端到端量化研究基准与公开排行榜：模型构建特征与选股代码，只在 2022 至 2023 年获得反馈，冻结一个策略后在封存的 2024 年评估；现金账户评测器施加交易约束与成本，包括由模拟订单簿估计的市场冲击。得分以已实现超额收益为主，辅以信号质量与策略所用特征多样性。评测九个前沿模型，GPT-6 Astra 得分最高，但 2024 年没有任何模型跑赢等权市场基准。该基准向任何模型或 Agent 框架开放提交。

Stratified Sparse Attention：在极端稀疏度下缩小与稠密注意力的差距
长上下文推理日益受限于不断增长的 KV cache 访问成本。稀疏注意力只访问一部分缓存，但现有方法在确定性检索与采样之间取舍：前者抓住高分 token 却丢弃残余注意力质量，后者覆盖更好但方差更高；top-k 加均匀采样的混合方法在激进稀疏度下仍与稠密注意力差距明显。论文提出 SSA，将确定性检索与分数引导采样统一：确定性地关注高分 token，同时用代理注意力分数对残余部分采样，并按纳入概率做修正，从而回收检索集之外的注意力质量，top-k、top-p 与混合方法均为其特例。在 RULER、LongBench、LOFT 与 AIME 上，五个 3B 至 27B 模型在同等稀疏度下均稳定优于基线；RULER-HARD 上 Ministral-3-8B 在 50 倍注意力稀疏下，32K 准确率从 81.8% 升至 84.2%，128K 从 63.8% 升至 69.3%，分别恢复稠密注意力性能的 94% 与 85%；配合优化 CUDA 内核，解码加速最高达 2.96 倍。
★★★★★

Retrieval Augmented Generation Compositionality：RAG 组件收益未必可叠加
现代 RAG 流水线组合嵌入、分块、检索、重排、查询增强、上下文压缩与 Agent 校验，但这些技术通常被单独评测。论文预先声明三个假设，并推出开源框架 LASAGNA 做受控评测，在八个基准、5K 至 200K 文档的语料上测试 450 种配置。三点发现：其一，来自不同阶段的单项强技术不一定能组合，三项检索技术单独预测可带来 47% 的合并提升，同时使用只兑现 17%；其二，组件收益在检索质量与答案忠实度上叠加方式不同，优化其一可能损害另一；其三，最佳组合随语料规模变化，小语料上的赢家未必在大规模下仍最佳。作者据此指出孤立测量的收益不能可靠预测真实表现，新 RAG 技术应在完整技术栈中测试，并以 LASAGNA 降低这类实验的门槛。
★★★★★

Hidden Messages Between Diffusion Language Model Agents：连续隐状态通信的因果证据
扩散语言模型通过一系列可修订的连续状态形成答案，但多智能体系统通常丢弃这些状态，只在解码成文本后通信。论文研究一条独立扩散轨迹能否把紧凑隐藏消息传给另一条，以及接收方是否真的使用了消息内容。实验中发送方把去噪状态压缩为四个带符号稠密向量，接收方在保留自身上下文、画布与轨迹的情况下消费它们；移除消息检验通道是否起作用，替换为另一样例的消息检验内容是否起作用。结果显示，错配替换在 Tiny-A2D 上抹去 +63.6 点优势，在 Dream-7B 上抹去 +100.0 点优势，定向替换则把接收方引向被替换的事实。QASC 上把两个支撑事实分给不同 Agent，匹配通信达 80.8%，错误样例消息把准确率压到 46.8%，内容效应为 +34.0 点。最反直觉的是时序：单次较晚传输达 87.8%，比四次循环交换还高 7.0 点。
