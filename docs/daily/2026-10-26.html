Anthropic：模型能力足够后，单智能体架构优于多子智能体
Anthropic 发布工程建议，认为随着模型自身处理复杂任务的能力提升，企业应重新评估是否把多个子智能体合并为单个按需加载上下文的智能体。在一次架构对比测试中，单智能体方案的运行速度约为多子智能体方案的两倍。Anthropic 同时在 GitHub 上发布了迁移工具包，帮助团队完成从多智能体编排到单智能体的改造。这一判断与当前业界普遍追捧多智能体分工的潮流相反，其核心逻辑是：子智能体之间的通信与协调开销，在模型单次可处理更长上下文、更强推理之后已成为净损失。对正在搭建 Agent 系统的团队而言，这意味着架构选型应以模型能力基线为前提，而非默认采用多智能体拓扑，迁移前需先测量自身任务中的协调成本占比。

Jack Clark 将自我改进 AI 的时间预测提前至 2027 年
Anthropic 联合创始人 Jack Clark 修改了自己此前对自我改进型 AI 到来时间的判断，把预测提前到 2027 年。触发这一调整的是 P-Zero Research 发布的新 benchmark，该基准专门衡量 AI 模型自主设计实验、评估实验结果的能力。结果显示，模型在这项能力上的进步速度超出预期。自我改进 AI 指的是模型能够自行提出假设、设计验证实验并根据结果迭代自身能力，一旦成立，能力提升曲线将不再依赖人类研究者的产出速度。Clark 的预测调整属于时间点判断而非确定性结论，但作为前沿实验室联合创始人的公开表态，它会影响外界对 AI 研发节奏、算力投入回报周期以及安全评估窗口期的预期。

TARSphere 发布面向长程具身智能体的全栈框架与基准
机器人需在物理与社会约束下行动并适应环境变化，现有具身智能体系统多聚焦指定目标或将执行抽象为符号动作，难以在动态世界中评估。TARSphere 由三部分组成：TARSphere-Infra 在带具身 NPC 与受限对话的物理模拟器中运行机器人策略，用事件驱动有限状态机依据已完成动作与已交付信息更新任务状态并评估结果；TARSphere-Harness 让冻结的多模态大模型通过多级可执行技能行动，借助观测、分层记忆与执行反馈修正决策；在此基础上以 agent-in-the-loop 方式对齐任务语义、因果依赖与场景几何，构建含 30 个室内场景、360 个 episode 的 TARSphere-Bench，设置五组配对条件考察感知鲁棒性、中断适应、任务更新、人类协作与意图理解。对 8 个 MLLM 的评测显示通用模型可胜过具身模型，任务更新与人机交互仍是难点，频繁碰撞与跌倒说明执行安全需与任务成功率并列评估。

LLM-Attacker 统一分割式与分布式 LLM 系统的隐私评测
分割语言模型将输入文本留在客户端，只把中间表示发送到服务器，攻击者可据此重建文本，但当攻击者可见消息、已知模型权重、所用数据集与恢复度量各不相同时，隐私评测难以横向比较。LLM-Attacker 记录这些选择，使研究者能检查、比较和扩展评测：兼容攻击可复用已记录消息，预测结果单独保存以便独立打分；评分规则要求先有可关联的无防御参照，防御才算通过；报告还会标出尚未测试的攻击。在受控 GPT-2 实验中，加入训练时回传的梯度使 token 恢复率从 94.20% 升至 97.38%，整文档精确恢复率从 13.71% 升至 37.77%，token 增益的 95% 区间高于测试前设定的两个百分点阈值。框架将实现检查与实测攻击效果分开报告，作者主张每项隐私声明都应说明攻击者、数据集与评分规则，报告对照条件并列出未测试攻击。

扩散语言模型的计算成本随任务与语言大幅波动
扩散语言模型可在一次前向中写出多个 token，并在生成过程中自行决定前向次数，因此同样长度的两个输出成本可能相差很大。论文分析两个扩散模型在 10 个任务上的表现，发现每 token 所需前向次数高度依赖任务：从输入复制或轻微编辑的文本便宜，开放式写作昂贵，在 DiffusionGemma 中写故事生成一个 token 所需前向次数是语法纠错的三倍以上。两个输出属性解释了大部分差距：相对输入的新增内容比例，以及词在该任务中的稀有程度；同一回答内部也成立，最终答案重复推理轨迹时便宜，加入新内容时昂贵。多语言生成中，分词粒度高的语言每 token 需要更多前向，在本已因 token 更多而付出的成本上进一步叠加。成本还与正确性相关：同一道数学题，错误答案每 token 前向次数多于正确答案，按解码速度对候选答案加权可在无额外成本下比多数投票最多高 4.2 分。结果表明扩散的计算优势取决于输出中有多少已被确定。

Agent Mosaic 量化智能体从多文档拼接推断敏感结论的泄密风险
