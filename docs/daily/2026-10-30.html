Mistral 发布 1T 参数开源多模态模型 Mistral Large 4
Mistral 上线 Mistral Large 4（代号 Le Chonk），这是其迄今最大模型：约 1 万亿参数的原生多模态 MoE，每 token 激活约 520 亿参数（含 embedding 与输出层），128 个路由专家每 token 激活 4 个加 1 个共享专家，支持 1M 上下文，采用 Pixtral 风格视觉编码器处理可变尺寸图像。模型在 Mistral 欧洲自有数据中心、由 3800 块 NVIDIA Grace Blackwell GPU 从零训练，统一指令跟随、推理、编码与 agentic 工作流，在网络安全、金融、法律负载上表现突出，视觉 grounding 超过前沿闭源模型，原生支持 160 多种语言（含全部欧盟官方语言）。GGUF 与 NVFP4 量化版本已由 ggml-org、unsloth 发布，API 名为 mistral-large-4。对开源社区而言，这是首次有欧洲实验室把万亿级 MoE 权重按开放形式放出，本地部署门槛与显存规划将成为接下来讨论焦点。

PreView 用预处理视图与线索提升 GUI grounding，无需重训主模型
GUI grounding 需要在杂乱截图中定位小控件，裁剪放大虽能暴露局部细节，但仍可能留下目标歧义。PreView 作为辅助预处理器，在不额外训练 grounding 模型的前提下改进其输入：一个轻量辅助模型预测并精修中心点，把截图裁成局部视图并放大，同时生成红色圆圈标记加位置提示的视觉线索，以及描述候选控件身份或功能的文本线索。冻结的 grounding 模型据此输出最终点击位置。在五个基准上，PreView 提升了 Qwen3-VL-2B、OS-Atlas-4B 与 Qwen3-VL-4B 的平均 grounding 准确率，且三者均未再训练。论文还分析了视图与线索各自的贡献、中心精修的作用以及视觉输入预算的影响。
★★★★★

PersonaCUABench：同一任务换人提问，计算机使用 agent 完成率下降 36%
现有计算机使用 agent（CUA）通常在固定任务描述下评测，但真实用户会省略需求、追加约束，或在关键操作前要求确认，完成基准指令并不等于服务好了提问的人。PersonaCUABench 固定 74 个任务、覆盖 11 个领域，只改变提问者：44 个 persona 分四组，用自己的话重写指令并回答 CUA 的追问，CUA 只看到对话，看不到用户画像和原始指令。在九个基座模型、3330 次运行中，平均任务完成率相对原始请求下降 36%；失分单元里 59.9% 是 agent 按用户要求执行却做错，11.2% 是用户主动叫停却被判失败。即使任务完全完成，用户给出最高满意度的比例仅 62.7%，原始请求为 84.1%。结论是 CUA 评测需同时考察是否满足用户表达的需求与约束。

LOB-Impact：生成式限价订单簿模型自发涌现市场冲击
生成式限价订单簿模型要作为交易 agent 的世界模型，必须重现真实的市场冲击；若模拟器把这一机制定价错误，agent 会学到在模拟中最优、在真实市场错误的策略。已有指标只做与历史数据的分布比较，几乎不考察对 agent 自身订单的反事实响应。作者向五个自回归模型在五只 NASDAQ 股票上生成的报文流注入执行型 metaorder，用实证冲击文献的估计量测量响应，基准的物理性质事先已知。评测分三阶段：自由生成、metaorder 注入（给出冲击律的指数与幅度）、执行后窗口（测量松弛），并用仅模拟器的盲对照分离模型学到的响应与订单簿机械效应。结果显示冲击在仅做下一 token 预测训练的模型中自然涌现，指数落在 0.63 至 1.21 区间。

Know, then Draw：自回归预训练学知识、扩散后训练做渲染
视觉生成既需要高层语义知识，也需要细粒度像素细节。该工作把两种角色分给不同阶段：自回归预训练负责知识获取，扩散后训练负责高保真渲染，并系统研究了知识获取与渲染的目标函数、表示与规模定律。受控对比显示自回归是更强的预训练目标，提升了下游渲染的学习效率与最终质量；而纯自回归的生成质量并不必然与最终表现相关，语义质量更重要。这促使其采用仅用语言监督训练、不含图像解码器与重建损失的纯语义 tokenizer。作者建立了知识获取与渲染的计算最优缩放律，发现自回归预训练比从零训练的像素扩散模型有更低的渐近渲染损失。据此训练的 3B 参数文生图模型仅耗 6600 H100 GPU 小时，在 GenEval 得 86、DPG-Bench 得 87。

Instruction Capacity：用可计算单位量化语言模型的指令承载上限
语言模型遵循指令的质量随负载上升而下降，但此前没有带不确定度的量来表达模型在负载单位下的极限。作者提出的测量工具让负载由替换文本中单 token 虚词的规则构成：指令是原子的，规则因任务构造而相互独立，每次应用规则的结果都由可计算参考答案确定。每个待替换词的出现成为一次伯努利试验，位置与规则编号已知。统计模型先测量正确替换概率对文本长度、词位置、替换密度、规则数与规则编号的依赖形状，再用平滑律描述并恢复与编码选择无关的参考水平，最终给出在给定正确率下可保持的规则数即指令容量及其不确定度。对 GPT-4o mini 的测量（2958 次请求、642430 次试验）显示各负载因子下规律稳定，正确率 0.95 时容量约 37 至 38 条规则，满替换密度下约 18 至 19 条。

LongZero：不依赖任何外部数据提升长上下文推理
强化学习能增强长上下文推理，但需要长、多样、有挑战且可验证的训练数据。人工标注昂贵，自然数据不足以支撑 RL，现有合成方法依赖外部语料或更强教师模型，而随着被训练模型变强，这些资源越来越难获得。LongZero 让模型从自身提出的任务中学习：先以紧凑结构化形式合成问题、答案及其支撑证据，再把证据单独扩展成长篇多文档上下文，从而避免直接在现有文档上出题。方法把自写的多跳推理任务与自写多轮检索任务结合，用 GRPO 训练。在两个模型、五个长上下文推理基准上，LongZero 可泛化到真实任务，并优于基于外部语料合成数据的 RL 基线，为无外部数据的长上下文推理改进提供了可行路径。

CausGround：把交互经验蒸馏为可复用的因果知识
多模态大模型具备推理能力，但可靠物理交互需要规划考虑动作何时可执行、如何改变世界，这些前置条件与效果依赖环境且常未被模型捕获。CausGround 是非参数化因果交互 grounding 框架，把交互经验蒸馏为以动作为中心的因果知识，识别动作前置条件与效果，并组织成刻画物体属性与物体间关系的因子化世界状态表示。规划时把任务相关因果依赖 grounded 到当前观测，支持对前置条件的反向推理和对效果的前向推理。在 VirtualHome 上平均任务成功率从 24.9% 提升到 53.3%，RoboCasa 上闭环规划成功率从 43.0% 提升到 57.0%，SWITCH 上交互推理准确率从 25.8% 提升到 31 以上。
