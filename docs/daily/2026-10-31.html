🗞 AI 行业动态

OpenAI 发布新版 Model Spec，围绕五项核心价值重构行为准则
OpenAI 更新了 Model Spec，将 AI 行为准则围绕五项核心价值重新组织，其中包括对人类意图的忠实（faithfulness to human intent）与可纠正性（correctability）。新规范要求 GPT 系列模型主动利用对话历史推断用户的真实意图，并披露自身所做的假设，而不是机械地按字面执行指令。The Decoder 的报道指出，这些规则针对的正是此前已被证明难以控制的模型行为，但模型是否真正遵守规范仍是另一回事。对开发者而言，这意味着系统提示词与产品逻辑需要重新对齐：依赖模型「照字面执行」的旧工作流可能出现行为漂移，而利用对话上下文推断意图的能力提升，也为多轮任务型 Agent 提供了更好的基础。OpenAI 同时发布了官方博文说明此次修订，两份材料可对照阅读以理解规范的具体变化。

OpenAI 公布前沿模型失准检测方法，采用分层监控提前干预
OpenAI 发布文章介绍其如何检测前沿模型失准（misalignment）与未经授权的 Agent 行为。核心做法是分层监控（layered monitoring）：在不同层级上部署检测手段，使响应团队能够在事件升级之前介入处置。这一披露的背景是前沿模型的自主性与工具使用能力持续增强，Agent 一旦出现目标偏离或越权操作，后果可能难以回滚。对构建 Agent 产品的团队来说，这套思路的价值在于把「事后审计」前移为「运行中拦截」，即监控不应只作为日志系统存在，而应具备触发干预的能力。OpenAI 未在摘要中给出具体检测指标或误报率数据，但分层设计本身提示了一种工程取向：单一检测器难以覆盖全部风险面，需要组合多种信号并明确各层的响应权限。

Anthropic 研究：专家会采纳 AI Agent 随机生成的观点并误认为是自己的判断

EPSBench 用 149 个公司季度检验 LLM 智能体盈利预测
研究团队发布 EPSBench，覆盖 86 家美国公司的 149 个公司-季度，智能体需读取固定财报、电话会记录与新闻集合，给出带证据引用的利润表驱动项估计，再由统一的会计计算器换算为 GAAP 摊薄每股收益。在统一测试框架下评测六个模型，其中三个模型的点预测误差与同日分析师一致预期无可检测的配对差异，另三个误差更高；六个模型名义 80% 预测区间实际仅覆盖 37% 至 70% 的报告 EPS，且多数未命中落在上界之上，说明预测系统性偏低。驱动项记录显示，模型间误差差距主要来自营业收入估计。对做金融智能体的团队而言，这说明当前瓶颈不在信息获取而在会计驱动项建模与不确定性校准。

WISD：用「弱化版自己」做在线自蒸馏，无需特权信息
针对自蒸馏依赖特权信息构造更强教师的问题，论文提出 Weakening-Induced On-Policy Self-Distillation，反向构造原模型的弱化副本，用两者对比作为训练信号，弱化方式包括低比特量化和幅度剪枝。在数学与代码推理任务上跨多种架构和规模验证，量化与剪枝分别带来平均 4.0 和 5.5 个百分点的准确率提升。具体地，剪枝让 Qwen3.5-4B 在 HMMT 2025 上从 57.7% 升至 70.5%、LiveCodeBench v6 上从 39.1% 升至 56.7%；量化让 Qwen3.6-35B-A3B 在同一基准上从 68.5% 升至 74.6%、从 61.8% 升至 69.5%。这条路线把「弱模型」当作可复用的监督来源，为只有无标注 prompt 的场景提供了可行替代。

把预训练自回归图像模型改造成任意顺序生成器
自回归图像生成器用固定光栅扫描顺序训练，推理时无法做 inpainting、outpainting 或编辑；现有方案从零训练混合顺序，算力约为标准训练的 3 倍，且离散扩散牺牲了 KV 缓存、vLLM 等 AR 推理生态兼容性。论文主张这一成本不必要，提出用 future-aware positional embeddings 解决目标位置可识别性问题，再配合顺序课程，把预训练光栅模型迁移为任意顺序生成器。在 LlamaGen-L/XL 与 RAR-L/XL 四个基座上，ImageNet inpainting FID 为 6.21，显著优于 MaskGIT 的 10.44，outpainting 同样占优，与 MAR-L 相当，代价是类别条件 FID 上升 1.2 至 1.9，额外算力 13% 至 33%。对已有 AR 图像栈的团队，这是一条低成本获得编辑能力的路径。
