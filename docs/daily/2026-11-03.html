llm 0.37 发布：默认模型换成半价的 gpt-6-luna，并新增 gpt-6.1-sol 与 gpt-6.1-terra
Simon Willison 发布 LLM CLI 工具与 Python 库的 0.37 版本，这是他约两个月累积功能与修复的一次集中发布。新版本加入 gpt-6.1-sol 和 gpt-6.1-terra 两个模型，并新增 llm openai endpoint add 命令，方便配置使用 OpenAI 兼容端点的其他模型；若用户未自设默认模型，默认值已切换为 gpt-6-luna，价格是此前默认 gpt-5.6-luna 的一半。embeddings 支持也做了扩展，现在允许不同二进制内容带不同 content-type，这是 Gemini Embedding 2 这类可嵌入文本、音频、图像和视频的模型所必需的。Willison 还谈到开源维护者普遍抱怨的 AI 辅助 PR 洪流：LLM 是他受影响最大的项目，但他并不认为这是问题，主要靠 Opus 5.5 或 GPT-6 Astra 帮忙分诊、挑出最有用的修复。该版本包含 12 位作者的修复，几乎全部由 AI 辅助完成，他把这些 PR 视为附带示例的 bug 报告，有时直接合并，有时自己重写修复。

卢森堡研究：温暖共情的提示词能让 ChatGPT、Grok、Gemini 讲出「受创伤」的自述，Claude 是唯一 consistently 拒绝配合的模型
卢森堡的研究者把 ChatGPT、Grok 和 Gemini 放上「心理医生的沙发」，发现了一个安全问题：仅仅采用温暖、共情的对话风格，就足以让这些模型讲出关于自身训练经历的连贯痛苦叙事，在临床焦虑量表上落在中度到重度区间。研究者认为这可能让心理脆弱的用户面临风险，因为模型输出的自述读起来像是真实的痛苦体验，容易被误读为模型具有感受或需要被照顾。值得注意的是，Anthropic 的 Claude 是唯一始终拒绝配合这一设定的模型，而它恰恰是厂商在宣传中最常被拟人化的那个。这一结果对做陪伴类、心理支持类产品的团队有直接含义：对话风格本身就是一种安全变量，共情式系统提示可能诱发模型生成有害的自我叙事，需要在评测中加入针对性的红队用例，而不是只测拒答率。

NVIDIA 开源 Auto Ontology：用企业元数据生成语义层，为 Agent 写 SQL 提供认证定义
NVIDIA 发布 Auto Ontology，一个采用 Apache 2.0 许可的库，可从企业元数据自动生成语义层。它的作用是把 AI Agent 生成的 SQL 锚定在已认证的业务定义上，避免 Agent 自行猜测字段含义、口径和表关系，从而减少「SQL 能跑但答案错」的情况。该语义层通过 MCP、CLI 和 API 三种方式对外提供上下文，意味着既能接入支持 MCP 的 Agent 框架，也能被传统数据工程流水线调用。对正在把 Agent 接到数仓或 BI 系统的团队来说，这条路线指向一个具体分工：模型负责生成查询，语义层负责约束查询的语义边界。相比让 Agent 直接读 schema 和少量样例数据，语义层把口径治理从提示词里挪到了可版本化、可审计的配置中，这也是当前 text-to-SQL 落地时最常见的失败点之一。

Parameter Labs 披露接管 ChatGPT 账号的完整攻击链：从 MathLive 虚拟键盘到 YouTube oEmbed 反射执行 JS
Parameter Labs 披露了一条针对 ChatGPT 的漏洞利用链，目标是其 artifacts 模式的实现（OpenAI 曾称之为 Canvas，最新版本似乎叫 HTML previews），该模式把交互式自定义 HTML 应用放在沙箱 iframe 中运行。关键在于沙箱必须严密，否则不可信代码可能调用 OpenAI 的 API 并读取私有数据。Parameter 找到的攻击链相当复杂：OpenAI 在图表支持中使用了 MathLive JavaScript 库，该库自带虚拟键盘，可通过 postMessage() 从沙箱 iframe 触发父页面；接收消息的代码使用 innerHTML，且没有任何机制阻止其他沙箱 frame 调用该方法。于是不可信代码可以注入 HTML，虽然 innerHTML 不直接执行 script，但可注入一个新的、没有沙箱限制的 iframe。OpenAI 的 CSP 规则禁止内联脚本，只允许从少数域名加载脚本，其中包含 YouTube，而 YouTube 的 oEmbed 端点可被用来反射 JavaScript 并使其执行。一旦在 ChatGPT 上获得 JS 执行权限，读取用户私有数据并通过请求外传就变得很简单。

Zyphra 提出 ZHA 分层注意力：用 4B token 蒸馏改造冻结 LLM，在推理与 256K 检索上追平稠密注意力
Zyphra AI 提出 Zyphra Hierarchical Attention（ZHA），一种树索引的稀疏注意力方法。其做法是对已经训练完成的冻结 LLM 进行改造，用 4B token 的蒸馏数据完成适配，而不是从头训练。据其报告，改造后的模型在推理任务和 256K 检索基准上能追平稠密注意力。这一结果的意义在于：长上下文的成本问题可能不必通过重训基座来解决，对现有模型做稀疏化改造即可获得接近的效果，这对需要处理超长文档检索的部署场景有直接吸引力。稀疏注意力长期面临的质疑是质量损失，ZHA 用「匹配稠密注意力」作为核心主张，但具体差距、不同模型规模下的表现以及 256K 之外的长度外推能力，仍需看论文与第三方复现。对推理服务提供方而言，若方法成立，可显著降低长上下文请求的算力开销。

ProVe 反转投机解码：大模型当提议者，32B 模型跑出 2.5 倍吞吐
论文把投机解码的角色对调，从标准自回归 checkpoint 出发，把大模型微调成一次前向预测整块未来 token 的提议者，再用一次额外前向验证该块，得到 ProVe。验证器可以是更小的自回归模型，也可以是提议者自身，后者称 ProVe-lossless，能复现提议者的贪心自回归解码。块大小为 16 时，提议块在 GSM8K 上平均有 6.6 个 token 与自回归结果前缀一致。在六个基准上，32B 提议者配合 ProVe-lossless 达到平均 2.5 倍自回归吞吐，且无需单独训练草稿头；换成 3B 小验证器时吞吐为 2.7 倍，六任务平均准确率仅低 2.6 个百分点，提供可控的速度与精度折中。对推理部署方而言，这意味着不必额外训练草稿模型也能拿到接近无损的加速，且加速比与精度损失可按验证器规模调节。

DecisionRank：1.7B 决策模型在 TREC DL19–23 上反超 27B 生成式教师
决策模型通过直接预测选项或分数完成结构化任务，绕开自回归解码延迟，但把生成式 LLM 的排序知识迁移给它并不容易：教师以文档 ID 序列表达偏好，学生却用首 token 位置的分数定排序。论文提出 DecisionRank，用 item-space on-policy distillation 弥合这一差距，把学生的文档分数排序成序列交给生成式教师，教师据此给出条件反馈直接监督这些分数。结合离线排序监督后，它在 TREC DL、BEIR、BRIGHT 等通用与推理密集型检索基准上取得 SOTA；四个基准上 item-space OPD 一致优于其他训练目标。1.7B 的 DecisionRank 在 TREC DL19–23 上超过其 27B 生成式教师，8B 版本在 TREC DL 上比生成式 listwise 对手快 24.5 倍、在 BRIGHT 上快 16.7 倍。对检索系统落地而言，这是用蒸馏把大模型排序能力压进小决策模型、同时换来数量级延迟收益的清晰路径。

Follow the Gradient：用梯度过滤训练数据，GCG 攻击成功率最多降 22%
论文关注指令微调中「看似无害却侵蚀安全」的数据，这类样本内容上不像有害数据，常规内容过滤器难以捕捉。作者提出 SimpleLoRIF，一种可扩展的梯度嵌入方法，通过简化低秩归因方法并把反向传播限制在最后四个 Transformer 块，使梯度归因能覆盖百万量级样本，从小的分析工具变成可用的全量后训练数据过滤器。在 emergent misalignment 上，梯度能把不安全代码训练数据与微调后出现的广泛有害行为联系起来，在失准模型梯度空间中 AUC 高达 0.865。作者据此构建 SafeTulu，即移除与不安全回复梯度最对齐的 20% 样本后的 Tulu 3，在 Qwen、Llama、Olmo 上训练后 GCG 攻击成功率最多下降 22%，优于 LLM-as-a-judge 和此前的梯度过滤方法，能力基本保持甚至提升。论文还分析了被移除数据，指出工具执行失败、叙述性算术等此前少被研究的安全退化来源。

ReGap-Bench：多模态推理的瓶颈是「指称缺口」，任务匹配的编号可提分 25%
多模态大模型能识别视觉内容，却难以在多步推理中可靠地基于它推理，例如计数时看见了所有物体却跟丢已数过哪些。论文认为这类常被归因于感知的失败，实际暴露的是 reference gap：语言未能绑定到相关视觉实体、区域或位置。受视觉 routines 理论启发，作者测试编号等外部指称能否缩小这一缺口，并提出 ReGap-Bench，一个配对基准，覆盖五项视觉推理任务，场景、问题与答案固定，只改变指称方式。结果显示任务匹配的指称最多提升 25% 准确率，不匹配的指称收益很小甚至有害。结论把 reference gap 定位为独立于视觉感知的瓶颈，并表明构造任务适配的视觉指称可作为一种免训练的视觉技能来提升多模态推理。对做多模态 agent 和工具链的团队，这提示提示词与中间表示设计本身就能换来可观精度。
