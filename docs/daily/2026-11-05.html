Say the Same, Act Differently：视觉扰动可让 VLA 动作改变而推理文本逐字不变
研究揭示 reasoning VLA 模型存在文本与动作解耦的安全盲区。作者在 Alpamayo（驾驶）和 InstructVLA（操作）的文本/动作共享接口上提出 TNAS 诊断，发现局部最动作敏感方向与文本损失梯度近乎正交，范数重叠仅 1.87% 和 5.28%。在等范数扰动下，沿该文本中性残差方向的干预对动作的位移是文本梯度扰动的 4.64 至 47.8 倍，而文本梯度扰动带来的文本漂移高 21.2 至 277 倍。在 Alpamayo 的 154 个带障碍标注驾驶场景中，TNAS 引导攻击在全图扰动下 52.6% 的场景在理由逐字相同的情况下新增碰撞，局部前视摄像头 patch 下为 35.1%，无引导动作攻击仅 4.55%。相对保文本基线，TNAS 将理由完全保持率从 83.0% 提升到 89.5%，同等碰撞率下教师强制文本漂移降低 68.4%。这意味着仅靠阅读模型给出的自然语言理由来监控具身安全并不可靠。

Length Is Cheap, Competition Is Not：检索中的上下文腐化源于注意力竞争而非长度
论文挑战「长输入导致模型失败」的通行解释。在五个开放模型（0.5B 至 3B、四个家族）上，中性填充几乎无代价：Qwen2.5-1.5B 在 32K token 内准确率保持 0.97 至 1.00；但把同样位置的填充换成证据格式的陈述，准确率跌至 0.16 至 0.33。一条给被查询键提供竞争值的陈述会把损失放大 9 至 110 倍，且每增加一条竞争者损失继续上升。模型内部唯一与失败同步的量是留在证据上的注意力质量：在 126,473 次试验中它最多解释 58% 的损失方差，而对数长度最多解释 8%。此前支撑「长度有害」的掩码填充协议在 MMLU 上可复现（30K token 掉 11 至 18 分），但在检索的可见对照中失效：32K token 下掩码损失 45 个准确率点，同样填充保持可见则毫无损失。作者开源探针与全部 12.6 万条试验级测量。

Adversarial Speculative Reasoning：把投机解码的数值噪声当作长程智能体的推理增强手段
论文指出投机解码并非纯粹的系统加速，在长程智能体推理中会改变模型行为。作者在前沿开放权重模型上测量发现，验证窗口内数值噪声会累积，思考过程的草稿接受结果在 30 步之后能改变模型输出分布，从而以随机方向明显影响长程推理准确率。其方法不改变目标模型验证的整体 token 分布，而是训练草稿模型在关键推理点主动被拒绝：先在智能体轨迹中定位这些决策点，再用对抗偏好训练草稿模型，使推理时草稿与目标模型恰在此处分道扬镳、验证重启，让关键思考 token 由目标模型在其噪声最小的条件下采样。作者称这让关键推理在长程上更易索引、更耐久，并在复杂智能体编程基准上提升了端到端成功率。该工作把草稿模型的优化目标从接受率扩展到推理质量，为投机解码在 agent 场景的部署提供了新视角。

Dory1.0-4B：带弹性深度的循环归一化 GPT，单检查点适配不同推理算力
作者发布 40 亿参数的循环（潜在递归）语言模型，基于 nGPT 骨干，交错滑动窗口与全注意力层，结构分为输入块、共享循环块和输出块；推理时循环块可执行可变次数，因此同一检查点可服务不同算力预算。模型在 6 万亿 token 上预训练，前 4.5 万亿 token 使用 NVFP4，随后扩展上下文至 256K token，并用 SFT 与 RLVR 后训练，配合难度感知的循环课程把更难提示路由到更深循环。增加循环次数可提升准确率，收益最大的是编程、智能体与长上下文基准；两次及以上循环时，Dory1.0-4B 在 12 个基准的平均成绩超过 Qwen3.5-9B、Gemma 4 12B 和 Gemma 4 26B-A4B。循环还带来 token 效率：四次循环比一次循环少生成 1.3 至 2.5 倍 token，因为额外计算花在潜空间而非更长输出。为降低循环内存，模型只缓存最后一轮的 KV，使 KV-cache 占用与非循环模型相当。

You don't need long context：频繁压缩上下文几乎不损失长程任务准确率
