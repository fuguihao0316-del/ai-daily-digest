OpenAI 发布 GPT-Image-2.6 Flare 与 Sunburst

D3D 解耦扩散草稿模型实现异步投机解码
现有 target-conditioned 扩散草稿器虽然能并行预测候选 token，但每个新块都必须等待目标模型更新后的 hidden states，导致起草与验证只能串行执行。复旦团队提出的 D3D 去掉了这一轮间依赖，用块级去噪加辅助自回归监督，在没有目标 hidden states 的情况下也能获得长接受前缀，从而可以在验证当前块的同时一次性打包起草后续块。作者按对接受长度的影响逐层剪枝，36 层中删去 5 层后，以 Qwen3-8B 为目标时在三个基准上仍保留超过 99% 的平均接受长度。在七个基准上，D3D 对 Qwen3-8B 和 Qwen3-32B 目标分别取得 5.00 倍和 5.71 倍解码加速，而 DFlash 为 4.03 倍和 3.67 倍；在 Qwen3-32B 上跑 GSM8K 时加速达到 7.48 倍。代码已开源。

Multi-layer Indexer 让 DeepSeek 稀疏注意力的索引扫描与注意力并发
在 DeepSeek Sparse Attention（DeepSeek-V3.2 与 GLM-5 系列使用）中，每层前面都有一个 lightning indexer 扫描整个 KV cache 并保留得分最高的 k=2048 个 token，长上下文解码时间主要花在这个扫描而非稀疏注意力本身。作者观察到相邻层选出的 token 几乎相同，于是让某层直接复用上一层 indexer 的选择结果，从而解除依赖，使每个 indexer 与本层注意力并发执行。MLI 无需重训练、不新增权重，默认实现不改内核，直接跑在 SGLang 生产解码图中，另有一个可选融合解码内核在 DeepSeek-V3.2 上进一步加速。与 GLM-5.2 已商用的 IndexCache 组合后，在 1/2 到 1/32 的保留率、10K 至 195K 上下文下，DeepSeek-V3.2 解码最多快 14.5%，GLM-5 快 9.8%。

SIMPLE 定律给出 LLM 推理能耗的四参数闭式模型
生成式 AI 按 token 计费，但 token 成本并不相等：每个 token 进入 KV-cache 都会抬高后续 token 的开销，能量随序列非线性增长。现有最准的 SOTA 模型只是拟合，把架构信息吸收进拟合系数，需要逐模型标定。作者从 MHA 与 GQA 的计算与访存复杂度推导闭式表达式，得到四参数的 SIMPLE 推理能耗模型，把 prefill 与 decode 分离，并把 decode 拆成 KV-cache 成本与下一 token 计算。在 NVIDIA H100 上对六个家族 13 个稠密 LLM 的 trace 测试，达到 R2=0.969、MAPE 11.97%，比 SOTA 低 3.1 至 3.5 倍，且无需逐模型校准。该定律还给出解释：prefill 能耗随 hidden dimension 二次增长；更激进的 GQA 分组可把每 token 能耗降至标准 MHA 的三分之一；推理 token 预算推高输出长度后会越过解析导出的能耗最低点，导致超线性能耗增长。
★★★★★

多轮强化学习到底提升了智能体的什么：优势集中在纠错与长程韧性
多轮 agentic RL 在长程任务上表现突出，但收益对交互约束高度敏感。作者用 Pass@(K,T) 在采样宽度 K 与交互深度 T 两个维度上评测，发现轨迹级 RL 优势依赖足够的轮次预算，预算收紧时收益显著衰减；agentic RL 也并未普遍提升单步决策质量，其强项集中在错误恢复与长程韧性。为缓解这种预算依赖带来的部署风险，论文初步讨论了过程监督信号的收益与局限，并提出 BudgetMix RL，在训练中变化交互预算，实验显示其在多种执行设置下都保持稳健表现。

TAC-CoT 用隐式推理段加显式工具 token 降低智能体开销
基于 LLM 的智能体系统越来越多地结合 CoT 推理来处理需要准确推理、外部知识与多步审议的任务，但显式 CoT 生成开销大，而用紧凑连续 token 替代文本理由的隐式 CoT 又不天然支持智能体工具调用所需的显式通信接口。TAC-CoT 是一个工具赋能的隐式 CoT 框架，用紧凑的隐式推理段替代显式推理轨迹，只在工具调用、观察结果与最终答案处保留文本 token，这种交错设计让智能体无需把每个中间推理步骤都说出来即可使用工具。在 agentic 数学与 QA 基准上，TAC-CoT 最高提升 8.8 个点准确率，同时把模型前向次数最多减少 6.8 倍；分析还显示它在单工具与多工具设置下都改善了工具使用质量。

Koopman 生成算子把概率时序预测压缩到单步生成
概率时序预测要求同时具备结构化时序动态、表达力强的不确定性与高效推理，但潜动态模型结构受限，扩散与流匹配等现代生成方法则以迭代采样换取灵活性。KGO 把预测视为结构化不确定性的演化，包含三个组件：Koopman Patch Embedding（KoPE）做时间一致的潜轨迹外推；Koopman Flow Matching（KoFM）借助 Koopman 潜空间中的闭式矩阵指数实现快速单步生成，绕过迭代采样；自适应不确定性门（AUG）按变量与预测步长调整不确定性，对应一种无需手工调参的偶然不确定性学习分解。KGO 在 ProbTS 的 17 个基准中取得 13 个 CRPS 最优、16 个 NMAE 最优，并因消除迭代采样使推理时间比迭代生成模型至少减少 25 倍。
