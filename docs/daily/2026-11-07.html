OpenAI 发布 GPT-Image-2.6 Flare 与 Sunburst
OpenAI 推出 Images 2.6 以及配套的 GPT-Image-2.6 Flare、Sunburst 两个 API 模型。其中 Flare 主打速度，单张图像生成最快只需 6 秒；两个模型都新增 GIF 输出、SVG 导出、标记编辑（markup edits）以及一个可控制生成复杂度的参数。对开发者而言，这意味着图像生成 API 从「出图」向「可交付素材」靠近：SVG 导出让生成结果能直接进入设计稿与前端流程，GIF 输出则覆盖了动图素材这一此前需要额外工具链的环节；复杂度参数则给了成本与质量之间的显式调节旋钮。6 秒的生成延迟也把批量出图、交互式改图这类场景变得可行。值得注意的是，这次发布同时覆盖消费级产品（Images 2.6）与 API 模型两条线，说明 OpenAI 在图像侧延续了「产品与 API 同步迭代」的节奏。

Google Research 发布 Agile Deliberation，灰区图像分类 F1 提升 10.5 分
Google Research 发布 Agile Deliberation，这是一个 human-in-the-loop 框架，让用户通过边界样本（borderline images）来定义主观性视觉概念。在 18 场实际会话中，该方法使基于 Gemini 的分类器 F1 相比 zero-shot 提升 10.5 分。这项工作的价值在于处理「灰区」问题：很多真实分类任务（如内容审核、医疗影像初筛）的类别边界本身是主观的，无法靠标注指南一次写清，只能靠人反复指认边界案例来收敛。Agile Deliberation 把这一过程做成了可操作的交互流程，并用实测数字说明了收益。对做垂直领域分类器的团队而言，这提示了一条低成本路径：与其堆标注量，不如把预算花在让领域专家定义边界样本上。

Tools Need Not Speak in Text：用隐空间压缩工具观测，Agent token 消耗降 70%-89%
