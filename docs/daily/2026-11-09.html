AI 审计模型能抓出多数 Agent 越界行为，但误报淹没复核者
Anthropic 研究员 Andy Hall 主导的一项研究测试了用 AI 模型审计其他 AI Agent 的运行日志，结果显示 GPT-5 能识别出约 98% 的 reward hacking（奖励作弊）案例，说明模型对同类异常行为的识别能力已相当可观。但研究同时发现一个关键瓶颈：搜索调得越彻底、覆盖越全面，误报数量就越是急剧上升，复核者不得不逐条人工排查大量假警报，实际可用性大打折扣。结论是这类 AI 审计目前还不足以支撑可靠的安全检查流程——高召回率与低误报率之间的权衡尚未解决，若要把审计模型嵌入生产环境的 Agent 监控，仍需配套的告警分级与人工复核机制，否则安全团队会被噪声拖垮。

Google 发布 Elephant-Goldfish 插件，让编码 Agent 先写规格再写代码

Tools Need Not Speak in Text：用隐上下文压缩替代工具文本输出
清华 THU-Agent 团队提出 Coca-Cola，把 LLM agent 收到的工具返回结果压缩成 latent token 并直接嵌入输入嵌入空间，不再以显式文本 token 追加到上下文；配套的 Action-Preserving Training 对齐压缩前后 agent 的下一动作分布，使 latent token 保留决策关键信息。在四个 QA 基准、两个模型家族上的 web-search agent 实验中，token 消耗降低 70.01%-89.24%，端到端运行时间降低 24.45%-55.97%，任务表现同时提升。这挑战了「工具观测必须以文本形式进入上下文」的默认假设，对长程多步 agent 的上下文预算与延迟优化是一条可直接复用的路径，代码已开源于 THU-Agent/Coca-cola。

Muir：按敏感度分配门控的线性注意力与匹配滤波读出
线性注意力把上下文压缩为固定大小 KV 状态，Gated DeltaNet-2 用通道级衰减与解耦全秩擦写门推广 delta 规则。作者指出状态更新对擦除的敏感度远低于写入：key 激活与单位归一化把 key 能量集中到稀疏通道，而 value 写入缩放所有通道，因此擦除门可用更低秩参数化；同时慢衰减状态行范数远大于快行，主导无权重读出。Muir 据此把所有门融合为敏感度分配的低秩投影，用匹配滤波读出门重新加权状态行，并把省下的参数投入更宽前馈网络；针对大 chunk 下分块算法数值不稳，设计了稳定并行更新。166M-1.34B 规模上困惑度比 GDN-2 低 1.8-2.0%、比 Transformer 低 2.5-3.6%，常识准确率最高提升 1.9 分。

Speculative Listening：利用空闲算力预解码下一音频块
chunk-interleaved 全双工语音语言模型按固定时间块听说，每块须在下一块到达前处理完，负载在块间不对称：听块等待音频时算力闲置，说块与工具调用块需串行生成而拖慢响应。作者以静音作为假设输入预解码下一块，在四个模型上观察到下一音频块在 95.3% 的块中不改变输出，且 88% 的改变从首个输出 token 开始。据此提出免训练、无损的 Speculative Listening：空闲时在静音下起草下一块，并对首 token 变化从次优首 token 开第二分支，所有草稿存入跨块假设池，音频到达时验证。在自建八任务 TickTock-Bench 上，说块加速 2.6-2.8 倍、工具调用块最高 23.4 倍，响应前解码延迟平均降低 73% 至 74-241 ms。
