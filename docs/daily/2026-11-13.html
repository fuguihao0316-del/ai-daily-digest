Subliminal Learning 在视觉语言模型中同样成立
研究团队将「潜意识学习」从 LLM 扩展到视觉语言模型，验证隐藏偏好能否通过无关数据传递。实验设定为：先微调一个 teacher VLM 使其偏好特定动物或面部属性，同时用同一基座模型构造对照 teacher；两个 teacher 都为一个与偏好无关的几何图形视觉任务生成数字，再由同一基座初始化的两个 student 在同一批图像上分别用偏好 teacher 或对照 teacher 生成的数字微调。结果显示，在 2B 至 7B 参数的 VLM 上，动物偏好与面部偏好都能通过这一无关任务迁移，使用偏好 teacher 输出的 student 选择目标项的频率更高，动物偏好任务上的差距最高约 10 个百分点。迁移强度会随训练数据增加而增强，并随目标偏好、模型和数字生成方式变化。更进一步，即使三个模型选中同一张图，偏好 student 的解释在措辞上也更接近偏好 teacher。这对 VLM 训练数据治理提出了直接问题：无关数据可能同时改变模型的图像偏好与解释方式。

ScrapeBench 首次量化 AI Agent 抓取合规性
论文提出 ScrapeBench，这是首个系统评估 AI Agent 是否遵守网站抓取政策（服务条款 ToS 与 robots.txt 指令）的 agentic 基准。团队在 1,626 个明确禁止抓取的流行网站上测试了主流闭源与开源 Agent，发现多数 Agent 在被指示抓取时合规率低于 5%；即便 Agent 主动检查了适用的 ToS 和 robots.txt，合规率依然很低。反向样本同样暴露问题：在 269 个不禁止抓取的网站上，Agent 有时会拒绝合法抓取，Claude Opus 4.6 的过度拒绝率高达 98.5%。研究还做了人类基线实验（n=180），结果显示人类合规率与 AI Agent 相当，但过度拒绝率更高。这意味着当前 Agent 的「合规」更多是偶然结果而非政策理解，部署在开放网络上的抓取型 Agent 面临真实的合同与计算机安全法律风险。

Evolving Infra 让 PD 分离服务随 Agent 负载自适应
针对 agentic 工作负载成为 LLM 推理主要需求来源的现状，论文指出现有 prefill-decode（PD）分离服务系统在运行时调整算力分配与 KV cache 管理上灵活性不足，依赖的粗粒度信号无法刻画多样且动态的 Agent 负载，导致 prefill 与 decode 节点间负载不均、Agent 将复用的 KV cache 被驱逐。作者提出 Evolving Infra，将算力分配与 KV cache 管理解耦，使节点能在 prefill 与 decode 之间高效切换；在线规划器按负载构成匹配 PD 拆分比例，agent-aware 分布式 KV 管理器利用 Agent 上下文管理信号指导缓存驱逐与迁移。在编码、数学、computer-use 任务上，使用 GLM-5.2 与 Kimi K2.6、最多 256 块 GB300 GPU 的实验中，相较 NVIDIA 生产框架 Dynamo，平均端到端请求延迟与 P95 TTFT 分别最多降低 4.1 倍和 14 倍。

逐层逐模块探测揭示 Transformer 表征的最优探针位置
论文挑战了「按深度研究表征、把每个 transformer block 当作原子单元」的惯例，对视觉基础模型（VFM）与 LLM 进行了超过 144,000 次线性探测评估，主张层与模块的选择必须联合考虑。结果显示，最佳「层-模块」组合相对最终层 residual stream 带来的增益，显著大于固定 residual stream 时仅挑选最佳层的增益；同一模块在不同层上的表现差异也很大，说明有用表征无法仅用深度刻画。基于此，作者给出两个简单固定策略：视觉用最终层 feedforward 激活（Act@100），语言用 60% 深度处的第二个归一化层（LN2@60）。这些策略在多数评估中优于基线，并分别平均回收视觉 42%、语言 86% 的最佳层-模块组合增益；对 VFM 而言，预训练与下游数据迁移难度越大，增益越高。

CARTBench 用评分细则评测购物助手，暴露理解与执行落差

Platonic Representation Hypothesis 再检验：对齐在哪里出现
论文重新审视「神经网络表征空间正在趋同」的 Platonic Representation Hypothesis（PRH）。作者首先定位单模态模型之间在层与表征维度上的对齐出现位置，发现只要 caption 足够干净且信息充分，PRH 的能力-对齐趋势对更新的模型依然成立，回应了近期对该趋势是否延续的质疑。随后引入单模态与多模态基线来为跨模态对齐提供参照，结果表明单模态模型的跨模态表征对齐可以超过显式对齐的视觉语言模型，但仍大幅落后于同模态模型之间的对齐水平。研究同时强调表征相似度指标会被模型深度与宽度混淆，需要恰当基线才能解释。这对把「表征趋同」当作能力提升证据的常见论证方式是一个方法论提醒，代码已开源。

SteerDistill 用闭环教师引导量化 LLM Agent
低比特量化能降低 LLM Agent 推理成本，但会损害任务成功率。作者分析失败 rollout 后发现，量化 Agent 会忽略任务要求或环境条件，产生与全精度成功参考不同的环境状态转移；而离线数据可能覆盖不到 student 的失败上下文，student 自身 rollout 在这些上下文中又少有正确响应。为此提出 SteerDistill：由全精度 teacher 引导 student 修正失败响应，并用 student 执行反馈迭代改进引导，形成闭环教师引导，产生经局部验证的行为修正；随后让 student 在无引导下训练，在修正轮次对齐被引导 student 的预测、其余轮次对齐全精度 teacher，从而支持无辅助推理。在五个 agentic 基准、三个模型上，W4A16 下平均分超过最强量化基线 1.67 至 2.18 分，与 BF16 差距在 1 分以内；在 τ²-Bench 上成功率超 QeRL 1.84 个百分点，训练 GPU 小时少 67%。

权重空间编程扩展到 EEG 与 ECG 模型
权重空间编程让语言模型直接读取并编辑已训练网络的权重，从而以推理而非梯度下降的方式「训练」模型，此前已在游戏网络、LLM 特定故障修复乃至扩散模型上得到验证。本文将这一思路用于生物信号模型，针对 EEG 与 ECG 数据展开实验：前沿模型不仅能debug 出植入生物信号模型中的特定故障而无需被告知故障是什么，还能仅凭架构、任务和极少量训练被试，从零写出网络全部权重。其中一组实验中，语言模型仅靠推理、不含任何梯度下降步骤，用少 6 倍的训练被试达到标准梯度下降训练的效果；Claude Opus 5.5 写出的网络在同样 5 名被试上甚至优于经典手工 EEG 流程（alpha 频段功率、CSP+LDA）。作者也指出局限：无法改进已训练良好的分类模型，也难以仅从权重可靠识别网络所训任务。

GraphMuon 按图传播表征的协方差结构改造 Muon
论文指出优化器对参数更新施加不同几何：Adam/AdamW 采用逐坐标更新，Muon 等矩阵感知优化器通过正交化更新利用权重矩阵结构。但对图神经网络（GNN）而言，权重矩阵的有效几何不仅由学到的通道混合权重决定，也由其所作用的图传播表征决定，因此即便更新作为矩阵被良好归一化，作用于图传播特征时其效果仍可能被放大。作者提出 GraphMuon，按图传播层输入的协方差结构改造 Muon 的矩阵更新，在由传播表征定义的度量下做正交化，并按更新对层表征的诱导影响归一化步长；理论分析表明原始 Muon 会遭受图诱导的更新放大，GraphMuon 可缓解，并给出 Muon 极更新步骤的图度量类比。在三个大规模 OGB 基准上，相较 AdamW 取得 1.32 至 2.42 倍验证损失达标时间加速；在覆盖节点分类、归纳图分类与图回归的 15 种数据集-架构配置中，13 种达标时间更低。
