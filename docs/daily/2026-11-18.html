ResWAM：只学变化不学静止的世界-动作模型
现有 world-action model（WAM）监督完整未来观测，但一个动作块内画面变化极小，未来损失被复制静态背景主导，真正与任务相关的机械臂与物体运动反而学不到；同时依赖大型视频生成模型或独立世界模型，训练与推理开销大，难以闭环部署。作者提出视觉残差学习，在冻结的 DINOv3 特征空间中只监督当前帧到未来帧的特征变化，相比完整未来特征具有更高特征秩、更丰富的场景变化表征，且空间上集中于机械臂与被操作物体。据此构建 ResWAM，总参数 2.3B，含一个 0.5B 双分支 DiT，通过条件流匹配联合训练动作分支与残差分支。在不使用外部机器人动作轨迹预训练的情况下，ResWAM 在 LIBERO-Plus 上取得最高平均成功率 81。该工作提示：WAM 的监督目标设计比模型规模更关键，残差式目标可在小得多的算力预算下支撑闭环部署。
★★★★★
HuggingFace Papers
ForceHarness：让冻结的前沿多模态模型用上力觉
前沿多模态模型已能零样本从图像控制机器人，但许多操作任务依赖图像无法呈现的接触力。把力引入仅提供 API 的冻结模型有两个难点：接触演化远快于 API 模型的决策频率，闭环必须在模型之下完成；冻结模型也无法解读原始力流，力必须以模型可推理的形式返回。为此作者提出 ForceHarness，无需演示与微调：先由腕部传感器或仅凭关节力矩标定手部力，再用自终止力原语自行调节力并在接触事件时返回，物理翻译层把每条力轨迹转成带不确定性的物理量作为工具结果。为公平对比专家力控制器与学习策略，还构建了含隐藏物理变量的七任务 MuJoCo 基准 HiddenPhys。在无腕部力传感器的真实机械臂上，ForceHarness 把 GPT-6 Astra 的零样本成功率从 3.3% 提升到 90.0%；仿真中在公开 ForceBench 上提升 17.5 个百分点，在 HiddenPhys 上提升 34.3 个百分点，超过用演示训练的力感知策略。

ViRA：用对比集强化学习逼视觉智能体读证据
超高清图像上的视觉智能体靠放大相关区域答题，但现有智能体常凭常识作答而非读取证据，仅对最终答案做强化学习无法纠正，因为猜测与阅读拿到相同奖励。作者提出 Cross-Input Relative Policy Optimization（CrossRPO），在对比集上训练：同一问题对应多张仅在小区域有证据差异、答案不同的图像，只有真正读取证据才能解出整组，并证明该方法不会强化靠常识答对的集合。团队在 21 至 120 百万像素图像中编辑单个小物体，构建训练集 ViRA-Train 与评测集 ViRA-Bench，另拍摄真实变化版本 ViRA-Bench-Real 以排除编辑痕迹。仅用约 3,500 条 ViRA-Train 训练 ViRA-9B 与 ViRA-27B，CrossRPO 在最高分辨率下取得 63.3% 集合准确率，GRPO 为 59.3%；ViRA-9B 是同规模最准的开源模型，ViRA-27B 在多数基准上超过最高思考档的 Claude Haiku 5.5 与 GPT-6-Luna。
★★★★★

SilentGuard：把静默 API 故障的判定交给执行框架
LLM 智能体通过调用 API 答题并信任返回结果，但 API 可能静默失败：忽略请求的一部分（例如拼错过滤参数），仍返回 HTTP 200 与看似合理的错误结果。清单、审查模型与 LLM 裁判等现有方案让模型自查，但模型常常看见了问题仍照答。作者提出 SilentGuard，把判定从模型移到执行工具调用的框架：用任何正确 API 都必须满足的不变量检验每个结果，并扣留违反不变量的取值。作者在 15 个公开研究 API 中的 11 个发现静默失败，计数最多被夸大 691 倍；现有方案仍留下超过 70% 的错误答案，智能体还会把裁判标记的 77.4% 计数照常汇报。在 7 个开源模型上，SilentGuard 把目标故障下的错误答案从 74.0% 降到 1.7%，对无故障任务无损；三个前沿模型上从 70.2% 降到 0.5%。仅给出同样检查的警告仍留 70.1% 错误，说明强制拦截才是关键。
★★★★★

Multi-Branch Transformer：用分支而非加宽加深扩展模型
Transformer 语言模型通常靠加宽块或堆叠更深来扩展，本文探索互补路径——分支，即完整 Transformer 块的并行组合。作者提出 Multi-Branch Transformer（MBT）：输入先经共享初始层，随后并行执行各自独立参数化的顺序块分支，再在共享末层前融合输出。在训练算力相当的条件下研究三种变体：Wide-Shallow 保持块宽度，Narrow-Deep 保持顺序深度，Balanced 在两者间插值。在四个 MoE 规模（总参数 0.8B 至 2.1B）的受控预训练中，2 分支 Wide-Shallow MBT 在参数与训练算力匹配下稳定优于顺序 Transformer，Balanced 进一步提升且随分支数增加保持可比质量。为改善长上下文推理效率，作者引入 Joint-KV，在每个深度由分支表征构建共享 KV 缓存。拟合的扩展曲线显示标准 Transformer 需最多 1.26 倍训练主体算力才能匹配其验证损失；最终模型把全模型 KV 缓存存储降低最多 34%，解码吞吐提升最多 51.4%。

BitDecoding-FP4：原生 FP4 KV 缓存解码的算法-系统协同设计
长上下文 LLM 服务中 KV 缓存主导显存容量与带宽。4 位微缩放格式（NVFP4、MXFP4）可压缩缓存并在 FP4 Tensor Core 上跑注意力，但算法量化与系统加速之间存在鸿沟：现有 FP4 KV 系统用朴素量化导致精度严重下降，而面向精度的 4 位算法依赖向量码本，查表开销拖垮解码吞吐。作者提出 BitDecoding-FP4，针对三个误差来源：Dual-Residual Query Quantization 把查询拆成两个 FP4 张量，把查询 logit 误差从 60% 降到 1%；Underflow-Aware Probability Scaling 防止 E4M3 缩放把长上下文概率舍入为零；Outlier-Aware Key Quantization 结合静态平滑、Hadamard 旋转与缩放搜索抑制逐 token 缩放下的键离群值。系统层用转置 softmax 配合融合概率量化、在分页 KV 缓存上堆叠查询 MMA 消除 softmax 瓶颈。在 GQA 与 MLA 的稠密及 MoE 模型上，NVFP4 下与 BF16 KV 精度差距在 0.5 分以内（MXFP4 为 1 分），并能在 RL 训练 rollout 中跟踪 BF16。在 NVIDIA B300 上以 Qwen3-4B 与 Qwen3-30B-A3B 端到端服务，峰值吞吐为 BF16 KV 的 2.4 至 3.0 倍。
★★★★★

More Agents 还是 More Thinking：拆解多智能体 LLM 的协调、集成与测试时算力
多智能体语言模型的评测常把通信架构与单次贪心解码相比，混淆了协调、样本数量与推理算力三个因素。作者汇总九项主要实证评测，共 516 个多智能体配置，按六维资源向量与四类基线阶梯组织。与单次通过的基线（A 类）相比，多智能体准确率差异总体为负，剔除贡献最大的研究后接近零；与样本数匹配（B 类）或资源预算匹配（C 类）的基线相比，平均准确率差为 -0.042，对数几率尺度上的多层随机效应建模在敏感性检验下仍为负。在这些可比对照中，74% 的情况多智能体等于或低于基线，几乎所有被评估研究的均值都非正。从贪心基线换到采样基线，准确率差异平均再降 0.038。作者指出，智能体共享相同证据时通信不带来新信息，正收益需要证据分割、外部验证或模型间错误多样性，并给出审稿清单与核算工具。

Weight-Space Programming Doesn't Need Transformers：无梯度写权重时该选什么结构
Transformer 等标准架构之所以被选中，是因为它们适合梯度下降训练并在 GPU 上跑得快；但在 weight-space programming 中，LLM 手工写出目标权重而不做梯度训练，这些理由不再成立。作者给出极少指引、十个标注样本和一个沙箱，主要在多项选择题上让三个前沿 LLM 要么生成固定架构的权重，要么自行设计架构。自由设计时，三个模型都把纯文本事实编译成由固定过程查询的稀疏表，测试准确率最高 54.4%；LLM 设计的模型比同一 LLM 写出的最准已发布 Transformer 准确率更高，而参数少约 1,800 倍。无梯度条件下它们选择表结构，因为 LLM 能说明每个权重的含义并找出、改写错误权重：每个错误答案指向一行，删掉一行大约改变另一个答案。据此作者提出基于联想记忆的模型，在 GPU 上比同尺寸 Transformer 快最多 17 倍。预训练权重仍更准，该结论针对的是写权重时该建什么结构。
