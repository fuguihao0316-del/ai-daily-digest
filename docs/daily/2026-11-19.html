🗞 AI 行业动态

OpenAI 发布 GPT-6.2 Astra 与 GPT-6.2 Sol
OpenAI 于 11 月 17 日推出两款新模型，Astra 定位前沿旗舰、面向最难的项目，Sol 定位高效通用、面向日常工作，API 型号分别为 gpt-6.2-astra 与 gpt-6.2-sol。价格上 Astra 降至每百万 token 输入 8 美元、输出 40 美元，为上一代 GPT-6 Astra 的 80%，与 Claude Fable 5.2 同价；缓存价格从每百万 1 美元降到 0.40 美元，对长时间运行的 agentic 会话是明显利好。Sol 维持每百万输入 2 美元、输出 10 美元的定价，与前代 Sol 一致。Simon Willison 同步发布 LLM 0.38 支持新模型，并用同一道 Three.js 动画基准题做对比测试，认为两款模型在把 Yonkers 变形为大机甲这一环节上都不如 Claude Fable 5.2 和 Gemini 4 Carbon。Astra 在 Artificial Analysis 智能指数上排名第二。

AnisoFlow 把流模型的预测目标变成可学习的各向异性权重
基于流的生成模型通常手工指定预测目标（速度、噪声或干净数据），这一选择直接影响训练稳定性与样本质量。AnisoFlow 用完全可学习的目标替代固定目标，在联合学习的一组基上为每个方向分配独立的非负权重，对目标的噪声分量做各向异性缩放，并通过闭式映射从网络预测中精确恢复速度，架构、flow-matching 损失与采样器均无需改动。作者从理论上分析了预测误差，预测每个方向上偏好的噪声权重随数据方差近似线性增长，这与像素空间中实际学到的权重一致。在 ImageNet 256×256 上，仅学习预测目标、不做表征对齐也不改架构，FID 从 JiT 基线的 1.90 降到 1.55；在像素空间文本到图像生成中，更好的条件速度恢复还大幅消除了低精度推理下的 patch 接缝伪影。

DWD 让扩散 Transformer 跳过解码器直接输出像素
潜空间扩散模型依赖解码器把去噪后的潜变量映射回像素，增加了复杂度和推理开销。DWD 的做法是分离两个角色：原有去噪头继续驱动采样轨迹，新增的 DWD 头只在最后一步预测像素，训练时仅微调最后几个 transformer 块，用像素质量损失训练新头，同时把去噪头锚定到预训练模型以保持采样轨迹。在潜空间图像与视频生成器上，DWD 去掉了解码器并降低推理成本，像素质量持平甚至更好；在 Wan 视频生成上明显减少细节失真与闪烁，warping error 降低 23%。同样的分离思路对本来就不用解码器的像素扩散模型也有效，最后一步的 DWD 头在文本到图像中显著改善纹理细节，并把 ImageNet FID 从 1.55 提升到 1.43，刷新像素流模型的最优结果。

WeightBench 系统评测 LLM 的权重空间编程能力
已有工作显示大模型可以直接操作其他神经网络的参数，读取网络训练目标、修复失效网络、从零写出可用网络，全程不用梯度下降，这一能力被称为权重空间编程（WSP）。WeightBench 覆盖 42 个 WSP 任务、分五个赛道：读权重、修权重、写权重、识别不可能完成的编辑、无数据压缩，涉及网络从 2K 参数的控制策略到 7B 参数语言模型。结果显示前沿 agent 已能读懂小网络并在不运行的情况下写出可用的控制策略，但还不能修补语言模型、做无数据压缩，也分不清「不可能编辑」和「困难编辑」。42 项任务上 Claude Opus 5.5 宏平均 0.535，Sonnet 5.5 为 0.466，Haiku 5.5 为 0.402，DeepSeek v4-flash 为 0.215；GPT-6.1-sol 在其运行的 38 项任务上得 0.568，Opus 同范围为 0.546。代码、任务注册表与沙箱环境已公开。

Attention at Absolute Zero 用零温度注意力精确外推到千倍规模
作者构建了一种高阶注意力层，其状态定义在元素对上：对 (a, b) 这一对，每个第三项 k 作为见证者，通过 (a, k) 与 (k, b) 两条腿被评判。该层在零温度下读取见证者，保留最优者及与其并列的计数，只传递比较这些计数的比特，每一轮循环都从输入和这些比特重建对状态，且仅从答案训练。作者称每个设计都消除了软注意力在规模上的一种失效模式：权重弥散、学到的分数间间隙无法分辨、软状态漂移。在最大检索任务上，对规模为训练时 1000 倍的集合，十个随机种子全部达到至少 99.95% 正确率，而用软计数训练的同一网络在 4096 项时跌到 42%。在无提示的 CLRS-30 上，该层的一般形式超过已发表最佳模型；从是/否答案出发，它能在 500 个变量上精确判定 2-SAT 与二着色，并按理论预测无法判定奇偶方程。

QDA 用 LLM agent 闭环设计量化方案，320B MoE 上恢复 98.3% FP8 精度
训练后量化是低成本部署大模型的标准手段，但最佳量化配方随模型和精度而变，需专家逐个重设计，耗时且常非最优。QDA 让 agent 在多轮构建与评估中迭代改进配方。为加速评估，它用候选模型在 agent 从未见过的推理轨迹上相对原模型的输出 KL 散度在几分钟内打分，再对表现好的候选做长生成检查，以捕捉重复循环等失败模式；为加速构建，它提供一套彼此兼容且适配新架构的公开 PTQ 方法库。在四个推理模型上，QDA 在 W4A16、W4A8、W3A16 下平均比最强公开配方分别高出 0.9、1.4、2.2 个百分点，每次搜索用 64 GPU 小时；在 320B 参数 MoE 模型 GLM-5.3-Flash 的 NVFP4 W4A4 上恢复 FP8 模型 98.3% 的精度，优于最佳厂商 checkpoint 的 96.9%。

MInfoVisQA 揭示多模态模型跨语言视觉理解的一致性缺口
多模态大模型在视觉语言任务上表现出色，但当表层语言变化时，它们对信息密集型可视化（InfoVis）的理解是否一致仍不清楚。MInfoVisQA 是一个平行基准，由 128 个种子实例扩展出 24 种语言共 8,960 个 QA 配置，通过把数值-结构数据与文本解耦、并用程序同步翻译标签，构造种子匹配的语言平行视觉与问答对。研究在语言对齐 QA（图文语言一致）和跨语言 QA（固定问答语言、变换视觉语言）两种设置下评测 25 个 MLLM。结果显示聚合准确率掩盖了显著的鲁棒性差距：两个平均 LQA 准确率相当（80.4%）的模型，跨语言性能极差分别达 7.8 和 20.3 个百分点；且在固定英文问答下，全部 25 个模型在非英文视觉上得分更低。
