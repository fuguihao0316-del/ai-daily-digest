语言模型可重写自身权重
论文提出 self-rewriting，一个 27B 模型在给定权重、评分答案与自运行能力的条件下，无需梯度、无需训练，仅凭自身推理诊断失败并直接编辑权重。在事先固定的 490 道未见问题上，其自我编辑使准确率提升 6.6 个百分点，另一会话的编辑同样带来显著提升；模型仅在自测支持时才提交编辑，前八次会话准确率单调上升。该方法还能修复自身损坏副本：定位被污染矩阵并用自生成数值重写，从未读取未损坏权重，仅在文本数学题上发现的修复使该副本在六个未见图像基准上从 7% 升至 70%，达到未损坏模型的 83%。与测试时扩展不同，增益持久存于权重且不增加单次回答成本；与训练不同，只需一个开放模型和单卡数小时。该能力随规模出现。

扩散 Transformer 的 RL 后训练本质是激活引导
论文检验 RL 后训练带来的视觉质量、文字渲染与组合准确率提升能否由输入无关的固定偏移解释。在 SD3.5-M 上，研究者用一组加到冻结基模型 block 输出上的固定 steering 向量拟合公开 RL 微调 checkpoint 的速度预测，目标函数中不含奖励，参数量仅 0.29M，比 RL 微调的 LoRA（18.8M）少 65 倍。尽管这些向量对所有 prompt、token 与采样种子完全相同，它们恢复了六个 RL 图像模型 90.0-96.3% 的奖励增益，在两个 RL 视频模型上分别为 89.8% 与 111.9%。从零初始化并用在线 RL 训练时，仅这些向量在 SD3.5-M 的文字渲染（OCR）与人类偏好（PickScore）上就超过基于权重的 RL。结论是：策略梯度 RL 后训练的大部分增益来自常量偏移，它把预训练生成器引向它本已能计算的内容，而非学习新的输入相关变换。

ITPD 用局部因果父节点发现加速时间序列结构学习
时间序列的自相关、分布漂移与维数灾难使因果发现算法的计算与样本复杂度居高不下。论文提出 Iterative Temporal Parent Discovery（ITPD），一种在具有因果非平稳性的多变量时间序列上进行因果结构学习的可靠且完备的约束型方法。它采用局部到全局策略，通过依次发现每个变量的父集合来构建全局图，并利用时间结构先验、图划分与局部 Markov 条件，把高阶条件独立检验替换为低阶检验。在精确 oracle 下，ITPD 的检验次数最少、平均条件集规模最小；基准仿真中它在 F1 与 wall-clock 时间上处于 Pareto 前沿，在 1000 节点以上的大图上快于基线。对 2000 节点的图，ITPD 分别比迭代 IAMB、DF-PC 和 PCMCI 快 2.3 倍、9.1 倍和 40.9 倍。

SimAudit 审计仿真操作基准的成功判定器，发现 61 个缺陷
仿真操作基准用手写成功判定器给每个 episode 打成功或失败标签，但专家演示只能证明判定器接受一种完成方式，学习策略可能中途停止或以不同方式完成任务。论文提出 SimAudit，一个基于 LLM 的流水线，对照任务指令审计判定器：分析指令与判定器代码找出可能分歧的场景，在仿真中重建这些场景并运行原判定器，再用多视角渲染验证行为是否满足指令。在 RoboTwin 2.0、RoboCasa365 与 RoboDojo 上，183 个仿真测试用例产生了预测的判定结果，视觉验证与去重后得到 49 个任务中的 61 个不同缺陷，包括 40 个幻影成功与 21 个静默失败。RoboCasa365 的缺陷多接受不完整执行，RoboDojo 的多拒绝有效执行，RoboTwin 2.0 两类都常见。
