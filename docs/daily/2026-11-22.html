Bytedance 发布 Axion 1.0，主张多数训练阶段并非必要
Bytedance 联合多所美国高校推出 AI agent 模型 Axion 1.0，在基准测试上对标 OpenAI 与 Anthropic 的顶级商用模型，而整个训练流程只用了三个阶段。研究团队把性能提升归因于精心筛选的训练数据，而不是不断堆叠训练步数，这一结论直接挑战了当前「更多阶段、更多算力」的主流训练范式。更关键的是，模型权重、训练数据和代码全部免费开放，意味着中小团队可以复现并在此基础上继续迭代。对从业者而言，这条消息的价值在于它提供了一条可验证的替代路线：如果数据质量能替代训练阶段数量，那么预训练与后训练的预算分配逻辑需要重写。同时它也是开源阵营在 agent 能力上追平闭源前沿的一次公开证据，后续值得关注社区复现结果与第三方评测是否支持其基准表现。

语言模型可零梯度改写自身权重
论文提出 self-rewriting，让模型在无梯度、无训练的情况下诊断自身失败并直接编辑自己的权重。一个 27B 模型在 490 道未见过的题目上，通过自我编辑提升 6.6 个百分点准确率，且该测试集事先固定；编辑仅在模型自身测试支持时才提交，前八次会话中准确率只升不降。该方法还能修复受损副本：仅凭文本数学题定位并重写被破坏的矩阵，从未读取完好权重，却把该副本在六个未见图像基准上的准确率从 7% 提升到 70%，达到完好模型的 83%。与测试时扩展不同，收益固化在权重中且不增加每次回答的成本；与训练不同，只需一个开放模型和单卡数小时。作者称该能力随规模出现，在四个同系列尺寸模型上均观察到。

扩散 Transformer 的 RL 后训练本质是激活引导
论文检验一个假设：RL 后训练带来的视觉质量、文字渲染与组合准确率提升，有多少能由一个与输入无关的固定偏移解释。作者在冻结基座模型的 block 输出上加入一组固定 steering 向量，参数量 0.29M，比 RL 调优的 LoRA（18.8M）少 65 倍，拟合目标是对齐公开 RL checkpoint 的速度预测，目标函数中不含奖励。尽管这些向量对所有 prompt、token 和采样种子完全相同，它们仍恢复了六个 RL 图像模型 90.0-96.3% 的奖励增益，在两个 RL 视频模型上分别为 89.8% 和 111.9%。在 SD3.5-M 上，从零初始化并用在线 RL 训练这些向量，其 OCR 与 PickScore 增益超过基于权重的 RL。结论是策略梯度 RL 的大部分收益无需学习输入相关的复杂变换，只需把预训练生成器推向它本已能计算的方向。

用编码智能体在硬件上原位训练光学神经网络
光学神经网络速度快、能耗低，但每个器件都偏离设计，必须结合硬件训练。现有原位训练依赖专家为每个器件构建校准数字模型，或使用无梯度试错。作者提出 optics as code：编码智能体仅凭测量结果训练光学网络，测试框架返回探针的相机图像，并要求每次请求附带一个假设。研究发现智能体能形成对光学的物理理解，并用可解释的光学元件重新参数化网络，在硬件上调优。在分类与图像编码任务上，它优于无梯度方法，以远低于校准模型反传的成本接近后者的表现。该方法既不需要逐器件校准，也不需要穿过硬件的梯度，且随模型能力提升而改善，为大规目光学网络的校准与优化提供了可行路径。

模拟操作基准的成功检测器存在大量误判
模拟操作基准用手写 success checker 判定每个 episode 成败，但通过专家演示只能证明检测器接受一种完成方式。作者提出 SimAudit，用 LLM 审计检测器与任务指令的一致性：分析指令与检测器代码找出可能分歧的场景，在仿真中重建并运行原检测器，再用多视角渲染验证行为是否满足指令。在 RoboTwin 2.0、RoboCasa365 和 RoboDojo 上，183 个测试用例全部产生预测的判定结果，去重后得到 49 个任务中的 61 个缺陷，包括 40 个 phantom success（接受不完整执行）和 21 个 silent failure（拒绝合法执行）。RoboCasa365 的缺陷多为前者，RoboDojo 多为后者，RoboTwin 2.0 两类都常见。这提示基准评测需要同时测试不完整执行与专家演示之外的合法替代方案。

时序因果结构学习的局部父节点发现方法
多变量时序上的因果发现问题受自相关、分布漂移和维数灾难困扰，通用算法计算与样本复杂度都高。作者提出 ITPD（Iterative Temporal Parent Discovery），一种针对具有因果非平稳性的多变量时序的可靠且完备的约束型算法，采用局部到全局策略，逐个发现每个变量的父集合从而构建全局图，并利用时序结构先验、图划分与局部马尔可夫条件，把高阶条件独立检验替换为低阶检验。在精确 oracle 下，ITPD 相对基线使用最少的检验次数和最小的平均条件集规模；仿真基准中它位于 F1 与 wall-clock 时间的 Pareto 前沿，在千节点以上大图上更快：2000 节点图分别比 iterative IAMB、DF-PC 和 PCMCI 快 2.3 倍、9.1 倍和 40.9 倍。

流式说话人头像实现单卡实时生成
现有音频驱动视频扩散模型能合成逼真说话头，但需对多秒视频块做数十步去噪，难以用于语音助手和虚拟形象等要求低延迟、在线因果生成的流式场景。AURA 用滚动 KV cache 逐块生成，只需当前块的音频即可开始，无需双向模型的多秒音频前瞻。两个尺寸：AURA 1.3B 在单 GPU 上实时流式输出 576p（16 Hz 播放率下 20.7 fps），适合交互式头像；AURA 5B 以 9.7 fps 输出 720p。两阶段蒸馏先让因果学生用更少扩散步和块级滑动窗口因果掩码匹配教师轨迹，再用带反向模拟的 Distribution Matching Distillation 缩小剩余质量差距。AURA 1.3B 比其双向教师快 23 倍，AURA 5B 在 720p 上匹配 TalkVerse 教师且快 17 倍；作者同时开源两个模型权重与 3 万条合成视频数据集。

原生体素域的无潜空间 3D 扩散 Transformer
原生 3D 生成长期围绕潜空间扩散展开，改进集中在更强的 VAE 与更精细的潜表示（vecset、triplane、结构化稀疏体素），但都预设几何先被压缩进潜空间再建模。Direct3D-V3 反其道而行，提出无 VAE 的扩散 Transformer 框架，训练与采样都直接在原始 SDF 体素网格上进行。为保证几何可靠性，作者对相邻体素施加隐式流形正则以抑制非水密表面，并用 Marching Cubes 把预测 SDF 转成网格，使渲染法线损失能直接监督预测的 SDF；同时把条件图像的相机参数预测作为辅助任务，强化图像观测到 3D 形状的映射。该设计消除了重建瓶颈，把训练置于原生体素域的目标之下，生成的网格局部细节明显更丰富，预测的相机与原生 SDF 输出也带来额外能力。

零梯度把精确电路编译进预训练权重
预训练语言模型在多位数精确算术上仍不可靠，除非做梯度微调或调用外部解释器。作者提出闭式、零梯度的电路嫁接原语，用零训练样本、零运行时钩子把确定性计算编译进预训练权重，同时约束逐层归一化漂移并保留自然语言能力。构造包含三个解析机制：对无偏置 SwiGLU/GeGLU 层做两层 Mellin-GLU 求积，把未知的逐 token RMSNorm 缩放转为对数间隔门控网格上的平移（超过 250 倍动态范围）并给出 IEEE 754 误差界；用带符号 Chebyshev Indefinite-RoPE self-sink attention 与无记忆 SiLU 反对称 GatedDeltaNet 位移实现跨 token 尺度抵消；以及轴对齐宽度扩展（d 到 d+K）配合 d/(d+K) 范数补偿、Base-1000 规范 BPE 输出和差分 tied unembedding。五阶段编译器可合成 4-8 位带符号加减乘电路，在 6 位数算术上 IBM Granite 4.2 3B 与 Alibaba Qwen 3.5 4B 分别达到 99.17% 与 100.00% 的 ALU 前缀准确率。

System 1 智能体：不生成文本的本地工具调用
