语言模型可重写自身权重
论文提出 self-rewriting，一个 27B 模型仅凭自身推理、无梯度、无训练即可诊断失败并编辑自身权重。在预先固定的 490 道未见题上，自我编辑使准确率提升 6.6 个百分点；它只在自测通过时才提交编辑，前八次会话中准确率持续上升。该方法还能修复受损副本：仅凭文本数学题定位并重写被损坏矩阵，使该副本在六个未见图像基准上从 7% 升至 70%，达到未受损模型 83% 的水平。与测试时扩展不同，收益固化在权重中且不增加单次回答成本；与训练不同，它无需预训练或后训练基础设施，只需一个开放模型和单卡数小时。该能力随规模涌现，在四个同系列尺寸上均出现。

扩散 Transformer 的 RL 后训练本质是激活引导
论文用刻意简单的参数化探测 RL 后训练的增益来源：在冻结基座模型的 block 输出上加一组固定 steering 向量。在 SD3.5-M 上，这些向量参数比 RL 调优的 LoRA 少 65 倍（0.29M 对 18.8M），且拟合目标不含奖励，仅匹配公开 RL checkpoint 的速度预测。尽管向量对所有 prompt、token 和采样种子完全相同，仍恢复了六个 RL 图像模型 90.0-96.3% 的奖励增益，两个 RL 视频模型上分别为 89.8% 和 111.9%。从零初始化并用在线 RL 训练，这些向量在文本渲染（OCR）和人类偏好（PickScore）上单独超过基于权重的 RL。结论是：大部分策略梯度 RL 后训练收益可由一个常数偏移解释，它把预训练生成器引向它本已能计算的内容，而无需学习输入相关变换。

System 1 agents：不生成文本的本地工具调用智能体
临床等敏感数据分析需要智能体自动化，但云端 LLM 会暴露患者数据，本地 LLM 又会幻觉，而工具调用中一个编造的值会沿后续每一步传播。论文提出构建 System 1 agents 的方法：局部智能体不生成文本而直接调用工具。确定性编译器把每个工具的 schema 和请求转成多选题，选项来自请求与 schema，再由单遍决策模型作答。在面向 157 个生物医学工具的 1952 个请求上，最佳 System 1 agent 正确选择工具或正确拒答的比例达 97.0%，显著超过全部 18 种本地 LLM agent 配置（最佳 95.2%）；它填对 6056 个声明参数值中的 97.0%，且没有任何一次调用包含编造内容，而 LLM 调用中该比例为 5.5-19.7%。框架已开源。

TwinD：从 blending 假脸泛化到整脸合成检测
现有面部 deepfake 检测器多在 blending 假脸上训练，即把生成人脸贴回真实帧；而新生成器合成整张脸，不留 blending 痕迹。在 2019 至 2026 年发布的 19 个数据集基准上，最佳既有检测器在十个 blending 数据集上平均 AUROC 达 96.2%，但在五个整脸合成（EFS）数据集上无一超过 78.1%，AIGC 检测器也未能弥补该差距。TwinD 仅在 FaceForensics++ 假脸和两类 twin 上训练：重建 twin 由自编码器重建真实帧并随机区域回填真实像素，针对解码器神经痕迹；blob twin 将真实帧的改动副本与原帧混合，针对 blending 伪影，无需生成器和人脸形状掩码。TwinD 平均 AUROC 达 96.3%，比先前 SOTA 高 8.9 个百分点，blending 数据集 98.1%、EFS 数据集 95.6%；仅用 twin 训练、不接触 deepfake 数据集时，三个随机种子平均仍达 94.3%。代码、模型与数据已公开。

AURA：音频驱动的流式数字人
