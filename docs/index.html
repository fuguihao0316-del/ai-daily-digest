Self-Retrospection Distillation 让智能体用事后经验监督事前预判
论文提出 prospective learning，用交互后的完整轨迹监督同一策略在行动前的 foresight 预测，并实例化为 Self-Retrospection Distillation（SRD）。核心观察是 group-relative 目标在组内 rollout 奖励全相同时信号归零，而轨迹本身仍包含任务要求与失败模式的信息；SRD 把这种「事后特权信息」蒸馏为轨迹盲的预判，预判仅作训练目标，推理时无需显式生成。在 10 个工具集成推理与长程智能体任务上，SRD 与 RLVR、自蒸馏基线互补，最高提升 24.2 个百分点；在 37%–98% rollout 组奖励均匀、信号稀缺时优势尤为明显。2B 规模下 98% 的组为全失败，纯 RLVR 训练最终成功率 0.0%，加入 SRD 后达到 60.6%。

Agent Plasticity：用经验换取未来性能的效率成为新评测维度
论文指出已有评测只衡量智能体在某一时点的能力，而非它学得多好，因此提出 agent plasticity 这一指标，定义为智能体把经验转化为留出环境性能增益的效率。实验在受控设定下进行：智能体把过往经验摊销为可复用产物，由未来实例继承；在每个 checkpoint 同时测量训练交互与留出交互上的表现，并计入学习成本。结果显示，多个前沿模型即便学习机会相当，改进轨迹差异显著：有的取得持续大幅提升，有的始终接近甚至低于初始水平，且训练分布内的收益往往只能部分迁移到分布外条件。终点能力与获取效率也出现分离，最终表现最好的智能体未必是改进效率最高的那个；对改进回路的失败追踪进一步揭示了瓶颈所在。

EngramEdit 用条件记忆实现 LLM 知识的解耦更新
论文针对 DeepSeek Engram 这类条件记忆架构——用输入 n-gram 查表得到学习到的 embedding，以有限额外算力扩展 LLM 容量——提出 EngramEdit，目标是在冻结 Transformer 主干的前提下更新事实知识。难点在于同一事实的不同表述会激活不同 n-gram embedding，而更新共享 embedding 又可能连带改变模型对其他事实的预测。EngramEdit 先计算目标记忆表示，使模型在多种表述下都预测更新后的事实，再联合更新共享 n-gram embedding 去匹配这些目标，并对高频复用的 embedding 施加更强惩罚以保护无关知识。实验显示该方法实现近乎完美的编辑成功率，修订后的知识可用于未见表述与多跳推理，在 CoT 提示下准确率接近最强基线的三倍，无关知识与通用能力基本保持。

DSReg：无需重建即可可证明地恢复单个世界潜变量
论文指出，从非线性 ICA 到字典学习、因果表示学习，恢复世界单个潜变量的方法都依赖重建、辅助监督或非高斯性等分布不对称来锚定潜变量；而缺少这些锚定的方法（包括 JEPA）只能把潜状态识别到线性变换，单个潜变量仍然混合。作者提出关键条件 Structural Diversity：不同潜变量在观测上留下不同的依赖足迹。基于 LeJEPA 提供的线性可识别性，论文证明在该条件下 DSReg（Dependency-Sparsity Regularization）可在无重建、无解码器的情况下把单个世界潜变量恢复到带符号置换，并可事后应用于任何已线性识别的表示，复用已有 checkpoint 且不损失联合训练效果。作者称这是首个完全可识别的 JEPA。
