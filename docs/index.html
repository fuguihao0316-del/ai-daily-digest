GLM-5.4 发布：Z.ai 首个 Loop Transformer 架构模型
中国 AI 实验室 Z.ai 发布 GLM-5.4，这是其首个采用 looped transformer 架构的模型。标准 Transformer 中每层在前向传播中只运行一次，而 Loop Transformer 让一组权重共享层多次迭代、反复精炼上一轮的隐藏状态，从而在不增加参数量的前提下获得更深的网络。这已是本周内第二次出现循环 Transformer 的消息，此前 Thinking Machines Lab 于 11 月 20 日发布的 Inkling 2 Mini 同样采用该架构，其中间层对每个 token 运行三次，以更少 token 完成推理，尤其针对依赖推理质量的 agentic coding 任务。GLM-5.4 暂未开放权重，Z.ai 表示将在完成必要的安全加固后负责任地开源。目前该模型无法通过常规 API 访问，需订阅 Coding Plan；两者共用同一套 OpenAI 兼容的 Responses API（https://api.z.ai/api/v1），Coding Plan 的密钥可直接调用新模型。

PINE 单步扩散同时输出点图、法线与实例图
PINE 是一个单步 Omni Diffusion Transformer，一次前向同时预测点图、表面法线和实例图，把每张图当作一条 token 流并用流掩码控制哪些流交互；用相机感知的射线编码按相机射线而非像素定位 token，并把预训练 DINOv3 特征的亲和度加入注意力 logits。几何部分仅用 13.9 万张合成图像训练，在有或无内参条件下均取得 SOTA 点图，表面法线平均排名最佳；在大物体上以不足 SAM 百分之一的训练图像超过 SAM，且预测三张图比 MoGe-3 加 SAM 快 5.7 倍。

LoomFormer 用织机注意力在每 token 重接电路
论文提出 loom attention，把每个 head 对前序 head 输出的垂直注意力（用于得到 query、key、value）与对 token 的水平注意力交织，使 Transformer 能在每个 token 上动态重接电路；垂直注意力用逐 token 矩阵记忆上的归一化门控线性注意力高效实现，该记忆充当第二条残差流，形成控制与内容分离的双流架构 LoomFormer。在多种模型规模与训练 token 预算下，它匹配用 3 倍以上算力训练的 Transformer，以及用约 1.7-2.8 倍算力训练的 HC/mHC、MUDDFormer、AttnRes 等残差流基线；同样 300B token、仅多 2% FLOPs 的 LoomPythia-2.8B，下游平均增益约为 mHC-Pythia-2.8B 的 1.6 倍，并追平 0-shot 的 Pythia-12B。
