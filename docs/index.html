LayoutRecall 让多轮 3D 布局编辑记住被遮挡物体的外观
3D 布局控制的图像编辑允许用户显式指定物体位置与相机视角，但在连续多轮编辑中，物体一旦被遮挡或移出视野，其外观就会丢失，而目标布局又要求它重新出现。为此研究者提出 LayoutRecall，把外观信息存储在 3D 包围盒的局部坐标系中复用：Box-Surface Latent Memory 将图像 latent 保留在盒面上，并沿目标视角的光线检索；Geometry-Aligned Memory Conditioning 通过目标视角位置、共享盒局部嵌入和逐物体注意力，把检索到的 token 送入 FLUX.2 编辑器；此外还设计了 correspondence loss，促使编辑器在去噪时关注匹配的观测。团队同时发布 LayoutLoop 基准，包含校准布局与刻意设计的重访场景，并在该基准与真实场景数据上验证了方法有效性。

DAWIN 用阻尼原子波积分神经元统一连续时间时空学习
传统人工神经元把空间特征聚合与连续物理时间分离，难以建模不规则采样观测。论文提出 Damped Atomic Wave Integration Neuron（DAWIN），将空间投影与依赖经过时间的波激励耦合，通过闭式阻尼演化积分进局部复数状态，无需数值微分方程求解器。作者证明该神经元可推广静态正弦与无记忆波神经元，给出闭式梯度，并在正阻尼与采样间隔有下界时建立 BIBO 稳定性；配套的 DAWINLinear 用 Triton 前缀扫描实现，FP32 累加，序列长度 L 下并行深度 O(log L)。在 11 个参数量匹配任务上，DAWIN 在 9 个任务上优于 Neural CDE、8 个任务上优于 ReLU-MLP，密集临床动力学取得 0.9531 NRMSE 并在全部 10 个种子上获胜，死亡率预测 AUROC 0.9993 并列最佳；打乱时间间隔会使部分动力学任务误差上升 58.2%-77.4%，而时间无关对照组仅 0.06%。

BiSAT 用双向对齐的语义-声学分词改进语音语言模型
语音语言模型把语音生成为离散 token 序列，因此分词器必须在低码率下同时保留声学细节与语言内容。语义增强分词器可能丢失声学细节，声学导向分词器保留的变化又让语言建模更难；统一分词器把两者放进同一特征空间会互相干扰，且现有方法通常对齐到冻结教师给出的固定语义目标。BiSAT 采用分离的声学与语义分支，通过共享索引机制对齐，在各自连续空间中学习表示并输出单一离散码序列，联合优化两个编码器而不依赖固定语义教师。基于此构建的 BiSAT-TTS 是零样本 TTS 系统，由自回归文本-语音 LM 与条件流匹配声学解码器组成。重建、下游理解与诊断分析显示其能在码流中同时保留语义与声学信息，在野生与域外语音上表现良好，并学到互补的码本表示。
